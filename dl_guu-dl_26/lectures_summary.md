## Лекция 2: Сети прямого распространения (`02_feed_forward.pdf`)

### Основные концепции
*   **Один нейрон (математическая модель):**
    $$out = f(z), \quad z = w \cdot x + b$$
    где $x$ — входные данные, $w$ — веса, $b$ — смещение (bias), $f$ — функция активации.
*   **Многослойная сеть:**
    $$OUT^1 = A(W^{1T} \cdot INPUT + B^1)$$
    $$OUT^2 = A(W^{2T} \cdot OUT^1 + B^2)$$
    Каждый скрытый слой обучается извлекать всё более высокоуровневые признаки из предыдущего.

### Функции активации
1.  **Пороговая (Sign):** $f(x) = 1$, если $x \ge 0$, и $-1$, если $x < 0$. (Не дифференцируема в $0$, производная везде $0$ — не подходит для градиентного спуска).
2.  **Сигмоида (Sigmoid):** $f(z) = \frac{1}{1 + e^{-z}}$. Диапазон $(0, 1)$. Подвержена затуханию градиентов (gradient saturation) при больших $|z|$.
3.  **ReLU (Rectified Linear Unit):** $f(x) = \max(0, x)$. Ускоряет обучение за счет линейности для положительных значений, но может приводить к проблеме «отмирания» нейронов (dying ReLU) для отрицательных входов.
4.  **Softplus:** Гладкая аппроксимация ReLU: $f(x) = \ln(1 + e^x)$.
5.  **Softmax:** Используется на выходном слое для многоклассовой классификации для получения распределения вероятностей классов:
    $$\sigma(z_j) = \frac{e^{z_j}}{\sum_{k=1}^K e^{z_k}}$$
    Математически выводится из формулы Байеса: $P(C_j | data) = \frac{P(data|C_j) P(C_j)}{\sum_k P(data|C_k)P(C_k)}$, где $z_k = \ln [P(data|C_k) P(C_k)]$.

### Обучение нейросетей
*   **Принцип максимального правдоподобия (MLE):** минимизация отрицательного логарифма правдоподобия: $-\ln p(data) = -\sum_i \ln p(y_i | x_i, w)$.
*   **Функции потерь (Loss functions):**
    *   *Регрессия:* Среднеквадратичная ошибка (MSE): $E = (Y - T)^2$ (или MAE). Связана с предположением о нормальном распределении шума.
    *   *Классификация:* Кросс-энтропия (Cross-Entropy): $H(p, q) = -\sum_x p(x) \ln q(x)$.

## Лекция 3: Оптимизация и PINN (`03_optimization.pdf` и `03_pinn.pdf`)

### Часть 1: Методы оптимизации в PyTorch (`torch.optim`)
*   **Градиентный спуск (GD):** $w_j = w_{j-1} - \eta \nabla L(w)$, где $\eta$ — скорость обучения (learning rate).
*   **Критерии сходимости:**
    1.  Незначительное изменение весов: $\|w_j - w_{j-1}\| < \epsilon$.
    2.  Близость градиента к нулю: $\|\nabla L(w)\| < \epsilon$.
    3.  *Правило DL:* остановка процесса, когда ошибка на валидационном множестве перестает уменьшаться (ранняя остановка / Early Stopping).
*   **Стохастический градиентный спуск (SGD):** оценивает градиент по одному случайно выбранному объекту. Работает быстрее ($O(1)$ вместо $O(n)$ за шаг). Шум помогает выходить из локальных минимумов.
*   **Mini-batch SGD:** компромисс между GD и SGD, оценивает градиент по пакету (батчу) данных (размер обычно $32, 64, 128, \dots$). Эффективен благодаря векторизации на GPU.
*   **Модификации оптимизаторов:**
    *   **Momentum (Импульс):** запоминает направление предыдущего шага для преодоления осцилляций:
        $$u_t = \gamma u_{t-1} + \eta g_t, \quad \Delta w = -u_t$$
    *   **AdaGrad:** адаптирует скорость обучения индивидуально для каждого параметра на основе суммы квадратов прошлых градиентов $G_t^j = G_{t-1}^j + (g_t^j)^2$. Недостаток — скорость обучения со временем стремится к нулю.
    *   **RMSProp:** решает проблему затухания AdaGrad за счет использования экспоненциально взвешенного скользящего среднего квадратов градиентов:
        $$G_t^j = \alpha G_{t-1}^j + (1 - \alpha) (g_t^j)^2$$
    *   **Adam (Adaptive Moment Estimation):** объединяет идеи Momentum и RMSProp (отслеживает как первый, так и второй моменты градиента с поправкой на смещение):
        $$\Delta w_j = -\frac{\eta}{\sqrt{\hat{G}_t^j + \epsilon}} \hat{u}_t^j$$
*   **Контроль обучения:** кросс-валидация и полный перебор гиперпараметров по сетке в DL практически не используются из-за высокой вычислительной стоимости. Эксперименты проводятся путем внесения одного изменения за раз.

### Часть 2: Физически информированные нейронные сети (PINN)
*   **Проблема «черного ящика»:** стандартные нейросети хорошо интерполируют, но плохо экстраполируют физические процессы за пределы обучающей выборки.
*   **Идея PINN:** встраивание законов физики (дифференциальных уравнений) непосредственно в функцию потерь (loss).
*   **Loss-функция PINN:**
    $$Loss = a_0 MSE_{data} + a_1 MSE_{PDE\_residual} + a_2 MSE_{boundary\_conditions}$$
    где $MSE_{PDE\_residual}$ — невязка дифференциального уравнения, рассчитываемая в точках коллокации с помощью автоматического дифференцирования (Autograd).
*   **Реализация автоградиента в PyTorch:**
    ```python
    dy_dt = torch.autograd.grad(y, t, grad_outputs=torch.ones_like(y), create_graph=True)[0]
    ```
*   **Подводные камни PINN:**
    1.  Нельзя использовать ReLU (его вторая производная равна $0$ везде, что делает невозможным расчет вторых производных в уравнениях вроде теплопроводности). Требуются гладкие активации (Tanh, SiLU).
    2.  Баланс весов лосса: компоненты лосса (физика vs данные) могут конкурировать («перетягивать канат»), замедляя сходимость.
    3.  Опасность застревания в локальных минимумах по сравнению с классическими численными методами (например, Рунге-Кутты).

## Лекция 4: Сверточные нейросети (CNN) (`04_layers_conv.pdf` и `04_architech_conv.pdf`)

### Слои и принципы работы сверточных сетей
1.  **Операция свертки (Convolution):** ядро свертки (матрица весов) скользит по изображению, вычисляя скалярное произведение. Позволяет извлекать локальные признаки (границы, текстуры) и обеспечивает инвариантность к сдвигу.
2.  **Субдискретизация (Pooling / Пулинг):** уменьшает пространственную размерность тензора. Максимальный пулинг (Max Pooling) выбирает максимальное значение в окне, сохраняя наиболее яркие признаки. Средний пулинг (Average Pooling) вычисляет среднее.
3.  **Полносвязный слой (FC):** классический слой FNN на выходе сети для финальной классификации или регрессии.
4.  **Регуляризация и нормализация:**
    *   **Dropout:** случайное зануление доли активаций во время обучения для предотвращения переобучения.
    *   **Batch Normalization (Батч-нормализация):** нормирует выходы предыдущего слоя по батчу, ускоряя сходимость и стабилизируя обучение:
        $$\hat{x}_i = \frac{x_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}, \quad y_i = \gamma \hat{x}_i + \beta$$

### Эволюция архитектур CNN (на ImageNet / ILSVRC)
*   **AlexNet (2012 г., 8 слоев):** первая глубокая сверточная сеть, выигравшая ImageNet. Использовала ReLU, Dropout, Local Response Normalization и обучение на GPU.
*   **VGG-16 / VGG-19 (2014 г.):** глубина увеличена за счет использования стеков маленьких фильтров $3\times3$ вместо крупных (например, $11\times11$ или $5\times5$ в AlexNet). Это снижает число параметров и добавляет нелинейности.
*   **GoogLeNet / Inception (2014 г., 22 слоя):** введение блоков Inception (параллельные свертки размеров $1\times1, 3\times3, 5\times5$ и MaxPooling). Использование сверток $1\times1$ для уменьшения размерности (сжатия каналов) перед дорогими операциями.
*   **ResNet (2015 г., 152+ слоев):** введение Skip-connections (остаточных связей), передающих исходный сигнал в обход слоев: $y = \mathcal{F}(x) + x$. Решило проблему затухания градиентов при очень большой глубине.
*   **DenseNet:** каждый слой получает на вход конкатенацию выходов всех предыдущих слоев в рамках блока. Это способствует повторному использованию признаков и сокращает количество параметров.
*   **SqueezeNet:** миниатюрная архитектура (размер файла < 5 МБ при качестве AlexNet). Состоит из блоков Fire, которые сначала сжимают число каналов (свертки $1\times1$), а затем расширяют (свертки $1\times1$ и $3\times3$).

## Лекция 5: Передача обучения (Transfer Learning) (`05_tr_learning.pdf`)

### Суть Transfer Learning
*   Использование предобученной модели (например, обученной на ImageNet с 1 млн картинок и 1000 классами) для решения новой задачи на гораздо меньшем наборе данных (например, 100 изображений, 4 класса).
*   **Обоснование:** начальные слои сети учатся распознавать универсальные признаки (ребра, цветовые пятна), которые полезны для любой задачи компьютерного зрения.

### Сценарии применения
1.  **Feature Extraction (Извлечение признаков):** «замораживание» весов всех слоев предобученной сети, кроме последнего классификационного слоя. Этот слой обучается заново под новую задачу. Метод очень быстрый и защищает от переобучения на маленьких датасетах.
2.  **Fine-Tuning (Тонкая настройка):** обучение всей сети на новых данных с очень маленькой скоростью обучения ($\eta$). Позволяет адаптировать базовые фильтры под специфику новых изображений.

### Сравнение моделей для Transfer Learning
*   **SqueezeNet** обеспечивает высокую точность (около 92-93.5% на тестовых задачах) при микроскопическом размере модели (6.6 МБ) и быстром обучении (~7 минут).
*   **AlexNet** обучается быстро (~12 минут), но имеет большой вес (245 МБ) и меньшую точность.
*   **VGG-16** точен (~94%), но весит более 538 МБ.
*   **InceptionResNet** крайне тяжел в обучении (более 112 минут) и требует много ресурсов.

## Лекция 6: Повышение качества обучения (`06_improve.pdf`)

### Архитектурные компоненты и выбор нелинейностей
*   **Архитектурное решение включает:** Вход (Input), Свертки (Convolution), Пулинг (Pooling), Нелинейности (Nonlinearities), Нормализацию (Normalization), Функцию потерь (Loss).
*   **Виды нелинейностей:**
    *   *Sigmoid:* $f(x) = \frac{1}{1 + e^{-x}}$.
    *   *ReLU:* $f(x) = \max(0, x)$.
    *   *Leaky ReLU:* $f(x) = \max(0.1x, x)$ (не дает нейронам «умирать» при отрицательных входах).
*   **Функции потерь:** $L_2$ (MSE), кросс-энтропия (связанная с дивергенцией Кульбака-Лейблера): $H(t, y) = H(t) + D_{KL}(t, y)$, где $H(t) = -\sum t_i \log t_i$, $D_{KL}(t, y) = \sum t_i \log \frac{t_i}{y_i}$.

### Способы борьбы с переобучением (Регуляризация)
1.  **Аугментация данных:** искусственное увеличение выборки путем кадрирования, поворотов, сжатия, изменения цветов и масштабирования.
2.  **L1-регуляризация (Lasso):** $L_1 = \sum (y - t)^2 + \lambda \sum |w_i|$ (зануляет наименее важные веса, создавая разреженные матрицы).
3.  **L2-регуляризация (Ridge / Weight Decay):** $L_2 = \sum (y - t)^2 + \lambda \sum w_i^2$ (ограничивает рост весов, делая модель более гладкой).
4.  **Dropout:** исключение случайных нейронов в процессе обучения с вероятностью $p$.

### Оптимизация гиперпараметров
*   **Grid Search (Поиск по сетке):** полный перебор фиксированных комбинаций. Медленный и неэффективный в DL.
*   **Random Search (Случайный поиск):** случайный выбор гиперпараметров. Намного эффективнее поиска по сетке на практике.
*   **Bayesian Optimization (Байесовская оптимизация):**
    *   Строит суррогатную вероятностную модель целевой функции (обычно с помощью Гауссовских процессов — GP).
    *   Использует функцию выбора (Acquisition function), например, Expected Improvement (EI), для определения наиболее перспективной следующей точки замера:
        $$EI(x, Q) = E_Q[\max(0, \mu_Q(x_{best}) - f(x))]$$

## Лекция 7: Сиамские сети и метрическое обучение (`07_siamese.pdf`)

### Концепция сиамских сетей
*   **Метрическое обучение (Metric Learning):** обучение сети находить близость (расстояние) между объектами, а не классифицировать их напрямую (применяется, например, для распознавания лиц или One-Shot learning).
*   **Устройство:** Две идентичные подсети с разделяемыми (одинаковыми) весами $W$ кодируют два входных объекта в эмбеддинги. Затем вычисляется расстояние между ними (например, евклидово).

### Функции потерь для метрического обучения
1.  **Contrastive Loss (Контрастивная функция потерь):**
    $$L = Y D^2 + (1 - Y) \max(m - D, 0)^2$$
    где $D$ — расстояние между эмбеддингами. $Y=1$ для пары из одного класса (стремимся сблизить объекты), $Y=0$ для разных классов (раздвигаем объекты на расстояние не менее $m$).
2.  **Triplet Loss:** использует тройки объектов — Anchor (якорь $A$), Positive (похожий $P$), Negative (непохожий $N$):
    $$L = \max(\|F(A) - F(P)\|^2 - \|F(A) - F(N)\|^2 + \alpha, 0)$$
3.  **Softmax Loss (в контексте метрик):** $L_{softmax} = -\frac{1}{N} \sum_i \ln \frac{e^{W_{y_i}^T x_i + b_{y_i}}}{\sum_j e^{W_j^T x_i + b_j}}$, где веса $W$ интерпретируются как центроиды классов.
4.  **Угловые функции потерь (Normalized Softmax / ArcFace-семейство):** нормируют веса и признаки ($\|W\|=1$, $\|x\|=1$), сводя скалярное произведение к косинусу угла: $W^T x = s \cos(\theta)$.
    *   *SphereFace Loss (мультипликативный угловой маргин):* использует $m\theta$ вместо $\theta$.
    *   *CosFace Loss (аддитивный косинусный маргин):* использует $\cos(\theta) - m$.
    *   *ArcFace Loss (аддитивный угловой маргин):* использует $\cos(\theta + m)$. Это дает наиболее четкие границы между классами на гиперсфере.

## Лекция 8: Задачи компьютерного зрения (`08_applications.pdf`)

### Семантическая сегментация
*   **Задача:** классификация каждого пикселя изображения.
*   **Архитектуры:**
    *   *Автоэнкодер (AE):* Encoder сжимает картинку в латентный код, Decoder восстанавливает маску сегментации.
    *   *SegNet:* декодер использует индексы максимальных элементов пулинга (pooling indices) из энкодера для точного нелинейного восстановления разрешения.
    *   *U-Net:* использует skip-connections (проброс признаков) между соответствующими слоями энкодера и декодера для сохранения мелких пространственных деталей.
    *   *DeepLabv3:* применяет Atrous Convolution (разреженную/дырчатую свертку) для увеличения рецептивного поля без потери разрешения и ASPP (Atrous Spatial Pyramid Pooling) для извлечения контекста разного масштаба.

### Детектирование объектов (Object Detection)
*   **R-CNN (Region-based CNN):** Selective Search выделяет ~2000 регионов (ROI), каждый регион прогоняется через CNN, признаки классифицируются SVM, координаты уточняются регрессией. (Очень медленно).
*   **Fast R-CNN:** CNN прогоняет все изображение один раз, ROI проецируются на карту признаков, RoI Pooling нарезает из них фиксированные векторы для классификации и регрессии.
*   **Faster R-CNN:** заменяет Selective Search на встроенную сеть предложений регионов (RPN — Region Proposal Network) на основе анкеров (anchors), делая модель полностью сквозной (end-to-end).
*   **YOLO (You Only Look Once):** одностадийный детектор. Делит изображение на сетку $S \times S$. Каждая ячейка предсказывает $B$ рамок (координаты, уверенность/objectness) и $C$ вероятностей классов. Выходной тензор имеет размер $S \times S \times (5B + C)$. Применяет Non-Maximum Suppression (NMS) по порогу IoU. В YOLO v3 предсказания идут на трех разных масштабах.

### Pose Estimation и Трекинг
*   **Pose Estimation (Определение позы):** поиск координат ключевых точек скелета. Популярна архитектура CPM (Convolutional Pose Machines), уточняющая положение точек в несколько стадий.
*   **Трекинг:** отслеживание объектов на видео. Используются подходы с вырезанием региона поиска вокруг объекта и сравнением его с шаблоном через общую сверточную сеть (сиамский трекинг).

## Лекция 9: Генеративные модели (`09_gen_data.pdf`)

### Вариационные автоэнкодеры (VAE)
*   В отличие от обычного AE, VAE отображает вход $x$ в параметры распределения (векторы средних $\mu$ и логарифма дисперсии $\log\sigma^2$) в латентном пространстве.
*   **Лосс VAE:** минимизация функционала ELBO:
    $$L_{VAE} = -E_{q_\phi(z|x)}[\log p_\theta(x|z)] + D_{KL}(q_\phi(z|x) \parallel \mathcal{N}(0, I))$$
    где первый член — ошибка реконструкции (MSE/BCE), второй — штраф за отклонение от стандартного нормального распределения.
*   **Reparameterization Trick:** замена случайного сэмплирования $z \sim q(z|x)$ на детерминированную операцию $z = \mu + \sigma \odot \epsilon$, где $\epsilon \sim \mathcal{N}(0, I)$. Это позволяет градиентам течь обратно через шаг сэмплирования.
*   **CVAE (Conditional VAE):** входы кодера и декодера дополняются вектором условия $y$ (например, меткой класса), что позволяет управлять свойствами генерации.

### Генеративно-состязательные сети (GAN)
*   **Концепция:** состязание двух сетей. Генератор $G(z)$ создает подделки из случайного шума. Дискриминатор $D(x)$ классифицирует объекты на реальные ($1$) и сгенерированные ($0$).
*   **Целевая функция (минимаксная игра):**
    $$\min_G \max_D V(D, G) = E_{x \sim p_{data}}[\log D(x)] + E_{z \sim p_z}[\log(1 - D(G(z)))]$$
*   **Conditional GAN (cGAN):** условие $y$ подается на вход как $G$, так и $D$.

### Диффузионные модели (Diffusion Models)
*   **Прямой процесс (Forward):** постепенное добавление гауссовского шума к изображению за $T$ шагов: $q(x_t|x_{t-1}) = \mathcal{N}(x_t; \sqrt{1 - \beta_t} x_{t-1}, \beta_t I)$. Прямой переход к любому шагу: $x_t = \sqrt{\bar{\alpha}_t} x_0 + \sqrt{1 - \bar{\alpha}_t} \epsilon$.
*   **Обратный процесс (Reverse):** нейросеть (U-Net) учится пошагово предсказывать и убирать добавленный шум:
    $$L_{t} = \|\epsilon - \epsilon_\theta(x_t, t)\|^2 \to \min$$
    Восстановление: $x_{t-1} = \frac{1}{\sqrt{\alpha_t}} \left( x_t - \frac{1 - \alpha_t}{\sqrt{1 - \bar{\alpha}_t}} \epsilon_\theta(x_t, t) \right) + \sigma_t z$.

### Нормализующие потоки (Normalizing Flows)
*   Отображают простое распределение $z \sim \mathcal{N}(0, I)$ в сложное распределение данных $x = f(z)$ с помощью последовательности обратимых дифференцируемых преобразований.
*   Используют теорему о замене переменных: $p_x(x) = p_z(f^{-1}(x)) \left| \det \frac{\partial f^{-1}(x)}{\partial x} \right|$. Лосс — минимизация NLL. Для простоты вычисления якобиана применяют треугольные матрицы преобразования (например, RealNVP, Glow).

## Лекция 10: CLIP (Contrastive Language-Image Pre-training) (`10_CLIP.pdf`)

### Мотивация и подход
*   **Проблема:** классические моделиCV ограничены фиксированным набором классов.
*   **Идея CLIP:** совместное обучение кодировщика изображений (ResNet или ViT) и кодировщика текста (Transformer) на 400 миллионах пар (изображение, текст) из Интернета.
*   **Метод:** контрастивное обучение. Модель максимизирует косинусное сходство между правильными парами «текст-изображение» в батче и минимизирует для неправильных (всего $N^2$ сравнений).

### Архитектурные детали
*   **Кодировщик изображений:** ResNet (с Attention Pooling вместо Global Average Pooling) или Vision Transformer (ViT).
*   **Кодировщик текста:** Transformer (12 слоев, 8 голов, BPE токенизация, контекст 76 токенов). Вектор представления извлекается из токена [EOS] (End of Sequence).
*   Линейные проекции переводят выходы обоих кодировщиков в общее мультимодальное латентное пространство.
*   **Лосс:** симметричная кросс-энтропия по матрице сходств с обучаемым параметром температуры $\tau$: $S_{ij} = \frac{f_I(I_i) \cdot f_T(T_j)}{\tau}$.
*   **Параметры обучения:** размер батча 32 768, оптимизатор AdamW с косинусным затуханием скорости обучения, mixed-precision (FP16).

### Zero-Shot классификация
*   Позволяет классифицировать изображения без дообучения модели.
*   Формируются текстовые промпты для каждого класса (например, «a photo of a {class_name}»).
*   Тексты и изображение кодируются, вычисляются косинусные сходства. Выбирается класс с максимальным сходством.
*   CLIP демонстрирует высокую устойчивость (robustness) к сдвигам распределения данных (out-of-distribution) по сравнению со стандартным supervised-обучением.

## Лекция 11: Введение в языковое моделирование (`11_Ввеление в языковое моделирование.pdf`)

### Статистический машинный перевод (SMT)
*   **Вероятностная модель:** поиск предложения $y$, максимизирующего вероятность:
    $$\text{argmax}_y P(y|x) = \text{argmax}_y P(x|y) P(y)$$
    где $P(x|y)$ — модель перевода (словарные соответствия, выравнивание/alignment слов), а $P(y)$ — языковая модель (оценивает грамматическую корректность предложения на целевом языке).
*   **Проблема выравнивания:** слова в разных языках переводятся не один к одному (перестановки, добавления, пропуски слов). Используются матрицы выравнивания (alignment).

### Представление слов (Embeddings)
*   *One-Hot Encoding:* кодирует слова векторами размерности словаря с одной $1$ и остальными $0$. Не отражает семантическую близость слов (скалярное произведение любых двух разных слов равно $0$).
*   *Word2vec:* плотные низкоразмерные векторы, где геометрическое расстояние отражает смысловое сходство.
    *   Свойства: улавливает линейные семантические отношения, например: `король` - `мужчина` + `женщина` = `королева`.
    *   Архитектура CBOW (Continuous Bag of Words): предсказывает центральное слово по контекстным.
    *   Архитектура Skip-gram: предсказывает контекст по центральному слову.

### Нейронный машинный перевод (NMT)
*   **Базовый Seq2seq (2014 г.):** состоит из двух RNN.
    *   *Encoder* читает входное предложение и сжимает его в один вектор контекста $S$.
    *   *Decoder* генерирует перевод по одному слову, принимая на вход предыдущее сгенерированное слово и текущее скрытое состояние.
*   **Стратегии декодирования:**
    *   *Greedy Search (Жадный поиск):* выбор наиболее вероятного слова на каждом шаге. Быстро, но ведет к субоптимальным результатам.
    *   *Beam Search (Поиск по лучу):* отслеживание $K$ (размер луча) наиболее вероятных цепочек перевода.
        $$\text{score}(y_1, \dots, y_n) = \frac{1}{n} \sum_{i=1}^n \log P(y_i | y_1, \dots, y_{i-1} | x)$$
        Деление на длину $n$ (нормировка) предотвращает штрафование длинных предложений.
*   **Метрика BLEU:** оценивает качество перевода по доле совпадающих N-грамм (от 1 до 4) между машинным переводом и эталоном с добавлением штрафа за краткость (brevity penalty):
    $$\text{BLEU} = \min\left(1, \frac{\text{length}_{output}}{\text{length}_{reference}}\right) \left( \prod_{i=1}^4 \text{precision}_i \right)^{\frac{1}{4}}$$

## Лекция 12: Трансформеры (`12_трансформеры.pdf`)

### Недостатки RNN и мотивация Трансформера
1.  Последовательная обработка в RNN делает невозможным параллельные вычисления при обучении на GPU.
2.  Вектор контекста в Seq2seq является «бутылочным горлышком», из-за чего модель забывает начало длинных предложений.
*   *Решение Seq2seq с вниманием (Attention):* декодер получает доступ ко всем скрытым состояниям энкодера на каждом шаге генерации через веса внимания.

### Архитектура Transformer («Attention is all you need»)
Состоит из стопок блоков энкодера и декодера (обычно по 6 блоков). Не содержит рекуррентных связей.
*   **Блок Энкодера:**
    *   Self-Attention (Само-внимание) + Residual connection + LayerNorm.
    *   Feed-Forward Network (полносвязная сеть над каждой позицией независимо) + Residual connection + LayerNorm.
*   **Блок Декодера:**
    *   Masked Self-Attention (маскированное само-внимание — запрещает заглядывать в будущее при генерации).
    *   Encoder-Decoder Attention (внимание на выходы энкодера).
    *   Feed-Forward Network.

### Механизм Self-Attention
1.  Для каждого входного вектора (эмбеддинга) $X$ создаются три вектора: Query ($Q$), Key ($K$) и Value ($V$) через умножение на обучаемые матрицы весов:
    $$Q = X W^Q, \quad K = X W^K, \quad V = X W^V$$
2.  Вычисляются оценки соответствия (scaled dot-product attention):
    $$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V$$
    Деление на $\sqrt{d_k}$ (размерность ключей) предотвращает попадание softmax в зоны с очень малыми градиентами.
3.  **Multi-Head Attention (Многоголовое внимание):** расчет внимания ведется параллельно в $h$ независимых «головах» со своими матрицами проекций. Результаты конкатенируются и проецируются матрицей $W^O$:
    $$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, head_h) W^O$$

### Positional Encoding (Позиционное кодирование)
Поскольку Трансформер обрабатывает все слова одновременно, порядок слов задается сложением эмбеддингов слов с синусоидальными позиционными кодировками:
$$PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d_{model}}}\right), \quad PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$

## Лекция 13, 14: Введение в Reinforcement Learning (`13_intro_RL.pdf`, `14_intro_RL_2.pdf`)

### Терминология и схема взаимодействия
*   **Агент (Agent)** совершает действие $a_t$ в **Среде (Environment)**, получая в ответ наблюдение $o_{t+1}$ (или состояние $s_{t+1}$) и скалярное вознаграждение $r_{t+1}$.
*   **История (History):** $H_t = \langle o_1, r_1, a_1, \dots, o_t, r_t \rangle$.
*   **Состояние (State):** $S_t = f(H_t)$ — информация для выбора действия.
    *   *Марковское состояние:* состояние $s_t$ марковское, если $P[s_{t+1}|s_t] = P[s_{t+1}|s_1, \dots, s_t]$ (будущее зависит только от настоящего, а не от прошлого).
*   **Среды:**
    *   *Полностью наблюдаемая (MDP):* агент видит состояние среды напрямую ($o_t = s_t^e$).
    *   *Частично наблюдаемая (POMDP):* агент видит только косвенные признаки (наблюдения). Для восстановления состояния агент использует историю, вероятностные оценки (belief states) или RNN.

### Элементы RL-агента
1.  **Стратегия / Политика (Policy, $\pi$):** функция выбора действия. Детерминированная: $a = \pi(s)$, или стохастическая: $\pi(a|s) = P[a_t = a | s_t = s]$.
2.  **Функция полезности (Value Function, $V(s)$ или $Q(s,a)$):** ожидаемая дисконтированная сумма будущих вознаграждений (Return, отдача $G_t$):
    $$G_t = \sum_{k=0}^{\infty} \gamma^k r_{t+k+1}, \quad \gamma \in [0, 1] \text{ (дисконтирующий множитель)}$$
    *   $V^\pi(s) = E_\pi [ G_t | S_t = s ]$ (ценность состояния).
    *   $Q^\pi(s, a) = E_\pi [ G_t | S_t = s, a_t = a ]$ (ценность действия в состоянии).
3.  **Модель среды (Model):** предсказывает переходы среды $P_{ss'}^a$ и вознаграждения $R_s^a$.

### Классификация агентов
*   *Value-based:* оптимизируют функцию ценности, политика неявная (жадная).
*   *Policy-based:* оптимизируют параметры политики напрямую.
*   *Actor-Critic:* обучают и политику (Actor), и функцию ценности (Critic).
*   *Model-Free / Model-Based:* без модели среды (обучение на опыте) или с использованием модели для планирования.

## Лекция 15: Марковские процессы принятия решений (MDP) (`15_mdp.pdf`)

### Математическая постановка
Марковский процесс принятия решений — это кортеж $\langle S, A, P, R, \gamma \rangle$, где $P$ — вероятности переходов $P_{ss'}^a$, $R$ — функция немедленного вознаграждения $R_s^a$.

### Уравнения Беллмана
*   **Уравнение Беллмана для оценки $V^\pi(s)$:**
    $$V^\pi(s) = \sum_{a \in A} \pi(a|s) \left( R_s^a + \gamma \sum_{s' \in S} P_{ss'}^a V^\pi(s') \right)$$
    В матричной форме: $V^\pi = R^\pi + \gamma P^\pi V^\pi \implies V^\pi = (I - \gamma P^\pi)^{-1} R^\pi$ (аналитическое решение сложностью $O(n^3)$).
*   **Уравнения оптимальности Беллмана (для $V^*(s)$ и $Q^*(s, a)$):**
    $$V^*(s) = \max_{a \in A} \left( R_s^a + \gamma \sum_{s' \in S} P_{ss'}^a V^*(s') \right)$$
    $$Q^*(s, a) = R_s^a + \gamma \sum_{s' \in S} P_{ss'}^a \max_{a'} Q^*(s', a')$$

### Динамическое программирование для планирования в MDP
Предполагает полное знание модели среды.
1.  **Policy Iteration (Итерация по стратегиям):**
    *   *Оценка (Policy Evaluation):* расчет $V^k \to V^\pi$ с помощью уравнения Беллмана.
    *   *Улучшение (Policy Improvement):* жадный выбор действий относительно полученной ценности: $\pi' = \text{greedy}(V^\pi)$. Цикл повторяется до сходимости к оптимальной политике $\pi^*$.
2.  **Value Iteration (Итерация по полезностям):** рекурсивное обновление значений состояний по уравнению оптимальности Беллмана:
    $$V^{k+1}(s) \leftarrow \max_{a \in A} \left( R_s^a + \gamma \sum_{s' \in S} P_{ss'}^a V^k(s') \right)$$
    Прямой сходимости к $V^*$ без явного шага улучшения политики.

## Лекция 16: Метод Cross-Entropy (`16_cross_entropy.pdf`)

### Суть метода Cross-Entropy (CEM)
Относится к эволюционным методам поиска политик (безградиентная оптимизация).
*   **Алгоритм (табличный случай):**
    1.  Инициализировать политику $\pi(a|s)$ (например, равномерным распределением).
    2.  Сыграть $N$ (например, 100) игровых сессий.
    3.  Выбрать $M$ (например, 25) лучших сессий с максимальным суммарным вознаграждением — «элитные сессии».
    4.  Обновить политику $\pi(a|s)$ так, чтобы максимизировать вероятность повторения действий из элитных сессий:
        $$\pi(a|s) = \frac{\sum_{\text{elite}} \text{count}(s, a)}{\sum_{\text{elite}} \text{count}(s)}$$
*   **Приближенный (глубокий) CEM:**
    Для сред с непрерывным или очень большим пространством состояний политика параметризуется нейросетью $\pi_w(a|s)$. На шаге обновления веса сети $w$ настраиваются с помощью кросс-энтропийного лосса (обучение с учителем) на действиях из элитных сессий:
    $$w \leftarrow \text{argmax}_w \sum_{s_i, a_i \in \text{Elite}} \log \pi_w(a_i | s_i)$$

## Лекция 17: Алгоритмы на основе стратегии и ценности (`17_policy.pdf`)

### Развитие Value-Based методов: DQN
*   **DQN (Deep Q Network):** использование глубокой нейросети для аппроксимации функции $Q(s, a)$.
    *   *Лосс:* $L \approx E [ (Q(s_t, a_t) - (r + \gamma \max_{a'} Q(s_{t+1}, a')))^2 ]$.
    *   *Experience Replay (Буфер воспроизведения):* сохранение переходов $(s_t, a_t, r, s_{t+1})$ в буфер и случайное сэмплирование батчей для обучения. Устраняет корреляцию между последовательными шагами.
    *   *Double DQN:* решает проблему переоценки (overestimation bias) значений $Q$. Сеть весов $\theta$ выбирает действие, а сеть целевых весов $\theta^-$ оценивает его: $Target = r + \gamma Q(s_{t+1}, \text{argmax}_a Q(s_{t+1}, a; \theta); \theta^-)$.
    *   *Dueling DQN:* разделение сети на две ветки для предсказания ценности состояния $V(s)$ и преимущества каждого действия (Advantage $A(s, a)$):
        $$Q(s, a) = V(s) + A(s, a) - \frac{1}{|A|} \sum_{a'} A(s, a')$$

### Policy Gradient (Градиент стратегии)
Максимизируем ожидаемое вознаграждение $J(\theta) = E [ G(s, a) ]$ напрямую.
*   **Теорема о градиенте стратегии (с логарифмическим трюком):**
    $$\nabla_\theta J(\theta) = E_{\pi_\theta} [ \nabla_\theta \ln \pi_\theta (a|s) Q^{\pi_\theta}(s, a) ]$$
*   **Алгоритм REINFORCE:** использует фактическую отдачу полного эпизода $G_t$ в качестве несмещенной оценки $Q(s_t, a_t)$:
    $$\theta \leftarrow \theta + \alpha \nabla_\theta \ln \pi_\theta(a_t | s_t) G_t$$
*   **Снижение дисперсии с помощью Baseline:** вычитание из отдачи функции $b(s)$, не зависящей от действия $a$ (математическое ожидание градиента при этом не меняется):
    $$\nabla_\theta J(\theta) = E_{\pi_\theta} [ \nabla_\theta \ln \pi_\theta(a|s) (Q(s, a) - b(s)) ]$$
    Оптимальный выбор baseline: $b(s) = V(s)$. Множитель превращается в преимущество $A(s, a) = Q(s, a) - V(s)$.

### Actor-Critic методы (A2C)
*   **Идея:** одновременное обучение политики (Actor) и функции ценности (Critic).
*   Критик оценивает состояние $V_\phi(s)$ и считает преимущество через TD-ошибку: $A(s, a) \approx r + \gamma V_\phi(s') - V_\phi(s)$.
*   *Обновление актора (политики):* $\theta \leftarrow \theta + \alpha_{actor} \nabla_\theta \ln \pi_\theta(a|s) A(s, a)$.
*   *Обновление критика (ценности):* минимизация квадрата TD-ошибки: $\phi \leftarrow \phi + \alpha_{critic} (r + \gamma V_\phi(s') - V_\phi(s)) \nabla_\phi V_\phi(s)$.
