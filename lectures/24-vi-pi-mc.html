1. Динамическое программирование: Оценивание стратегии

Методы динамического программирования (Dynamic Programming, DP) предполагают, что нам полностью известна модель среды (матрица переходов $\mathcal{P}(s' \mid s, a)$ и функция наград $\mathcal{R}(s, a)$).

📐 Итеративное оценивание стратегии (Iterative Policy Evaluation)

Чтобы вычислить $V^\pi(s)$ для заданной фиксированной стратегии $\pi$, мы запускаем итерационный процесс применения оператора Беллмана:

$$ V_{k+1}(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s) \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma V_k(s') \right] $$

Итерации повторяются до тех пор, пока максимальное изменение ценности $\Delta = \max_{s} |V_{k+1}(s) - V_k(s)|$ не станет меньше порога $\theta$ (например, $10^{-6}$).

2. Улучшение стратегии (Policy Improvement)

Имея вычисленную функцию ценности $V^\pi(s)$, мы можем построить новую строго лучшую стратегию $\pi'$, действуя жадно относительно $V^\pi$:

$$ \pi'(s) = \arg\max_{a \in \mathcal{A}} Q^\pi(s, a) = \arg\max_{a \in \mathcal{A}} \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma V^\pi(s') \right] $$
🔒 Теорема об улучшении стратегии (Policy Improvement Theorem)

Пусть $\pi$ и $\pi'$ — две детерминированные стратегии такие, что для всех $s \in \mathcal{S}$:

$$ Q^\pi(s, \pi'(s)) \ge V^\pi(s) $$

Тогда стратегия $\pi'$ гарантированно не хуже стратегии $\pi$ во всех состояниях: $V^{\pi'}(s) \ge V^\pi(s)$. Если равенство достигается во всех состояниях, то стратегия $\pi$ является строго оптимальной $\pi^*$.

3. Алгоритм Policy Iteration (Итерация по стратегиям)

ЦИКЛ POLICY ITERATION: π_0 ──▶ [ Policy Evaluation ] ──▶ V^{π_0} ──▶ [ Policy Improvement ] ──▶ π_1 ──▶ ... ──▶ π* Policy Iteration: полный цикл оценки $V^\pi$ до сходимости чередуется с жадным обновлением стратегии $\pi$.
💡 Почему Policy Iteration сходится за конечное число шагов?

В конечном MDP число состояний $|\mathcal{S}|$ и действий $|\mathcal{A}|$ конечно. Число всех возможных детерминированных стратегий строго равно $|\mathcal{A}|^{|\mathcal{S}|}$. Так как на каждом шаге стратегия строго улучшается ($V^{\pi_{k+1}} > V^{\pi_k}$), алгоритм не может зациклиться и гарантированно находит точную оптимальную стратегию $\pi^*$ за конечное число итераций!

4. Алгоритм Value Iteration (Итерация по ценностям)

В Policy Iteration фаза оценки (Policy Evaluation) требует сотен итераций для точного вычисления $V^\pi$. Value Iteration усекает фазу оценки до ровно одного шага, объединяя оценку и улучшение в единую формулу обновления:

$$ V_{k+1}(s) = \max_{a \in \mathcal{A}} \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma V_k(s') \right] $$ Value Iteration: прямое итеративное применение оператора оптимальности Беллмана $V_{k+1} = \mathcal{T}^* V_k$.

5. Обобщенная итерация стратегий (GPI)

Стратегия π ▲ │ Improvement │ │ Evaluation (Жадный шаг) │ ▼ (Оценка ценности) Функция V Generalized Policy Iteration (GPI): фундамент теории RL по Саттону и Барто.

GPI (Generalized Policy Iteration) описывает взаимодействие двух встречных процессов:

  1. Evaluation (Оценивание): приближает функцию ценности $V$ к истинной ценности текущей стратегии $\pi$.
  2. Improvement (Улучшение): делает стратегию $\pi$ жадной относительно текущей функции ценности $V$.

Оба процесса конкурируют и одновременно сотрудничают, стабилизируясь только в единственной точке оптимума $(V^*, \pi^*)$.

6. Методы Монте-Карло (Monte Carlo RL)

Что делать, если модель среды $\mathcal{P}$ и $\mathcal{R}$ неизвестна (Model-Free)? Агент может просто взаимодействовать со средой, генерируя полные эпизоды, и усреднять накопленные доходы $G_t$ методом Монте-Карло!

$$ V(s) \approx \frac{1}{N(s)} \sum_{i=1}^{N(s)} G_t^{(i)} $$

First-Visit MC vs Every-Visit MC:

  • First-Visit MC: Доход $G_t$ усредняется только для первого посещения состояния $s$ в рамках каждого эпизода. Дает строго несмещенную (Unbiased) оценку $\mathbb{E}[V(s)]$.
  • Every-Visit MC: Доход $G_t$ усредняется для каждого посещения состояния $s$ в эпизоде. Оценка состоятельна, но имеет небольшое смещение на малых выборках.

7. Сравнение: DP vs MC (Бутстрэппинг и знание модели)

8. Практическая реализация на Python

import numpy as np

def value_iteration(P, n_states, n_actions, gamma=0.9, theta=1e-6):
    """
    P[s][a] = [(prob, next_state, reward, done), ...]
    """
    V = np.zeros(n_states)
    
    while True:
        delta = 0
        for s in range(n_states):
            v_old = V[s]
            q_values = np.zeros(n_actions)
            for a in range(n_actions):
                for prob, next_s, r, done in P[s][a]:
                    q_values[a] += prob * (r + gamma * V[next_s] * (not done))
            V[s] = np.max(q_values)
            delta = max(delta, abs(v_old - V[s]))
            
        if delta < theta:
            break
            
    # Извлекаем детерминированную стратегию
    policy = np.zeros(n_states, dtype=int)
    for s in range(n_states):
        q_values = [sum(prob * (r + gamma * V[next_s] * (not done)) 
                        for prob, next_s, r, done in P[s][a]) 
                    for a in range(n_actions)]
        policy[s] = np.argmax(q_values)
        
    return V, policy

🎯 Препод спросит

В чем главное отличие Policy Iteration от Value Iteration?

В Policy Iteration на каждом шаге функция $V^\pi$ вычисляется до полной сходимости системы уравнений Беллмана, после чего строится новая стратегия $\pi'$. В Value Iteration оценивание стратегии обрывается ровно после одной итерации обновления: максимум берется непосредственно внутри шага обновления $V(s)$.

Сформулируйте и строго докажите Теорему об улучшении стратегии (Policy Improvement Theorem).

Формулировка: Пусть $\pi$ и $\pi'$ — две детерминированные стратегии такие, что для всех $s \in \mathcal{S}$ выполняется $Q^\pi(s, \pi'(s)) \ge V^\pi(s)$. Тогда стратегия $\pi'$ не хуже стратегии $\pi$ во всех состояниях: $V^{\pi'}(s) \ge V^\pi(s)$.

Доказательство: Раскроем $V^\pi(s)$ по определению $Q^\pi$ и последовательно применим индукцию по будущим состояниям:

$$ V^\pi(s) \le Q^\pi(s, \pi'(s)) = \mathbb{E}_{\pi'} \left[ R_{t+1} + \gamma V^\pi(S_{t+1}) \mid S_t = s \right] $$ $$ \le \mathbb{E}_{\pi'} \left[ R_{t+1} + \gamma Q^\pi(S_{t+1}, \pi'(S_{t+1})) \mid S_t = s \right] $$ $$ = \mathbb{E}_{\pi'} \left[ R_{t+1} + \gamma R_{t+2} + \gamma^2 V^\pi(S_{t+2}) \mid S_t = s \right] $$

Продолжая подстановку на $k$ шагов вперед при $k \to \infty$:

$$ V^\pi(s) \le \mathbb{E}_{\pi'} \left[ \sum_{l=0}^\infty \gamma^l R_{t+l+1} \mid S_t = s \right] = V^{\pi'}(s) $$

Если $Q^\pi(s, \pi'(s)) > V^\pi(s)$ хотя бы в одном состоянии, то $\pi'$ строго лучше $\pi$.

Как устроен критерий сходимости $\Delta < \theta$ в Policy Evaluation и как порог $\theta$ связан с погрешностью оценки ценности?

В алгоритме итеративного оценивания политики на каждой эпохе отслеживается максимальное абсолютное изменение ценности по всем состояниям:

$$ \Delta = \max_{s \in \mathcal{S}} |v_{k+1}(s) - v_k(s)| = \|V_{k+1} - V_k\|_\infty $$

Итерации останавливаются, как только $\Delta < \theta$. По свойству $\gamma$-сжатия оператора Беллмана гарантируется верхняя оценка погрешности:

$$ \|V_k - V^\pi\|_\infty \le \frac{\gamma}{1 - \gamma} \|V_k - V_{k-1}\|_\infty < \frac{\gamma \theta}{1 - \gamma} $$

Это дает строгую гарантию точности аппроксимации функции ценности текущей политики.

Приведите геометрическую интерпретацию концепции Generalized Policy Iteration (GPI).

В пространстве «политика — функция ценности» $(\pi, V)$ алгоритмы RL интерпретируются как взаимодействие двух встречных векторных полей:

  • Policy Evaluation: направляет вектор ценностей $V \to V^\pi$ при неизменной политике $\pi$.
  • Policy Improvement: смещает политику $\pi \to \text{greedy}(V)$ относительно фиксированного вектора ценностей $V$.

Каждый шаг одного процесса нарушает баланс для другого, порождая зигзагообразную траекторию сходимости. Обе силовые линии взаимно уравновешиваются исключительно в единственной точке пересечения — глобальном оптимуме $(V^*, \pi^*)$.

В чем математическая разница свойств несмещенности и дисперсии между First-Visit MC и Every-Visit MC?

First-Visit Monte Carlo: усредняет доходы $G_t$ только от первого входа в состояние $s$ в каждом эпизоде. Выборки доходов из разных эпизодов строго независимы (i.i.d.), поэтому оценка $\hat{V}(s)$ является строго несмещенной ($\mathbb{E}[\hat{V}(s)] = V^\pi(s)$) для любого конечного числа эпизодов.

Every-Visit Monte Carlo: усредняет доходы от всех посещений состояния $s$ внутри каждого эпизода. Из-за корреляции повторных визитов внутри одной траектории оценка имеет слабое начальное смещение, но является асимптотически несмещенной и состоятельной. При малом числе эпизодов Every-Visit MC часто дает меньшую среднеквадратичную ошибку (MSE) благодаря большему объему точек.

В чем суть предположения Exploring Starts в Monte Carlo Control и почему на практике используют $\epsilon$-мягкие ($\epsilon$-soft) стратегии?

Exploring Starts (Исследующие старты): предполагает, что каждый эпизод начинается со случайно выбранной пары $(s_0, a_0)$ с ненулевой вероятностью $P(S_0=s, A_0=a) > 0$ для всех пар. Это гарантирует исследование всех действий, но неприменимо в реальных физических системах (нельзя мгновенно телепортировать робота в произвольное состояние).

$\epsilon$-soft / $\epsilon$-greedy контроль: агент действует по стохастической политике, где наилучшее действие выбирается с вероятностью $1 - \epsilon + \frac{\epsilon}{|\mathcal{A}|}$, а все остальные действия — с вероятностью $\frac{\epsilon}{|\mathcal{A}|} > 0$. Это гарантирует постоянное исследование среды из стандартного начального состояния без искусственных допущений об инициализации.

Что такое «бутстрэппинг» (Bootstrapping) в RL?

Бутстрэппинг — это обновление оценки ценности одного состояния на основе уже существующих оценок ценности других состояний ($V(s) \leftarrow r + \gamma V(s')$), а не на основе реального завершенного дохода $G_t$. Динамическое программирование и TD-методы используют бутстрэппинг, а методы Монте-Карло — нет.

Почему методы Монте-Карло не могут применяться в непрерывных (бесконечных) задачах?

Потому что метод Монте-Карло требует вычисления фактического суммарного дохода эпизода $G_t = \sum r_k$. В непрерывных средах без терминального состояния эпизод никогда не заканчивается, и агент не может получить числовое значение $G_t$.

В чем разница между First-Visit MC и Every-Visit MC?

Если в течение одного эпизода агент попал в состояние $s$ трижды ($s \to s_1 \to s \to s_2 \to s$), First-Visit MC засчитает для обновления $V(s)$ только доход $G_t$ после первого входа в $s$. Every-Visit MC посчитает среднее по всем трем доходам из каждого посещения $s$.

Что такое концепция Generalized Policy Iteration (GPI)?

GPI — это общая концепция взаимодействия двух процессов: Policy Evaluation (оценка ценности текущей стратегии) и Policy Improvement (жадное улучшение стратегии по вычисленной ценности). Практически все алгоритмы RL представляют собой вариации GPI с разной частотой и глубиной чередования этих двух шагов.

📝 Микро-задачи

Задача 1. Расчет шага Value Iteration

Состояние $s$. Действие $a_1$: $r=2$, ведет в $s_1$ ($V_0(s_1)=4$). Действие $a_2$: $r=0$, ведет в $s_2$ ($V_0(s_2)=10$). При $\gamma = 0.5$ найдите $V_1(s)$.

Решение

$Q(s, a_1) = 2 + 0.5 \cdot 4 = 2 + 2 = 4$.

$Q(s, a_2) = 0 + 0.5 \cdot 10 = 5$.

$$ V_1(s) = \max(4, 5) = 5 $$

Жадное действие: $a_2$.

Задача 2. Расчет First-Visit Monte Carlo

Сгенерирован эпизод: $s_1 \xrightarrow{r=1} s_2 \xrightarrow{r=2} s_1 \xrightarrow{r=3} s_3 \xrightarrow{r=10} \text{End}$. $\gamma = 1.0$. Найдите доход $G(s_1)$ по правилу First-Visit MC.

Решение

Первое посещение $s_1$ произошло на шаге 0. Доход от этого момента до конца:

$$ G_0 = 1 + 2 + 3 + 10 = 16 $$

(Второе посещение $s_1$ на шаге 2 с доходом $3 + 10 = 13$ игнорируется).

Задача 3. Оценка числа стратегий в дискретном MDP

Среда GridWorld $4 \times 4$ (16 клеток, 1 терминальная). В каждой клетке доступно 4 действия. Сколько всего существует различных детерминированных стратегий?

Решение

Число нетерминальных состояний: $|\mathcal{S}| = 15$. В каждом 4 действия.

$$ \text{Число стратегий} = |\mathcal{A}|^{|\mathcal{S}|} = 4^{15} = 2^{30} = 1\,073\,741\,824 \approx 1.07 \times 10^9 $$

Полный перебор невозможен, но Policy Iteration находит оптимум всего за 4–5 шагов!

Задача 4. Условие остановки Policy Evaluation

Вектор $V_k = [4.0, 5.0]$, вектор $V_{k+1} = [4.0005, 4.9998]$. Порог $\theta = 0.001$. Остановится ли алгоритм оценивания?

Решение

$$ \Delta = \max(|4.0005 - 4.0|, |4.9998 - 5.0|) = \max(0.0005, 0.0002) = 0.0005 $$

Так как $\Delta = 0.0005 < \theta = 0.001$, условие остановки выполнено, алгоритм завершает фазу оценки.

Задача 5. Дисперсия MC vs DP на простом примере

Из состояния $s$ агент делает 10 шагов. На каждом шаге награда случайна: $r \in \{-1, +1\}$ с вероятностью 0.5. Чему равна дисперсия оценки дохода в MC при $\gamma=1$?

Решение

Доход $G = \sum_{t=1}^{10} r_t$. Дисперсия одного шага $\text{Var}(r) = 1$.

Дисперсия суммы 10 независимых шагов: $\text{Var}(G) = 10 \times 1 = 10$.

В методах Монте-Карло дисперсия накапливается линейно с ростом длины траектории.

Задача 6. Доказательство оптимальности стратегии

Для всех состояний $s$ выполнено: $\arg\max_a Q^\pi(s, a) = \pi(s)$. Что это означает для стратегии $\pi$?

Решение

Это означает, что шаг Policy Improvement оставляет стратегию неизменной: $\pi'(s) = \pi(s)$. По теореме об улучшении стратегии это необходимое и достаточное условие того, что стратегия $\pi$ является глобально оптимальной: $\pi = \pi^*$.

⚡ Ответ за 3 минуты

Скелет устного ответа по билету 22 (ч. 2, VI, PI, GPI, Monte Carlo)
  1. Policy Evaluation. Итеративное вычисление $V^\pi(s)$ по формуле ожидания Беллмана до сходимости ($\Delta < \theta$).
  2. Policy Improvement. Построение новой жадной стратегии $\pi'(s) = \arg\max_a Q^\pi(s, a)$. По теореме об улучшении $V^{\pi'}(s) \ge V^\pi(s)$.
  3. Policy Iteration. Чередование полной оценки $V^\pi$ и улучшения $\pi$. Гарантированно сходится за конечное число шагов ($|\mathcal{A}|^{|\mathcal{S}|}$).
  4. Value Iteration. Объединение оценки и улучшения в 1 шаг через оператор Беллмана: $V_{k+1}(s) = \max_a \sum \mathcal{P} [\mathcal{R} + \gamma V_k]$.
  5. GPI (Generalized Policy Iteration). Фундаментальная идея взаимодействия двух процессов: Evaluation (делает $V$ согласованной с $\pi$) и Improvement (делает $\pi$ жадной к $V$).
  6. Методы Монте-Карло (MC). Model-Free подход: модель среды неизвестна, $V(s)$ оценивается прямым усреднением эмпирических доходов $G_t$ по завершенным эпизодам.
  7. First-visit vs Every-visit. First-visit усредняет $G_t$ только по первому входу в состояние за эпизод (несмещенная оценка).
  8. DP vs MC. DP знает модель и использует бутстрэппинг ($V(s) \to V(s')$). MC не знает модель, не использует бутстрэппинг, но требует полных эпизодов и имеет высокую дисперсию.
