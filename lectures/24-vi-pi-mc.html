1. Интуиция и мотивация

Когда математическая модель среды известна (заданы матрицы переходов $\mathcal{P}(s'|s, a)$ и наград $\mathcal{R}(s, a)$), задача нахождения оптимального поведения называется планированием (Planning) и решается методами динамического программирования (Dynamic Programming, DP).

Однако в реальном мире (управление роботом, беспилотный автомобиль, финансовые рынки) точные уравнения физики и поведения мира неизвестны. В этом случае агент может обучаться только на основе сэмплирования реальных траекторий методом Монте-Карло (Monte Carlo, MC).

💡 Две фундаментальные парадигмы оценивания ценности
  • Динамическое программирование (DP / Bootstrapping): Вычисляет ценность $V(s)$ через математическое ожидание по всем возможным ветвям преемников, опираясь на текущие оценки $V(s')$. Требует знания модели среды $\mathcal{P}$. Нулевая дисперсия, но зависит от точности модели.
  • Методы Монте-Карло (MC / Sampling): Оценивают ценность $V(s)$ путем эмпирического усреднения фактических накопленных доходов $G_t$ по завершенным эпизодам. Модель среды $\mathcal{P}$ не требуется вовсе. Оценка абсолютно несмещенная ($\mathbb{E}[G_t] = V(s)$), но обладает высокой дисперсией.

2. Архитектура и схема: Generalized Policy Iteration (GPI)

Generalized Policy Iteration (GPI) — концептуальный каркас, объединяющий почти все алгоритмы RL. Он описывает непрерывное взаимодействие двух конкурирующих процессов:

  1. Policy Evaluation (Оценка стратегии): Фиксируем стратегию $\pi$ и подгоняем функцию ценности $V \to V^\pi$.
  2. Policy Improvement (Улучшение стратегии): Фиксируем функцию ценности $V$ и делаем стратегию жадной относительно нее $\pi \leftarrow \text{greedy}(V)$.
ОЦЕНКА СТРАТЕГИИ (Evaluation) V ───────────────────────────────▶ v^π ▲ │ │ │ УЛУЧШЕНИЕ │ │ СТРАТЕГИИ │ ▼ (Improvement) π* ◀─────────────────────────────── π' Сходимость в точке (π*, V*) GPI: Процессы оценки и улучшения подталкивают друг друга к глобальной оптимальной паре (π*, V*).
СРАВНЕНИЕ ПУТЕЙ ОБНОВЛЕНИЯ: Policy Iteration (PI): π_0 ──Eval (до сходимости V^π)──▶ V_0 ──Improve──▶ π_1 ──Eval──▶ V_1 ──Improve──▶ ... ──▶ π* Value Iteration (VI): V_0 ──1 шаг max_a──▶ V_1 ──1 шаг max_a──▶ V_2 ──1 шаг max_a──▶ ... ──▶ V* ──1 Improvement──▶ π* Monte Carlo (MC): Сэмплирование эпизода τ = (S_0, A_0, R_1, ..., S_T) ──▶ Накопление G_t ──▶ V(S_t) ← V(S_t) + α(G_t - V(S_t)) Policy Iteration выполняет полную оценку на каждом шаге; Value Iteration объединяет оценку и улучшение в 1 шаг; Monte Carlo учится по реальным траекториям без модели.

3. Математический аппарат

1. Policy Iteration (Итерация по стратегиям)

Алгоритм состоит из чередования двух фаз:

  1. Фаза 1: Оценка стратегии (Policy Evaluation). Итеративно решается линейное уравнение Беллмана до сходимости ($\max_s |V_{k+1}(s) - V_k(s)| < \theta$):
    $$ V_{k+1}(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s) \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma V_k(s') \right] $$
  2. Фаза 2: Улучшение стратегии (Policy Improvement). Жадный выбор действия по вычисленной функции ценности:
    $$ \pi_{\text{new}}(s) = \arg\max_{a \in \mathcal{A}} Q^{\pi}(s, a) = \arg\max_{a \in \mathcal{A}} \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma V^\pi(s') \right] $$
📐 Теорема об улучшении стратегии (Policy Improvement Theorem)

Пусть $\pi$ и $\pi'$ — две детерминированные стратегии такие, что для всех $s \in \mathcal{S}$ выполняется:

$$ Q^\pi(s, \pi'(s)) \ge V^\pi(s) $$

Тогда стратегия $\pi'$ гарантированно не хуже стратегии $\pi$ во всех состояниях: $V^{\pi'}(s) \ge V^\pi(s) \quad \forall s \in \mathcal{S}$.

Доказательство:

$$ V^\pi(s) \le Q^\pi(s, \pi'(s)) = \mathbb{E}_{\pi'} [R_{t+1} + \gamma V^\pi(S_{t+1}) \mid S_t = s] \le \mathbb{E}_{\pi'} [R_{t+1} + \gamma Q^\pi(S_{t+1}, \pi'(S_{t+1})) \mid S_t = s] \le \dots \le V^{\pi'}(s) $$

2. Value Iteration (Итерация по ценностям)

Value Iteration объединяет фазу оценки и улучшения в один шаг обновления с оператором максимума, применяя оператор оптимальности Беллмана $\mathcal{T}^*$:

$$ V_{k+1}(s) \leftarrow \max_{a \in \mathcal{A}} \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma V_k(s') \right] $$

Критерий остановки: $\max_{s \in \mathcal{S}} |V_{k+1}(s) - V_k(s)| < \frac{\epsilon(1 - \gamma)}{2\gamma}$, что гарантирует $\|V_{k+1} - V^*\|_\infty \le \epsilon$. После сходимости оптимальная стратегия извлекается за 1 жадный шаг: $\pi^*(s) = \arg\max_a \sum_{s'} \mathcal{P}(s'|s, a) [\mathcal{R} + \gamma V^*(s')]$.

3. Методы Монте-Карло (Monte Carlo Methods)

Методы Монте-Карло не требуют знания $\mathcal{P}$ и $\mathcal{R}$. Обучение происходит на основе сгенерированных эпизодов $\tau = (S_0, A_0, R_1, S_1, A_1, \dots, S_T)$:

$$ G_t = \sum_{k=0}^{T - t - 1} \gamma^k R_{t+k+1} $$
  • First-Visit Monte Carlo: Ценность состояния $s$ обновляется только по первому визиту состояния $s$ в рамках эпизода (строго несмещенная оценка $V(s)$).
  • Every-Visit Monte Carlo: Ценность состояния $s$ обновляется по каждому вхождению состояния $s$ в эпизод (асимптотически несмещенная, меньшая дисперсия).

Инкрементная форма обновления (Running Average):

$$ V(S_t) \leftarrow V(S_t) + \alpha \left( G_t - V(S_t) \right) $$

где $\alpha = \frac{1}{N(S_t)}$ для простого среднего или постоянный $\alpha \in (0, 1]$ для нестационарных сред.

4. Важностное сэмплирование (Off-Policy Importance Sampling)

Если данные собираются по стратегии исследования $b(a|s)$ (Behavior Policy), а оценивается целевая стратегия $\pi(a|s)$ (Target Policy), отношение правдоподобия траектории (Importance Sampling Ratio) равно:

$$ \rho_{t:T-1} \doteq \prod_{k=t}^{T-1} \frac{\pi(A_k \mid S_k)}{b(A_k \mid S_k)} $$
  • Ordinary Importance Sampling (Обычное): $V(s) = \frac{\sum_{\tau} \rho_{t(\tau):T-1} G_{t(\tau)}}{N}$ (несмещенная, но неограниченная дисперсия).
  • Weighted Importance Sampling (Взвешенное): $V(s) = \frac{\sum_{\tau} \rho_{t:T-1} G_t}{\sum_\tau \rho_{t:T-1}}$ (небольшое смещение, но дисперсия строго ограничена).

5. Практическая реализация Value Iteration и Monte Carlo на Python

import numpy as np

def run_value_iteration(P, R, gamma=0.9, theta=1e-6):
    """Алгоритм Value Iteration динамического программирования."""
    n_states, n_actions, _ = P.shape
    V = np.zeros(n_states)
    while True:
        delta = 0.0
        for s in range(n_states):
            v_old = V[s]
            q_sa = [R[s, a] + gamma * np.sum(P[s, a] * V) for a in range(n_actions)]
            V[s] = np.max(q_sa)
            delta = max(delta, abs(v_old - V[s]))
        if delta < theta:
            break
    policy = np.zeros(n_states, dtype=int)
    for s in range(n_states):
        q_sa = [R[s, a] + gamma * np.sum(P[s, a] * V) for a in range(n_actions)]
        policy[s] = int(np.argmax(q_sa))
    return V, policy

def run_first_visit_mc(episodes, n_states, gamma=0.9):
    """Оценка ценности состояний методом First-Visit Monte Carlo."""
    returns_sum = np.zeros(n_states)
    returns_count = np.zeros(n_states)
    for episode in episodes:
        G = 0.0
        visited = set()
        traj_returns = []
        for s, a, r in reversed(episode):
            G = r + gamma * G
            traj_returns.append((s, G))
        for s, g in reversed(traj_returns):
            if s not in visited:
                visited.add(s)
                returns_sum[s] += g
                returns_count[s] += 1
    V = np.zeros(n_states)
    for s in range(n_states):
        if returns_count[s] > 0:
            V[s] = returns_sum[s] / returns_count[s]
    return V

4. Пошаговый числовой пример

🔢 Пример 1. Ручной расчет шага Value Iteration в среде GridWorld

Рассмотрим цепочку из 3 клеток: $S_1 \leftrightarrow S_2 \to \text{Goal}$. Дисконт $\gamma = 0.9$.

  • В $S_1$: действие «Вправо» ведет в $S_2$ ($R=0$), действие «Влево» оставляет в $S_1$ ($R=0$).
  • В $S_2$: действие «Вправо» ведет в Goal ($R=+10$, терминал), действие «Влево» ведет в $S_1$ ($R=0$).
  • В Goal: $V(\text{Goal}) = 0$. Инициализация: $V_0(S_1) = 0, V_0(S_2) = 0$.

Итерация 1 ($k=1$):

  • $V_1(S_1) = \max(\text{влево}: 0 + 0.9 \cdot 0, \; \text{вправо}: 0 + 0.9 \cdot 0) = 0.0$
  • $V_1(S_2) = \max(\text{влево}: 0 + 0.9 \cdot 0, \; \text{вправо}: 10 + 0.9 \cdot 0) = 10.0$

Итерация 2 ($k=2$):

  • $V_2(S_1) = \max(\text{влево}: 0 + 0.9 \cdot 0, \; \text{вправо}: 0 + 0.9 \cdot V_1(S_2)) = \max(0, 0 + 0.9 \cdot 10.0) = 9.0$
  • $V_2(S_2) = \max(\text{влево}: 0 + 0.9 \cdot V_1(S_1), \; \text{вправо}: 10 + 0) = \max(0, 10.0) = 10.0$

Итерация 3 ($k=3$):

  • $V_3(S_1) = \max(0 + 0.9(9.0), 0 + 0.9(10.0)) = 9.0$
  • $V_3(S_2) = \max(0 + 0.9(9.0), 10.0) = \max(8.1, 10.0) = 10.0$

Алгоритм сошелся за 3 итерации: $V^*(S_1) = 9.0, V^*(S_2) = 10.0$. Оптимальная политика: $\pi^*(S_1) = \text{Вправо}, \pi^*(S_2) = \text{Вправо}$.

🔢 Пример 2. Обновление методом First-Visit Monte Carlo по эпизоду

Пусть сгенерирован эпизод: $(S_1, a, +1) \to (S_2, a, 0) \to (S_1, a, +2) \to (S_3, a, +10 \text{ term})$. Дисконт $\gamma = 1.0$. Текущие оценки: $V(S_1) = 5.0, V(S_2) = 8.0$. Шаг $\alpha = 0.5$.

  • Доход из первого посещения $S_1$ ($t=0$): $G_0 = R_1 + R_2 + R_3 + R_4 = 1 + 0 + 2 + 10 = 13.0$.
  • Доход из второго посещения $S_1$ ($t=2$): $G_2 = R_3 + R_4 = 2 + 10 = 12.0$.
  • Доход из $S_2$ ($t=1$): $G_1 = R_2 + R_3 + R_4 = 0 + 2 + 10 = 12.0$.

Обновление First-Visit MC для $S_1$ (берется только $G_0 = 13.0$):

$$ V(S_1) \leftarrow V(S_1) + \alpha (G_0 - V(S_1)) = 5.0 + 0.5 \cdot (13.0 - 5.0) = 5.0 + 0.5 \cdot 8.0 = 9.0 $$

Обновление для $S_2$:

$$ V(S_2) \leftarrow V(S_2) + \alpha (G_1 - V(S_2)) = 8.0 + 0.5 \cdot (12.0 - 8.0) = 8.0 + 0.5 \cdot 4.0 = 10.0 $$

Алгоритм Policy Iteration на Python

import numpy as np

def policy_iteration(P, R, gamma=0.9):
    n_states, n_actions, _ = P.shape
    policy = np.zeros(n_states, dtype=int)
    while True:
        P_pi = np.array([P[s, policy[s]] for s in range(n_states)])
        R_pi = np.array([R[s, policy[s]] for s in range(n_states)])
        V = np.linalg.solve(np.eye(n_states) - gamma * P_pi, R_pi)
        
        policy_stable = True
        for s in range(n_states):
            old_a = policy[s]
            q_sa = [R[s, a] + gamma * np.sum(P[s, a] * V) for a in range(n_actions)]
            new_a = int(np.argmax(q_sa))
            if new_a != old_a:
                policy_stable = False
            policy[s] = new_a
        if policy_stable:
            break
    return V, policy

5. Преимущества, недостатки и применимость

6. 🎯 Препод спросит

1. В чем ключевое отличие Policy Iteration от Value Iteration?

Policy Iteration на каждом шаге проводит полную оценку текущей стратегии до бесконечной сходимости $V_k \to V^\pi$ (решая линейную систему), после чего производит улучшение стратегии. Value Iteration объединяет оценку и улучшение в один-единственный итерационный шаг с оператором $\max$, не дожидаясь сходимости оценки промежуточных неоптимальных стратегий.

2. В чем разница между First-Visit MC и Every-Visit MC?

В First-Visit MC в оценку $V(s)$ включается доход $G_t$ только от первого появления состояния $s$ в рамках эпизода. Оценка First-Visit строго несмещенная (i.i.d. сэмплы). В Every-Visit MC усредняются доходы от всех посещений состояния $s$ внутри эпизода. Сэмплы внутри одного эпизода коррелируют, поэтому Every-Visit MC слегка смещен на малых выборках, но имеет меньшую среднеквадратичную ошибку (MSE) и асимптотически сходится к $V^\pi(s)$.

3. Почему методы Монте-Карло неприменимы в бесконечных непрерывных средах без терминальных состояний?

Потому что для вычисления эмпирического дохода $G_t = \sum_{k=0}^{T-t-1} \gamma^k R_{t+k+1}$ метод Монте-Карло обязан дождаться полного завершения эпизода (шага $T$). В бесконечной задаче без терминальных состояний эпизод никогда не заканчивается, и агент не может рассчитать $G_t$. Для бесконечных задач необходим бутстрэпинг (TD-обучение).

4. Что такое Bootstrapping в RL и почему Монте-Карло им не пользуется?

Бутстрэпинг (Bootstrapping) — это обновление текущей оценки ценности $V(s)$ на основе другой существующей оценки $V(s')$ следующего состояния без ожидания конца эпизода (как в Беллмане и TD). Монте-Карло не использует бутстрэпинг: он ждет реального завершения эпизода и обновляет оценку по честному накопленному доходу $G_t$.

5. В чем разница между Ordinary Importance Sampling и Weighted Importance Sampling?

Ordinary Importance Sampling делит сумму взвешенных доходов на общее число эпизодов $N$: $\frac{1}{N} \sum \rho G$. Оно строго несмещенное, но дисперсия может быть бесконечной из-за произведения отношений вероятностей $\prod \frac{\pi}{b}$. Weighted Importance Sampling делит на сумму весов $\frac{\sum \rho G}{\sum \rho}$. Оно слегка смещено (смещение $\to 0$ при $N \to \infty$), но дисперсия строго ограничена, что делает его предпочтительным на практике.

6. Какова вычислительная сложность одной итерации Value Iteration?

Сложность одного полного прохода Value Iteration составляет $O(|\mathcal{S}|^2 |\mathcal{A}|)$, так как для каждого состояния $s \in \mathcal{S}$ мы перебираем все действия $a \in \mathcal{A}$ и вычисляем сумму по всем возможным переходам $s' \in \mathcal{S}$. Если переходы разрежены (не более $k$ преемников), сложность снижается до $O(k |\mathcal{S}| |\mathcal{A}|)$.

7. Почему Policy Iteration сходится за меньшее число внешних итераций, чем Value Iteration?

Потому что число детерминированных стратегий в конечном MDP строго ограничено величиной $|\mathcal{A}|^{|\mathcal{S}|}$. На каждом шаге улучшения Теорема об улучшении стратегии гарантирует строгое возрастание $V^{\pi'}(s) > V^\pi(s)$ (если стратегия не оптимальна). Следовательно, стратегия никогда не повторяется, и алгоритм гарантированно находит точную $\pi^*$ за конечное (обычно очень небольшое) число шагов.

8. Как Монте-Карло решает проблему отсутствия модели среды?

Вместо математического ожидания по неизвестному тензору переходов $\sum_{s'} \mathcal{P}(s'|s, a)$, Монте-Карло использует закон больших чисел: среднее арифметическое фактических доходов $G_t$ по большому числу независимых эпизодов сходится по вероятности к истинному математическому ожиданию: $\frac{1}{N}\sum_{i=1}^N G_t^{(i)} \xrightarrow{P} V^\pi(s)$.

9. В чем суть компромисса Bias-Variance между DP и Monte Carlo?

DP имеет нулевую дисперсию (чистый детерминированный расчет), но страдает от смещения модели, если $\mathcal{P}$ и $\mathcal{R}$ неточны. Monte Carlo имеет нулевое смещение относительно истинной среды, но обладает чрезвычайно высокой дисперсией из-за накопления стохастичности на десятках шагов траектории, требуя огромного объема выборки.

10. Что такое асинхронное динамическое программирование (Asynchronous DP)?

Классический DP обновляет все состояния синхронно за один такт. Асинхронный DP обновляет состояния по отдельности в произвольном порядке (например, In-Place Value Iteration, Prioritized Sweeping или Real-Time DP). Это снижает требования к памяти и позволяет фокусировать вычисления только на состояниях, часто посещаемых агентом.

7. 📝 Микро-задачи с решениями

Задача 1. Расчет шага Policy Evaluation для 2 состояний

В среде с двумя состояниями $S_1, S_2$ зафиксирована стратегия $\pi$. Из $S_1$ переход в $S_2$ с $R=4$. Из $S_2$ переход в $S_1$ с $R=2$. Дисконт $\gamma = 0.5$. Начальные оценки $V_0(S_1) = 0, V_0(S_2) = 0$. Вычислите $V_1(S_1), V_1(S_2)$ и $V_2(S_1), V_2(S_2)$.

Решение

Итерация 1:

  • $V_1(S_1) = 4 + 0.5 \cdot V_0(S_2) = 4 + 0 = 4.0$
  • $V_1(S_2) = 2 + 0.5 \cdot V_0(S_1) = 2 + 0 = 2.0$

Итерация 2:

  • $V_2(S_1) = 4 + 0.5 \cdot V_1(S_2) = 4 + 0.5 \cdot 2.0 = 4 + 1.0 = 5.0$
  • $V_2(S_2) = 2 + 0.5 \cdot V_1(S_1) = 2 + 0.5 \cdot 4.0 = 2 + 2.0 = 4.0$

Ответ: $V_1 = (4.0, 2.0), V_2 = (5.0, 4.0)$.

Задача 2. Точная сходимость Policy Evaluation аналитически

Для системы из Задачи 1 найдите точные предельные значения $V^\pi(S_1)$ и $V^\pi(S_2)$ при $k \to \infty$.

Решение

Составляем систему уравнений Беллмана:

$$ \begin{cases} V(S_1) = 4 + 0.5 V(S_2) \\ V(S_2) = 2 + 0.5 V(S_1) \end{cases} $$

Подставляем второе в первое:

$$ V(S_1) = 4 + 0.5 (2 + 0.5 V(S_1)) = 4 + 1 + 0.25 V(S_1) = 5 + 0.25 V(S_1) $$ $$ 0.75 V(S_1) = 5 \implies V(S_1) = \frac{5}{0.75} = \frac{20}{3} \approx 6.6667 $$ $$ V(S_2) = 2 + 0.5 \left(\frac{20}{3}\right) = 2 + \frac{10}{3} = \frac{16}{3} \approx 5.3333 $$

Ответ: $V^\pi(S_1) = 20/3 \approx 6.67, V^\pi(S_2) = 16/3 \approx 5.33$.

Задача 3. Расчет шага улучшения стратегии (Policy Improvement)

В состоянии $s$ доступны два действия $a_1$ и $a_2$. Текущие оценки ценностей состояний: $V(s_1) = 10.0, V(s_2) = 20.0$. Действие $a_1$ ведет в $s_1$ с $R=5$. Действие $a_2$ ведет в $s_2$ с $R=1$. Фактор $\gamma = 0.9$. Какое действие выберет жадный шаг Policy Improvement?

Решение

Вычисляем $Q$-ценности:

  • $Q(s, a_1) = R_1 + \gamma V(s_1) = 5 + 0.9 \cdot 10.0 = 5 + 9.0 = 14.0$
  • $Q(s, a_2) = R_2 + \gamma V(s_2) = 1 + 0.9 \cdot 20.0 = 1 + 18.0 = 19.0$

Так как $Q(s, a_2) = 19.0 > Q(s, a_1) = 14.0$, жадная стратегия выберет действие $a_2$.

Ответ: $\pi_{\text{new}}(s) = a_2$ с $Q(s, a_2) = 19.0$.

Задача 4. First-Visit MC vs Every-Visit MC на зацикленном эпизоде

В эпизоде состояние $S_1$ встретилось трижды: на шагах $t=0, 1, 2$. Награды: $R_1 = 1, R_2 = 1, R_3 = 1, R_4 = 10$ (терминал). Дисконт $\gamma = 1.0$. Найдите доходы $G_0, G_1, G_2$. Какое значение пойдет в First-Visit MC, а какие в Every-Visit MC?

Решение

Рассчитываем доходы:

  • $G_0 = 1 + 1 + 1 + 10 = 13.0$ (первый визит, $t=0$)
  • $G_1 = 1 + 1 + 10 = 12.0$ (второй визит, $t=1$)
  • $G_2 = 1 + 10 = 11.0$ (третий визит, $t=2$)

First-Visit MC учитывает только первый визит: сэмпл $G = 13.0$.

Every-Visit MC усредняет все три сэмпла внутри эпизода: $G_{\text{avg}} = \frac{13 + 12 + 11}{3} = \frac{36}{3} = 12.0$.

Ответ: First-Visit: 13.0; Every-Visit: среднее 12.0.

Задача 5. Расчет веса Importance Sampling Ratio

Целевая стратегия $\pi$ в состояниях $S_0, S_1$ выбирает действие $a_1$ с вероятностью $\pi(a_1|S_0)=0.8, \pi(a_1|S_1)=0.9$. Поведенческая стратегия $b$ выбирает действия равномерно: $b(a_1|S_0)=0.5, b(a_1|S_1)=0.5$. Эпизод длины 2 совершил действия $(a_1, a_1)$ с итоговым доходом $G_0 = 10.0$. Чему равен взвешенный сэмпл $\rho_{0:1} G_0$ для Ordinary Importance Sampling?

Решение

Вычисляем коэффициент важности траектории:

$$ \rho_{0:1} = \frac{\pi(a_1 \mid S_0)}{b(a_1 \mid S_0)} \cdot \frac{\pi(a_1 \mid S_1)}{b(a_1 \mid S_1)} = \frac{0.8}{0.5} \cdot \frac{0.9}{0.5} = 1.6 \cdot 1.8 = 2.88 $$

Взвешенный доход: $\rho_{0:1} G_0 = 2.88 \cdot 10.0 = 28.8$.

Ответ: $\rho_{0:1} = 2.88, \rho G_0 = 28.8$.

Задача 6. Инкрементное среднее Monte Carlo

Текущая оценка $V(s) = 20.0$, накопленное число посещений $N(s) = 4$. Пришел новый эпизод с доходом $G = 30.0$. Обновите оценку $V(s)$ по формуле точного среднего $V \leftarrow V + \frac{1}{N}(G - V)$.

Решение

Новое число посещений: $N'(s) = 4 + 1 = 5$.

$$ V(s) \leftarrow 20.0 + \frac{1}{5} (30.0 - 20.0) = 20.0 + \frac{1}{5} \cdot 10.0 = 20.0 + 2.0 = 22.0 $$

Проверка: $\frac{20 \cdot 4 + 30}{5} = \frac{80 + 30}{5} = \frac{110}{5} = 22.0$.

Ответ: $V(s) = 22.0$.

8. ⚡ Скелет ответа по билету

Скелет устного ответа по билету 22 (ч. 2, Итерации по полезностям/стратегиям, Монте-Карло)
  1. Каркас GPI (Generalized Policy Iteration): Чередование процессов Policy Evaluation ($V \to V^\pi$) и Policy Improvement ($\pi \to \text{greedy}(V)$) до сходимости к оптимальной точке $(\pi^*, V^*)$.
  2. Policy Iteration (PI): 1) Полная оценка $V_{k+1}(s) = \sum \pi \sum \mathcal{P} [ \mathcal{R} + \gamma V_k(s') ]$ до сходимости; 2) Улучшение стратегии $\pi'(s) = \arg\max_a \sum \mathcal{P} [ \mathcal{R} + \gamma V(s') ]$. Сходится за малое число шагов.
  3. Теорема об улучшении стратегии: Если $Q^\pi(s, \pi'(s)) \ge V^\pi(s) \quad \forall s$, то $V^{\pi'}(s) \ge V^\pi(s)$.
  4. Value Iteration (VI): Объединение оценки и улучшения в один шаг с оператором $\max$: $V_{k+1}(s) \leftarrow \max_a \sum \mathcal{P} [ \mathcal{R} + \gamma V_k(s') ]$. Сходимость по сжатию Банаха.
  5. Методы Монте-Карло (MC): Обучение без модели ($\mathcal{P}$ неизвестна) на основе завершенных эпизодов по формуле $V(S_t) \leftarrow V(S_t) + \alpha (G_t - V(S_t))$. Несмещенно, но высокая дисперсия.
  6. First-Visit vs Every-Visit MC: First-Visit обновляет $V(s)$ только по первому вхождению $s$ в эпизод (i.i.d. сэмплы, строго несмещенная); Every-Visit обновляет по всем вхождениям (меньше дисперсия).
  7. Importance Sampling (Off-Policy): Коррекция распределений весом $\rho_{t:T-1} = \prod_{k=t}^{T-1} \frac{\pi(A_k|S_k)}{b(A_k|S_k)}$. Weighted Importance Sampling стабилизирует дисперсию.
