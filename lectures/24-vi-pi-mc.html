1. Интуиция и мотивация

Когда модель среды известна ($\mathcal{P}$ и $\mathcal{R}$ заданы), поиск оптимальной политики называется планированием (Planning) и решается методами динамического программирования (DP). Если модель неизвестна, агент обучается по сэмплированным траекториям методами Монте-Карло (Monte Carlo, MC).

💡 Две парадигмы оценивания ценности
  • Динамическое программирование (DP / Bootstrapping): Вычисляет $V(s)$ через математическое ожидание по ветвям преемников, опираясь на текущие оценки $V(s')$. Требует знания модели $\mathcal{P}$. Нулевая дисперсия, но зависит от точности модели.
  • Методы Монте-Карло (MC / Sampling): Оценивают $V(s)$ путём усреднения фактических накопленных доходов $G_t$ по завершённым эпизодам. Модель $\mathcal{P}$ не требуется. Оценка строго несмещённая ($\mathbb{E}[G_t] = V(s)$), но обладает высокой дисперсией.

2. Архитектура и схема

Generalized Policy Iteration (GPI) — концептуальный каркас RL, описывающий взаимодействие двух процессов:

  1. Policy Evaluation (Оценка): Фиксируем $\pi$, вычисляем $V \to V^\pi$.
  2. Policy Improvement (Улучшение): Фиксируем $V$, строим жадную стратегию $\pi \leftarrow \text{greedy}(V)$.
ОЦЕНКА СТРАТЕГИИ (Evaluation) V ───────────────────────────────▶ v^π ▲ │ │ │ УЛУЧШЕНИЕ │ │ СТРАТЕГИИ │ ▼ (Improvement) π* ◀─────────────────────────────── π' Сходимость в точке (π*, V*) GPI: Процессы оценки и улучшения сходятся к оптимальной паре $(\pi^*, V^*)$.
СРАВНЕНИЕ ПУТЕЙ ОБНОВЛЕНИЯ: Policy Iteration (PI): π_0 ──Eval (до сходимости V^π)──▶ V_0 ──Improve──▶ π_1 ──Eval──▶ V_1 ──Improve──▶ ... ──▶ π* Value Iteration (VI): V_0 ──1 шаг max_a──▶ V_1 ──1 шаг max_a──▶ V_2 ──1 шаг max_a──▶ ... ──▶ V* ──1 Improvement──▶ π* Monte Carlo (MC): Сэмплирование τ = (S_0, A_0, R_1, ..., S_T) ──▶ Накопление G_t ──▶ V(S_t) ← V(S_t) + α(G_t - V(S_t)) Policy Iteration оценивает стратегию полностью; Value Iteration делает 1 шаг $\max$; Monte Carlo учится по реальным эпизодам без модели.

3. Математический аппарат

1. Policy Iteration (Итерация по стратегиям)

Алгоритм чередует две фазы:

  1. Оценка (Policy Evaluation): Решение уравнения Беллмана до сходимости ($\max_s |V_{k+1}(s) - V_k(s)| < \theta$):
    $$ V_{k+1}(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s) \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma V_k(s') \right] $$
  2. Улучшение (Policy Improvement): Жадный выбор действия:
    $$ \pi_{\text{new}}(s) = \arg\max_{a \in \mathcal{A}} \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma V^\pi(s') \right] $$
📐 Теорема об улучшении стратегии (Policy Improvement Theorem)

Если для двух стратегий $\pi, \pi'$ выполняется $Q^\pi(s, \pi'(s)) \ge V^\pi(s) \quad \forall s \in \mathcal{S}$, то $V^{\pi'}(s) \ge V^\pi(s) \quad \forall s \in \mathcal{S}$.

Доказательство:

$$ V^\pi(s) \le Q^\pi(s, \pi'(s)) = \mathbb{E}_{\pi'} [R_{t+1} + \gamma V^\pi(S_{t+1}) \mid S_t = s] \le \mathbb{E}_{\pi'} [R_{t+1} + \gamma Q^\pi(S_{t+1}, \pi'(S_{t+1})) \mid S_t = s] \le \dots \le V^{\pi'}(s) $$

2. Value Iteration (Итерация по ценностям)

Value Iteration объединяет оценку и улучшение в один шаг обновления с оператором $\max$:

$$ V_{k+1}(s) \leftarrow \max_{a \in \mathcal{A}} \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma V_k(s') \right] $$

Остановка при $\max_s |V_{k+1}(s) - V_k(s)| < \frac{\epsilon(1-\gamma)}{2\gamma}$, гарантирующая $\|V_{k+1} - V^*\|_\infty \le \epsilon$. Затем $\pi^*(s) = \arg\max_a \sum_{s'} \mathcal{P}(s'|s, a) [\mathcal{R} + \gamma V^*(s')]$.

3. Методы Монте-Карло (Monte Carlo)

MC работает по завершённым эпизодам $\tau = (S_0, A_0, R_1, \dots, S_T)$ с $G_t = \sum_{k=0}^{T - t - 1} \gamma^k R_{t+k+1}$:

  • First-Visit MC: $V(s)$ обновляется только по первому визиту $s$ в эпизоде (строго несмещённая оценка).
  • Every-Visit MC: $V(s)$ обновляется по всем визитам $s$ в эпизоде (меньшая дисперсия).

Инкрементное обновление:

$$ V(S_t) \leftarrow V(S_t) + \alpha \left( G_t - V(S_t) \right) $$

4. Важностное сэмплирование (Importance Sampling)

При сборе данных по $b(a|s)$ и оценке $\pi(a|s)$ отношение важности равно $\rho_{t:T-1} = \prod_{k=t}^{T-1} \frac{\pi(A_k \mid S_k)}{b(A_k \mid S_k)}$:

  • Ordinary: $V(s) = \frac{\sum \rho G}{N}$ (несмещённое, неограниченная дисперсия).
  • Weighted: $V(s) = \frac{\sum \rho G}{\sum \rho}$ (небольшое смещение, ограниченная дисперсия).

5. Реализация Value Iteration и Monte Carlo на Python

import numpy as np

def run_value_iteration(P, R, gamma=0.9, theta=1e-6):
    n_states, n_actions, _ = P.shape
    V = np.zeros(n_states)
    while True:
        delta = 0.0
        for s in range(n_states):
            v_old = V[s]
            q_sa = [R[s, a] + gamma * np.sum(P[s, a] * V) for a in range(n_actions)]
            V[s] = np.max(q_sa)
            delta = max(delta, abs(v_old - V[s]))
        if delta < theta:
            break
    policy = np.zeros(n_states, dtype=int)
    for s in range(n_states):
        q_sa = [R[s, a] + gamma * np.sum(P[s, a] * V) for a in range(n_actions)]
        policy[s] = int(np.argmax(q_sa))
    return V, policy

def run_first_visit_mc(episodes, n_states, gamma=0.9):
    returns_sum = np.zeros(n_states)
    returns_count = np.zeros(n_states)
    for episode in episodes:
        G = 0.0
        visited = set()
        traj_returns = []
        for s, a, r in reversed(episode):
            G = r + gamma * G
            traj_returns.append((s, G))
        for s, g in reversed(traj_returns):
            if s not in visited:
                visited.add(s)
                returns_sum[s] += g
                returns_count[s] += 1
    V = np.zeros(n_states)
    for s in range(n_states):
        if returns_count[s] > 0:
            V[s] = returns_sum[s] / returns_count[s]
    return V

4. Пошаговый числовой пример

🔢 Пример 1. Расчёт Value Iteration в GridWorld

Цепочка $S_1 \leftrightarrow S_2 \to \text{Goal}$ при $\gamma = 0.9$:

  • В $S_1$: «влево» $\to S_1$ ($R=0$); «вправо» $\to S_2$ ($R=0$).
  • В $S_2$: «влево» $\to S_1$ ($R=0$); «вправо» $\to \text{Goal}$ ($R=10$). $V_0 = [0, 0]$.
  • $k=1$: $V_1(S_1) = 0$, $V_1(S_2) = \max(0, 10 + 0) = 10.0$.
  • $k=2$: $V_2(S_1) = \max(0, 0 + 0.9 \cdot 10) = 9.0$, $V_2(S_2) = 10.0$.
  • $k=3$: $V_3(S_1) = 9.0$, $V_3(S_2) = 10.0$ (сходимость: $\pi^*(S_1)=\text{вправо}, \pi^*(S_2)=\text{вправо}$).
🔢 Пример 2. Обновление First-Visit Monte Carlo

Эпизод: $(S_1, a, +1) \to (S_2, a, 0) \to (S_1, a, +2) \to (S_3, a, +10 \text{ term})$ при $\gamma = 1.0, \alpha = 0.5$, начальные $V(S_1)=5.0, V(S_2)=8.0$:

  • Первый визит $S_1$ ($t=0$): $G_0 = 1 + 0 + 2 + 10 = 13.0$.
  • Визит $S_2$ ($t=1$): $G_1 = 0 + 2 + 10 = 12.0$.
$$ V(S_1) \leftarrow 5.0 + 0.5 \cdot (13.0 - 5.0) = 9.0, \quad V(S_2) \leftarrow 8.0 + 0.5 \cdot (12.0 - 8.0) = 10.0 $$

Алгоритм Policy Iteration на Python

import numpy as np

def policy_iteration(P, R, gamma=0.9):
    n_states, n_actions, _ = P.shape
    policy = np.zeros(n_states, dtype=int)
    while True:
        P_pi = np.array([P[s, policy[s]] for s in range(n_states)])
        R_pi = np.array([R[s, policy[s]] for s in range(n_states)])
        V = np.linalg.solve(np.eye(n_states) - gamma * P_pi, R_pi)
        
        policy_stable = True
        for s in range(n_states):
            old_a = policy[s]
            q_sa = [R[s, a] + gamma * np.sum(P[s, a] * V) for a in range(n_actions)]
            new_a = int(np.argmax(q_sa))
            if new_a != old_a:
                policy_stable = False
            policy[s] = new_a
        if policy_stable:
            break
    return V, policy

6. 🎯 Препод спросит

1. В чем ключевое отличие Policy Iteration от Value Iteration?

Policy Iteration оценивает стратегию до полной сходимости $V \to V^\pi$ на каждом шаге перед улучшением. Value Iteration объединяет оценку и улучшение в 1 шаг с оператором $\max$, не дожидаясь точной оценки промежуточных стратегий.

2. В чем разница между First-Visit MC и Every-Visit MC?

First-Visit MC учитывает доход $G_t$ только от первого визита в состояние за эпизод (строго несмещённая оценка). Every-Visit MC усредняет доходы от всех визитов (сэмплы зависимы, но меньше MSE).

3. Почему методы Монте-Карло неприменимы в бесконечных непрерывных средах без терминальных состояний?

Для расчёта дохода $G_t = \sum \gamma^k R$ методу MC требуется дождаться окончания эпизода (шаг $T$). В бесконечных задачах эпизод не завершается, что требует бутстрэпинга (TD-обучение).

4. Что такое Bootstrapping в RL и почему Монте-Карло им не пользуется?

Бутстрэпинг — обновление оценки $V(s)$ на основе оценки следующего состояния $V(s')$. Монте-Карло не бутстрэпит, а использует честный накопленный доход $G_t$ по завершённому эпизоду.

5. В чем разница между Ordinary Importance Sampling и Weighted Importance Sampling?

Ordinary делит взвешенные доходы на число эпизодов $N$ (несмещённо, но дисперсия может быть бесконечной). Weighted делит на сумму весов $\sum \rho$ (небольшое смещение, но дисперсия строго ограничена).

6. Какова вычислительная сложность одной итерации Value Iteration?

$O(|\mathcal{S}|^2 |\mathcal{A}|)$, так как для каждого состояния $s$ перебираются действия $a$ и суммируются переходы по всем преемникам $s'$. Для разреженных сред — $O(k |\mathcal{S}| |\mathcal{A}|)$.

7. Почему Policy Iteration сходится за меньшее число внешних итераций, чем Value Iteration?

Число детерминированных стратегий конечно ($|\mathcal{A}|^{|\mathcal{S}|}$). Теорема об улучшении гарантирует $V^{\pi'} > V^\pi$, поэтому стратегии не повторяются и точный оптимум достигается за считанные шаги.

8. Как Монте-Карло решает проблему отсутствия модели среды?

Заменяет математическое ожидание по $\mathcal{P}$ выборочным средним доходов $G_t$ по закону больших чисел: $\frac{1}{N}\sum G_t^{(i)} \xrightarrow{P} V^\pi(s)$.

9. В чем суть компромисса Bias-Variance между DP и Monte Carlo?

DP имеет нулевую дисперсию (детерминированный расчёт), но чувствителен к ошибкам модели $\mathcal{P}$. MC свободен от смещения модели, но обладает высокой траекторной дисперсией.

10. Что такое асинхронное динамическое программирование (Asynchronous DP)?

Обновление состояний по отдельности в произвольном порядке (In-Place VI, Prioritized Sweeping) вместо синхронного прохода, экономя память и фокусируя ресурсы на ключевых состояниях.

7. 📝 Микро-задачи с решениями

Задача 1. Расчёт шага Policy Evaluation для 2 состояний

$S_1 \to S_2$ ($R=4$), $S_2 \to S_1$ ($R=2$) при $\gamma = 0.5, V_0 = [0, 0]$. Вычислите $V_1$ и $V_2$.

Решение

$V_1(S_1) = 4 + 0.5(0) = 4.0$, $V_1(S_2) = 2 + 0.5(0) = 2.0$.

$V_2(S_1) = 4 + 0.5(2.0) = 5.0$, $V_2(S_2) = 2 + 0.5(4.0) = 4.0$.

Ответ: $V_1 = (4.0, 2.0), V_2 = (5.0, 4.0)$.

Задача 2. Точная сходимость Policy Evaluation аналитически

Для системы из Задачи 1 найдите предельные $V^\pi(S_1)$ и $V^\pi(S_2)$.

Решение
$$ V(S_1) = 4 + 0.5(2 + 0.5 V(S_1)) = 5 + 0.25 V(S_1) \implies 0.75 V(S_1) = 5 \implies V(S_1) = \frac{20}{3} \approx 6.67 $$ $$ V(S_2) = 2 + 0.5(20/3) = \frac{16}{3} \approx 5.33 $$

Ответ: $V^\pi(S_1) = 20/3 \approx 6.67, V^\pi(S_2) = 16/3 \approx 5.33$.

Задача 3. Расчёт шага улучшения стратегии (Policy Improvement)

$V(s_1) = 10.0, V(s_2) = 20.0, \gamma = 0.9$. $a_1 \to s_1$ ($R=5$), $a_2 \to s_2$ ($R=1$). Какое действие выберет улучшение стратегии?

Решение

$Q(s, a_1) = 5 + 0.9 \cdot 10.0 = 14.0$. $Q(s, a_2) = 1 + 0.9 \cdot 20.0 = 19.0$. Так как $19.0 > 14.0$, выбирается $a_2$.

Ответ: $\pi_{\text{new}}(s) = a_2$ с $Q = 19.0$.

Задача 4. First-Visit MC vs Every-Visit MC на зацикленном эпизоде

Эпизод: $S_1$ встретилось на $t=0, 1, 2$ с $R_1=1, R_2=1, R_3=1, R_4=10$ ($\gamma = 1.0$). Найдите сэмплы First-Visit и Every-Visit.

Решение

$G_0 = 13.0, G_1 = 12.0, G_2 = 11.0$. First-Visit: $G = 13.0$. Every-Visit: среднее $\frac{13+12+11}{3} = 12.0$.

Ответ: First-Visit: 13.0; Every-Visit: 12.0.

Задача 5. Расчёт веса Importance Sampling Ratio

$\pi(a_1|S_0)=0.8, \pi(a_1|S_1)=0.9$, $b(a_1|S_0)=0.5, b(a_1|S_1)=0.5$. Для траектории $(a_1, a_1)$ с $G_0 = 10.0$ найдите $\rho_{0:1} G_0$.

Решение
$$ \rho_{0:1} = \frac{0.8}{0.5} \cdot \frac{0.9}{0.5} = 1.6 \cdot 1.8 = 2.88 \implies \rho G_0 = 2.88 \cdot 10.0 = 28.8 $$

Ответ: $\rho_{0:1} = 2.88, \rho G_0 = 28.8$.

Задача 6. Инкрементное среднее Monte Carlo

$V(s) = 20.0, N(s) = 4$. Пришёл доход $G = 30.0$. Обновите $V(s) \leftarrow V + \frac{1}{N}(G - V)$.

Решение
$$ N' = 5 \implies V(s) \leftarrow 20.0 + \frac{1}{5}(30.0 - 20.0) = 20.0 + 2.0 = 22.0 $$

Ответ: $V(s) = 22.0$.

8. ⚡ Скелет ответа по билету

Скелет ответа по билету 22 (ч. 2, Итерации по ценностям/стратегиям, Монте-Карло)
  1. Каркас GPI: Чередование Policy Evaluation ($V \to V^\pi$) и Policy Improvement ($\pi \to \text{greedy}(V)$) до сходимости к $(\pi^*, V^*)$.
  2. Policy Iteration: Полная оценка $V_{k+1}(s) = \sum \pi \sum \mathcal{P} [ \mathcal{R} + \gamma V_k(s') ]$ и улучшение $\pi'(s) = \arg\max_a \sum \mathcal{P} [ \mathcal{R} + \gamma V(s') ]$.
  3. Теорема об улучшении стратегии: Если $Q^\pi(s, \pi'(s)) \ge V^\pi(s) \quad \forall s$, то $V^{\pi'}(s) \ge V^\pi(s)$.
  4. Value Iteration: Объединение оценки и улучшения в 1 шаг с оператором $\max$: $V_{k+1}(s) \leftarrow \max_a \sum \mathcal{P} [ \mathcal{R} + \gamma V_k(s') ]$. Сжатие Банаха.
  5. Методы Монте-Карло: Обучение без модели по завершённым эпизодам: $V(S_t) \leftarrow V(S_t) + \alpha (G_t - V(S_t))$. Несмещённо, высокая дисперсия.
  6. First-Visit vs Every-Visit MC: First-Visit обновляет $V(s)$ только по первому визиту $s$ в эпизоде (несмещённая); Every-Visit — по всем вхождениям (меньше MSE).
  7. Importance Sampling: Коррекция распределений весом $\rho_{t:T-1} = \prod_{k=t}^{T-1} \frac{\pi(A_k|S_k)}{b(A_k|S_k)}$. Weighted Importance Sampling стабилизирует дисперсию.
