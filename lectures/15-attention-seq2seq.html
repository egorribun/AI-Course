1. Интуиция и мотивация

Классический Seq2Seq (Sutskever et al., 2014) сжимает входную фразу $(x_1, \dots, x_S)$ в единственный вектор фиксированной длины $h_S$.

КЛАССИЧЕСКИЙ SEQ2SEQ БЕЗ ВНИМАНИЯ (ИНФОРМАЦИОННОЕ УЗКОЕ ГОРЛЫШКО): x_1 ──▶ [ RNN ] ──▶ h_1 x_2 ──▶ [ RNN ] ──▶ h_2 Бутылочное горлышко (Вектор фиксированной длины!) ... ──▶ [ RNN ] ──▶ ... ───▶ [ h_S ] ───▶ Декодер генерирует y_1, y_2, ..., y_T x_S ──▶ [ RNN ] ──▶ h_S Информационное бутылочное горлышко: при длине $> 15\text{--}20$ слов метрика BLEU резко падает.
❌ Дефекты фиксированного контекста
  1. Потеря начала фразы: из-за рекуррентного сжатия RNN забывает ранние токены к моменту формирования $h_S$.
  2. Ограниченная ёмкость: невозможно упаковать сложное предложение в вектор из 256/512 чисел без потерь.
💡 Принцип динамического внимания (Bahdanau et al., 2014)

1. Сохранять все скрытые состояния энкодера $(h_1, \dots, h_S)$ как внешнюю память.

2. При генерации слова $y_t$ вычислять веса внимания $\alpha_{t, i}$ и формировать динамический вектор контекста: $c_t = \sum_{i=1}^S \alpha_{t, i} h_i$.

2. Архитектура и схема

Внимание служит дифференцируемым интерфейсом между памятью энкодера и состоянием декодера:

СХЕМА МЕХАНИЗМА ВНИМАНИЯ В SEQ2SEQ: Энкодер: h_1 h_2 h_3 h_S │ │ │ │ └──────┬──────┴──────┬──────┴──────┬──────┘ │ │ │ Оценки score(s_{t-1}, h_i) ▼ └───▶ [ Softmax ] ──▶ Веса внимания α_{t,1}, ..., α_{t,S} │ ▼ Вектор контекста c_t = ∑ α_{t,i} h_i │ Декодер: s_{t-1} ────────────────────┼──▶ [ Декодер RNN ] ──▶ Состояние s_t ──▶ Слово y_t На шаге $t$ декодер фокусируется на ключевых словах источника через взвешенный вектор $c_t$.

Матрица выравнивания (Alignment Matrix)

Матрица весов $\alpha_{t, i}$ размера $T \times S$ отражает синтаксические перестановки слов между языками (Soft Alignment):

[ 0.01 0.01 0.01 0.02 0.95 ] Мягкое выравнивание: наглядно демонстрирует инверсию порядка прилагательных и существительных.

3. Математический аппарат

Вычисление внимания на шаге декодера $t \in \{1, \dots, T\}$ состоит из трёх фаз:

1. Скоринг (Alignment Score)

Оценка соответствия между декодером и состоянием энкодера $h_i \in \mathbb{R}^{d_{\text{enc}}}$: $e_{t, i} = \text{score}(s, h_i)$.

2. Нормализация (Softmax)

$$ \alpha_{t, i} = \frac{\exp(e_{t, i})}{\sum_{k=1}^S \exp(e_{t, k})}, \quad \sum_{i=1}^S \alpha_{t, i} = 1, \quad \alpha_{t, i} \ge 0 $$

3. Агрегация контекста (Context Vector)

$$ c_t = \sum_{i=1}^S \alpha_{t, i} h_i $$

Сравнение: Bahdanau vs Luong

Параметр Аддитивное (Bahdanau, 2014) Мультипликативное (Luong, 2015)
Формула Score $e_{t, i} = v_a^\top \tanh\left( W_a s_{t-1} + U_a h_i \right)$ $$ e_{t, i} = \begin{cases} s_t^\top h_i & \text{(Dot)} \\ s_t^\top W_a h_i & \text{(General)} \\ v_a^\top \tanh(W_a [s_t; h_i]) & \text{(Concat)} \end{cases} $$
Состояние декодера $s_{t-1}$ (до шага RNN) $s_t$ (после шага RNN)
Выход $s_t = \text{RNN}(s_{t-1}, [y_{t-1}; c_t])$ $\tilde{s}_t = \tanh(W_c [c_t; s_t])$
Эффективность Высокая сложность (два умножения, $\tanh$) Быстрое матричное умножение на GPU (GEMM)

4. Пошаговый числовой пример

Один шаг Luong Dot Attention ($e_{t, i} = s_t^\top h_i$):

Вход: $s_t = [1.0, \, 2.0]^\top$. Память энкодера ($S=3$): $h_1 = [2.0, \, 0.0]^\top$, $h_2 = [0.0, \, 1.0]^\top$, $h_3 = [1.0, \, 1.0]^\top$.

Пошаговый расчёт:

  1. Dot-Product Scores:
    • $e_1 = s_t^\top h_1 = 1.0(2.0) + 2.0(0.0) = \mathbf{2.0}$.
    • $e_2 = s_t^\top h_2 = 1.0(0.0) + 2.0(1.0) = \mathbf{2.0}$.
    • $e_3 = s_t^\top h_3 = 1.0(1.0) + 2.0(1.0) = \mathbf{3.0}$.
  2. Softmax:
    • $\exp(e_1) = e^2 \approx 7.3891, \quad \exp(e_2) = e^2 \approx 7.3891, \quad \exp(e_3) = e^3 \approx 20.0855$.
    • $\sum \exp = 7.3891 + 7.3891 + 20.0855 = \mathbf{34.8637}$.
    • $\alpha_1 = \frac{7.3891}{34.8637} \approx \mathbf{0.2119}, \quad \alpha_2 = \mathbf{0.2119}, \quad \alpha_3 = \frac{20.0855}{34.8637} \approx \mathbf{0.5762}$.
  3. Вектор контекста $c_t = \sum \alpha_i h_i$:
    • 1-я компонента: $0.2119(2.0) + 0.2119(0.0) + 0.5762(1.0) = \mathbf{1.0000}$.
    • 2-я компонента: $0.2119(0.0) + 0.2119(1.0) + 0.5762(1.0) = \mathbf{0.7881}$.
    • Итог: $c_t = [1.0000, \, 0.7881]^\top$.

Реализация внимания Луонга на PyTorch

import torch
import torch.nn as nn
import torch.nn.functional as F

class LuongAttention(nn.Module):
    def __init__(self, hidden_dim: int):
        super().__init__()
        self.hidden_dim = hidden_dim
        self.W = nn.Linear(hidden_dim, hidden_dim, bias=False)

    def forward(self, decoder_state: torch.Tensor, encoder_outputs: torch.Tensor, mask: torch.Tensor = None) -> tuple[torch.Tensor, torch.Tensor]:
        # decoder_state: [B, 1, d], encoder_outputs: [B, S, d]
        projected_enc = self.W(encoder_outputs)
        scores = torch.bmm(decoder_state, projected_enc.transpose(1, 2))
        
        if mask is not None:
            scores = scores.masked_fill(mask == 0, -1e9)
            
        attn_weights = F.softmax(scores, dim=-1)
        context = torch.bmm(attn_weights, encoder_outputs)
        return context.squeeze(1), attn_weights.squeeze(1)

5. Преимущества, недостатки и применимость

Тип механизма Сложность Преимущества Недостатки Применимость
Seq2Seq без внимания $O(S + T)$ Простая модель, $O(1)$ памяти на инференсе. Деградация качества при $S > 15$. Устарела; короткие команды.
Global Attention (Bahdanau/Luong) $O(S \cdot T)$ Прямой доступ ко всему входу, путь градиента $O(1)$. Квадратичный рост памяти при больших $S, T$. Перевод, ASR, суммаризация средних текстов.
Local Attention (Оконное) $O(D \cdot T)$ ($D \ll S$) Линейная масштабируемость по окну $[p_t - D, p_t + D]$. Теряет контекст вне окна $2D$. Длинные аудиозаписи и документы.
Self-Attention (Transformer) $O(T^2 \cdot d)$ Полный параллелизм на GPU, отказ от рекуррентности. Квадратичная память по длине контекста. Современные LLM (BERT, GPT, T5, LLaMA).

6. 🎯 Препод спросит

В чём фундаментальное отличие Bahdanau Attention от Luong Attention?

1. Скоринг: Bahdanau использует аддитивный перцептрон $v_a^\top \tanh(W_a s_{t-1} + U_a h_i)$, а Luong — скалярное произведение $s_t^\top h_i$ или билинейную форму $s_t^\top W_a h_i$.
2. Время: Bahdanau берёт $s_{t-1}$ (до шага RNN), Luong — $s_t$ (после шага RNN).

По какой размерности вычисляется Softmax при расчёте весов внимания в Seq2Seq?

Softmax всегда вычисляется по длине входной последовательности энкодера $S$ (Source Length). На каждом шаге декодера сумма весов равна единице: $\sum_{i=1}^S \alpha_{t, i} = 1$.

Почему механизм внимания называют дифференцируемым поиском по словарю (Differentiable Key-Value Lookup)?

Запрос (Query, $s_{t-1}$) непрерывно сравнивается со всеми ключами (Keys, $h_i$), формируя веса через Softmax. Результат — непрерывная взвешенная сумма значений (Values, $h_i$), пропускающая градиенты Backpropagation сквозным образом.

Какова размерность вектора контекста $c_t$ и зависит ли она от длины входа $S$?

Размерность $c_t$ равна $d_{\text{enc}}$ (или $2 d_{\text{enc}}$ для biLSTM) и не зависит от $S$, так как суммирование по оси $S$ схлопывает это измерение.

Что показывает матрица выравнивания (Alignment Matrix) при переводе на язык с другим порядком слов?

Матрица $\alpha_{t, i}$ размера $T \times S$ визуализирует Soft Alignment. При прямом порядке слов веса идут по диагонали; при инверсиях (например, прилагательное после существительного) диагональ локально смещается, фиксируя перестановку.

В чём преимущество Local Attention перед Global Attention?

Global Attention требует $O(S \cdot T)$ операций. Local Attention находит центр $p_t$ и вычисляет внимание только в окне $[p_t - D, p_t + D]$, снижая сложность до $O(D \cdot T)$ для длинных текстов.

Какова максимальная длина пути градиента в Seq2Seq с вниманием по сравнению с классической RNN?

В классической RNN путь градиента равен $O(S + T)$ шагам (затухание). В модели с вниманием вектор $c_t$ связывает декодер с любым $h_i$ напрямую за $O(1)$ шаг без затухания.

Зачем вектор контекста $c_t$ объединяется с состоянием декодера $s_t$ перед генерацией?

Это даёт классификатору одновременный доступ к грамматическому контексту перевода ($s_t$) и семантическому содержанию фрагмента оригинала ($c_t$).

Сравните функции скоринга: Bahdanau, Luong General и Scaled Dot-Product.

1. Bahdanau: $v_a^\top \tanh(W_a q + U_a k)$ — перцептрон, тяжело для GPU.
2. Luong General: $q^\top W_a k$ — быстрый GEMM на GPU, требует $d_q \times d_k$ параметров.
3. Scaled Dot-Product: $\frac{q^\top k}{\sqrt{d_k}}$ — 0 параметров внутри скоринга, масштабирование стабилизирует Softmax.

Как по матрице выравнивания выявить пропуск слов, зацикливание и галлюцинации?

• Пропуск слов: столбец $j$, где все $\alpha_{t, j} \approx 0$.
• Зацикливание: повторный фокус на одном участке входа.
• Галлюцинации: равномерное размытие ($\alpha_{t, i} \approx 1/S$) или фокус только на пунктуации.

7. 📝 Микро-задачи с решениями

Задача 1. Ручной расчёт вектора контекста $c_t$

Состояния: $h_1 = [1.0, 0.0]^\top, h_2 = [0.0, 2.0]^\top, h_3 = [1.0, 1.0]^\top$. Веса: $\alpha_1 = 0.5, \alpha_2 = 0.3, \alpha_3 = 0.2$. Найдите $c_t$.

Решение

Формула $c_t = \sum \alpha_i h_i$:

  • 1-я: $0.5(1.0) + 0.3(0.0) + 0.2(1.0) = 0.5 + 0.2 = \mathbf{0.7}$.
  • 2-я: $0.5(0.0) + 0.3(2.0) + 0.2(1.0) = 0.6 + 0.2 = \mathbf{0.8}$.

Ответ: $c_t = [0.7, \, 0.8]^\top$.

Задача 2. Расчёт весов Softmax Luong Dot-Product

Состояние декодера $s_t = [1.0, 1.0]^\top$. Состояния энкодера: $h_1 = [2.0, 0.0]^\top, h_2 = [1.0, 2.0]^\top$. Найдите $e_1, e_2$ и $\alpha_1, \alpha_2$.

Решение

1. Scores: $e_1 = s_t^\top h_1 = 2.0$, $e_2 = s_t^\top h_2 = 1.0(1.0) + 1.0(2.0) = 3.0$.
2. Softmax: $\exp(2) \approx 7.389$, $\exp(3) \approx 20.085$. Сумма $= 27.474$.
$\alpha_1 = \frac{7.389}{27.474} \approx \mathbf{0.269}, \quad \alpha_2 = \frac{20.085}{27.474} \approx \mathbf{0.731}$.

Задача 3. Размерности тензоров в Batch Matrix Multiplication (BMM)

Батч $B=16$, $S=40$, $d=128$. Тензор весов $(16, 1, 40)$, тензор выходов энкодера $(16, 40, 128)$. Какова форма результата `torch.bmm`?

Решение

$(B, 1, S) \times (B, S, d) \to (B, 1, d) = (16, 1, 128) \xrightarrow{\text{squeeze}(1)} \mathbf{(16, 128)}$.

Задача 4. Подсчёт параметров слоя Bahdanau Attention

$d_{\text{dec}} = 256, d_{\text{enc}} = 512, d_{\text{attn}} = 256$. Сколько обучаемых весов в слое (без bias)?

Решение

1. $W_a$: $256 \times 256 = 65\,536$.
2. $U_a$: $512 \times 256 = 131\,072$.
3. $v_a$: $256 \times 1 = 256$.
Итого: $65\,536 + 131\,072 + 256 = \mathbf{196\,864}$.

Задача 5. Вычислительная сложность Global vs Local Attention

$S=1000, T=1000$. Число операций score при Global Attention vs Local Attention ($D=10$)?

Решение

1. Global: $S \times T = 1000 \times 1000 = \mathbf{1\,000\,000}$.
2. Local: $(2D + 1) \times T = 21 \times 1000 = \mathbf{21\,000}$ (в 48 раз меньше).

Задача 6. Маскирование Padding-токенов в Attention

Батч дополнен нулями до $S=10$, реальная длина 4 токена. Чем заполнить позиции $5\dots10$ перед Softmax, чтобы их веса были равны 0?

Решение

Значением $-\infty$ (`-1e9` в коде). Так как $e^{-\infty} = 0$, веса паддинга после $\text{Softmax}$ станут строго равны $0.0$, исключая их влияние на $c_t$.

8. ⚡ Скелет ответа по билету

Скелет ответа по билету 14 (Механизм внимания в Seq2Seq)
  1. Проблема Seq2Seq: сжатие всей последовательности в единственный вектор $h_S$ (бутылочное горлышко при $S > 15$).
  2. Решение: сохранение всех состояний $(h_1, \dots, h_S)$ и динамический вектор контекста $c_t = \sum \alpha_{t, i} h_i$.
  3. 3 этапа внимания: 1) Скоринг $e_{t, i} = \text{score}(s, h_i)$; 2) Softmax по оси $S$: $\alpha_{t, i}$; 3) Взвешенная сумма $c_t = \sum \alpha_{t, i} h_i$.
  4. Внимание Бахданау (2014): аддитивный перцептрон $v_a^\top \tanh(W_a s_{t-1} + U_a h_i)$ до шага RNN.
  5. Внимание Луонга (2015): мультипликативный скоринг ($s_t^\top h_i$ или $s_t^\top W_a h_i$) после шага RNN.
  6. Матрица выравнивания: карта $\alpha_{t, i}$ размера $T \times S$, отражающая синтаксические перестановки слов.
  7. Global vs Local: Global охватывает все $S$ токенов ($O(S \cdot T)$); Local фокусируется в окне $[p_t - D, p_t + D]$ ($O(D \cdot T)$).
  8. Путь градиента: сокращение расстояния между любыми токенами с $O(S)$ до прямого контакта $O(1)$.
  9. Связь с Transformer: внимание доказало самодостаточность («Attention is all you need»), устранив необходимость в RNN.
