1. Проблема бутылочного горлышка в Seq2Seq

В классической архитектуре Seq2Seq (Sutskever et al. 2014, Cho et al. 2014) энкодер последовательно обрабатывает входную фразу $(x_1, x_2, \dots, x_S)$ и сжимает всю информацию в один вектор фиксированной размерности — финальное скрытое состояние $h_S$ (Context Vector):

БЕЗ ВНИМАНИЯ (КЛАССИЧЕСКИЙ SEQ2SEQ): x_1 ──▶ [ RNN ] ──▶ h_1 x_2 ──▶ [ RNN ] ──▶ h_2 Бутылочное горлышко (Вектор фиксированной длины!) ... ──▶ [ RNN ] ──▶ ... ───▶ [ h_S ] ───▶ Декодер генерирует y_1, y_2, ..., y_T x_S ──▶ [ RNN ] ──▶ h_S Информационное бутылочное горлышко: при длине предложения > 15–20 слов качество перевода (BLEU) стремительно падает.
❌ В чем дефект фиксированного контекста?
  1. Потеря информации о начале фразы: Из-за экспоненциального сжатия скрытого состояния RNN забывает первые слова предложения к моменту формирования $h_S$.
  2. Несоответствие размерности: Невозможно упаковать смысл предложения из 5 слов и сложного научного абзаца из 50 слов в один и тот же вектор размерности 256 без колоссальных потерь.

2. Идея динамического внимания (Bahdanau et al., 2014)

Дмитрий Бахданау, Кёнхён Чо и Йошуа Бенжио (ICLR 2015) предложили революционную концепцию:

💡 Принцип работы внимания (Attention)

1. Сохранить все: Мы не выбрасываем промежуточные скрытые состояния энкодера $(h_1, h_2, \dots, h_S)$, а сохраняем их в памяти.

2. Динамический фокус: При генерации каждого конкретного выходного слова $y_t$ декодер «смотрит» на все состояния энкодера, вычисляет степень их важности (веса $\alpha_{t, i}$) и собирает индивидуальный вектор контекста $c_t$ как взвешенную сумму:

$$ c_t = \sum_{i=1}^S \alpha_{t, i} h_i $$
СХЕМА МЕХАНИЗМА ВНИМАНИЯ В SEQ2SEQ: Энкодер: h_1 h_2 h_3 h_4 │ │ │ │ └──────┬──────┴──────┬──────┴──────┬──────┘ │ │ │ Оценки score(s_{t-1}, h_i) ▼ └───▶ [ Softmax ] ──▶ Веса внимания α_{t,1}, ..., α_{t,4} │ ▼ Вектор контекста c_t = ∑ α_{t,i} h_i │ Декодер: s_{t-1} ────────────────────┼──▶ [ Декодер RNN ] ──▶ Состояние s_t ──▶ Слово y_t На каждом шаге $t$ декодер формирует уникальный вектор $c_t$, сфокусированный на релевантных словах источника.

3. Математический аппарат: Score, Softmax и Context Vector

Вычисление внимания состоит из трех последовательных шагов на каждом такте времени $t$ декодера:

Шаг 1: Вычисление функции соответствия (Score / Energy)

Функция $e_{t, i} = \text{score}(s_{t-1}, h_i)$ оценивает, насколько скрытое состояние энкодера $h_i$ в позиции $i$ подходит к текущему состоянию декодера $s_{t-1}$.

Шаг 2: Нормализация через Softmax (Attention Weights)

Превращаем сырые скаляры $e_{t, i}$ в вероятностное распределение весов по входной длине $S$:

$$ \alpha_{t, i} = \frac{\exp(e_{t, i})}{\sum_{k=1}^S \exp(e_{t, k})}, \quad \sum_{i=1}^S \alpha_{t, i} = 1, \quad \alpha_{t, i} \ge 0 $$ $\alpha_{t, i}$ — степень внимания (коэффициент важности) $i$-го слова входа при генерации $t$-го слова выхода.

Шаг 3: Взвешенная сумма (Context Vector)

$$ c_t = \sum_{i=1}^S \alpha_{t, i} h_i $$ Вектор $c_t \in \mathbb{R}^{d_{\text{enc}}}$ подается в декодер вместе с эмбеддингом предыдущего слова.

4. Bahdanau (Additive) vs Luong (Multiplicative) Attention

В литературе и на экзамене выделяют две классические формулировки внимания:

5. Матрица выравнивания (Alignment Matrix) и интерпретируемость

Собрав все веса внимания $\alpha_{t, i}$ для всех шагов генерации $t \in \{1, \dots, T\}$ и входов $i \in \{1, \dots, S\}$, мы получаем двумерную матрицу выравнивания (Alignment Matrix) размера $T \times S$.

🔍 Мягкое выравнивание (Soft Alignment)

В отличие от классического статистического перевода (IBM Models), где выравнивание было дискретным и жестким (Hard Alignment), нейросетевое внимание является дифференцируемым (Soft Attention): оно обучается сквозным методом градиентного спуска (End-to-End) без ручной разметки соответствий!

6. Global Attention vs Local Attention

  • Global Attention: На каждом шаге $t$ декодер вычисляет веса по абсолютно всем $S$ токенам энкодера. Плюс: видит всю фразу. Минус: вычислительная сложность $O(S \cdot T)$, дорого для длинных текстов.
  • Local Attention (Luong et al., 2015): Модель предсказывает центральную позицию $p_t$ во входной последовательности и вычисляет внимание только в узком симметричном окне $[p_t - D, \, p_t + D]$ с гауссовским затуханием. Это снижает затраты до $O(D \cdot T)$.

7. Мостик к Трансформерам: почему внимание убило рекуррентность

Механизм внимания задумывался лишь как вспомогательный «костыль» для RNN, помогающий передавать контекст. Однако ученые быстро осознали два фундаментальных факта:

  1. Длина пути градиента: В RNN сигнал проходит расстояние $O(S)$ шагов через цепочку умножений. В механизме внимания между любым входным словом $i$ и любым выходным словом $t$ расстояние взаимодействия равно строго $O(1)$ (прямое скалярное произведение).
  2. Параллелизм: Вычисление внимания между всеми парами слов — это просто матричное умножение $QK^T$, которое выполняется на GPU мгновенно параллельно для всей последовательности.

Это привело команду Google к эпохальной идее статьи 2017 года: «Attention is all you need» — полностью выбросить рекуррентные слои RNN/LSTM и оставить только внимание (Transformer)!

8. Практическая реализация на PyTorch

Модуль внимания Бахданау (Additive Attention) на чистом PyTorch:

import torch
import torch.nn as nn
import torch.nn.functional as F

class BahdanauAttention(nn.Module):
    def __init__(self, hidden_size):
        super().__init__()
        # Проекции для состояния декодера и состояний энкодера
        self.W_dec = nn.Linear(hidden_size, hidden_size, bias=False)
        self.W_enc = nn.Linear(hidden_size, hidden_size, bias=False)
        self.v = nn.Linear(hidden_size, 1, bias=False)

    def forward(self, decoder_hidden, encoder_outputs):
        # decoder_hidden: (B, hidden_size)
        # encoder_outputs: (B, S, hidden_size)
        
        # 1. Расширяем decoder_hidden до (B, 1, hidden_size) для broadcast
        dec_proj = self.W_dec(decoder_hidden).unsqueeze(1)
        enc_proj = self.W_enc(encoder_outputs)
        
        # 2. Вычисляем score: e_{t, i} = v^T * tanh(W_dec*s + W_enc*h)
        energy = torch.tanh(dec_proj + enc_proj) # (B, S, hidden_size)
        scores = self.v(energy).squeeze(-1)      # (B, S)
        
        # 3. Softmax по длине входной последовательности S
        attn_weights = F.softmax(scores, dim=-1) # (B, S)
        
        # 4. Взвешенная сумма: context = sum(alpha_i * h_i)
        # (B, 1, S) x (B, S, hidden_size) -> (B, 1, hidden_size)
        context = torch.bmm(attn_weights.unsqueeze(1), encoder_outputs).squeeze(1)
        
        return context, attn_weights

🎯 Препод спросит

В чем фундаментальное отличие Bahdanau Attention от Luong Attention?

1. Математическая форма: Bahdanau использует аддитивный скоринг через однослойный перцептрон $v^T \tanh(W s + U h)$, а Luong — мультипликативный скоринг через скалярное произведение $s^T W h$.
2. Порядок вычислений: Bahdanau считает внимание на основе состояния декодера с предыдущего шага $s_{t-1}$ (до вычисления шага RNN), а Luong берет уже вычисленное текущее состояние $s_t$.

По какой размерности вычисляется Softmax при расчете весов внимания в Seq2Seq?

Softmax всегда вычисляется по длине входной последовательности энкодера $S$ (Source Length). На каждом шаге декодера сумма весов по всем $S$ словам входа должна быть строго равна $1$: $\sum_{i=1}^S \alpha_{t, i} = 1$.

Почему механизм внимания называют дифференцируемым поиском по словарю (Differentiable Key-Value Lookup)?

В обычном словаре мы ищем точное совпадение ключа $K$ по запросу $Q$ и возвращаем дискретное значение $V$. В механизме внимания запрос $Q$ сравнивается со всеми ключами $K_i$ непрерывно (через скалярное произведение / softmax), возвращая взвешенную сумму значений $\sum \alpha_i V_i$. Так как все операции непрерывны, через такой «поиск» свободно протекают градиенты.

Какова размерность вектора контекста $c_t$ и зависит ли она от длины входного предложения $S$?

Размерность вектора $c_t$ равна размерности скрытого состояния энкодера $d_{\text{hidden}}$ (или $2 d_{\text{hidden}}$ при biLSTM). Она абсолютно не зависит от входной длины $S$, так как операция взвешенного суммирования схлопывает измерение $S$.

Что показывает матрица выравнивания (Alignment Matrix) при переводе на язык с другим порядком слов?

Для языков с прямым порядком слов матрица имеет яркую главную диагональ. При инверсиях (например, в немецком глагол в конце придаточного предложения или во французском прилагательное после существительного) диагональ локально смещается или идет перпендикулярно, точно указывая на синтаксические перестановки.

В чем преимущество Local Attention перед Global Attention?

Global Attention вычисляет веса по всей длине входа $S$, что требует $O(S)$ вычислений на каждый выходной токен. Local Attention выбирает окно фиксированной ширины $2D$ вокруг предсказанной позиции $p_t$, снижая вычислительную сложность и затраты памяти до $O(D)$, что критично для обработки длинных текстов.

Какова длина пути градиента (Maximum Path Length) в Seq2Seq с вниманием по сравнению с обычной RNN?

В обычной RNN длина пути между первым входным токеном $x_1$ и последним сгенерированным токеном $y_T$ равна $O(S + T)$ шагов через цепочку нелинейностей. В Seq2Seq с вниманием вектор контекста $c_t$ соединяет состояние $h_1$ с декодером напрямую за $O(1)$ шаг.

Зачем вектору контекста $c_t$ конкатенироваться с выходом декодера перед финальным линейным слоем?

Это дает финальному классификатору слов одновременный доступ как к информации о текущей структуре целевого языка (из состояния декодера $s_t$), так и к семантике исходного предложения (из вектора контекста $c_t$).

Сравните три основные функции скоринга внимания: аддитивное (Bahdanau), мультипликативное (Luong) и Scaled Dot-Product. В чем их вычислительные компромиссы?

Три функции оценки сходства запроса $q \in \mathbb{R}^{d_q}$ и ключа $k \in \mathbb{R}^{d_k}$:

  1. Аддитивное (Bahdanau): $\text{score}(q, k) = v_a^\top \tanh(W_a q + U_a k)$. Вычислительно наиболее дорогое: требует двух матричных умножений, сложения векторов и вычисления нелинейности $\tanh$, что создает накладные расходы по памяти и не оптимизируется в единое GEMM-ядро на GPU.
  2. Мультипликативное (Luong General): $\text{score}(q, k) = q^\top W_a k$. Выполняется как произведение матриц $Q W_a K^\top$. Эффективно утилизирует тензорные ядра GPU, но при совпадении размерностей требует $d_q \times d_k$ обучаемых параметров.
  3. Scaled Dot-Product (Vaswani et al.): $\text{score}(q, k) = \frac{q^\top k}{\sqrt{d_k}}$ (при $d_q = d_k$). Не требует дополнительных параметров внутри скоринга, сводится к быстрому матричному умножению $Q K^\top$, а коэффициент $\frac{1}{\sqrt{d_k}}$ предотвращает насыщение Softmax.

При наличии масштабирующего множителя Scaled Dot-Product дает сопоставимое с аддитивным качеством выравнивание при значительно более высокой скорости и меньших затратах памяти.

Как по тепловой карте матрицы выравнивания (Alignment Matrix) диагностировать типичные ошибки машинного перевода (галлюцинации, пропуски, зацикливания)?

Матрица весов внимания $\alpha \in \mathbb{R}^{T \times S}$ (где строки $T$ — токены перевода, столбцы $S$ — токены оригинала) служит ключевым инструментом интерпретации Seq2Seq моделей:

  • Качественный перевод: Четкая непрерывная диагональная траектория с локальными перестановками в местах грамматических инверсий (высокая уверенность, низкая энтропия распределения на каждом шаге).
  • Пропуск слов (Under-translation): Вертикальный столбец $j$, в котором все веса $\alpha_{t, j} \approx 0$ для всех $t \in [1, T]$. Декодер полностью проигнорировал $j$-е слово входа.
  • Зацикливание и повторы (Repetition loop): Декодер генерирует одинаковые токены, а строки матрицы внимания многократно фокусируются на одном и том же узком диапазоне столбцов исходного предложения.
  • Галлюцинации (Hallucinations): Размытое, почти равномерное распределение внимания ($\alpha_{t, i} \approx \frac{1}{S}$ по всем $i$), либо фокус исключительно на токенах пунктуации. Декодер теряет связь с исходным контекстом и генерирует текст исключительно за счет своей внутренней языковой модели.

📝 Микро-задачи

Задача 1. Ручной расчет вектора контекста $c_t$

Энкодер выдал 3 вектора скрытых состояний: $h_1 = [1.0, 0.0]$, $h_2 = [0.0, 2.0]$, $h_3 = [1.0, 1.0]$. Веса внимания составили $\alpha_1 = 0.5$, $\alpha_2 = 0.3$, $\alpha_3 = 0.2$. Найдите вектор контекста $c_t$.

Решение

Формула: $c_t = \alpha_1 h_1 + \alpha_2 h_2 + \alpha_3 h_3$.

$$ c_t = 0.5 \cdot [1.0, 0.0] + 0.3 \cdot [0.0, 2.0] + 0.2 \cdot [1.0, 1.0] $$

1-я компонента: $0.5 \cdot 1.0 + 0.3 \cdot 0.0 + 0.2 \cdot 1.0 = 0.5 + 0.2 = 0.7$.

2-я компонента: $0.5 \cdot 0.0 + 0.3 \cdot 2.0 + 0.2 \cdot 1.0 = 0.6 + 0.2 = 0.8$.

$$ c_t = [0.7, \, 0.8] $$

Задача 2. Расчет весов Softmax Luong Dot-Product

Состояние декодера $s_t = [1.0, 1.0]$. Состояния энкодера: $h_1 = [2.0, 0.0]$, $h_2 = [1.0, 2.0]$. Найдите сырые score $e_1, e_2$ и веса внимания $\alpha_1, \alpha_2$.

Решение

1. Скалярные произведения (Dot score):

$e_1 = s_t \cdot h_1 = 1.0 \cdot 2.0 + 1.0 \cdot 0.0 = 2.0$.

$e_2 = s_t \cdot h_2 = 1.0 \cdot 1.0 + 1.0 \cdot 2.0 = 3.0$.

2. Softmax:

$\exp(e_1) = e^2 \approx 7.389$, $\exp(e_2) = e^3 \approx 20.085$.

Сумма: $7.389 + 20.085 = 27.474$.

$\alpha_1 = \frac{7.389}{27.474} \approx 0.269$ ($26.9\%$).

$\alpha_2 = \frac{20.085}{27.474} \approx 0.731$ ($73.1\%$).

Задача 3. Размерности тензоров в Batch Matrix Multiplication (BMM)

Батч $B=16$. Длина входа $S=40$, размерность энкодера $d=128$. Тензор весов внимания имеет форму $(16, 1, 40)$, тензор выходов энкодера — $(16, 40, 128)$. Какова форма результата `torch.bmm`?

Решение

Операция умножения матриц батча: $(B, 1, S) \times (B, S, d) \to (B, 1, d)$.

Результат имеет размерность $(16, 1, 128)$. После вызова `.squeeze(1)` получаем батч векторов контекста $(16, 128)$.

Задача 4. Подсчет параметров слоя Bahdanau Attention

Размерность скрытого состояния декодера $d_{\text{dec}} = 256$, энкодера $d_{\text{enc}} = 512$. В слое Bahdanau Attention размерность проекции $d_{\text{attn}} = 256$. Сколько обучаемых весов в слое (без bias)?

Решение

1. Матрица $W_{\text{dec}}$: $256 \times 256 = 65\,536$.

2. Матрица $W_{\text{enc}}$: $512 \times 256 = 131\,072$.

3. Вектор $v$: $256 \times 1 = 256$.

$$ \text{Итого параметров} = 65\,536 + 131\,072 + 256 = 196\,864 $$

Задача 5. Сложность вычисления внимания

Входная последовательность имеет длину $S=1000$, выходная — $T=1000$. Сколько скалярных оценок score $e_{t, i}$ нужно вычислить при Global Attention? При Local Attention с радиусом окна $D=10$?

Решение

1. Global Attention: $S \times T = 1000 \times 1000 = 1\,000\,000$ (1 миллион операций).

2. Local Attention: $(2D + 1) \times T = (2 \cdot 10 + 1) \times 1000 = 21 \times 1000 = 21\,000$ операций.

Local Attention требует почти в 50 раз меньше вычислений.

Задача 6. Маскирование Padding-токенов в Attention

Входной батч дополнен нулями (padding) до длины $S=10$. Реальное предложение занимает 4 токена. Каким значением нужно заполнить позиции $5 \dots 10$ в тензоре scores перед Softmax, чтобы веса внимания к паддингу были строго равны 0?

Решение

Их нужно заполнить значением $-\infty$ (на практике `-1e9` или `-float('inf')`).

Так как $\exp(-\infty) = 0$, после вычисления $\text{Softmax}$ веса $\alpha_{t, i}$ для всех позиций padding станут равны $0.0$, и они не окажут никакого влияния на вектор контекста $c_t$.

⚡ Ответ за 3 минуты

Скелет устного ответа по билету 14 (Механизм внимания в Seq2Seq)
  1. Проблема. Классический Seq2Seq сжимает всю входную фразу в один вектор $h_S$. Бутылочное горлышко: при длине $> 15$ слов память теряется, BLEU падает.
  2. Решение. Сохранить все состояния энкодера $(h_1, \dots, h_S)$ и на каждом шаге декодера формировать динамический вектор контекста $c_t = \sum \alpha_{t,i} h_i$.
  3. Три шага расчета. 1) Оценка $e_{t,i} = \text{score}(s, h)$; 2) Softmax по длине входа $S \implies \alpha_{t,i}$; 3) Взвешенная сумма $c_t = \sum \alpha_{t,i} h_i$.
  4. Bahdanau Attention (2014). Аддитивный скоринг через перцептрон: $v^T \tanh(W s_{t-1} + U h_i)$. Использует состояние $s_{t-1}$.
  5. Luong Attention (2015). Мультипликативный скоринг: Dot ($s_t^T h_i$) или General ($s_t^T W h_i$). Быстрее, использует $s_t$.
  6. Матрица выравнивания. Таблица весов $\alpha_{t,i}$ размера $T \times S$. Наглядно показывает синтаксические соответствия и перестановки слов (мягкое дифференцируемое выравнивание).
  7. Global vs Local. Global смотрит на все $S$ токенов ($O(S \cdot T)$). Local смотрит в узкое окно $[p_t - D, p_t + D]$ ($O(D \cdot T)$).
  8. Длина пути. Внимание сокращает путь между любыми словами последовательности с $O(S)$ до $O(1)$.
  9. Мостик к Трансформерам. Внимание устранило необходимость в рекуррентных связях, сделав возможным полный параллелизм («Attention is all you need»).
