1. Интуиция и мотивация

Классический детерминированный автоэнкодер (AE) сжимает $x \in \mathbb{R}^D$ в код $z = f_\phi(x) \in \mathbb{R}^d$ ($d \ll D$) и восстанавливает $\hat{x} = g_\theta(z)$, но не является генеративной моделью.

⚠️ Почему классический AE не генерирует новые данные?

В AE латентное пространство представляет собой изолированные точки в $\mathbb{R}^d$. Пространство между ними не структурировано: случайный сэмпл $z \sim \mathcal{N}(0, I)$ из пустоты между кластерами декодируется в бессмысленный шум.

💡 Идея Variational Autoencoder (VAE)

Энкодер VAE отображает $x$ в вероятностное распределение $q_\phi(z|x) = \mathcal{N}(\mu(x), \Sigma(x))$. Штраф KL-дивергенции приближает его к стандартному нормальному априорному распределению $p(z) = \mathcal{N}(0, I)$, превращая латент в гладкое непрерывное многообразие для генерации и интерполяции.

3. Математический аппарат

3.1 Постановка задачи и неберущийся интеграл

Маргинальное правдоподобие $p_\theta(x) = \int p_\theta(x|z) p(z) \, dz$ аналитически не берётся для нелинейных сетей. Истинный апостериор $p_\theta(z|x) = \frac{p_\theta(x|z)p(z)}{p_\theta(x)}$ приближается вариационным распределением $q_\phi(z|x) \approx p_\theta(z|x)$.

3.2 Строгий вывод Evidence Lower Bound (ELBO)

📐 Вывод ELBO через неравенство Йенсена
$$\log p_\theta(x) = \log \int q_\phi(z|x) \frac{p_\theta(x, z)}{q_\phi(z|x)} \, dz = \log \mathbb{E}_{q_\phi(z|x)}\left[ \frac{p_\theta(x, z)}{q_\phi(z|x)} \right] \ge \mathbb{E}_{q_\phi(z|x)}\left[ \log \frac{p_\theta(x, z)}{q_\phi(z|x)} \right] \equiv \text{ELBO}$$

Раскладывая $p_\theta(x, z) = p_\theta(x|z) p(z)$:

$$\text{ELBO}(\theta, \phi; x) = \underbrace{\mathbb{E}_{q_\phi(z|x)} [\log p_\theta(x|z)]}_{\text{Качество реконструкции}} - \underbrace{D_{\text{KL}}\Big(q_\phi(z|x) \,\parallel\, p(z)\Big)}_{\text{KL-регуляризация к } \mathcal{N}(0, I)}$$

Точная связь с апостериором: $\log p_\theta(x) = \text{ELBO} + D_{\text{KL}}\Big(q_\phi(z|x) \,\parallel\, p_\theta(z|x)\Big)$. Так как $D_{\text{KL}} \ge 0$, максимизация ELBO максимизирует правдоподобие данных и минимизирует ошибку вариационного приближения.

3.3 Аналитический расчёт KL-дивергенции для Гауссиан

Для $p(z) = \mathcal{N}(0, I)$ и $q_\phi(z|x) = \mathcal{N}(\mu, \text{diag}(\sigma^2))$ интеграл вычисляется аналитически:

$$D_{\text{KL}}\Big(\mathcal{N}(\mu, \sigma^2) \,\parallel\, \mathcal{N}(0, I)\Big) = -\frac{1}{2} \sum_{j=1}^d \Big( 1 + \log(\sigma_j^2) - \mu_j^2 - \sigma_j^2 \Big)$$

3.4 Репараметризационный трюк (Reparameterization Trick)

Прямой сэмплинг $z \sim \mathcal{N}(\mu, \sigma^2)$ блокирует градиенты Backprop. Kingma & Welling (2013) вынесли стохастичность в независимый шум $\epsilon \sim \mathcal{N}(0, I)$:

$$z = \mu(x) + \sigma(x) \odot \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$$

Операция становится детерминированной и дифференцируемой по параметрам $\mu$ и $\sigma$ энкодера.

3.5 Реализации на PyTorch

import torch
import torch.nn as nn
import torch.nn.functional as F

class VAE(nn.Module):
    def __init__(self, input_dim=784, hidden_dim=256, latent_dim=32):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, hidden_dim), nn.ReLU()
        )
        self.fc_mu = nn.Linear(hidden_dim, latent_dim)
        self.fc_logvar = nn.Linear(hidden_dim, latent_dim)

        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, input_dim), nn.Sigmoid()
        )

    def reparameterize(self, mu, logvar):
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)
        return mu + eps * std

    def forward(self, x):
        h = self.encoder(x)
        mu, logvar = self.fc_mu(h), self.fc_logvar(h)
        z = self.reparameterize(mu, logvar)
        return self.decoder(z), mu, logvar
class ConditionalVAE(nn.Module):
    def __init__(self, input_dim=784, num_classes=10, hidden_dim=256, latent_dim=32):
        super().__init__()
        self.class_emb = nn.Embedding(num_classes, num_classes)
        self.encoder = nn.Sequential(
            nn.Linear(input_dim + num_classes, hidden_dim), nn.ReLU()
        )
        self.fc_mu = nn.Linear(hidden_dim, latent_dim)
        self.fc_logvar = nn.Linear(hidden_dim, latent_dim)

        self.decoder = nn.Sequential(
            nn.Linear(latent_dim + num_classes, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, input_dim), nn.Sigmoid()
        )

    def forward(self, x, label):
        y = self.class_emb(label)
        h = self.encoder(torch.cat([x, y], dim=1))
        mu, logvar = self.fc_mu(h), self.fc_logvar(h)
        z = mu + torch.randn_like(mu) * torch.exp(0.5 * logvar)
        return self.decoder(torch.cat([z, y], dim=1)), mu, logvar
def vae_loss(x, x_recon, mu, logvar, beta=1.0):
    recon_loss = F.binary_cross_entropy(x_recon, x, reduction='sum')
    kl_loss = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
    return recon_loss + beta * kl_loss

4. Пошаговый числовой пример

🔢 Дано:
  • Объект $x = [0.8, 0.2]^\top$, латент $d=2$: $\mu = [0.5, -0.2]^\top$, $\log(\sigma^2) = [0.0, -0.5]^\top$.
  • Шум $\epsilon = [0.4, -1.0]^\top \sim \mathcal{N}(0, I)$. Реконструкция $\hat{x} = [0.75, 0.25]^\top$.

Шаг 1. Стандартные отклонения $\sigma$

$$\sigma_1 = \exp(0) = 1.0, \qquad \sigma_2 = \exp(0.5 \cdot (-0.5)) = e^{-0.25} \approx 0.7788$$

Шаг 2. Латентный вектор $z = \mu + \sigma \odot \epsilon$

$$z_1 = 0.5 + 1.0 \cdot 0.4 = 0.900, \qquad z_2 = -0.2 + 0.7788 \cdot (-1.0) = -0.9788$$

Шаг 3. Аналитический расчёт $D_{\text{KL}}$

  • $\text{term}_1 = 1 + 0.0 - 0.5^2 - 1.0 = -0.25$
  • $\text{term}_2 = 1 + (-0.5) - (-0.2)^2 - e^{-0.5} = 0.5 - 0.04 - 0.60653 = -0.14653$
$$D_{\text{KL}} = -\frac{1}{2}(-0.25 - 0.14653) = -\frac{1}{2}(-0.39653) \approx 0.19827$$

Шаг 4. Ошибка реконструкции (BCE) и общий Loss

$$\text{BCE} = -\Big(0.8\ln 0.75 + 0.2\ln 0.25 + 0.2\ln 0.25 + 0.8\ln 0.75\Big) \approx 1.0148$$
$$\mathcal{L}_{\text{VAE}} = \text{BCE} + D_{\text{KL}} = 1.0148 + 0.1983 = 1.2131$$

6. 🎯 Препод спросит

В чем фундаментальная разница между классическим AE и VAE?

Классический AE детерминирован ($x \to z$); его латент содержит разрывы, сэмплирование из которых даёт шум. VAE вероятностен: энкодер предсказывает $q(z|x) = \mathcal{N}(\mu, \Sigma)$, а $D_{\text{KL}}$ регуляризует латент к $\mathcal{N}(0, I)$, обеспечивая связность пространства для генерации.

Почему в VAE нельзя просто взять сэмпл z ~ N(μ, σ²) без репараметризации?

Прямой сэмплинг стохастичен и разрывает вычислительный граф (градиент Backprop не проходит через случайный узел). Репараметризация $z = \mu + \sigma \odot \epsilon$ выносит случайность в $\epsilon \sim \mathcal{N}(0, I)$, делая $z$ детерминированной функцией параметров.

Почему энкодер VAE предсказывает log(σ²), а не саму дисперсию σ² или отклонение σ?

Дисперсия $\sigma^2 > 0$ обязана быть строго положительной. Линейный слой сети может выдать отрицательное число. Предсказание $\log(\sigma^2) \in (-\infty, +\infty)$ с переходом $\sigma = \exp(0.5\log\sigma^2)$ автоматически гарантирует положительность $\sigma$.

Что такое Posterior Collapse (схлопывание апостериора) в VAE и как с ним бороться?

Posterior Collapse — энкодер игнорирует $x$ ($q(z|x) \approx p(z), D_{\text{KL}} \to 0$), а декодер выдаёт среднее по выборке. Борьба: 1) KL Annealing (плавный рост веса $\beta$); 2) Free Bits ($\max(\tau, D_{\text{KL}})$); 3) ослабление декодера или переход к VQ-VAE.

Почему сгенерированные VAE изображения часто получаются размытыми (blurry)?

Пиксельные лоссы (L2/BCE) при неопределённости высокочастотных деталей оптимизируются на условном математическом ожидании всех вариантов, что приводит к усреднению (размытию) пикселей.

Что такое β-VAE и как параметр β управляет Disentanglement?

В $\beta$-VAE лосс равен $\text{Recon} + \beta D_{\text{KL}}$. При $\beta > 1$ строгое информационное горлышко заставляет сеть кодировать независимые семантические факторы (угол, толщина) в отдельные координаты $z$ (Disentanglement).

Как математически устроена условная генерация в CVAE?

В CVAE вариационный вывод строится от условного распределения: энкодер $q_\phi(z|x, y)$, декодер $p_\theta(x|z, y)$. Вектор условия $y$ конкатенируется с $x$ на входе энкодера и с $z$ на входе декодера, позволяя генерировать объекты заданного класса.

В чём разница между q(z|x) и p(z|x)? Как они связаны с ELBO?

$p(z|x)$ — истинный апостериор с неберущимся интегралом в знаменателе; $q_\phi(z|x)$ — параметрическое вариационное приближение (энкодер). Связь: $\log p(x) = \text{ELBO} + D_{\text{KL}}(q_\phi(z|x) \parallel p(z|x))$.

Как подавать условие y в CVAE на практике?

1) Конкатенация One-Hot вектора с $x$ и $z$; 2) Embedding Layer $y \to e_y$ с добавлением к признакам; 3) FiLM-модуляция (предсказание масштаба $\gamma(y)$ и сдвига $\beta(y)$ для нормализации).

Почему репараметризационный трюк даёт меньшую дисперсию градиента, чем Score Function Estimator (REINFORCE)?

REINFORCE использует логарифмическую производную $\nabla_\phi \log q_\phi(z)$ с огромной дисперсией. Репараметризация вычисляет градиент через прямые частные производные $\nabla_z f(z) \nabla_\phi g(x, \epsilon)$, снижая дисперсию на порядки.

Что такое VQ-VAE и почему он используется в Stable Diffusion?

В VQ-VAE латент квантуется по кодовой книге (Codebook), устраняя размытие. В Stable Diffusion VAE сжимает картинку $512\times512\times3$ в латент $64\times64\times4$, ускоряя процесс диффузии в 64 раза.

Что произойдет, если в функции потерь VAE полностью убрать KL-дивергенцию?

Модель выродится в детерминированный AE: $\sigma_j^2 \to 0$, средние $\mu(x)$ разлетятся по $\mathbb{R}^d$, латент потеряет непрерывность, а генерация через сэмплирование $z \sim \mathcal{N}(0, I)$ станет невозможной.

7. 📝 Микро-задачи с решениями

Задача 1. Расчёт KL-дивергенции для 3D латентного распределения

Параметры энкодера: $\mu = [1.0, 0.0, -2.0]^\top$, $\log\sigma^2 = [0.0, 1.0, -1.0]^\top$. Вычислите $D_{\text{KL}}(q(z|x) \parallel \mathcal{N}(0, I))$.

Решение

$D_{\text{KL}} = -\frac{1}{2}\sum_{j=1}^3 (1 + \log\sigma_j^2 - \mu_j^2 - \sigma_j^2)$:

1) $j=1$: $-\frac{1}{2}(1 + 0 - 1 - 1) = 0.5$.

2) $j=2$: $-\frac{1}{2}(1 + 1 - 0 - e^1) = -\frac{1}{2}(2 - 2.7183) \approx 0.3591$.

3) $j=3$: $-\frac{1}{2}(1 - 1 - 4 - e^{-1}) = -\frac{1}{2}(-4 - 0.3679) \approx 2.1839$.

Ответ: $D_{\text{KL}} = 0.5 + 0.3591 + 2.1839 = 3.043$.

Задача 2. Что случится при удалении KL-слагаемого?

Что выучит VAE при $\mathcal{L} = \mathcal{L}_{\text{recon}}$ без $D_{\text{KL}}$?

Решение

Дисперсии $\sigma \to 0$, средние $\mu(x)$ образуют дискретные кластеры. Пространство потеряет непрерывность, сэмплирование из $\mathcal{N}(0, I)$ даст шум.

Ответ: Модель вырождается в негенеративный детерминированный AE.

Задача 3. Подсчет параметров полносвязной сети VAE

Архитектура: вход $784$, энкодер $[784 \to 256 \to 128]$, латент $64$ (головы $\mu$ и $\log\sigma^2$), декодер $[64 \to 128 \to 256 \to 784]$. Посчитайте параметры (с bias).

Решение

Энкодер: $(784\cdot256 + 256) + (256\cdot128 + 128) = 200\,960 + 32\,896 = 233\,856$.

Головы: $2 \times (128\cdot64 + 64) = 2 \times 8\,256 = 16\,512$.

Декодер: $(64\cdot128+128) + (128\cdot256+256) + (256\cdot784+784) = 8\,320 + 33\,024 + 201\,488 = 242\,832$.

Ответ: $233\,856 + 16\,512 + 242\,832 = 493\,200$ параметров.

Задача 4. Репараметризационный трюк в Python

Реализуйте функцию `reparameterize(mu, logvar)`, возвращающую дифференцируемый сэмпл $z$.

Решение
def reparameterize(mu, logvar):
    std = torch.exp(0.5 * logvar)
    eps = torch.randn_like(std)
    return mu + eps * std

Ответ: Градиенты $\nabla_\mu z = 1$, $\nabla_{\log\sigma^2} z = 0.5 \cdot \text{std} \odot \epsilon$.

Задача 5. Анализ потерь VAE и связь с вероятностями

Для батча $\text{Recon} = 150.0$, $D_{\text{KL}} = 12.5$. Чему равен ELBO?

Решение

$\mathcal{L}_{\text{VAE}} = -\text{ELBO} = \text{Recon} + D_{\text{KL}} \implies \text{ELBO} = -(150.0 + 12.5) = -162.5$.

Ответ: $\text{ELBO} = -162.5$.

Задача 6. Диагностика Posterior Collapse по логам обучения

В обучении VAE Recon упал с 200 до 85, а $D_{\text{KL}}$ упал до 0.002. Картинки серые. Диагноз и лечение?

Решение

Диагноз: Posterior Collapse ($q(z|x) \approx \mathcal{N}(0, I)$, энкодер проигнорирован).

Лечение: KL Annealing (плавный разогрев веса $\beta$), Free Bits ($\max(\tau, D_{\text{KL}})$), ослабление декодера.

8. ⚡ Скелет ответа по билету

Скелет ответа по билету 10: Автоэнкодеры, VAE, ELBO и репараметризация
  1. Проблема AE: Детерминированное сжатие $x \to z$ создаёт разрывы в латенте. VAE задаёт вероятностное отображение $q_\phi(z|x) = \mathcal{N}(\mu, \Sigma)$.
  2. Вывод ELBO: По неравенству Йенсена $\log p(x) \ge \text{ELBO} = \mathbb{E}_{q}[\log p_\theta(x|z)] - D_{\text{KL}}(q_\phi(z|x) \parallel p(z))$. Зазор равен $D_{\text{KL}}(q \parallel p(z|x))$.
  3. Аналитический KL: $D_{\text{KL}} = -\frac{1}{2}\sum (1 + \log\sigma_j^2 - \mu_j^2 - \sigma_j^2)$. Предсказание $\log\sigma^2$ обеспечивает $\sigma > 0$.
  4. Репараметризация: $z = \mu(x) + \sigma(x) \odot \epsilon$, $\epsilon \sim \mathcal{N}(0, I)$ сохраняет дифференцируемость для Backpropagation.
  5. CVAE: Конкатенация метки $y$ на входах энкодера $q(z|x,y)$ и декодера $p(x|z,y)$ для условного синтеза.
  6. Модификации: Posterior Collapse (KL Annealing/Free Bits), $\beta$-VAE для Disentanglement, VQ-VAE с Codebook (базис Stable Diffusion).
