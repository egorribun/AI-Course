1. Интуиция и мотивация

Для взаимодействия с физическим миром (автопилоты, медицина, робототехника) классификации недостаточно: требуется пространственная локализация и сегментация объектов.

💡 Лестница задач Computer Vision
  1. Классификация: метка всего изображения («кошка»).
  2. Локализация: класс + 1 Bounding Box $(x, y, w, h)$.
  3. Детекция: $N$ рамок с классами и уверенностью (множество объектов).
  4. Семантическая сегментация: класс для каждого пикселя без разделения экземпляров.
  5. Инстанс-сегментация: раздельные попиксельные маски для каждого экземпляра.
  6. Паноптическая сегментация: объединение фонового Stuff (небо, дорога) и счётных Things (пешеходы, машины).
  7. Ключевые точки / Pose: скелетные анатомические узлы (17 точек COCO).
  8. MOT (Multi-Object Tracking): сохранение ID объектов во времени на видео.

3. Математический аппарат

3.1 Метрика пересечения IoU (Jaccard Index)

Для рамок или масок $A$ и $B$:

$$\text{IoU}(A, B) = \frac{|A \cap B|}{|A \cup B|} = \frac{|A \cap B|}{|A| + |B| - |A \cap B|}, \qquad \text{GIoU} = \text{IoU} - \frac{|C \setminus (A \cup B)|}{|C|}$$

где $C$ — минимальный объемлющий прямоугольник. Порог $\text{IoU} \ge 0.5$ определяет True Positive.

3.2 Алгоритм Non-Maximum Suppression (NMS)

  1. Сортировка рамок по убыванию уверенности ($\text{conf}$).
  2. Выбор рамки $B_{\text{max}}$ с наивысшим баллом в список $\mathcal{D}$.
  3. Удаление всех рамок $B_i$, у которых $\text{IoU}(B_{\text{max}}, B_i) > \tau_{\text{nms}}$ (например, $0.5$).
  4. Повторение до исчерпания списка кандидатов.

3.3 Метрика mAP (Mean Average Precision)

$$\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}}, \quad \text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}, \quad \text{AP}_c = \int_0^1 p_{\text{interp}}(r) \, dr, \quad \text{mAP} = \frac{1}{C}\sum_{c=1}^C \text{AP}_c$$

3.4 Focal Loss (RetinaNet)

Устраняет подавление градиента лёгким фоном в одностадийных детекторах:

$$\text{FL}(p_t) = -\alpha_t (1 - p_t)^\gamma \log(p_t), \quad \gamma \approx 2, \; \alpha \approx 0.25$$

3.5 Dice Loss для сегментации

$$\mathcal{L}_{\text{Dice}} = 1 - \frac{2 \sum p_i g_i + \epsilon}{\sum p_i + \sum g_i + \epsilon}$$

3.6 Реализации на PyTorch

import torch
import torch.nn as nn
import torch.nn.functional as F

def box_iou(boxes1, boxes2):
    area1 = (boxes1[:, 2] - boxes1[:, 0]) * (boxes1[:, 3] - boxes1[:, 1])
    area2 = (boxes2[:, 2] - boxes2[:, 0]) * (boxes2[:, 3] - boxes2[:, 1])
    lt = torch.max(boxes1[:, None, :2], boxes2[:, :2])
    rb = torch.min(boxes1[:, None, 2:], boxes2[:, 2:])
    wh = (rb - lt).clamp(min=0)
    inter = wh[:, :, 0] * wh[:, :, 1]
    return inter / (area1[:, None] + area2 - inter)
def non_max_suppression(boxes, scores, iou_threshold=0.5):
    order = scores.argsort(descending=True)
    keep = []
    while order.numel() > 0:
        i = order[0].item()
        keep.append(i)
        if order.numel() == 1:
            break
        ious = box_iou(boxes[i].unsqueeze(0), boxes[order[1:]]).squeeze(0)
        remaining = torch.where(ious <= iou_threshold)[0]
        order = order[remaining + 1]
    return torch.tensor(keep, dtype=torch.long)
class FocalLoss(nn.Module):
    def __init__(self, alpha=0.25, gamma=2.0):
        super().__init__()
        self.alpha, self.gamma = alpha, gamma

    def forward(self, pred_logits, targets):
        ce = F.cross_entropy(pred_logits, targets, reduction='none')
        p = torch.exp(-ce)
        return (self.alpha * ((1.0 - p) ** self.gamma) * ce).mean()
class DiceLoss(nn.Module):
    def __init__(self, eps=1e-5):
        super().__init__()
        self.eps = eps

    def forward(self, pred, target):
        p, t = torch.sigmoid(pred).view(-1), target.view(-1)
        inter = (p * t).sum()
        return 1.0 - (2.0 * inter + self.eps) / (p.sum() + t.sum() + self.eps)

4. Пошаговый числовой пример

🔢 Дано:
  • Истинный бокс: $GT = [20, 30, 120, 130]$ ($x_1, y_1, x_2, y_2$).
  • Предсказания: A $[30, 35, 110, 125]$ ($\text{conf}=0.90$), B $[25, 30, 115, 130]$ ($\text{conf}=0.75$), C $[200, 200, 250, 250]$ ($\text{conf}=0.85$, фон).

Шаг 1. Расчёт IoU между A и GT

Площадь $GT = 100 \times 100 = 10\,000$. Площадь A $= 80 \times 90 = 7\,200$.

Пересечение: $[30, 35, 110, 125] \implies 80 \times 90 = 7\,200$.

$$\text{IoU}(A, GT) = \frac{7\,200}{10\,000 + 7\,200 - 7\,200} = \frac{7\,200}{10\,000} = 0.72$$

Шаг 2. NMS фильтрация

Берём бокс A ($\text{conf}=0.90$). Так как $\text{IoU}(A, B) \approx 0.85 > 0.5 \implies$ бокс B подавляется.

Шаг 3. Precision и Recall

Бокс A: $\text{IoU} \ge 0.5 \implies \text{TP}=1$. Бокс C: ложное срабатывание $\implies \text{FP}=1, \text{FN}=0$.

$$\text{Precision} = \frac{1}{1 + 1} = 0.50, \qquad \text{Recall} = \frac{1}{1 + 0} = 1.00$$

6. 🎯 Препод спросит

Что такое IoU и почему это хорошая метрика?

$\text{IoU} = \frac{|A \cap B|}{|A \cup B|}$. Преимущества: 1) инвариантность к масштабу (одинаково штрафует ошибку для малых и больших боксов); 2) диапазон $[0, 1]$; 3) стандартный порог ($\text{IoU} \ge 0.5$) для фиксации True Positive.

Объясни NMS алгоритм и почему он нужен.

NMS сортирует боксы по $\text{conf}$, берёт лучший и удаляет пересекающиеся с $\text{IoU} > 0.5$. Устраняет избыточные дублирующие рамки вокруг одного объекта.

Как вычисляется mAP? Что мера AP?

AP — площадь под Precision-Recall кривой при ранжировании по уверенности. mAP — среднее AP по всем классам. Стандарт COCO $\text{mAP}@[0.5:0.95]$ усредняет AP по порогам IoU от $0.5$ до $0.95$ с шагом $0.05$.

Почему Faster R-CNN двухстадийная, а YOLO одностадийная? Плюсы и минусы.

Faster R-CNN сначала генерирует предложения регионов (RPN), затем классифицирует (высокая точность, низкая скорость). YOLO предсказывает боксы и классы за один проход по сетке (real-time скорость, ниже точность на мелких объектах).

Что такое Focal Loss и когда её использовать?

$\text{FL} = -\alpha(1-p_t)^\gamma \log p_t$. Подавляет влияние лёгких примеров фона ($(1-p_t)^\gamma \to 0$), фокусируя градиенты на редких сложных объектах в 1-стадийных детекторах.

DETR: как это детектирует без anchor'ов и NMS?

DETR использует Transformer с $N$ объектными запросами (queries) и венгерский алгоритм (Bipartite Matching) для сопоставления $1$-к-$1$ между предсказаниями и GT, исключая необходимость в NMS.

Сегментация: семантическая vs instance vs panoptic?

Семантическая: класс каждому пикселю без деления объектов. Instance: отдельная маска для каждого экземпляра (Things). Panoptic: объединяет семантику фона (Stuff) и маски экземпляров (Things).

U-Net: почему skip-connections помогают?

Skip-connections передают высокодетализированные пространственные карты признаков из энкодера напрямую в декодер, восстанавливая точные границы объектов, утерянные при пулинге.

Dice loss vs Cross-entropy в сегментации. Когда что использовать?

Cross-Entropy штрафует каждый пиксель по отдельности и страдает от дисбаланса классов. Dice Loss $\mathcal{L}_{\text{Dice}} = 1 - \frac{2\text{TP}}{2\text{TP}+\text{FP}+\text{FN}}$ оптимизирует перекрытие масок и инвариантен к дисбалансу.

Ключевые точки: прямая регрессия vs heatmap. Почему heatmap работает лучше?

Heatmap представляет координату как 2D-гауссиан вероятности: задача сводится к свёрточному прогнозу маски, сохраняет пространственную структуру и даёт точность ~95% против ~75% у регрессии координат.

SORT vs DeepSORT: в чём разница?

SORT использует фильтр Калмана + венгерский алгоритм по IoU. DeepSORT добавляет re-ID нейросетевые эмбеддинги внешности, сохраняя ID объекта при длительных перекрытиях (окклюзиях).

Что такое "anchor" в детекции и почему anchor-free лучше?

Якоря (Anchors) — шаблонные рамки с регрессией смещений ($\Delta$). Anchor-free методы (FCOS, CenterNet) предсказывают координаты и центры напрямую, избавляя от гиперпараметров форм якорей.

7. 📝 Микро-задачи с решениями

Задача 1. Расчёт IoU между двумя боксами

Бокс 1: $(20, 30, 120, 130)$. Бокс 2: $(30, 35, 110, 125)$. Найдите IoU.

Решение

Пересечение: $[30, 35, 110, 125] \implies 80 \times 90 = 7\,200$.

Площади: $A_1 = 100 \times 100 = 10\,000$, $A_2 = 80 \times 90 = 7\,200$.

$\text{IoU} = 7\,200 / (10\,000 + 7\,200 - 7\,200) = 7\,200 / 10\,000 = 0.72$.

Ответ: $\text{IoU} = 0.72$.

Задача 2. Прогон NMS вручную

Боксы с $\text{conf}$: A (0.95), B (0.80), C (0.75), D (0.60), E (0.50). $\text{IoU}(A, B)=0.7, \text{IoU}(A, C)=0.1, \text{IoU}(A, D)=0.8, \text{IoU}(A, E)=0.05$. Порог $0.5$. Кто останется?

Решение

1) Берём A (0.95); удаляем B ($\text{IoU}=0.7$) и D ($\text{IoU}=0.8$).

2) Из оставшихся C и E берём C (0.75), затем E (0.50).

Ответ: Остаются боксы [A, C, E].

Задача 3. Расчёт Precision, Recall, AP

10 истинных объектов. 4 TP, 2 FP. Найдите FN, Precision, Recall.

Решение

$\text{FN} = 10 - 4 = 6$.

$\text{Precision} = 4 / (4 + 2) = 4/6 \approx 0.667$.

$\text{Recall} = 4 / (4 + 6) = 4/10 = 0.40$.

Ответ: $\text{FN}=6, \text{Precision}=0.667, \text{Recall}=0.40$.

Задача 4. Dice coefficient

Истина: 100 пикселей, предсказано 80 пикселей, совпало 60 пикселей (TP). Найдите Dice.

Решение

$\text{Dice} = \frac{2 \cdot \text{TP}}{|A| + |B|} = \frac{2 \cdot 60}{100 + 80} = \frac{120}{180} = 0.667$.

Ответ: $\text{Dice} = 0.667$.

Задача 5. U-Net: роль skip-connections

Что теряется при сжатии карты признаков до $32\times 32$ и как Skip-Connections это исправляют?

Решение

Теряется высокочастотная информация о точных границах объектов. Skip-connections пробрасывают исходные карты признаков из энкодера в декодер через конкатенацию.

Ответ: Восстанавливают чёткие контуры и границы сегментации.

Задача 6. Heatmap vs регрессия координат

5 ключевых точек. Вариант A: 10 чисел. Вариант B: 5 карт $64\times 64$. Сравните память и точность.

Решение

Память: Вариант A — 10 float32 (40 байт); Вариант B — $5 \times 4096 \times 4$ байт ($81\,920$ байт, в 2048 раз больше). Точность: Heatmap ~95% (COCO) против ~75% у прямой регрессии.

Ответ: Heatmap требует больше памяти, но обеспечивает точность ~95% против ~75%.

  1. Лестница задач: Классификация $\to$ Локализация $\to$ Детекция (боксы) $\to$ Семантическая сегментация (пиксели) $\to$ Инстанс (маски) $\to$ Паноптическая (Stuff+Things) $\to$ Ключевые точки $\to$ Трекинг.
  2. Метрики: $\text{IoU} = \frac{|A \cap B|}{|A \cup B|}$; NMS устраняет перекрытия ($\text{IoU} > 0.5$); $\text{mAP}$ — средняя площадь под PR-кривой.
  3. Двухстадийные детекторы (Faster R-CNN): Backbone $\to$ RPN (генерация proposals с якорями) $\to$ RoIAlign (интерполяция) $\to$ головы классификации и регрессии.
  4. Одностадийные детекторы (YOLO / RetinaNet): Прямой прогноз классов и рамок за 1 проход. Focal Loss $\text{FL} = -\alpha(1-p_t)^\gamma \log p_t$ устраняет дисбаланс фона.
  5. DETR: Transformer без якорей и NMS на базе венгерского алгоритма (Bipartite Matching).
  6. Сегментация (U-Net, Mask R-CNN): U-Net с симметричными Skip-Connections; Mask R-CNN с веткой FCN масок. Лоссы: BCE + Dice Loss.
  7. Ключевые точки и трекинг: Heatmap-регрессия точнее координат; MOT (SORT с фильтром Калмана, DeepSORT с re-ID признаками).
