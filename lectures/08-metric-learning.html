1. Интуиция и мотивация

Softmax-классификация на $K$ классов не решает задачи с динамическим набором сущностей:

🎯 Ограничения Softmax
  • Open-Set Recognition: В FaceID новый пользователь — это новый класс; переобучать сеть накладно.
  • Few-Shot Learning: 1–2 образца (паспорт, подпись) недостаточны для обучения классификатора.
  • Visual Search / Re-ID: Поиск товаров или трекинг людей требует ранжирования по сходству, а не метки.
💡 Метрический подход

Обучается энкодер $f_\theta: \mathcal{X} \to \mathbb{R}^d$, проецирующий объект на сферу $S^{d-1}$, где семантическая близость соответствует геодезическому расстоянию:

$$x_i \approx x_j \iff D(f_\theta(x_i), f_\theta(x_j)) \le \tau, \qquad x_i \not\approx x_k \iff D(f_\theta(x_i), f_\theta(x_k)) > \tau$$

Добавление класса сводится к сохранению $z = f_\theta(x_{new})$ в базу без дообучения сети.

2. Архитектура и схема

Сиамские и триплетные сети используют энкодер $f_\theta$ с разделением весов (Weight Sharing).

Общие веса: обеспечивают симметрию $D(f(x_1), f(x_2)) = D(f(x_2), f(x_1))$, инвариантность пространства и экономию памяти.

3. Математический аппарат

3.1 Метрики и связь $L_2^2$ с косинусным расстоянием

Для векторов $a, b \in \mathbb{R}^d$ определены: $D_2(a, b) = \|a - b\|_2$, $\cos(a, b) = \frac{a^\top b}{\|a\|_2 \|b\|_2}$, $D_{cos}(a, b) = 1 - \cos(a, b)$.

📐 Вывод связи $L_2^2$ и $\cos(a, b)$ на единичной сфере

При $\|a\|_2 = \|b\|_2 = 1$:

$$\|a - b\|_2^2 = (a - b)^\top (a - b) = \|a\|_2^2 + \|b\|_2^2 - 2 a^\top b = 2(1 - \cos(a, b)) = 2 \cdot D_{cos}(a, b)$$

На единичной сфере Евклидово расстояние строго монотонно связано с косинусным: $\|a - b\|_2 = \sqrt{2(1 - \cos(a, b))}$.

3.2 Contrastive Loss (Hadsell et al., 2006)

Для пары $(x_1, x_2)$ с меткой $y \in \{0, 1\}$ ($y=1$ — один класс, $y=0$ — разные):

$$\mathcal{L}_{contrastive} = y \cdot \frac{1}{2} D^2 + (1 - y) \cdot \frac{1}{2} \max(0, m - D)^2, \quad D = \|f(x_1) - f(x_2)\|_2$$

где $m > 0$ — margin. При $y=0$ градиент обнуляется, если $D \ge m$.

3.3 Triplet Loss (FaceNet, Schroff et al., 2015)

Для тройки $(a, p, n)$ — Anchor, Positive, Negative:

$$\mathcal{L}_{triplet} = \max\Big(0, \|f(a) - f(p)\|_2^2 - \|f(a) - f(n)\|_2^2 + \alpha\Big)$$

где $\alpha > 0$ — требуемый отступ. Условие нуля ошибки: $D(a, n)^2 \ge D(a, p)^2 + \alpha$.

3.4 Стратегии майнинга триплетов (Triplet Mining)

КатегорияУсловиеLossРоль в обучении
Easy Negative$D(a, n)^2 > D(a, p)^2 + \alpha$$\mathcal{L} = 0$Не дают градиента, замедляют обучение.
Hard Negative$D(a, n)^2 < D(a, p)^2$$\mathcal{L} > \alpha$Максимальный градиент; риск коллапса в начале обучения.
Semi-Hard Negative$D(a, p)^2 < D(a, n)^2 < D(a, p)^2 + \alpha$$0 < \mathcal{L} < \alpha$Стандарт FaceNet: стабильный информативный градиент.

3.5 ArcFace (Additive Angular Margin Loss)

Устраняет комбинаторику отбора троек $O(N^3)$, добавляя угловой margin $m$ в Softmax:

$$\mathcal{L}_{ArcFace} = -\log \frac{e^{s \cdot \cos(\theta_{y_i} + m)}}{e^{s \cdot \cos(\theta_{y_i} + m)} + \sum_{j \ne y_i} e^{s \cdot \cos(\theta_j)}}$$

где $s$ — радиус сферы ($s \approx 64$), $m$ — угловой margin ($m \approx 0.5$ рад $\approx 28.6^\circ$), $\theta_j = \arccos\left(\frac{W_j^\top z}{\|W_j\| \|z\|}\right)$.

3.6 Реализация на PyTorch

import torch
import torch.nn as nn
import torch.nn.functional as F

class SiameseNet(nn.Module):
    def __init__(self, embedding_dim=128):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Linear(784, 256), nn.ReLU(),
            nn.Linear(256, 128), nn.ReLU(),
            nn.Linear(128, embedding_dim)
        )

    def forward(self, x):
        return F.normalize(self.encoder(x), p=2, dim=1)
class ContrastiveLoss(nn.Module):
    def __init__(self, margin=1.0):
        super().__init__()
        self.margin = margin

    def forward(self, z1, z2, label):
        dist = F.pairwise_distance(z1, z2)
        loss = label * torch.pow(dist, 2) + (1 - label) * torch.pow(torch.clamp(self.margin - dist, min=0.0), 2)
        return torch.mean(0.5 * loss)
class TripletLoss(nn.Module):
    def __init__(self, margin=0.2):
        super().__init__()
        self.margin = margin

    def forward(self, anchor, positive, negative):
        d_ap = torch.norm(anchor - positive, p=2, dim=1)
        d_an = torch.norm(anchor - negative, p=2, dim=1)
        loss = torch.clamp(d_ap - d_an + self.margin, min=0.0)
        return loss.mean()
class ArcFaceLinear(nn.Module):
    def __init__(self, in_features, num_classes, s=64.0, m=0.5):
        super().__init__()
        self.in_features = in_features
        self.num_classes = num_classes
        self.s = s
        self.m = m
        self.weight = nn.Parameter(torch.FloatTensor(num_classes, in_features))
        nn.init.xavier_uniform_(self.weight)

    def forward(self, embedding, label):
        cosine = F.linear(F.normalize(embedding), F.normalize(self.weight))
        sine = torch.sqrt(1.0 - torch.clamp(cosine ** 2, 0, 1))
        phi = cosine * torch.cos(torch.tensor(self.m)) - sine * torch.sin(torch.tensor(self.m))
        one_hot = torch.zeros_like(cosine)
        one_hot.scatter_(1, label.view(-1, 1), 1.0)
        output = (one_hot * phi) + ((1.0 - one_hot) * cosine)
        return output * self.s

4. Пошаговый числовой пример

🔢 Дано:

Нормализованные эмбеддинги ($d=2$) и margin $\alpha = 0.5$:

  • Якорь: $z_a = [0.6, 0.8]^\top$, Позитив: $z_p = [0.8, 0.6]^\top$, Негатив: $z_n = [0.0, 1.0]^\top$ ($\|z\|_2 = 1$).

Шаг 1. Квадраты евклидовых расстояний

$$D(a, p)^2 = (0.6 - 0.8)^2 + (0.8 - 0.6)^2 = (-0.2)^2 + (0.2)^2 = 0.08$$
$$D(a, n)^2 = (0.6 - 0.0)^2 + (0.8 - 1.0)^2 = 0.6^2 + (-0.2)^2 = 0.40$$

Шаг 2. Расчёт Triplet Loss

$$\mathcal{L}_{triplet} = \max\Big(0, D(a, p)^2 - D(a, n)^2 + \alpha\Big) = \max(0, 0.08 - 0.40 + 0.50) = 0.18$$

Шаг 3. Проверка Semi-Hard условия

$$D(a, p)^2 = 0.08 < D(a, n)^2 = 0.40 < D(a, p)^2 + \alpha = 0.58$$

Условие строго выполняется $\implies$ триплет Semi-Hard Negative с ненулевым градиентом.

Шаг 4. Градиентный шаг по якорю $z_a$

$$\frac{\partial \mathcal{L}}{\partial z_a} = 2(z_n - z_p) = 2([0.0, 1.0] - [0.8, 0.6]) = [-1.6, 0.8]$$

Обновление $z_a \leftarrow z_a - \eta \nabla_{z_a}\mathcal{L}$ притягивает $z_a$ к $z_p$ и отталкивает от $z_n$.

6. 🎯 Препод спросит

Почему классификация не работает для face recognition?

В классификации число классов $K$ фиксировано: добавление человека требует изменения архитектуры и переобучения. В метрическом подходе энкодер обучается один раз, а новый эталон просто сохраняется в галерею признаков.

Что такое сиамская сеть и почему веса в обеих ветках общие?

Сиамская сеть применяет идентичный энкодер $f_\theta$ к разным входам. Веса общие для соблюдения симметрии расстояния $D(a,b)=D(b,a)$, инвариантности пространства представлений и экономии памяти.

Разберите contrastive loss: оба слагаемых и margin.

$\mathcal{L} = y \cdot d^2 + (1-y)\max(0, m-d)^2$. При $y=1$ минимизируется расстояние между похожими объектами. При $y=0$ штраф начисляется только если $d < m$, предотвращая бесконечное расталкивание классов.

Что такое hard, easy и semi-hard triplets?

Easy: $D(a,n) > D(a,p)+m$ ($\mathcal{L}=0$, нет градиента). Hard: $D(a,n) < D(a,p)$ (максимальный лосс, риск нестабильности). Semi-Hard: $D(a,p) < D(a,n) < D(a,p)+m$ (оптимальный информативный градиент без коллапса).

Напишите формулу triplet loss и объясните каждый член.

$\mathcal{L} = \max(0, D(a,p)^2 - D(a,n)^2 + \alpha)$. Требует, чтобы негатив был дальше позитива минимум на $\alpha$. Если $D(a,n)^2 \ge D(a,p)^2 + \alpha$, лосс равен нулю.

Почему нормализуют эмбеддинги на единичную сферу?

Нормализация $\|z\|=1$ устраняет дрейф норм векторов, обеспечивает монотонную связь $L_2$ и косинусного расстояния $\|a-b\|_2^2 = 2(1-\cos(a,b))$ и ускоряет поиск в векторных индексах (FAISS).

ArcFace vs CosFace: в чём разница и почему ArcFace лучше?

CosFace вычитает margin из косинуса ($\cos\theta - m$), а ArcFace добавляет его к углу ($\cos(\theta + m)$). Угловой margin геодезически естественен на гиперсфере и обеспечивает более строгое разделение классов.

Как практически работает верификация лица?

1) Лицо прогоняется через энкодер $\to z \in S^{d-1}$. 2) Вычисляется расстояние $D(z, z_{ref})$ до эталона. 3) При $D < \tau$ верификация успешна. Порог $\tau$ настраивается по ROC-кривой (баланс FAR и FRR).

Что такое collapse в triplet loss и как его избежать?

Коллапс — отображение всех объектов в одну константную точку с нулевым лоссом. Устраняется использованием Semi-Hard mining, корректной инициализацией весов и $L_2$-нормализацией эмбеддингов.

Почему сиамская сеть, а не две разные сети?

Разные веса нарушают симметрию и транзитивность метрики: одинаковые входы дали бы разные эмбеддинги. Единые веса формируют единое метрическое пространство.

Как работает linear probing и почему это честная оценка качества представления?

Энкодер замораживается, поверх обучается линейный классификатор. Это объективно оценивает линейную разделимость и информативность признаков без адаптации весов самого энкодера.

7. 📝 Микро-задачи с решениями

Задача 1. Вывод связи L2 и косинуса

Пусть $\|a\|_2 = \|b\|_2 = 1$. Выведите связь между $\|a-b\|_2^2$ и $\cos(a, b)$.

Решение

$\|a-b\|_2^2 = a^\top a + b^\top b - 2a^\top b = 1 + 1 - 2\cos(a,b) = 2(1 - \cos(a,b))$.

Ответ: $\|a-b\|_2^2 = 2(1 - \cos(a,b))$.

Задача 2. Triplet loss численно

Расстояния: $d(a,p) = 0.15$, $d(a,n) = 0.85$, margin $m = 0.3$. Посчитайте triplet loss и определите тип тройки.

Решение

$\mathcal{L} = \max(0, 0.15 - 0.85 + 0.3) = \max(0, -0.4) = 0$.

Ответ: $\mathcal{L} = 0$, тип — Easy Triplet (негатив уже достаточно удалён, градиент нулевой).

Задача 3. Определение типа тройки

$d(a,p) = 0.4$, $d(a,n) = 0.65$, margin $m = 0.3$. Определите категорию тройки.

Решение

Проверка semi-hard: $d(a,p) < d(a,n) < d(a,p) + m \implies 0.4 < 0.65 < 0.70$.

Ответ: Semi-Hard Triplet (негатив дальше позитива, но внутри зоны margin).

Задача 4. Contrastive loss для пар

Вычислите Contrastive Loss при $m = 0.5$ для: (1) позитивной пары ($y=1, d=0.2$); (2) негативной пары ($y=0, d=0.3$).

Решение

(1) $\mathcal{L}_+ = 1 \cdot (0.2)^2 = 0.04$.

(2) $\mathcal{L}_- = 1 \cdot \max(0, 0.5 - 0.3)^2 = 0.2^2 = 0.04$.

Ответ: $\mathcal{L}_+ = 0.04$, $\mathcal{L}_- = 0.04$.

Задача 5. L2-нормализация эмбеддингов

Нормализуйте вектор $z = [3, 4]^\top$ на единичную сферу.

Решение

$\|z\|_2 = \sqrt{3^2 + 4^2} = 5 \implies z_{norm} = \frac{1}{5}[3, 4]^\top = [0.6, 0.8]^\top$.

Ответ: $z_{norm} = [0.6, 0.8]^\top$, норма $\|z_{norm}\|_2 = 1.0$.

Задача 6. Косинус через L2 нормализованные векторы

Для нормализованных векторов $a, b$ известно $\|a-b\|_2 = 0.6$. Найдите $\cos(a,b)$.

Решение

$\|a-b\|_2^2 = 2(1 - \cos(a,b)) \implies 0.36 = 2(1 - \cos(a,b)) \implies \cos(a,b) = 1 - 0.18 = 0.82$.

Ответ: $\cos(a,b) = 0.82$.

8. ⚡ Скелет ответа по билету

Скелет ответа по билету 8: Метрическое обучение и Сиамские сети
  1. Мотивация: Softmax не работает для Open-Set и Few-Shot (FaceID, поиск). Решение — обучение пространства эмбеддингов $f_\theta: \mathcal{X} \to \mathbb{R}^d$.
  2. Сиамская сеть: Общие веса (Weight Sharing) гарантируют симметрию $D(a,b)=D(b,a)$ и инвариантность. Проекция на сферу $S^{d-1}$.
  3. Связь $L_2$ и Косинуса: На сфере $\|a-b\|_2^2 = 2(1 - \cos(a,b))$ — евклидово расстояние монотонно эквивалентно косинусному.
  4. Contrastive Loss: $\mathcal{L} = y D^2 + (1-y)\max(0, m-D)^2$. Стягивает позитивы, расталкивает негативы на зазор $m$.
  5. Triplet Loss и Mining: $\mathcal{L} = \max(0, D(a,p)^2 - D(a,n)^2 + \alpha)$. Semi-Hard mining ($D(a,p) < D(a,n) < D(a,p)+\alpha$) — ключ к сходимости.
  6. ArcFace: Аддитивный угловой margin в Softmax $\cos(\theta + m)$. Устраняет майнинг $O(N^3)$, формирует компактные угловые кластеры.
  7. Инференс: Извлечение векторов $\to$ галерея в FAISS $\to$ пороговая верификация ($\tau$) по ROC (FAR/FRR/EER).
