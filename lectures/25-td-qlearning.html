1. Интуиция и мотивация

Обучение по временным разностям (Temporal Difference, TD) объединяет ключевые преимущества DP и MC:

  • Как и Монте-Карло, TD обучается на сыром опыте без модели среды ($\mathcal{P}$ и $\mathcal{R}$ не требуются).
  • Как и Динамическое программирование, TD использует бутстрэпинг — обновляет оценку на каждом шаге по $\gamma V(S_{t+1})$, не дожидаясь завершения эпизода.
💡 Интуиция: вождение автомобиля
  • Monte Carlo: Обновление только в конце поездки. Если машина чудом избежала аварии после заноса, MC оценивает действия как успешные.
  • Temporal Difference (TD): Мгновенная реакция. В момент опасного манёвра $V(S_{t+1}) \ll V(S_t)$, и действие сразу штрафуется через TD-ошибку $\delta_t$.

2. Архитектура и схема

3. Математический аппарат

1. Оценка функции состояния TD(0)

Обновление ценности состояния на шаге $t$:

$$ V(S_t) \leftarrow V(S_t) + \alpha \Big( \underbrace{R_{t+1} + \gamma V(S_{t+1})}_{\text{TD Target } y_t} - V(S_t) \Big) = V(S_t) + \alpha \, \delta_t $$

где $\delta_t \doteq R_{t+1} + \gamma V(S_{t+1}) - V(S_t)$ — ошибка временных разностей (TD-Error), а $\alpha \in (0, 1]$ — шаг обучения.

2. SARSA: On-Policy TD Control

SARSA оценивает $Q(s, a)$ для стратегии $\pi$, по которой совершаются действия ($\epsilon$-greedy):

$$ Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \left[ R_{t+1} + \gamma Q(S_{t+1}, A_{t+1}) - Q(S_t, A_t) \right] $$

где $A_{t+1} \sim \pi(\cdot \mid S_{t+1})$.

3. Q-Learning (Watkins, 1989): Off-Policy TD Control

Q-Learning оценивает $Q^*(s, a)$ независимо от исследовательской стратегии сбора данных $b(a|s)$:

$$ Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \left[ R_{t+1} + \gamma \max_{a \in \mathcal{A}} Q(S_{t+1}, a) - Q(S_t, A_t) \right] $$
📐 Сравнение On-Policy и Off-Policy
  • Q-Learning (Off-Policy): Таргет вычисляется по жадной политике $\max_a Q(S_{t+1}, a)$. Целевая стратегия $\pi$ отличается от исследовательской $b$.
  • SARSA (On-Policy): Таргет вычисляется по $Q(S_{t+1}, A_{t+1})$, где $A_{t+1}$ — реально совершаемое действие. Учитывает риск ошибок при exploration.

4. Deep Q-Networks (DQN, Mnih et al., 2015)

Аппроксимация табличных значений нейросетью $Q(s, a; \theta)$ с функцией потерь MSE:

$$ \mathcal{L}(\theta) = \mathbb{E}_{(s, a, r, s', d) \sim \mathcal{D}} \left[ \left( r + \gamma (1 - d) \max_{a'} Q(s', a'; \theta^-) - Q(s, a; \theta) \right)^2 \right] $$

где $d \in \{0, 1\}$ — флаг терминального состояния. Стабилизирующие механизмы:

  1. Experience Replay ($\mathcal{D}$): Случайные минибатчи переходов разрывают автокорреляцию данных и стабилизируют SGD.
  2. Target Network ($\theta^-$): Замороженные веса $\theta^-$ обновляются раз в $C$ шагов, предотвращая эффект «бегущей цели».

5. Double DQN (van Hasselt et al., 2015)

Устраняет Overestimation Bias (завышение оценок из-за $\mathbb{E}[\max X] \ge \max \mathbb{E}[X]$), разделяя выбор действия и оценку:

$$ y^{\text{DoubleDQN}} = r + \gamma (1 - d) Q\left(s', \arg\max_{a'} Q(s', a'; \theta); \, \theta^-\right) $$

6. Реализация Q-Learning, SARSA и DQN на Python / PyTorch

import numpy as np
import torch
import torch.nn as nn
import torch.nn.functional as F

def q_learning_update(q_table, s, a, r, s_prime, alpha=0.1, gamma=0.9):
    td_target = r + gamma * np.max(q_table[s_prime])
    q_table[s, a] += alpha * (td_target - q_table[s, a])
    return q_table

def sarsa_update(q_table, s, a, r, s_prime, a_prime, alpha=0.1, gamma=0.9):
    td_target = r + gamma * q_table[s_prime, a_prime]
    q_table[s, a] += alpha * (td_target - q_table[s, a])
    return q_table

class DQNNetwork(nn.Module):
    def __init__(self, state_dim, action_dim, hidden_dim=64):
        super().__init__()
        self.fc1 = nn.Linear(state_dim, hidden_dim)
        self.fc2 = nn.Linear(hidden_dim, hidden_dim)
        self.out = nn.Linear(hidden_dim, action_dim)

    def forward(self, x):
        x = F.relu(self.fc1(x))
        x = F.relu(self.fc2(x))
        return self.out(x)

def compute_dqn_loss(online_net, target_net, states, actions, rewards, next_states, dones, gamma=0.99):
    q_values = online_net(states).gather(1, actions.unsqueeze(1)).squeeze(1)
    with torch.no_grad():
        max_next_q = target_net(next_states).max(dim=1)[0]
        target_q = rewards + gamma * (1.0 - dones) * max_next_q
    return F.mse_loss(q_values, target_q)

4. Пошаговый числовой пример

🔢 Пример 1. Ручной расчёт обновлений Q-Learning и SARSA

В $s_0$ выбрано $a_1$, получено $R=+5.0$, переход в $s_1$. Параметры: $\alpha = 0.1, \gamma = 0.9$.

  • $Q(s_0) = [1.0, 0.0, 3.0]$, $Q(s_1) = [2.0, 6.0, 4.0]$.

Q-Learning: $\max Q(s_1) = 6.0$. Таргет: $5.0 + 0.9 \cdot 6.0 = 10.4$.

$$ Q_{\text{new}}(s_0, a_1) = 0.0 + 0.1 \cdot (10.4 - 0.0) = 1.04 $$

SARSA: политика выбрала в $s_1$ действие $a_0$ ($Q = 2.0$). Таргет: $5.0 + 0.9 \cdot 2.0 = 6.8$.

$$ Q_{\text{new}}(s_0, a_1) = 0.0 + 0.1 \cdot (6.8 - 0.0) = 0.68 $$
🔢 Пример 2. Расчёт таргета DQN для минибатча ($B=3, \gamma=0.99$)

$R = [1.0, 0.0, 2.0]$, $dones = [0.0, 0.0, 1.0]$, $\max Q(s') = [1.2, 1.5, 2.1]$:

$$ y_1 = 1.0 + 0.99 \cdot 1.2 = 2.188, \quad y_2 = 0.0 + 0.99 \cdot 1.5 = 1.485, \quad y_3 = 2.0 + 0.99 \cdot (1 - 1) \cdot 2.1 = 2.000 $$

Реализация Experience Replay на Python

import random
from collections import deque

class ReplayBuffer:
    def __init__(self, capacity=10000):
        self.buffer = deque(maxlen=capacity)

    def push(self, state, action, reward, next_state, done):
        self.buffer.append((state, action, reward, next_state, done))

    def sample(self, batch_size):
        return random.sample(self.buffer, batch_size)

    def __len__(self):
        return len(self.buffer)

6. 🎯 Препод спросит

1. В чем принципиальная разница в поведении SARSA и Q-learning на задаче Cliff Walking?

Q-Learning (Off-Policy) предполагает безошибочные будущие жадные действия, выбирая кратчайший путь по краю обрыва. SARSA (On-Policy) учитывает $\epsilon$-исследование и риск случайного падения, выбирая более длинный, но безопасный путь вдалеке от обрыва.

2. Зачем в DQN нужны Experience Replay и Target Network?

Experience Replay устраняет автокорреляцию кадров и делает данные i.i.d. для SGD. Target Network $\theta^-$ фиксирует таргет на $C$ шагов, предотвращая эффект «бегущей цели» и расходимость.

3. Что такое «Смертоносная триада» (Deadly Triad) в обучении с подкреплением?

Одновременное сочетание: 1) аппроксимации функций (нейросети); 2) бутстрэпинга (TD); 3) Off-Policy обучения. Без стабилизации (Replay + Target) триада может приводить к расходимости весов.

4. Почему стандартный Q-learning страдает от Overestimation Bias (завышения оценок)?

Из-за оператора максимума: $\mathbb{E}[\max_a (\mu_a + \epsilon_a)] \ge \max_a \mu_a$. Шум систематически завышает таргет. Double DQN решает проблему разделением выбора действия ($\theta$) и оценки ($\theta^-$).

5. Почему в формуле таргета DQN для терминального состояния $S_{t+1}$ отбрасывается член $\gamma \max Q$?

В терминальном состоянии эпизод закончен, будущих наград нет ($G = R_{\text{term}}$). Множитель $(1 - d)$ обнуляет несуществующую будущую ценность.

6. Можно ли применять Q-learning в задачах с непрерывным пространством действий $\mathcal{A} \subseteq \mathbb{R}^k$?

Напрямую нельзя: взятие $\max_{a \in \mathcal{A}} Q(s', a)$ в непрерывном пространстве требует решения сложной оптимизационной задачи на каждом шаге. Для этого используют Actor-Critic (DDPG, SAC).

7. Чем Dueling DQN отличается от стандартного DQN?

Dueling DQN разделяет сеть на два потока: ценность состояния $V(s)$ и преимущество действий $A(s, a)$, восстанавливая $Q(s, a) = V(s) + (A(s, a) - \frac{1}{|\mathcal{A}|}\sum A(s, a'))$.

8. Что такое Prioritized Experience Replay (PER)?

Сэмплирование переходов с вероятностью $P(i) \propto |\delta_i|^\alpha$, пропорциональной TD-ошибке. Смещение компенсируется весами важности $w_i = (N \cdot P(i))^{-\beta}$.

9. Каковы условия сходимости табличного Q-learning к $Q^*$ по теореме Ваткинса?

1) Все пары $(s, a)$ посещаются бесконечно часто; 2) Условия Роббинса-Монро для шага: $\sum \alpha_t = \infty, \sum \alpha_t^2 < \infty$; 3) Ограниченные награды и $\gamma < 1$.

10. Что такое TD($\lambda$) и Eligibility Traces (следы пригодности)?

TD($\lambda$) объединяет $n$-шаговые TD-доходы с весами $(1-\lambda)\lambda^{n-1}$. Следы пригодности $e_t(s) = \gamma \lambda e_{t-1}(s) + \mathbb{I}(S_t=s)$ распространяют ошибку назад во времени онлайн.

7. 📝 Микро-задачи с решениями

Задача 1. Расчёт ошибки TD(0) для ценности состояния

$V(S_t) = 15.0, R_{t+1} = 3.0, V(S_{t+1}) = 12.0$ при $\gamma = 0.9, \alpha = 0.2$. Вычислите $\delta_t$ и новое $V(S_t)$.

Решение

Таргет: $y = 3.0 + 0.9 \cdot 12.0 = 13.8$. Ошибка: $\delta = 13.8 - 15.0 = -1.2$.

Обновление: $V(S_t) \leftarrow 15.0 + 0.2 \cdot (-1.2) = 14.76$.

Ответ: $\delta_t = -1.2, V(S_t) = 14.76$.

Задача 2. Обновление Q-learning со штрафом

В $s_0$ $Q(s_0, a)=2.0$. $R=-10.0$. В $s_{\text{pit}}$ оценки $Q = [0.0, 1.0]$. При $\gamma = 0.9, \alpha = 0.5$ найдите новое $Q(s_0, a)$.

Решение

$\text{Target} = -10.0 + 0.9 \cdot 1.0 = -9.1$. $\delta = -9.1 - 2.0 = -11.1$.

$Q_{\text{new}} = 2.0 + 0.5 \cdot (-11.1) = -3.55$.

Ответ: $Q_{\text{new}} = -3.55$.

Задача 3. Расчёт таргета Double DQN

$Q(s'; \theta) = [4.2, 5.8, 3.1]$, $Q(s'; \theta^-) = [4.5, 3.9, 3.4]$. $R = 2.0, \gamma = 0.9, d=0$. Найдите таргеты Double DQN и DQN.

Решение

Double DQN: $a^* = \arg\max Q(\theta) = a_2 \implies y = 2.0 + 0.9 \cdot 3.9 = 5.51$.

Стандартный DQN: $y = 2.0 + 0.9 \cdot \max Q(\theta^-) = 2.0 + 0.9 \cdot 4.5 = 6.05$.

Ответ: Double DQN: 5.51; DQN: 6.05.

Задача 4. Влияние терминального флага done в DQN

$R = 10.0, \gamma = 0.9, \max Q(s') = 20.0$. Вычислите таргеты для $done=0$ и $done=1$.

Решение

$done=0 \implies y = 10.0 + 0.9 \cdot 20.0 = 28.0$. $done=1 \implies y = 10.0 + 0 = 10.0$.

Ответ: $y_1 = 28.0, y_2 = 10.0$.

Задача 5. Расчёт градиента функции потерь DQN

$Q(s, a; \theta) = 4.0, y = 6.0$. Для $\mathcal{L} = (y - Q)^2$ найдите $\frac{\partial \mathcal{L}}{\partial Q}$.

Решение

$\frac{\partial \mathcal{L}}{\partial Q} = 2(Q - y) = 2(4.0 - 6.0) = -4.0$.

Ответ: $-4.0$.

Задача 6. Сравнение шагов SARSA и Q-learning при стохастическом выборе

В $s_0$ $Q(s_0, a_1)=0, R=+1, \gamma=0.5, \alpha=1.0$. В $s_1$ $Q = [10.0, 2.0]$ с вероятностями $[0.8, 0.2]$. Найдите таргеты Q-Learning и Expected SARSA.

Решение

Q-Learning: $1 + 0.5 \cdot 10.0 = 6.0$. Expected SARSA: $1 + 0.5 \cdot (0.8 \cdot 10 + 0.2 \cdot 2) = 1 + 0.5 \cdot 8.4 = 5.2$.

Ответ: Q-Learning: 6.0; Expected SARSA: 5.2.

8. ⚡ Скелет ответа по билету

Скелет ответа по билету 23 (TD, SARSA, Q-Learning, DQN)
  1. TD-обучение: Обучение без модели с бутстрэпингом: $V(S_t) \leftarrow V(S_t) + \alpha \delta_t$, где $\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)$.
  2. SARSA (On-Policy): $Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha [ R_{t+1} + \gamma Q(S_{t+1}, A_{t+1}) - Q(S_t, A_t) ]$. Оценивает реальную политику с учётом риска (Cliff Walking).
  3. Q-Learning (Off-Policy): $Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha [ R_{t+1} + \gamma \max_a Q(S_{t+1}, a) - Q(S_t, A_t) ]$. Сходится к $Q^*$ независимо от поведенческой стратегии.
  4. DQN: Сеть $Q(s, a; \theta)$. Loss: $\mathcal{L} = \mathbb{E}[(r + \gamma(1-d)\max_{a'} Q(s', a'; \theta^-) - Q(s, a; \theta))^2]$.
  5. Experience Replay: Буфер $\mathcal{D}$ разрывает автокорреляцию кадров, стабилизируя обучение SGD.
  6. Target Network $\theta^-$: Замороженная сеть фиксирует таргет, устраняя эффект «бегущей цели».
  7. Double DQN: Разделяет выбор действия ($\arg\max Q(\theta)$) и его оценку ($Q(\theta^-)$), устраняя Overestimation Bias.
