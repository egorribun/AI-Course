1. Интуиция и мотивация

Алгоритмы на основе временных разностей (Temporal Difference, TD) объединяют лучшие черты двух миров:

  • Как и Монте-Карло, они обучаются напрямую на сыром опыте без знания модели среды ($\mathcal{P}$ и $\mathcal{R}$ неизвестны).
  • Как и Динамическое программирование, они бутстрэпят (bootstrapping) — обновляют оценку на каждом шаге времени, не дожидаясь исхода эпизода.
💡 Интуитивная аналогия: вождение автомобиля

Представьте, что вы учитесь водить машину:

  • Подход Монте-Карло: Вы едете 50 километров. В процессе вы чуть не вылетели на встречную полосу, но чудом доехали. Вы делаете вывод: «Поездка завершилась успешно, значит, выезд на встречку был отличным действием!» (Обновление только в конце).
  • Подход Temporal Difference (TD): В момент, когда машина вильнула на встречку, вы немедленно видите возросший риск аварии ($V(S_{t+1}) \ll V(S_t)$). Вы сразу же штрафуете это действие, не дожидаясь аварии в конце пути!

2. Архитектура и схема: SARSA, Q-Learning и контур DQN

3. Математический аппарат

1. Оценка функции состояния TD(0)

В алгоритме TD(0) ценность состояния обновляется после каждого шага $t$:

$$ V(S_t) \leftarrow V(S_t) + \alpha \Big( \underbrace{R_{t+1} + \gamma V(S_{t+1})}_{\text{TD Target } y_t} - V(S_t) \Big) = V(S_t) + \alpha \, \delta_t $$

где $\delta_t \doteq R_{t+1} + \gamma V(S_{t+1}) - V(S_t)$ — ошибка временных разностей (TD-Error), а $\alpha \in (0, 1]$ — скорость обучения.

2. SARSA: On-Policy TD Control

SARSA оценивает функцию $Q(s, a)$ для стратегии $\pi$, по которой сам же и действует (например, $\epsilon$-greedy):

$$ Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \left[ R_{t+1} + \gamma Q(S_{t+1}, A_{t+1}) - Q(S_t, A_t) \right] $$

где действие $A_{t+1} \sim \pi(\cdot \mid S_{t+1})$ сэмплируется согласно текущей исследовательской политике агента.

3. Q-Learning (Watkins, 1989): Off-Policy TD Control

Q-Learning напрямую оценивает оптимальную функцию $Q^*(s, a)$ независимо от стратегии сбора данных $b(a|s)$:

$$ Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \left[ R_{t+1} + \gamma \max_{a \in \mathcal{A}} Q(S_{t+1}, a) - Q(S_t, A_t) \right] $$
📐 Почему Q-learning — Off-Policy, а SARSA — On-Policy?
  • Q-Learning (Off-Policy): Таргет вычисляется по строго оптимальной жадной стратегии $\max_a Q(S_{t+1}, a)$, в то время как следующее реальное действие агент может выбрать случайно ($\epsilon$-greedy). Целевая стратегия $\pi$ отличается от поведенческой $b$.
  • SARSA (On-Policy): Таргет вычисляется по $Q(S_{t+1}, A_{t+1})$, где $A_{t+1}$ — действие, реально совершаемое агентом с учетом случайных исследовательских шагов $\epsilon$. SARSA оценивает реальную стратегию с учетом ее несовершенства и риска падений.

4. Deep Q-Networks (DQN, Mnih et al., 2015)

Для работы в непрерывных пространствах состояний таблица $Q(s, a)$ заменяется нейросетью $Q(s, a; \theta)$. Функция потерь DQN:

$$ \mathcal{L}(\theta) = \mathbb{E}_{(s, a, r, s', d) \sim \mathcal{D}} \left[ \left( r + \gamma (1 - d) \max_{a'} Q(s', a'; \theta^-) - Q(s, a; \theta) \right)^2 \right] $$

где $d \in \{0, 1\}$ — индикатор терминального состояния (done flag). Два ключевых механизма стабилизации:

  1. Experience Replay (Буфер воспроизведения $\mathcal{D}$): Хранит кортежи $(s, a, r, s', d)$. Сэмплирование случайных минибатчей устраняет автокорреляцию последовательных кадров и стабилизирует обучение SGD.
  2. Target Network (Целевая сеть $\theta^-$): Веса $\theta^-$ замораживаются и обновляются периодически $\theta^- \leftarrow \theta$ раз в $C$ шагов, предотвращая расходимость и эффект «бегущей цели».

5. Double DQN (van Hasselt et al., 2015)

Стандартный DQN систематически завышает оценки $Q$ (Overestimation Bias) из-за оператора $\mathbb{E}[\max(X)] \ge \max(\mathbb{E}[X])$. Double DQN разделяет выбор действия и его оценку:

$$ y^{\text{DoubleDQN}} = r + \gamma (1 - d) Q\left(s', \arg\max_{a'} Q(s', a'; \theta); \, \theta^-\right) $$

Online-сеть $\theta$ выбирает лучшее действие $a^* = \arg\max_{a'} Q(s', a'; \theta)$, а Target-сеть $\theta^-$ вычисляет его ценность $Q(s', a^*; \theta^-)$.

6. Практическая реализация Q-Learning, SARSA и DQN на Python / PyTorch

import numpy as np
import torch
import torch.nn as nn
import torch.nn.functional as F

def q_learning_update(q_table, s, a, r, s_prime, alpha=0.1, gamma=0.9):
    """Табличный шаг обновления Q-Learning (Off-Policy)."""
    td_target = r + gamma * np.max(q_table[s_prime])
    td_error = td_target - q_table[s, a]
    q_table[s, a] += alpha * td_error
    return q_table

def sarsa_update(q_table, s, a, r, s_prime, a_prime, alpha=0.1, gamma=0.9):
    """Табличный шаг обновления SARSA (On-Policy)."""
    td_target = r + gamma * q_table[s_prime, a_prime]
    td_error = td_target - q_table[s, a]
    q_table[s, a] += alpha * td_error
    return q_table

class DQNNetwork(nn.Module):
    """Архитектура Deep Q-Network."""
    def __init__(self, state_dim, action_dim, hidden_dim=64):
        super().__init__()
        self.fc1 = nn.Linear(state_dim, hidden_dim)
        self.fc2 = nn.Linear(hidden_dim, hidden_dim)
        self.out = nn.Linear(hidden_dim, action_dim)

    def forward(self, x):
        x = F.relu(self.fc1(x))
        x = F.relu(self.fc2(x))
        return self.out(x)

def compute_dqn_loss(online_net, target_net, states, actions, rewards, next_states, dones, gamma=0.99):
    """Расчет MSE функции потерь DQN с целевой сетью."""
    q_values = online_net(states).gather(1, actions.unsqueeze(1)).squeeze(1)
    with torch.no_grad():
        max_next_q = target_net(next_states).max(dim=1)[0]
        target_q = rewards + gamma * (1.0 - dones) * max_next_q
    loss = F.mse_loss(q_values, target_q)
    return loss

4. Пошаговый числовой пример

🔢 Пример 1. Ручной расчет обновления ячейки Q-таблицы

Агент находится в состоянии $S_t = s_0$, совершает действие $A_t = a_1$, получает награду $R_{t+1} = +5.0$ и переходит в состояние $S_{t+1} = s_1$.

  • Параметры: $\alpha = 0.1, \quad \gamma = 0.9$.
  • Текущая Q-таблица:
    • В $s_0$: $Q(s_0, a_0) = 1.0, \quad Q(s_0, a_1) = 0.0, \quad Q(s_0, a_2) = 3.0$.
    • В $s_1$: $Q(s_1, a_0) = 2.0, \quad Q(s_1, a_1) = 6.0, \quad Q(s_1, a_2) = 4.0$.

1. Расчет обновления по Q-Learning:

Ищем максимальное значение в новом состоянии: $\max_{a'} Q(s_1, a') = \max(2.0, 6.0, 4.0) = 6.0$.

$$ \text{TD Target} = R_{t+1} + \gamma \max_{a'} Q(s_1, a') = 5.0 + 0.9 \cdot 6.0 = 5.0 + 5.4 = 10.4 $$
$$ \text{TD Error } \delta_t = 10.4 - Q(s_0, a_1) = 10.4 - 0.0 = +10.4 $$
$$ Q_{\text{new}}(s_0, a_1) = 0.0 + 0.1 \cdot 10.4 = 1.04 $$

2. Расчет обновления по SARSA:

Предположим, в состоянии $s_1$ исследовательская политика $\epsilon$-greedy выбрала действие $A_{t+1} = a_0$ с $Q(s_1, a_0) = 2.0$:

$$ \text{SARSA Target} = R_{t+1} + \gamma Q(s_1, a_0) = 5.0 + 0.9 \cdot 2.0 = 5.0 + 1.8 = 6.8 $$
$$ Q_{\text{new}}(s_0, a_1) = 0.0 + 0.1 \cdot (6.8 - 0.0) = 0.68 $$
🔢 Пример 2. Расчет DQN-таргета для батча переходов на PyTorch

Пусть батч размера $B=3$ содержит переходы:

  • Награды $R = [1.0, 0.0, 2.0]$, дисконт $\gamma = 0.99$.
  • Флаги окончания $dones = [0.0, 0.0, 1.0]$ (3-й переход ведет в терминал).
  • Выходы Target-сети для $s'$: $Q(s') = \begin{pmatrix} 1.2 & 0.5 \\ 0.8 & 1.5 \\ 2.1 & 1.9 \end{pmatrix}$.

Максимумы по действиям: $\max Q(s') = [1.2, 1.5, 2.1]$.

$$ y_1 = 1.0 + 0.99 \cdot (1 - 0) \cdot 1.2 = 1.0 + 1.188 = 2.188 $$ $$ y_2 = 0.0 + 0.99 \cdot (1 - 0) \cdot 1.5 = 0.0 + 1.485 = 1.485 $$ $$ y_3 = 2.0 + 0.99 \cdot (1 - 1) \cdot 2.1 = 2.0 + 0.0 = 2.000 \quad \text{(Терминал: будущее обнулено!)} $$

Реализация буфера воспроизведения Experience Replay на Python

import random
from collections import deque

class ReplayBuffer:
    def __init__(self, capacity=10000):
        self.buffer = deque(maxlen=capacity)

    def push(self, state, action, reward, next_state, done):
        self.buffer.append((state, action, reward, next_state, done))

    def sample(self, batch_size):
        return random.sample(self.buffer, batch_size)

    def __len__(self):
        return len(self.buffer)

6. 🎯 Препод спросит

1. В чем принципиальная разница в поведении SARSA и Q-learning на задаче Cliff Walking?

В Cliff Walking путь по краю обрыва короче, но падение с обрыва штрафуется на $-100$. Q-Learning обучается вне политики (Off-Policy), предполагая, что в будущем будет действовать строго жадно без ошибок, поэтому выбирает кратчайший путь прямо по краю. SARSA обучается в политике (On-Policy), учитывая, что с вероятностью $\epsilon$ агент совершает случайный шаг и может сорваться в обрыв. Поэтому SARSA выбирает длинный, но абсолютно безопасный путь вдалеке от края.

2. Зачем в DQN нужны Experience Replay и Target Network?

1) Experience Replay устраняет сильную временную автокорреляцию между соседними кадрами и делает распределение обучающей выборки стационарным (i.i.d.), позволяя оптимизировать сеть батчами SGD. 2) Target Network с замороженными весами $\theta^-$ фиксирует целевые значения $y = r + \gamma \max Q(s'; \theta^-)$, устраняя проблему «бегущей цели» (moving target problem), когда обновление сети одновременно сдвигает и предсказание, и цель.

3. Что такое «Смертоносная триада» (Deadly Triad) в обучении с подкреплением?

Deadly Triad — это одновременное присутствие трех факторов: 1) Аппроксимация функций (нейросети вместо таблиц); 2) Бутстрэпинг (обновление через $\gamma V(s')$ или $\max Q(s', a)$); 3) Обучение вне политики (Off-Policy). При наличии всех трех факторов математическая гарантия сходимости теряется, и веса сети могут уйти в бесконечность (расходимость). DQN решает это буфером и целевой сетью.

4. Почему стандартный Q-learning страдает от Overestimation Bias (завышения оценок)?

Из-за оператора максимума. Если оценки $Q(s', a)$ содержат шум со средним 0, то математическое ожидание максимума шумов строго положительно: $\mathbb{E}[\max_a (\mu_a + \epsilon_a)] \ge \max_a \mu_a$. Оператор $\max$ систематически отбирает шум с завышенной оценкой, накапливая ошибку по цепочке Беллмана. Double DQN устраняет это, разделяя выбор действия ($\theta$) и его оценку ($\theta^-$).

5. Почему в формуле таргета DQN для терминального состояния $S_{t+1}$ отбрасывается член $\gamma \max Q$?

Потому что терминальное состояние означает окончание эпизода. Будущих наград после терминала не существует по определению ($G = R_{\text{term}} + 0$). Если не обнулить член $\gamma \max Q(S_{t+1})$ с помощью множителя $(1 - d)$, сеть попытается предсказать несуществующее будущее, что приведет к грубым искажениям ценностей.

6. Можно ли применять Q-learning в задачах с непрерывным пространством действий $\mathcal{A} \subseteq \mathbb{R}^k$?

Напрямую нельзя, потому что для вычисления таргета требуется найти $\max_{a \in \mathcal{A}} Q(s', a)$. Если действий бесконечно много в непрерывном пространстве, взятие точного $\max$ требует решения сложной нелинейной задачи глобальной оптимизации на каждом шаге. Для непрерывных действий используют Policy Gradient / Actor-Critic (DDPG, SAC, PPO).

7. Чем Dueling DQN отличается от стандартного DQN?

Dueling DQN разделяет архитектуру сети на два потока: поток ценности состояния $V(s)$ и поток преимущества действий $A(s, a)$. Итоговое значение восстанавливается как $Q(s, a) = V(s) + \left( A(s, a) - \frac{1}{|\mathcal{A}|} \sum_{a'} A(s, a') \right)$. Это позволяет оценивать ценность состояния $V(s)$ даже тогда, когда выбор конкретного действия не оказывает решающего влияния.

8. Что такое Prioritized Experience Replay (PER)?

В стандартном DQN сэмплы извлекаются из буфера равномерно случайно. В PER сэмплы извлекаются с вероятностью, пропорциональной величине их TD-ошибки: $P(i) \propto |\delta_i|^\alpha$. Переходы, на которых сеть сильнее всего ошибается (содержащие наибольшую неожиданность), сэмплируются чаще. Смещение исправляется весами Importance Sampling $w_i = (N \cdot P(i))^{-\beta}$.

9. Каковы условия сходимости табличного Q-learning к $Q^*$ по теореме Ваткинса?

1) Все пары $(s, a)$ посещаются бесконечное число раз; 2) Скорости обучения удовлетворяют условиям Роббинса-Монро: $\sum_{t=0}^\infty \alpha_t(s, a) = \infty$ и $\sum_{t=0}^\infty \alpha_t^2(s, a) < \infty$; 3) Награды ограничены, а фактор дисконтирования $\gamma < 1$.

10. Что такое TD($\lambda$) и Eligibility Traces (следы пригодности)?

TD($\lambda$) — это непрерывный мост между одношаговым TD(0) ($\lambda=0$) и полным методом Монте-Карло ($\lambda=1$). Он объединяет $n$-шаговые доходы с экспоненциальными весами: $G_t^\lambda = (1-\lambda) \sum_{n=1}^\infty \lambda^{n-1} G_{t:t+n}$. Механизм Eligibility Traces $e_t(s) = \gamma \lambda e_{t-1}(s) + \mathbb{I}(S_t=s)$ позволяет распространять ошибку назад во времени за один проход онлайн.

7. 📝 Микро-задачи с решениями

Задача 1. Расчет ошибки TD(0) для ценности состояния

Текущая оценка $V(S_t) = 15.0$. Агент получил награду $R_{t+1} = 3.0$ и перешел в $S_{t+1}$ с оценкой $V(S_{t+1}) = 12.0$. Дисконт $\gamma = 0.9$, шаг обучения $\alpha = 0.2$. Вычислите TD-ошибку $\delta_t$ и новое значение $V(S_t)$.

Решение

1) TD-таргет: $y_t = R_{t+1} + \gamma V(S_{t+1}) = 3.0 + 0.9 \cdot 12.0 = 3.0 + 10.8 = 13.8$.

2) TD-ошибка: $\delta_t = y_t - V(S_t) = 13.8 - 15.0 = -1.2$.

3) Обновление: $V(S_t) \leftarrow 15.0 + 0.2 \cdot (-1.2) = 15.0 - 0.24 = 14.76$.

Ответ: $\delta_t = -1.2, V(S_t) = 14.76$.

Задача 2. Обновление Q-learning со штрафом

В $s_0$ совершено действие $a_{\text{jump}}$ с $Q(s_0, a_{\text{jump}}) = 2.0$. Награда $R = -10.0$ (падение). Новое состояние $s_{\text{pit}}$ имеет оценки $Q(s_{\text{pit}}, a_1) = 0.0, Q(s_{\text{pit}}, a_2) = 1.0$. Дисконт $\gamma = 0.9$, $\alpha = 0.5$. Чему равно новое $Q(s_0, a_{\text{jump}})$?

Решение

1) $\max_{a'} Q(s_{\text{pit}}, a') = \max(0.0, 1.0) = 1.0$.

2) $\text{Target} = -10.0 + 0.9 \cdot 1.0 = -9.1$.

3) $\delta = -9.1 - 2.0 = -11.1$.

4) $Q_{\text{new}} = 2.0 + 0.5 \cdot (-11.1) = 2.0 - 5.55 = -3.55$.

Ответ: $Q_{\text{new}}(s_0, a_{\text{jump}}) = -3.55$.

Задача 3. Расчет таргета Double DQN

В состоянии $s'$ Online-сеть предсказывает $Q(s'; \theta) = [4.2, 5.8, 3.1]$ для трех действий. Target-сеть предсказывает $Q(s'; \theta^-) = [4.5, 3.9, 3.4]$. Награда $R = 2.0$, $\gamma = 0.9$, переход нетерминальный ($d=0$). Чему равен таргет Double DQN и стандартного DQN?

Решение

1) Double DQN: Online-сеть выбирает действие: $a^* = \arg\max(4.2, 5.8, 3.1) = a_2$ (индекс 1). Target-сеть оценивает это действие: $Q(s', a_2; \theta^-) = 3.9$.

$$ y^{\text{DoubleDQN}} = 2.0 + 0.9 \cdot 3.9 = 2.0 + 3.51 = 5.51 $$

2) Стандартный DQN: берет максимум по Target-сети $\max(4.5, 3.9, 3.4) = 4.5$.

$$ y^{\text{DQN}} = 2.0 + 0.9 \cdot 4.5 = 2.0 + 4.05 = 6.05 $$

Видно, что Double DQN защитил от переоценки (5.51 против 6.05)!

Ответ: Double DQN: 5.51; Стандартный DQN: 6.05.

Задача 4. Влияние терминального флага done в DQN

Даны два перехода с одинаковыми $R=10.0, \gamma=0.9, \max Q(s')=20.0$. Для первого перехода $done=0$, для второго $done=1$. Вычислите оба целевых значения $y$.

Решение

Формула таргета: $y = R + \gamma (1 - done) \max Q(s')$.

  • Переход 1 ($done=0$): $y_1 = 10.0 + 0.9 \cdot (1 - 0) \cdot 20.0 = 10.0 + 18.0 = 28.0$.
  • Переход 2 ($done=1$): $y_2 = 10.0 + 0.9 \cdot (1 - 1) \cdot 20.0 = 10.0 + 0.0 = 10.0$.

Ответ: $y_1 = 28.0, y_2 = 10.0$.

Задача 5. Расчет градиента функции потерь DQN

Для одного перехода предсказание сети $Q(s, a; \theta) = 4.0$, а вычисленный таргет $y = 6.0$. Функция потерь MSE: $\mathcal{L} = (y - Q(s, a; \theta))^2$. Чему равна производная $\frac{\partial \mathcal{L}}{\partial Q(s, a)}$?

Решение

Берем производную сложной функции по $Q$ (помня, что таргет $y$ зафиксирован через stop_gradient / target network):

$$ \frac{\partial \mathcal{L}}{\partial Q} = \frac{\partial (y - Q)^2}{\partial Q} = 2(y - Q) \cdot (-1) = -2(y - Q) = 2(Q - y) = 2(4.0 - 6.0) = -4.0 $$

Ответ: $\frac{\partial \mathcal{L}}{\partial Q} = -4.0$.

Задача 6. Сравнение шагов SARSA и Q-learning при стохастическом выборе

В $s_0$ выполнено $a_1$ с $Q(s_0, a_1)=0$. $R=+1, \gamma=0.5, \alpha=1.0$. В следующем состоянии $s_1$ оценки $Q(s_1, a_1)=10.0, Q(s_1, a_2)=2.0$. Стратегия с вероятностью $0.8$ выбирает $a_1$, с вероятностью $0.2$ выбирает $a_2$. Чему равно математическое ожидание нового значения $Q(s_0, a_1)$ для алгоритмов Expected SARSA и Q-Learning?

Решение

1) Q-Learning: Target $= 1 + 0.5 \cdot \max(10.0, 2.0) = 1 + 5.0 = 6.0 \implies Q_{\text{new}} = 6.0$.

2) Expected SARSA: берет матожидание по стратегии: $\mathbb{E}[Q(s_1, a')] = 0.8 \cdot 10.0 + 0.2 \cdot 2.0 = 8.0 + 0.4 = 8.4$.

$$ \text{Target}_{\text{ExpSARSA}} = 1 + 0.5 \cdot 8.4 = 1 + 4.2 = 5.2 \implies Q_{\text{new}} = 5.2 $$

Ответ: Q-Learning: 6.0; Expected SARSA: 5.2.

8. ⚡ Скелет ответа по билету

Скелет устного ответа по билету 23 (Базовые алгоритмы RL: TD, Q-Learning, SARSA, DQN)
  1. Суть TD-обучения: Синтез DP и MC. Обучение без модели (на сыром опыте) с бутстрэпингом (обновление оценки $V(S_t)$ через $R_{t+1} + \gamma V(S_{t+1})$ без ожидания исхода эпизода). TD-ошибка: $\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)$.
  2. SARSA (On-Policy TD Control): $Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha [ R_{t+1} + \gamma Q(S_{t+1}, A_{t+1}) - Q(S_t, A_t) ]$. Оценивает реальную исследовательскую политику, выбирая безопасные траектории (Cliff Walking).
  3. Q-Learning (Off-Policy TD Control): $Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha [ R_{t+1} + \gamma \max_a Q(S_{t+1}, a) - Q(S_t, A_t) ]$. Напрямую сходится к $Q^*$, обучаясь на опыте произвольной поведенческой стратегии.
  4. Deep Q-Network (DQN): Аппроксимация нейросетью $Q(s, a; \theta)$. Loss: $\mathcal{L}(\theta) = \mathbb{E} [ (r + \gamma(1-d)\max_{a'} Q(s', a'; \theta^-) - Q(s, a; \theta))^2 ]$.
  5. Experience Replay: Буфер $\mathcal{D}$ разрывает временную корреляцию последовательных кадров, превращая обучение в стационарный i.i.d. батчевый SGD.
  6. Target Network $\theta^-$: Фиксирует таргет на $C$ шагов, предотвращая расходимость и эффект «бегущей цели».
  7. Double DQN: Устраняет Overestimation Bias разделением выбора действия ($\arg\max Q(\theta)$) и его оценки ($Q(\theta^-)$): $y = r + \gamma Q(s', \arg\max Q(s'; \theta); \theta^-)$.
