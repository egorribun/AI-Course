1. Temporal Difference Learning

Temporal Difference (TD-обучение, Sutton, 1988) — центральная идея современного RL. Это синтез лучших качеств методов динамического программирования (DP) и методов Монте-Карло (MC):

  • Как Монте-Карло: Не требует знания модели среды (Model-Free) — учится напрямую на сыром опыте взаимодействия.
  • Как Динамическое Программирование: Использует бутстрэппинг — обновляет оценку на каждом отдельном шаге ($t \to t+1$), не дожидаясь завершения всего эпизода!

2. Алгоритм TD(0) для оценивания ценности

На шаге $t$ агент находится в $s_t$, совершает действие, получает награду $r_{t+1}$ и переходит в $s_{t+1}$. Мы обновляем ценность $V(s_t)$ в сторону TD-мишени (TD Target):

$$ \text{TD-Target}: \quad y_t = r_{t+1} + \gamma V(s_{t+1}) $$ $$ \text{TD-Error}: \quad \delta_t = r_{t+1} + \gamma V(s_{t+1}) - V(s_t) $$ $$ V(s_t) \leftarrow V(s_t) + \alpha \, \delta_t $$ $\alpha \in (0, 1]$ — скорость обучения (Learning Rate). Обновление происходит моментально после 1 шага!

3. SARSA: On-policy управление

Для бессмодельного поиска оптимальной стратегии мы переходим к функции ценности действий $Q(s, a)$.

SARSA (State-Action-Reward-State-Action, Rummery & Niranjan, 1994) использует кортеж $(s_t, a_t, r_{t+1}, s_{t+1}, a_{t+1})$.

$$ Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha \left[ r_{t+1} + \gamma Q(s_{t+1}, a_{t+1}) - Q(s_t, a_t) \right] $$ В SARSA действие $a_{t+1}$ берется из той же $\epsilon$-greedy стратегии, по которой агент реально действует.

4. Q-learning: Off-policy управление

Q-learning (Chris Watkins, 1989) — один из самых знаменитых алгоритмов в истории ИИ. В нем целевое действие следующего шага выбирается строго жадно (через оператор максимума $\max_{a'}$):

$$ Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha \left[ r_{t+1} + \gamma \max_{a' \in \mathcal{A}} Q(s_{t+1}, a') - Q(s_t, a_t) \right] $$ Q-learning аппроксимирует уравнение оптимальности Беллмана $Q^*(s, a)$ напрямую!

6. Deep Q-Networks (DQN, Mnih et al., 2015)

В реальных задачах (видеоигры Atari, робототехника) число состояний непрерывно или огромно ($|\mathcal{S}| \approx 256^{210 \times 160 \times 3}$). Табличный $Q(s, a)$ неприменим. Мы аппроксимируем его нейросетью: $Q(s, a; \theta) \approx Q^*(s, a)$.

❌ Смертельная триада RL (The Deadly Triad)

При наивном обучении нейросети лоссом $(r + \gamma \max Q(s', a'; \theta) - Q(s, a; \theta))^2$ обучение разваливается и расходится из-за трех факторов:

  1. Функциональная аппроксимация (нейросеть меняет предсказания сразу для многих состояний).
  2. Бутстрэппинг (мишень зависит от текущих весов $\theta$).
  3. Off-policy обучение (сдвиг распределения данных).

7. Два столпа стабильности DQN

Исследователи DeepMind решили проблему сходимости двумя ключевыми механизмами:

1. EXPERIENCE REPLAY BUFFER (D): [ (s_0, a_0, r_1, s_1), (s_1, a_1, r_2, s_2), ... ] (Размер: 1 000 000 кадров) │ Случайный мини-батч (B = 32) -> Разрушает временную корреляцию кадров! ▼ 2. TARGET NETWORK (θ⁻): Q-Network (θ) ──▶ Предсказание Q(s, a; θ) ├──▶ Loss = (Target - Pred)^2 ──▶ Оптимизация θ Target Net (θ⁻) ─▶ Мишень y = r + γ max Q(s', a'; θ⁻) ▲ └────── Копирование весов θ⁻ ⟵ θ раз в 10 000 шагов (Фиксированная мишень) Архитектура DQN: Experience Replay и Target Network стабилизируют глубинное обучение с подкреплением.
🎯 Почему Target Network устраняет расходимость?

Без Target Network, когда мы обновляем веса $\theta$, чтобы приблизить $Q(s, a; \theta)$ к мишени, сама мишень $r + \gamma \max Q(s', a'; \theta)$ тоже смещается в ту же сторону («собака гонится за собственным хвостом»). Фиксация весов целевой сети $\theta^-$ делает задачу эквивалентной стабильному Supervised Learning с неподвижной мишенью на протяжении $C$ шагов.

8. Улучшения DQN: Double DQN и Dueling DQN

1. Double DQN (DDQN, van Hasselt et al., 2015):

Классический Q-learning страдает от систематической переоценки Q-значений (Overestimation Bias) из-за оператора $\max_{a'} Q(s', a')$.

Решение: Разделить выбор действия и его оценку между двумя сетями:

$$ y_t^{\text{DoubleQ}} = r_{t+1} + \gamma Q\left( s_{t+1}, \, \arg\max_{a'} Q(s_{t+1}, a'; \, \theta); \, \theta^- \right) $$ Основная сеть $\theta$ выбирает лучшее действие, а целевая сеть $\theta^-$ беспристрастно оценивает его ценность.

2. Dueling DQN (Wang et al., 2016):

Архитектура нейросети делится на два потока: поток ценности состояния $V(s)$ и поток преимуществ действий $A(s, a)$ (Advantage):

$$ Q(s, a) = V(s) + \left( A(s, a) - \frac{1}{|\mathcal{A}|}\sum_{a'} A(s, a') \right) $$

9. Практическая реализация DQN на PyTorch

import torch
import torch.nn as nn
import torch.optim as optim
import random
from collections import deque

class DQN(nn.Module):
    def __init__(self, state_dim, action_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(state_dim, 128),
            nn.ReLU(),
            nn.Linear(128, 128),
            nn.ReLU(),
            nn.Linear(128, action_dim)
        )
    def forward(self, x):
        return self.net(x)

def compute_dqn_loss(model, target_model, batch, gamma=0.99):
    states, actions, rewards, next_states, dones = batch
    
    # 1. Текущие Q-значения: Q(s, a; \theta)
    q_values = model(states).gather(1, actions.unsqueeze(1)).squeeze(1)
    
    # 2. Target Q-значения по целевой сети: r + \gamma * max Q(s', a'; \theta^-)
    with torch.no_grad():
        next_q_values = target_model(next_states).max(dim=1)[0]
        target = rewards + gamma * next_q_values * (1 - dones)
        
    # 3. Huber Loss (Smooth L1) для устойчивости к выбросам
    loss = nn.functional.smooth_l1_loss(q_values, target)
    return loss

🎯 Препод спросит

В чем математическая разница в формулах обновления SARSA и Q-learning?

В SARSA в качестве мишени используется $r_{t+1} + \gamma Q(s_{t+1}, a_{t+1})$, где $a_{t+1}$ — действие, фактически выбранное текущей стратегией агента ($\epsilon$-greedy). В Q-learning в мишени стоит $r_{t+1} + \gamma \max_{a'} Q(s_{t+1}, a')$, то есть берется максимальное возможное значение без учета случайного исследования.

Почему SARSA называют On-policy, а Q-learning — Off-policy?

On-policy означает, что мы оцениваем и улучшаем ту же самую стратегию, которая управляет поведением агента при сборе данных. Off-policy означает, что мы собираем опыт по одной стратегии (исследовательской $\mu$, например $\epsilon$-greedy), но при этом вычисляем ценность и обучаем другую стратегию — целевую оптимальную стратегию $\pi^* = \arg\max Q$.

Зачем в DQN нужен буфер Experience Replay?

1. Устранение автокорреляции данных: Последовательные кадры в игре почти идентичны ($s_t \approx s_{t+1}$). Сэмплирование случайных батчей из буфера делает примеры независимыми и одинаково распределенными ($i.i.d.$).
2. Повторное использование опыта: Редкие и важные переходы (например, победа или смерть) проигрываются нейросетью многократно.

Какую проблему решает Target Network в DQN?

Проблему нестабильности целевого значения (Moving Target Problem). Если считать целевой таргет по той же сети, которую мы обучаем, мишень постоянно смещается при каждом градиентном шаге. Заморозка весов $\theta^-$ стабилизирует оптимизацию, превращая ее в контролируемую задачу регрессии.

Что такое Overestimation Bias в Q-learning и как его лечит Double DQN?

Оператор $\max_{a'} Q(s', a')$ в условиях шума и неточных оценок берет максимум по случайным флуктуациям ($\mathbb{E}[\max(X, Y)] \ge \max(\mathbb{E}[X], \mathbb{E}[Y])$), систематически завышая ценность действий. Double DQN устраняет это, используя основную сеть $\theta$ для выбора аргумента максимума $a^* = \arg\max Q(s', a'; \theta)$, а целевую сеть $\theta^-$ — для его независимой оценки $Q(s', a^*; \theta^-)$.

Что входит в «Смертельную триаду» (Deadly Triad) в RL?

Сочетание трех элементов: 1) Функциональная аппроксимация (нейросети); 2) Бутстрэппинг (обновление через оценки следующих состояний $V(s')$); 3) Off-policy обучение. Их совместное применение может приводить к расходимости алгоритмов обучения.

Как TD-ошибка $\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)$ связана с преимуществом (Advantage) и почему сумма дисконтированных TD-ошибок равна ошибке Монте-Карло?

1. Связь с функцией преимущества: Одношаговая TD-ошибка является несмещенной выборочной оценкой преимущества действия $A(s_t, a_t) = Q(s_t, a_t) - V(s_t)$:

$$ \mathbb{E}[\delta_t \mid S_t = s, A_t = a] = \mathbb{E}[R_{t+1} + \gamma V(S_{t+1}) \mid s, a] - V(s) = Q(s, a) - V(s) = A(s, a) $$

2. Телескопическая сумма вдоль траектории: Суммируя дисконтированные ошибки $\delta_{t+k}$ от шага $t$ до терминального состояния $T$ (где $V(S_T) = 0$):

$$ \sum_{k=0}^{T-t-1} \gamma^k \delta_{t+k} = \sum_{k=0}^{T-t-1} \gamma^k \left( R_{t+k+1} + \gamma V(S_{t+k+1}) - V(S_{t+k}) \right) = \sum_{k=0}^{T-t-1} \gamma^k R_{t+k+1} - V(S_t) = G_t - V(S_t) $$

Все промежуточные слагаемые ценностей $\gamma^k V(S_{t+k})$ взаимно сокращаются, доказывая, что накопленная сумма локальных TD-ошибок строго равна глобальной ошибке прогноза Монте-Карло.

В чем различие поведения SARSA и Q-learning на классической задаче Cliff Walking (Хождение по краю обрыва)?

В задаче Cliff Walking путь по краю обрыва минимален по длине, но шаг в пропасть дает штраф $-100$ и сброс на старт.

  • Q-learning (Off-policy): выучивает теоретически оптимальную политику $\pi^*(s)$, проходящую строго по самому краю обрыва. Однако во время обучения агент действует с $\epsilon$-исследованием, поэтому регулярно срывается в пропасть при случайных действиях и получает низкую суммарную награду на этапе тренировки.
  • SARSA (On-policy): учитывает, что агент реально действует по $\epsilon$-greedy политике. Оценивая реальный риск случайного срыва, SARSA выучивает более длинный, но безопасный путь вдали от края обрыва.
Докажите возникновение Overestimation Bias в Q-learning через неравенство Йенсена и объясните схему Double Q-Learning.

Пусть истинные ценности равны $Q^*(s, a)$, а оценки зашумлены случайной центрированной величиной $\epsilon_a$: $\hat{Q}(s, a) = Q^*(s, a) + \epsilon_a$ ($\mathbb{E}[\epsilon_a] = 0$).

Так как операция максимума является выпуклой функцией, по неравенству Йенсена:

$$ \mathbb{E}\left[ \max_{a} \hat{Q}(s, a) \right] \ge \max_{a} \mathbb{E}\left[ \hat{Q}(s, a) \right] = \max_{a} Q^*(s, a) $$

Оператор $\max$ отбирает положительные шумовые выбросы, систематически завышая целевое значение $y_t$.

Double Q-Learning (van Hasselt): разделяет выбор действия и его оценку между двумя независимыми моделями $Q^A$ и $Q^B$:

$$ a^* = \arg\max_{a} Q^A(s', a), \qquad y_t = R + \gamma Q^B(s', a^*) $$

Поскольку $Q^B$ не участвовала в выборе $a^*$, ее значение является несмещенной оценкой $\mathbb{E}[Q^B(s', a^*)] = Q^*(s', a^*)$, полностью устраняя систематическое смещение.

Почему возникает расходимость из-за «Смертельной триады» (Deadly Triad) и как DQN обеспечивает стабильность?

При совмещении функциональной аппроксимации (нейросеть $Q_\theta$), бутстрэппинга ($r + \gamma \max Q$) и обучения вне политики (Off-policy) оператор обновления представляет собой проекцию оператора Беллмана на гиперповерхность весов сети $\Pi \mathcal{T}$.

Вне политики норма оператора $\|\Pi \mathcal{T}\|$ может превышать 1 (спектральный радиус $\rho > 1$), что превращает сжимающее отображение в расширяющее: ошибки бутстрэппинга лавинообразно накапливаются, приводя к расходимости градиентов (контрпример Tsitsiklis-Van Roy).

Меры стабилизации в DQN:

  • Target Network ($\theta^-$): фиксирует параметры мишени на $C$ шагов, разрывая петлю положительной обратной связи при бутстрэппинге.
  • Experience Replay: перемешивает данные во времени, устраняя автокорреляцию между последовательными шагами среды.
  • Huber Loss / Smooth L1: предотвращает взрыв градиентов при больших TD-ошибках.

📝 Микро-задачи

Задача 1. Ручной расчет шага Q-learning

Текущее $Q(s, a) = 5.0$. Агент получил награду $r = 2.0$ и перешел в $s'$, где $Q(s', a_1) = 8.0, Q(s', a_2) = 4.0$. Параметры: $\gamma = 0.5, \alpha = 0.1$. Найдите новое значение $Q(s, a)$.

Решение

1. TD-мишень: $y = r + \gamma \max Q(s', a') = 2.0 + 0.5 \cdot \max(8.0, 4.0) = 2.0 + 0.5 \cdot 8.0 = 6.0$.

2. TD-ошибка: $\delta = y - Q(s, a) = 6.0 - 5.0 = 1.0$.

3. Обновление: $Q_{\text{new}}(s, a) = 5.0 + 0.1 \cdot 1.0 = 5.1$.

Задача 2. Ручной расчет шага SARSA

В тех же условиях ($Q(s, a) = 5.0, r = 2.0, \gamma=0.5, \alpha=0.1$). Агент перешел в $s'$ и по $\epsilon$-greedy стратегии случайно выбрал действие $a_2$ ($Q(s', a_2) = 4.0$). Найдите новое значение $Q(s, a)$.

Решение

1. TD-мишень SARSA: $y = r + \gamma Q(s', a_2) = 2.0 + 0.5 \cdot 4.0 = 4.0$.

2. TD-ошибка: $\delta = 4.0 - 5.0 = -1.0$.

3. Обновление: $Q_{\text{new}}(s, a) = 5.0 + 0.1 \cdot (-1.0) = 4.9$.

(В Q-learning значение выросло до 5.1, а в SARSA упало до 4.9 из-за учета выбранного действия $a_2$!).

Задача 3. Расчет мишени Double DQN (DDQN)

В состоянии $s'$ основная сеть выдает: $Q(s', a_1; \theta) = 10.0, Q(s', a_2; \theta) = 12.0$. Целевая сеть выдает: $Q(s', a_1; \theta^-) = 9.0, Q(s', a_2; \theta^-) = 5.0$. Награда $r = 1.0, \gamma = 0.9$. Найдите мишень $y$ для DQN и Double DQN.

Решение

1. Обычный DQN: $y = r + \gamma \max Q(s', a'; \theta^-) = 1.0 + 0.9 \cdot \max(9.0, 5.0) = 1.0 + 0.9 \cdot 9.0 = 9.1$.

2. Double DQN:

  • Основная сеть выбирает действие: $a^* = \arg\max(10.0, 12.0) = a_2$.
  • Целевая сеть оценивает это действие $a_2$: $Q(s', a_2; \theta^-) = 5.0$.
  • $y^{\text{DDQN}} = 1.0 + 0.9 \cdot 5.0 = 1.0 + 4.5 = 5.5$.

Double DQN предотвратил переоценку мишени с 9.1 до 5.5.

Задача 4. Учет терминального состояния в TD-таргете

Агент перешел в терминальное состояние $s_{\text{term}}$ (флаг `done = True`) с наградой $r = 10.0$. Чему равна TD-мишень $y$ при любом значении $\gamma$ и любых предсказаниях сети?

Решение

В терминальном состоянии будущее завершено, ценность преемников строго равна 0:

$$ y = r + \gamma \cdot 0 = 10.0 $$

Задача 5. Разделение потоков в Dueling DQN

Для состояния $s$ сеть выдала $V(s) = 10.0$ и вектор преимуществ $A(s) = [2.0, 4.0, 0.0]$. Найдите итоговые Q-значения для всех трех действий.

Решение

Среднее преимуществ: $\bar{A} = \frac{2.0 + 4.0 + 0.0}{3} = 2.0$.

Формула: $Q(s, a_i) = V(s) + (A(s, a_i) - \bar{A})$.

  • $Q(s, a_1) = 10.0 + (2.0 - 2.0) = 10.0$.
  • $Q(s, a_2) = 10.0 + (4.0 - 2.0) = 12.0$.
  • $Q(s, a_3) = 10.0 + (0.0 - 2.0) = 8.0$.
Задача 6. Мягкое обновление весов (Polyak Averaging)

Вместо жесткого копирования весов каждые $C$ шагов используется Polyak averaging: $\theta^- \leftarrow \tau \theta + (1-\tau) \theta^-$. Пусть $\theta^- = 10.0, \theta = 20.0, \tau = 0.01$. Найдите новое значение $\theta^-$.

Решение

$$ \theta^- = 0.01 \cdot 20.0 + 0.99 \cdot 10.0 = 0.2 + 9.9 = 10.1 $$

⚡ Ответ за 3 минуты

Скелет устного ответа по билету 23 (TD, SARSA, Q-learning, DQN)
  1. Суть TD-обучения. Синтез DP и MC: безмодельное обучение (Model-Free) с пошаговым бутстрэппингом $V(s) \leftarrow V(s) + \alpha [r + \gamma V(s') - V(s)]$.
  2. SARSA (On-policy). Кортеж $(s, a, r, s', a')$. Мишень $r + \gamma Q(s', a')$ использует действие $a'$, реально выбранное исследовательской стратегией.
  3. Q-learning (Off-policy). Кортеж $(s, a, r, s')$. Мишень $r + \gamma \max_{a'} Q(s', a')$ учит оптимальную функцию $Q^*$ независимо от действий агента.
  4. On vs Off policy. SARSA осторожна к риску exploration (обходит обрыв). Q-learning учит кратчайший теоретический путь и умеет учиться по офлайн-буферу.
  5. DQN (DeepMind, 2015). Аппроксимация $Q(s, a; \theta)$ нейросетью. Решает проблему смертельной триады (Deadly Triad).
  6. Experience Replay. Буфер переходов $\mathcal{D}$. Случайные батчи разрушают корреляцию последовательных кадров.
  7. Target Network $\theta^-$. Замороженная сеть для расчета мишени $r + \gamma \max Q(s', a'; \theta^-)$, устраняет проблему бегущей мишени.
  8. Double DQN. Сеть $\theta$ выбирает действие $\arg\max$, сеть $\theta^-$ оценивает его — устраняет завышение наград (Overestimation Bias).
