1. Интуиция и мотивация

До 2017 года в обработке естественного языка (NLP) и последовательностей безраздельно доминировали рекуррентные архитектуры (RNN, LSTM, biLSTM, GRU). Однако они упирались в фундаментальное ограничение — строгую последовательность вычислений по временной оси: шаг $t$ не может начаться до полного завершения шага $t-1$. Это делало невозможным масштабирование моделей на массивные вычислительные кластеры GPU и TPU.

Статья команды Google Brain (Vaswani et al., 2017) «Attention Is All You Need» доказала, что от рекуррентности и сверток можно отказаться целиком, построив глубокую модель исключительно на механизмах внимания, полносвязных слоях и нормализации.

💡 Три кита превосходства архитектуры Transformer
  1. Массивный параллелизм при обучении: Все $T$ токенов последовательности обрабатываются одновременно через матричные операции за $O(1)$ параллельных шагов на GPU.
  2. Прямой контакт между токенами ($O(1)$ длина пути): Любой токен напрямую взаимодействует с любым другим через скалярное произведение, устраняя затухание градиента на длинных контекстах.
  3. Законы масштабирования (Scaling Laws): Архитектура обладает превосходной вычислительной масштабируемостью, что открыло дорогу современным языковым моделям (LLM) с сотнями миллиардов параметров.

2. Архитектура и схема

Оригинальный Transformer имеет структуру Encoder-Decoder, предназначенную для задач трансформации последовательности в последовательность (Seq2Seq, машинный перевод):

ВЫХОДНЫЕ ВЕРОЯТНОСТИ (Словарь |V|) ▲ [ Linear + Softmax ] │ ┌─────────────────────────┴────────────────────────┐ │ СТЕК ДЕКОДЕРА (N = 6 слоев) │ │ ┌────────────────────────────────────────────┐ │ │ │ Feed-Forward Network + Add & LayerNorm │ │ │ └──────────────────────▲─────────────────────┘ │ │ │ │ ┌────────┼──────────┐ ┌──────┴─────────────────────┐ │ │ СТЕК ЭНКОДЕРА │ │ Cross-Attention (Q, K, V) │ │ │ (N = 6 слоев) │──────▶│ + Add & LayerNorm │ │ │ ┌──────────────┐ │ K, V └──────────────▲─────────────┘ │ │ │ FFN + Norm │ │ │ │ │ └──────▲───────┘ │ ┌──────────────┴─────────────┐ │ │ ┌──────┴───────┐ │ │ Masked Self-Attention │ │ │ │ Self-Attn │ │ │ + Add & LayerNorm │ │ │ │ + Norm │ │ └──────────────▲─────────────┘ │ │ └──────▲───────┘ │ │ │ └────────┼──────────┘ └──────────────┼────────────────┘ │ │ (Pos Encoding) (Pos Encoding) ▲ ▲ [ Input Embeddings ] [ Output Embeddings ] ▲ ▲ Входные токены (EN) Целевые токены (RU) (Сдвинуты вправо) Каноническая схема Transformer: $N=6$ блоков энкодера и $N=6$ блоков декодера со связью через Cross-Attention.

Сравнение топологий нормализации: Post-LN vs Pre-LN

В оригинальной статье 2017 года использовалась схема Post-LN, однако современные модели перешли на Pre-LN:

POST-LN (Оригинал 2017): PRE-LN (Современный стандарт: GPT, LLaMA): x ──┬──▶ [ SubLayer ] ──▶ [ + ] ──▶ [ LayerNorm ] ──▶ x ──┬──▶ [ LayerNorm ] ──▶ [ SubLayer ] ──▶ [ + ] ──▶ └─────────────────────▲ └────────────────────────────────────────▲ Pre-LN сохраняет прямой неискаженный остаточный тракт (Residual Stream), обеспечивая градиентный поток сквозь 100+ слоев.

3. Математический аппарат

1. Блок Энкодера (Encoder Block)

Входной тензор $X \in \mathbb{R}^{T \times d_{\text{model}}}$ проходит через два основных подблока, объединенных остаточными связями (Residual Connections) и послойной нормализацией (LayerNorm):

$$ X^{(1)} = \text{LayerNorm}\left( X + \text{MultiHeadSelfAttention}(X) \right) $$
$$ X^{(2)} = \text{LayerNorm}\left( X^{(1)} + \text{FFN}(X^{(1)}) \right) $$

2. Многоголовое внимание (Multi-Head Attention)

Вместо вычисления одной проекции внимания размерности $d_{\text{model}}$, вход проецируется в $h$ независимых пространств меньшей размерности $d_k = d_v = d_{\text{model}} / h$:

$$ \text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h) W^O $$
$$ \text{head}_i = \text{Attention}\left( Q W_i^Q, \, K W_i^K, \, V W_i^V \right) = \text{softmax}\left( \frac{(Q W_i^Q)(K W_i^K)^\top}{\sqrt{d_k}} \right) (V W_i^V) $$
  • $W_i^Q \in \mathbb{R}^{d_{\text{model}} \times d_k}$, $W_i^K \in \mathbb{R}^{d_{\text{model}} \times d_k}$, $W_i^V \in \mathbb{R}^{d_{\text{model}} \times d_v}$ — проекционные матрицы $i$-й головы.
  • $W^O \in \mathbb{R}^{h d_v \times d_{\text{model}}}$ — финальная объединяющая проекция.

3. Полносвязная сеть над каждой позицией (Position-wise FFN)

Применяется к каждому токену независимо и идентично, проецируя вектор в расширенное пространство $d_{\text{ff}} = 4 d_{\text{model}}$:

$$ \text{FFN}(x) = \max\left(0, \, x W_1 + b_1\right) W_2 + b_2 = \text{GELU}\left(x W_1 + b_1\right) W_2 + b_2 $$
  • $W_1 \in \mathbb{R}^{d_{\text{model}} \times d_{\text{ff}}}$, $b_1 \in \mathbb{R}^{d_{\text{ff}}}$ — расширяющий слой.
  • $W_2 \in \mathbb{R}^{d_{\text{ff}} \times d_{\text{model}}}$, $b_2 \in \mathbb{R}^{d_{\text{model}}}$ — сужающий слой.

4. Послойная нормализация (LayerNorm)

Вычисляет среднее $\mu$ и дисперсию $\sigma^2$ по вектору скрытых признаков одного токена (независимо от размера батча $B$ и позиции $t$):

$$ \mu = \frac{1}{d} \sum_{j=1}^d x_j, \quad \sigma^2 = \frac{1}{d} \sum_{j=1}^d (x_j - \mu)^2, \quad \hat{x} = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} \odot \gamma + \beta $$

где $\gamma, \beta \in \mathbb{R}^d$ — обучаемые масштабирующие параметры.

5. Синусоидальное позиционное кодирование (Positional Encoding)

Поскольку операция внимания инвариантна к перестановкам токенов, порядок слов кодируется вектором $PE \in \mathbb{R}^{T \times d_{\text{model}}}$, прибавляемым к входным эмбеддингам:

$$ PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i / d_{\text{model}}}}\right), \quad PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i / d_{\text{model}}}}\right) $$

где $pos \in [0, T-1]$ — позиция токена, $i \in [0, \frac{d}{2}-1]$ — индекс частотной гармоники.

4. Пошаговый числовой пример

Рассчитаем пошагово нормализацию LayerNorm и синусоидальное позиционное кодирование для вектора размерности $d_{\text{model}} = 4$.

1. Расчет LayerNorm для скрытого состояния токена:

Пусть входной вектор токена $x = [2.0, \, 4.0, \, 6.0, \, 8.0]$, параметры $\gamma = [1.0, 1.0, 1.0, 1.0]$, $\beta = [0.0, 0.0, 0.0, 0.0]$, $\epsilon = 10^{-5}$.

  1. Среднее значение:
    $$ \mu = \frac{2.0 + 4.0 + 6.0 + 8.0}{4} = \frac{20.0}{4} = \mathbf{5.0} $$
  2. Дисперсия:
    $$ \sigma^2 = \frac{(2-5)^2 + (4-5)^2 + (6-5)^2 + (8-5)^2}{4} = \frac{9 + 1 + 1 + 9}{4} = \frac{20}{4} = \mathbf{5.0} $$
    $$ \sqrt{\sigma^2 + \epsilon} = \sqrt{5.00001} \approx \mathbf{2.2361} $$
  3. Нормализованный вектор $\hat{x}$:
    • $\hat{x}_0 = \frac{2.0 - 5.0}{2.2361} = \frac{-3.0}{2.2361} \approx \mathbf{-1.3416}$
    • $\hat{x}_1 = \frac{4.0 - 5.0}{2.2361} = \frac{-1.0}{2.2361} \approx \mathbf{-0.4472}$
    • $\hat{x}_2 = \frac{6.0 - 5.0}{2.2361} = \frac{1.0}{2.2361} \approx \mathbf{0.4472}$
    • $\hat{x}_3 = \frac{8.0 - 5.0}{2.2361} = \frac{3.0}{2.2361} \approx \mathbf{1.3416}$
    $$ \hat{x} = [-1.3416, \, -0.4472, \, 0.4472, \, 1.3416] $$

2. Расчет синусоидального позиционного кодирования $PE(pos=1)$ для $d=4$:

  1. Частоты: $\omega_0 = \frac{1}{10000^0} = 1.0$, $\omega_1 = \frac{1}{10000^{2/4}} = \frac{1}{100} = 0.01$.
  2. Компоненты для $pos=1$:
    • $PE_{(1, 0)} = \sin(1 \cdot 1.0) = \sin(1.0) \approx \mathbf{0.8415}$
    • $PE_{(1, 1)} = \cos(1 \cdot 1.0) = \cos(1.0) \approx \mathbf{0.5403}$
    • $PE_{(1, 2)} = \sin(1 \cdot 0.01) = \sin(0.01) \approx \mathbf{0.0100}$
    • $PE_{(1, 3)} = \cos(1 \cdot 0.01) = \cos(0.01) \approx \mathbf{0.9999}$
    $$ PE(1) = [0.8415, \, 0.5403, \, 0.0100, \, 0.9999] $$

Практическая реализация слоя Transformer Encoder (Pre-LN) на PyTorch

import torch
import torch.nn as nn

class TransformerEncoderLayerPreLN(nn.Module):
    def __init__(self, d_model: int = 512, n_heads: int = 8, d_ff: int = 2048, dropout: float = 0.1):
        super().__init__()
        self.norm1 = nn.LayerNorm(d_model)
        self.self_attn = nn.MultiheadAttention(d_model, n_heads, dropout=dropout, batch_first=True)
        self.norm2 = nn.LayerNorm(d_model)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(d_ff, d_model),
            nn.Dropout(dropout)
        )
        self.dropout = nn.Dropout(dropout)

    def forward(self, x: torch.Tensor, mask: torch.Tensor = None) -> torch.Tensor:
        # 1. Pre-LN Self-Attention с остаточной связью
        norm_x = self.norm1(x)
        attn_out, _ = self.self_attn(norm_x, norm_x, norm_x, attn_mask=mask)
        x = x + self.dropout(attn_out)
        
        # 2. Pre-LN Feed-Forward с остаточной связью
        norm_x = self.norm2(x)
        ffn_out = self.ffn(norm_x)
        x = x + ffn_out
        return x

🎯 Препод спросит

В чем принципиальная разница между Self-Attention и Cross-Attention в архитектуре Transformer?

В Self-Attention Запросы ($Q$), Ключи ($K$) и Значения ($V$) вычисляются из одного и того же источника (из выходов предыдущего слоя того же стека). В Cross-Attention (в декодере) вектор Запроса $Q$ формируется из состояния декодера, а Ключи $K$ и Значения $V$ поступают из финального выхода энкодера. Декодер использует свои запросы для динамического извлечения релевантной информации из памяти исходного предложения.

Зачем в декодере применяется маскирование в Masked Multi-Head Attention?

Декодер предназначен для авторегрессионного моделирования языка. Во время параллельного обучения на GPU вся целевая последовательность подается в декодер одновременно. Без маски токен на позиции $t$ вычислил бы скалярные произведения с токенами на позициях $t+1, t+2$ (будущее), сделав обучение тривиальным списыванием ответов. Аддитивная верхнетреугольная маска с $-\infty$ зануляет веса внимания к будущим позициям после Softmax.

Чем Layer Normalization отличается от Batch Normalization и почему в NLP используется исключительно LayerNorm?

BatchNorm вычисляет статистики по всему батчу для каждого признака независимо. Это создает жесткую зависимость от размера батча $B$, ломается при работе с предложениями переменной длины $T$ и неприменимо при инференсе с $B=1$. LayerNorm вычисляет среднее и дисперсию по вектору скрытых каналов одного конкретного токена, обеспечивая полную независимость от размера батча и структуры других предложений.

Почему позиционное кодирование прибавляется к эмбеддингам токенов, а не конкатенируется?

Конкатенация увеличила бы размерность входного вектора до $d_{\text{model}} + d_{\text{pos}}$, требуя дополнительных параметров во всех последующих проекциях $W^Q, W^K, W^V$. Сложение сохраняет размерность $d_{\text{model}}$ неизменной. При высокой размерности ($d=512, 4096$) векторное пространство практически ортогонально, что позволяет линейным проекциям внимания легко разделять семантическую и позиционную информацию.

Какую роль выполняет подблок Position-wise Feed-Forward Network (FFN)?

Слой внимания выполняет лишь линейную комбинацию существующих представлений разных токенов ($\sum \alpha_i V_i$). Подблок FFN содержит нелинейную активацию (ReLU/GELU/SwiGLU) и проецирует вектор в пространство повышенной размерности ($4 \times d_{\text{model}}$) и обратно, выполняя нелинейную трансформацию признаков и выступая в роли ассоциативной памяти фактов модели.

В чем преимущество топологии Pre-LN перед оригинальной Post-LN?

В оригинальной схеме Post-LN нормализация стоит после сложения: $\text{LN}(x + \text{SubLayer}(x))$. В глубоких моделях дисперсия на выходе слоев изменяется, что приводило к затуханию или взрыву градиентов и требовало обязательного Learning Rate Warmup. В Pre-LN нормализуется вход: $x + \text{SubLayer}(\text{LN}(x))$. Это создает непрерывный градиентный «хайвей» (Residual Stream), позволяя стабильно обучать модели из сотен слоев с первого шага.

Сколько раз вызываются энкодер и декодер при генерации предложения из 20 токенов?

Энкодер вызывается ровно один раз в самом начале, формируя матрицу представлений $H_{\text{enc}}$. Декодер вызывается 20 раз последовательно (по одному разу на каждый авторегрессионный шаг генерации следующего токена).

Почему в оригинальной архитектуре Transformer выбрана размерность $d_{\text{ff}} = 4 \times d_{\text{model}}$?

Четырехкратное расширение скрытого пространства FFN (с 512 до 2048) дает нейросети достаточную нелинейную выразительную емкость для аппроксимации сложных лингвистических правил и ассоциативных знаний без переутяжеления матриц внимания.

Каким математическим свойством обладает синусоидальное позиционное кодирование при относительном сдвиге позиций?

Для любой пары компонент частоты $\omega_i = \frac{1}{10000^{2i/d}}$ вектор на позиции $pos + k$ выражается через вектор на позиции $pos$ с помощью линейного ортогонального преобразования (матрицы поворота):

$$ \begin{pmatrix} \sin(\omega_i (pos + k)) \\ \cos(\omega_i (pos + k)) \end{pmatrix} = \begin{pmatrix} \cos(\omega_i k) & \sin(\omega_i k) \\ -\sin(\omega_i k) & \cos(\omega_i k) \end{pmatrix} \begin{pmatrix} \sin(\omega_i pos) \\ \cos(\omega_i pos) \end{pmatrix} $$

Существует фиксированная блочно-диагональная матрица $M_k$, зависящая только от сдвига $k$, такая что $PE_{pos + k} = M_k PE_{pos}$, что позволяет матрицам внимания легко обучаться учету относительных расстояний между словами.

Почему современные LLM (LLaMA, Mistral) перешли от абсолютных эмбеддингов к RoPE?

Абсолютные позиционные эмбеддинги (табличные или синусоидальные) жестко привязаны к началу координат и не умеют экстраполировать генерацию за пределы длины обучения $L_{\text{train}}$. RoPE (Rotary Position Embedding) поворачивает векторы $Q$ и $K$ в комплексной плоскости на угол, пропорциональный их позиции. Скалярное произведение $q_m^\top k_n$ в логитах внимания становится функцией исключительно относительного расстояния $(m - n)$, что позволяет расширять контекст до сотен тысяч токенов через частотную интерполяцию.

📝 Микро-задачи

Задача 1. Подсчет параметров одного слоя Transformer Encoder

Параметры модели: $d_{\text{model}} = 512$, $d_{\text{ff}} = 2048$, $h = 8$ голов. Посчитайте суммарное количество параметров в одном слое энкодера (Multi-Head Attention + FFN + 2 слоя LayerNorm с bias).

Решение

1. Multi-Head Attention:

  • $W^Q, W^K, W^V$: $3 \times (512 \times 512 + 512) = 3 \times 262\,656 = 787\,968$.
  • $W^O$: $512 \times 512 + 512 = 262\,656$.
  • Итого Attention: $1\,050\,624$.

2. FFN:

  • Слой 1 ($512 \to 2048$): $512 \times 2048 + 2048 = 1\,050\,624$.
  • Слой 2 ($2048 \to 512$): $2048 \times 512 + 512 = 1\,049\,088$.
  • Итого FFN: $2\,099\,712$.

3. Два слоя LayerNorm: $2 \times (2 \cdot 512) = 2\,048$ ($\gamma$ и $\beta$).

$$ \text{Суммарно на 1 блок} = 1\,050\,624 + 2\,099\,712 + 2\,048 = \mathbf{3\,152\,384} \approx 3.15 \text{ млн} $$
Задача 2. Ручной расчет синусоидального позиционного кодирования

Пусть $d_{\text{model}} = 4$. Рассчитайте компоненты вектора $PE$ для позиции $pos = 0$ и позиции $pos = 1$.

Решение

Формула частот: $\omega_0 = 1.0$, $\omega_1 = 10000^{-0.5} = 0.01$.

Для $pos = 0$:

$$ PE(0) = [\sin(0), \, \cos(0), \, \sin(0), \, \cos(0)] = \mathbf{[0.0, \, 1.0, \, 0.0, \, 1.0]} $$

Для $pos = 1$:

$$ PE(1) = [\sin(1.0), \, \cos(1.0), \, \sin(0.01), \, \cos(0.01)] \approx \mathbf{[0.8415, \, 0.5403, \, 0.0100, \, 0.9999]} $$
Задача 3. Расчет Causal Mask для последовательности

Последовательность состоит из 3 токенов. Выпишите бинарную матрицу маски и аддитивную матрицу маски для сложения с логитами перед Softmax.

Решение

1. Булева маска видимости (1 — разрешено, 0 — запрещено):

$$ M_{\text{bool}} = \begin{pmatrix} 1 & 0 & 0 \\ 1 & 1 & 0 \\ 1 & 1 & 1 \end{pmatrix} $$

2. Аддитивная маска (0 — нейтрально, $-\infty$ — зануление в Softmax):

$$ M_{\text{add}} = \begin{pmatrix} 0 & -\infty & -\infty \\ 0 & 0 & -\infty \\ 0 & 0 & 0 \end{pmatrix} $$
Задача 4. Размерность Cross-Attention матриц

Батч $B=8$. Длина входа энкодера $S=50$, длина выхода декодера $T=20$. Размерность $d=512$, $h=8$ голов ($d_k = 64$). Каковы размерности матриц $Q, K, V$ и матрицы весов внимания до и после Softmax в Cross-Attention?

Решение

1. $Q$ (от декодера): $(B, h, T, d_k) = (8, 8, 20, 64)$.

2. $K, V$ (от энкодера): $(B, h, S, d_k) = (8, 8, 50, 64)$.

3. Матрица $Q K^\top$: $(8, 8, 20, 64) \times (8, 8, 64, 50) \to \mathbf{(8, 8, 20, 50)}$.

4. Softmax вычисляется по последней размерности $S=50$. Размерность весов: $\mathbf{(8, 8, 20, 50)}$.

Задача 5. Размерность тензора после FFN

Вход в FFN имеет размерность $(B=16, T=128, d=512)$. Промежуточный слой расширяет размерность до $d_{\text{ff}}=2048$. Каковы размеры тензора внутри FFN и на выходе?

Решение

После первого линейного слоя $W_1$ и активации: $\mathbf{(16, 128, 2048)}$.

После второго линейного слоя $W_2$: $\mathbf{(16, 128, 512)}$.

Пространственная форма $(16, 128)$ сохраняется неизменной.

Задача 6. Влияние Residual Connection на градиенты

Пусть блок описывается уравнением $y = x + F(x)$. Найдите производную $\frac{\partial y}{\partial x}$. Почему это предотвращает затухание градиента?

Решение
$$ \frac{\partial y}{\partial x} = I + \frac{\partial F(x)}{\partial x} $$

При обратном распространении ошибки через $N$ слоев градиент содержит слагаемое $I$ (единичную матрицу). Даже если градиент подблока затухает ($\frac{\partial F}{\partial x} \to 0$), сигнал ошибки беспрепятственно протекает через единичную матрицу $I$, предотвращая затухание градиентов.

⚡ Краткий скелет ответа по билету

Скелет устного ответа по билету 15 (Архитектура Transformer)
  1. Суть и мотивация: «Attention Is All You Need» (2017): полный отказ от RNN и CNN в пользу прямого внимания. Полный параллелизм при обучении, длина пути $O(1)$.
  2. Общая структура: Энкодер ($N=6$ слоев) переводит вход в контекстные представления. Декодер ($N=6$ слоев) авторегрессионно генерирует выходную последовательность.
  3. Блок Энкодера: 2 подблока: Multi-Head Self-Attention (двунаправленное) и Position-wise FFN ($d_{\text{model}} \to 4d \to d_{\text{model}}$), охваченные Residual и LayerNorm.
  4. Блок Декодера: 3 подблока: Masked Self-Attention (с причинной маской против подглядывания вперед), Cross-Attention ($Q$ от декодера, $K,V$ от энкодера) и FFN.
  5. LayerNorm vs BatchNorm: LayerNorm считает статистики по каналам одного токена независимо от размера батча $B$. Pre-LN ($x + F(\text{LN}(x))$) — современный стандарт стабильности глубоких сетей.
  6. Residual Connections: $x + F(x)$ формирует градиентный тракт $I + \frac{\partial F}{\partial x}$, защищая от затухания градиента.
  7. Позиционное кодирование: Внимание инвариантно к перестановкам токенов. Для учета порядка к эмбеддингам прибавляют $PE$. Синусоидальное кодирование выражает относительные сдвиги через линейные матрицы поворота. Современный аналог — RoPE.
  8. Сквозной поток данных: Токены $\to$ Embeddings + PE $\to$ Encoder Stack $\to$ Decoder Stack (авторегрессия с `[BOS]`) $\to$ Linear $\to$ Softmax $\to$ токен.
