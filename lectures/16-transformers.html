1. Интуиция и мотивация

Рекуррентные сети (RNN/LSTM) требовали последовательного шага во времени: вычисление $t$ невозможно без $t-1$, что блокировало параллелизм на GPU. Работа «Attention Is All You Need» (Vaswani et al., 2017) показала, что от рекуррентности можно отказаться, построив модель исключительно на внимании и полносвязных слоях.

💡 Три преимущества Transformer
  1. Массивный параллелизм: все $T$ токенов обрабатываются одновременно за $O(1)$ параллельных шагов на GPU.
  2. Прямой контакт ($O(1)$ путь): любой токен напрямую взаимодействует с любым другим через скалярное произведение, устраняя затухание градиента.
  3. Масштабируемость (Scaling Laws): архитектура эффективно утилизирует кластеры ускорителей при росте параметров до сотен миллиардов.

2. Архитектура и схема

Оригинальный Transformer имеет структуру Encoder-Decoder:

ВЫХОДНЫЕ ВЕРОЯТНОСТИ (Словарь |V|) ▲ [ Linear + Softmax ] │ ┌─────────────────────────┴────────────────────────┐ │ СТЕК ДЕКОДЕРА (N = 6 слоев) │ │ ┌────────────────────────────────────────────┐ │ │ │ Feed-Forward Network + Add & LayerNorm │ │ │ └──────────────────────▲─────────────────────┘ │ │ │ │ ┌────────┼──────────┐ ┌──────┴─────────────────────┐ │ │ СТЕК ЭНКОДЕРА │ │ Cross-Attention (Q, K, V) │ │ │ (N = 6 слоев) │──────▶│ + Add & LayerNorm │ │ │ ┌──────────────┐ │ K, V └──────────────▲─────────────┘ │ │ │ FFN + Norm │ │ │ │ │ └──────▲───────┘ │ ┌──────────────┴─────────────┐ │ │ ┌──────┴───────┐ │ │ Masked Self-Attention │ │ │ │ Self-Attn │ │ │ + Add & LayerNorm │ │ │ │ + Norm │ │ └──────────────▲─────────────┘ │ │ └──────▲───────┘ │ │ │ └────────┼──────────┘ └──────────────┼────────────────┘ │ │ (Pos Encoding) (Pos Encoding) ▲ ▲ [ Input Embeddings ] [ Output Embeddings ] ▲ ▲ Входные токены (EN) Целевые токены (RU) (Сдвинуты вправо) Схема Transformer: $N=6$ блоков энкодера и $N=6$ блоков декодера со связью через Cross-Attention.

Топологии нормализации: Post-LN vs Pre-LN

POST-LN (Оригинал 2017): PRE-LN (Современный стандарт: GPT, LLaMA): x ──┬──▶ [ SubLayer ] ──▶ [ + ] ──▶ [ LayerNorm ] ──▶ x ──┬──▶ [ LayerNorm ] ──▶ [ SubLayer ] ──▶ [ + ] ──▶ └─────────────────────▲ └────────────────────────────────────────▲ Pre-LN сохраняет прямой остаточный тракт (Residual Stream), обеспечивая градиентный поток сквозь 100+ слоёв.

3. Математический аппарат

1. Блок Энкодера

Вход $X \in \mathbb{R}^{T \times d_{\text{model}}}$ проходит через два подблока с остаточными связями (Residual) и LayerNorm:

$$ X^{(1)} = \text{LayerNorm}\left( X + \text{MultiHeadSelfAttention}(X) \right) $$
$$ X^{(2)} = \text{LayerNorm}\left( X^{(1)} + \text{FFN}(X^{(1)}) \right) $$

2. Многоголовое внимание (Multi-Head Attention)

Вход проецируется в $h$ независимых пространств размерности $d_k = d_v = d_{\text{model}} / h$:

$$ \text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h) W^O $$
$$ \text{head}_i = \text{Attention}\left( Q W_i^Q, \, K W_i^K, \, V W_i^V \right) = \text{softmax}\left( \frac{(Q W_i^Q)(K W_i^K)^\top}{\sqrt{d_k}} \right) (V W_i^V) $$
  • $W_i^Q, W_i^K \in \mathbb{R}^{d_{\text{model}} \times d_k}, W_i^V \in \mathbb{R}^{d_{\text{model}} \times d_v}, W^O \in \mathbb{R}^{h d_v \times d_{\text{model}}}$.

3. Position-wise Feed-Forward Network (FFN)

$$ \text{FFN}(x) = \max\left(0, \, x W_1 + b_1\right) W_2 + b_2 = \text{GELU}\left(x W_1 + b_1\right) W_2 + b_2 $$

где $d_{\text{ff}} = 4 d_{\text{model}}$, $W_1 \in \mathbb{R}^{d_{\text{model}} \times d_{\text{ff}}}$, $W_2 \in \mathbb{R}^{d_{\text{ff}} \times d_{\text{model}}}$.

4. Послойная нормализация (LayerNorm)

$$ \mu = \frac{1}{d} \sum_{j=1}^d x_j, \quad \sigma^2 = \frac{1}{d} \sum_{j=1}^d (x_j - \mu)^2, \quad \hat{x} = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} \odot \gamma + \beta $$

где $\gamma, \beta \in \mathbb{R}^d$ — обучаемые параметры.

5. Синусоидальное позиционное кодирование (Positional Encoding)

$$ PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i / d_{\text{model}}}}\right), \quad PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i / d_{\text{model}}}}\right) $$

4. Пошаговый числовой пример

1. Расчёт LayerNorm для $d_{\text{model}} = 4$:

Вход $x = [2.0, \, 4.0, \, 6.0, \, 8.0], \gamma = [1,1,1,1], \beta = [0,0,0,0], \epsilon = 10^{-5}$.

  1. $\mu = \frac{2 + 4 + 6 + 8}{4} = \mathbf{5.0}$.
  2. $\sigma^2 = \frac{(-3)^2 + (-1)^2 + 1^2 + 3^2}{4} = \frac{20}{4} = \mathbf{5.0}, \quad \sqrt{\sigma^2 + \epsilon} \approx \mathbf{2.2361}$.
  3. $\hat{x}_0 = \frac{2-5}{2.2361} \approx \mathbf{-1.3416}, \quad \hat{x}_1 \approx \mathbf{-0.4472}, \quad \hat{x}_2 \approx \mathbf{0.4472}, \quad \hat{x}_3 \approx \mathbf{1.3416}$.
    Итог: $\hat{x} = [-1.3416, \, -0.4472, \, 0.4472, \, 1.3416]$.

2. Расчёт $PE(pos=1)$ для $d=4$:

  1. $\omega_0 = 10000^0 = 1.0, \quad \omega_1 = 10000^{-2/4} = 0.01$.
  2. $PE_{(1, 0)} = \sin(1.0) \approx \mathbf{0.8415}, \quad PE_{(1, 1)} = \cos(1.0) \approx \mathbf{0.5403}$.
  3. $PE_{(1, 2)} = \sin(0.01) \approx \mathbf{0.0100}, \quad PE_{(1, 3)} = \cos(0.01) \approx \mathbf{0.9999}$.
    Итог: $PE(1) = [0.8415, \, 0.5403, \, 0.0100, \, 0.9999]$.

Реализация слоя Transformer Encoder (Pre-LN) на PyTorch

import torch
import torch.nn as nn

class TransformerEncoderLayerPreLN(nn.Module):
    def __init__(self, d_model: int = 512, n_heads: int = 8, d_ff: int = 2048, dropout: float = 0.1):
        super().__init__()
        self.norm1 = nn.LayerNorm(d_model)
        self.self_attn = nn.MultiheadAttention(d_model, n_heads, dropout=dropout, batch_first=True)
        self.norm2 = nn.LayerNorm(d_model)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(d_ff, d_model),
            nn.Dropout(dropout)
        )
        self.dropout = nn.Dropout(dropout)

    def forward(self, x: torch.Tensor, mask: torch.Tensor = None) -> torch.Tensor:
        norm_x = self.norm1(x)
        attn_out, _ = self.self_attn(norm_x, norm_x, norm_x, attn_mask=mask)
        x = x + self.dropout(attn_out)
        
        norm_x = self.norm2(x)
        ffn_out = self.ffn(norm_x)
        x = x + ffn_out
        return x

6. 🎯 Препод спросит

В чём принципиальная разница между Self-Attention и Cross-Attention?

В Self-Attention $Q, K, V$ поступают из одного источника (выход предыдущего слоя того же стека). В Cross-Attention запросы $Q$ идут от декодера, а ключи $K$ и значения $V$ — из выхода энкодера, связывая целевой текст с исходным.

Зачем в декодере применяется маскирование в Masked Multi-Head Attention?

При авторегрессионном обучении вся последовательность подаётся разом. Без маски токен $t$ «подглядывал» бы в $t+1, t+2$. Причинная маска с $-\infty$ зануляет веса внимания к будущим токенам после Softmax.

Чем Layer Normalization отличается от Batch Normalization и почему в NLP используется LayerNorm?

BatchNorm считает статистики по батчу для каждого признака, что ломается на переменной длине $T$ и при $B=1$. LayerNorm вычисляет $\mu$ и $\sigma^2$ по скрытым каналам одного токена, не завися от размера батча и соседних предложений.

Почему позиционное кодирование прибавляется к эмбеддингам, а не конкатенируется?

Конкатенация увеличила бы входную размерность до $d_{\text{model}} + d_{\text{pos}}$, требуя больше весов во всех слоях. В многомерных пространствах ($d=512, 4096$) векторы практически ортогональны, поэтому сложение сохраняет и семантику, и позицию.

Какую роль выполняет подблок Position-wise Feed-Forward Network (FFN)?

Внимание лишь перевзвешивает токены линейно. FFN добавляет нелинейность (GELU/ReLU) и расширяет размерность ($4 d_{\text{model}}$), выполняя роль ассоциативной памяти фактов и трансформации признаков.

В чём преимущество топологии Pre-LN перед оригинальной Post-LN?

В Post-LN нормализация $\text{LN}(x + F(x))$ искажала градиенты в глубоких сетях (требовался Warmup). В Pre-LN нормализуется вход $x + F(\text{LN}(x))$, создавая чистый Residual Stream и позволяя стабильно обучать 100+ слоёв с первого шага.

Сколько раз вызываются энкодер и декодер при генерации фразы из 20 токенов?

Энкодер вызывается 1 раз в начале, формируя память $H_{\text{enc}}$. Декодер вызывается 20 раз пошагово (авторегрессионная генерация).

Почему в архитектуре Transformer выбрана размерность $d_{\text{ff}} = 4 \times d_{\text{model}}$?

Четырёхкратное расширение даёт сети нелинейную ёмкость для аппроксимации лингвистических правил и фактов без утяжеления слоёв внимания.

Каким свойством обладает синусоидальное кодирование при относительном сдвиге?

Вектор позиции $pos + k$ выражается через вектор $pos$ с помощью ортогональной матрицы поворота $M_k$: $PE_{pos + k} = M_k PE_{pos}$. Это позволяет вниманию легко обучаться учёту относительных расстояний.

Почему современные LLM (LLaMA, Mistral) перешли от абсолютных эмбеддингов к RoPE?

Абсолютные эмбеддинги не экстраполируют длину контекста за пределы $L_{\text{train}}$. RoPE поворачивает $Q$ и $K$ на угол, пропорциональный позиции, делая скалярное произведение $q_m^\top k_n$ функцией строго относительного расстояния $(m - n)$.

7. 📝 Микро-задачи с решениями

Задача 1. Подсчёт параметров одного слоя Transformer Encoder

$d_{\text{model}} = 512, d_{\text{ff}} = 2048, h = 8$. Посчитайте параметры одного слоя энкодера (Multi-Head Attention + FFN + 2 LayerNorm с bias).

Решение

1. Attention: $W^Q, W^K, W^V, W^O \implies 4 \times (512 \times 512 + 512) = 1\,050\,624$.
2. FFN: $512 \times 2048 + 2048 + 2048 \times 512 + 512 = 2\,099\,712$.
3. 2 LayerNorm: $2 \times 2 \times 512 = 2\,048$.
Итого: $1\,050\,624 + 2\,099\,712 + 2\,048 = \mathbf{3\,152\,384} \approx 3.15 \text{ млн}$.

Задача 2. Ручной расчёт синусоидального позиционного кодирования

$d_{\text{model}} = 4$. Рассчитайте компоненты $PE$ для $pos = 0$ и $pos = 1$.

Решение

Частоты: $\omega_0 = 1.0, \omega_1 = 0.01$.
$pos = 0$: $[\sin(0), \cos(0), \sin(0), \cos(0)] = \mathbf{[0, 1, 0, 1]}$.
$pos = 1$: $[\sin(1), \cos(1), \sin(0.01), \cos(0.01)] \approx \mathbf{[0.8415, 0.5403, 0.0100, 0.9999]}$.

Задача 3. Расчёт Causal Mask для последовательности

Последовательность из 3 токенов. Выпишите аддитивную маску для сложения с логитами перед Softmax.

Решение
$$ M_{\text{add}} = \begin{pmatrix} 0 & -\infty & -\infty \\ 0 & 0 & -\infty \\ 0 & 0 & 0 \end{pmatrix} $$

Значения $-\infty$ зануляют внимание к будущим токенам после Softmax.

Задача 4. Размерность Cross-Attention матриц

Батч $B=8$, $S=50, T=20, d=512, h=8$ ($d_k=64$). Каковы размерности $Q, K, V$ и матрицы весов до и после Softmax?

Решение

1. $Q$ (декодер): $(8, 8, 20, 64)$, $K, V$ (энкодер): $(8, 8, 50, 64)$.
2. $Q K^\top$: $(8, 8, 20, 64) \times (8, 8, 64, 50) \to \mathbf{(8, 8, 20, 50)}$.
3. Softmax по $S=50$: размерность весов $\mathbf{(8, 8, 20, 50)}$.

Задача 5. Размерность тензора после FFN

Вход в FFN: $(B=16, T=128, d=512)$. Промежуточный слой $d_{\text{ff}}=2048$. Каковы размеры тензора внутри и на выходе?

Решение

Внутри FFN (после $W_1$): $\mathbf{(16, 128, 2048)}$. На выходе (после $W_2$): $\mathbf{(16, 128, 512)}$. Форма $(16, 128)$ неизменна.

Задача 6. Влияние Residual Connection на градиенты

Блок $y = x + F(x)$. Найдите $\frac{\partial y}{\partial x}$. Почему это устраняет затухание градиента?

Решение
$$ \frac{\partial y}{\partial x} = I + \frac{\partial F(x)}{\partial x} $$

Слагаемое $I$ (единичная матрица) обеспечивает сквозное протекание градиента без затухания, даже если $\frac{\partial F}{\partial x} \to 0$.

8. ⚡ Скелет ответа по билету

Скелет ответа по билету 15 (Архитектура Transformer)
  1. Суть: «Attention Is All You Need» (2017) — отказ от RNN/CNN, параллелизм на GPU, длина пути $O(1)$.
  2. Общая схема: Энкодер ($N=6$) строит контекст; декодер ($N=6$) авторегрессионно генерирует токены.
  3. Блок Энкодера: Multi-Head Self-Attention + Position-wise FFN ($d \to 4d \to d$) с Residual и LayerNorm.
  4. Блок Декодера: Masked Self-Attention (с причинной маской) + Cross-Attention ($Q$ от декодера, $K,V$ от энкодера) + FFN.
  5. LayerNorm vs BatchNorm: LayerNorm считает статистики по каналам одного токена независимо от $B$. Pre-LN — современный стандарт стабильности.
  6. Residual Connections: $x + F(x)$ даёт градиентный тракт $I + \frac{\partial F}{\partial x}$, защищая от затухания.
  7. Позиционное кодирование: внимание не учитывает порядок; к эмбеддингам прибавляют $PE$. RoPE — современный поворотный аналог.
  8. Сквозной поток: Токены $\to$ Embeddings + PE $\to$ Encoder $\to$ Decoder (авторегрессия) $\to$ Linear $\to$ Softmax.
