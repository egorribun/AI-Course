1. Интуиция и мотивация

Диффузионные модели (DDPM, Ho et al., 2020) вдохновлены статистической физикой и неравновесной термодинамикой (растворение порядка в хаос):

💡 Принцип диффузии
  • Прямой процесс ($q$): пошаговое добавление белого шума за $T$ шагов ($T=1000$) без параметров, переводящее $x_0$ в шум $x_T \sim \mathcal{N}(0, I)$.
  • Обратный процесс ($p_\theta$): нейросеть U-Net обращает термодинамическую стрелу времени, пошагово предсказывая и удаляя шум для восстановления $x_0$.

3. Математический аппарат

3.1 Прямой марковский процесс

Для расписания $\{\beta_1, \dots, \beta_T\}$ ($\beta_t \in (0, 1)$): $q(x_t | x_{t-1}) = \mathcal{N}(x_t; \sqrt{1 - \beta_t} x_{t-1}, \beta_t I)$. Положим $\alpha_t = 1 - \beta_t$ и $\bar{\alpha}_t = \prod_{s=1}^t \alpha_s$.

📐 Сэмплирование $x_t$ за 1 шаг

Рекурсией $x_t = \sqrt{\alpha_t} x_{t-1} + \sqrt{1 - \alpha_t}\epsilon_{t-1}$ через сумму Гауссианов получаем:

$$q(x_t | x_0) = \mathcal{N}\left(x_t; \, \sqrt{\bar{\alpha}_t} \, x_0, \, (1 - \bar{\alpha}_t) I\right) \implies x_t = \sqrt{\bar{\alpha}_t} x_0 + \sqrt{1 - \bar{\alpha}_t} \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$$

3.2 Обратный процесс и параметризация шума

Апостериорный шаг $q(x_{t-1}|x_t, x_0) = \mathcal{N}(\tilde{\mu}_t, \tilde{\beta}_t I)$, где:

$$\tilde{\mu}_t(x_t, x_0) = \frac{1}{\sqrt{\alpha_t}} \left( x_t - \frac{\beta_t}{\sqrt{1 - \bar{\alpha}_t}} \epsilon \right), \qquad \tilde{\beta}_t = \frac{1 - \bar{\alpha}_{t-1}}{1 - \bar{\alpha}_t} \beta_t$$

Нейросеть обучается предсказывать шум $\epsilon_\theta(x_t, t)$ через MSE-лосс:

$$\mathcal{L}_{\text{simple}}(\theta) = \mathbb{E}_{t, x_0, \epsilon} \left[ \left\| \epsilon - \epsilon_\theta\left(\sqrt{\bar{\alpha}_t} x_0 + \sqrt{1 - \bar{\alpha}_t} \epsilon, \, t\right) \right\|_2^2 \right]$$

3.3 Связь со Score Matching

$$\nabla_{x_t} \log q(x_t | x_0) = -\frac{\epsilon}{\sqrt{1 - \bar{\alpha}_t}} \implies \epsilon_\theta(x_t, t) = -\sqrt{1 - \bar{\alpha}_t} \, \nabla_{x_t} \log p_t(x_t)$$

3.4 Детерминированное сэмплирование DDIM

DDIM заменяет марковский процесс детерминированным ODE-интегратором ($\sigma_t = 0$), сокращая сэмплирование до 20–50 шагов:

$$x_{t-1} = \sqrt{\bar{\alpha}_{t-1}} \left( \frac{x_t - \sqrt{1 - \bar{\alpha}_t} \epsilon_\theta}{\sqrt{\bar{\alpha}_t}} \right) + \sqrt{1 - \bar{\alpha}_{t-1}} \cdot \epsilon_\theta$$

3.5 Classifier-Free Guidance (CFG)

$$\tilde{\epsilon}_\theta(x_t, y) = \epsilon_\theta(x_t, \emptyset) + s \cdot \Big( \epsilon_\theta(x_t, y) - \epsilon_\theta(x_t, \emptyset) \Big), \quad s > 1$$

3.6 Реализации на PyTorch

import torch
import torch.nn as nn
import torch.nn.functional as F

class DDPMScheduler:
    def __init__(self, num_steps=1000, beta_start=1e-4, beta_end=0.02):
        self.num_steps = num_steps
        self.betas = torch.linspace(beta_start, beta_end, num_steps)
        self.alphas = 1.0 - self.betas
        self.alphas_bar = torch.cumprod(self.alphas, dim=0)

    def add_noise(self, x_0, t, noise=None):
        if noise is None:
            noise = torch.randn_like(x_0)
        sqrt_alpha_bar = torch.sqrt(self.alphas_bar[t]).view(-1, 1, 1, 1)
        sqrt_one_minus = torch.sqrt(1.0 - self.alphas_bar[t]).view(-1, 1, 1, 1)
        return sqrt_alpha_bar * x_0 + sqrt_one_minus * noise, noise
def ddim_sample_step(x_t, pred_noise, alpha_bar_t, alpha_bar_prev, eta=0.0):
    pred_x0 = (x_t - torch.sqrt(1.0 - alpha_bar_t) * pred_noise) / torch.sqrt(alpha_bar_t)
    sigma_t = eta * torch.sqrt((1.0 - alpha_bar_prev) / (1.0 - alpha_bar_t) * (1.0 - alpha_bar_t / alpha_bar_prev))
    dir_xt = torch.sqrt(torch.clamp(1.0 - alpha_bar_prev - sigma_t ** 2, min=0.0)) * pred_noise
    noise = torch.randn_like(x_t) if eta > 0.0 else torch.zeros_like(x_t)
    return torch.sqrt(alpha_bar_prev) * pred_x0 + dir_xt + sigma_t * noise
def apply_classifier_free_guidance(model, x_t, t, cond, guidance_scale=7.5):
    null_cond = torch.zeros_like(cond)
    eps_cond = model(x_t, t, cond)
    eps_uncond = model(x_t, t, null_cond)
    return eps_uncond + guidance_scale * (eps_cond - eps_uncond)
def train_step(model, scheduler, x_0, optimizer, device):
    optimizer.zero_grad()
    B = x_0.size(0)
    t = torch.randint(0, scheduler.num_steps, (B,), device=device).long()
    x_t, noise = scheduler.add_noise(x_0, t)
    pred_noise = model(x_t, t)
    loss = F.mse_loss(pred_noise, noise)
    loss.backward()
    optimizer.step()
    return loss.item()

4. Пошаговый числовой пример

🔢 Дано:
  • Пиксель $x_0 = 2.0$, параметры шага: $\alpha_t = 0.9, \bar{\alpha}_{t-1} = 0.70, \bar{\alpha}_t = 0.63, \beta_t = 0.1$.
  • Шум $\epsilon = -0.5 \sim \mathcal{N}(0, 1)$, предсказание модели $\epsilon_\theta = -0.48$.

Шаг 1. Прямой шаг зашумления $x_0 \to x_t$

$$x_t = \sqrt{0.63} \cdot 2.0 + \sqrt{0.37} \cdot (-0.5) = 0.79373 \cdot 2.0 - 0.60828 \cdot 0.5 = 1.28332$$

Шаг 2. Оценка $\hat{x}_0$

$$\hat{x}_0 = \frac{1.28332 - 0.60828 \cdot (-0.48)}{0.79373} = \frac{1.57529}{0.79373} \approx 1.98466$$

Шаг 3. Среднее очищенного шага $\mu_\theta(x_t, t)$

$$\mu_\theta = \frac{1}{\sqrt{0.9}} \left( 1.28332 - \frac{0.1}{0.60828} \cdot (-0.48) \right) = \frac{1.36223}{0.94868} \approx 1.43592$$

6. 🎯 Препод спросит

Почему прямой процесс диффузии можно вычислить за один шаг без итераций?

Сумма независимых гауссовских величин остаётся Гауссианом. Рекуррентная подстановка $x_t = \sqrt{\alpha_t}x_{t-1} + \sqrt{1-\alpha_t}\epsilon$ сворачивает дисперсии в произведение $\bar{\alpha}_t = \prod \alpha_s$, давая замкнутую формулу $q(x_t|x_0) = \mathcal{N}(\sqrt{\bar{\alpha}_t}x_0, (1-\bar{\alpha}_t)I)$.

Что на самом деле предсказывает нейросеть в DDPM: картинку, среднее или шум?

Предсказание стандартного белого шума $\epsilon_\theta(x_t, t)$ стабильнее всего, так как целевой шум распределён как $\mathcal{N}(0, I)$ на всех шагах, что нормализует масштаб градиентов.

В чем фундаментальная разница между VAE, GAN и Диффузией?

VAE: одностадийный ELBO, быстрый, но размытый. GAN: состязательный, чёткий, но нестабильный (Mode Collapse). Диффузия: многостадийный обратный процесс, идеальное покрытие мод и стабильный MSE лосс, но медленный инференс.

Как работает Classifier-Free Guidance (CFG) и зачем нужен параметр $s > 1$?

CFG экстраполирует вектор шума: $\tilde{\epsilon} = \epsilon_{\text{uncond}} + s(\epsilon_{\text{cond}} - \epsilon_{\text{uncond}})$. При $s > 1$ усиливается семантика текстового промпта, повышая соответствие описанию.

Зачем в Stable Diffusion перешли от пиксельной диффузии к латентной (Latent Diffusion)?

Пиксельная диффузия тратит 95% ресурсов на невидимый высокочастотный шум. Latent Diffusion сжимает изображение через VAE в 64 раза по площади ($64\times 64$), запуская U-Net в компактном латенте.

Как DDIM удается генерировать изображения за 20–50 шагов вместо 1000?

DDIM строит детерминированный немарковский процесс ($\sigma_t = 0$), эквивалентный решению ОДУ. Траекторию ODE можно интегрировать с крупным шагом, пропуская промежуточные стадии.

Почему в расписании шума $\beta_t$ выбирают малыми величинами ($\approx 10^{-4} \dots 0.02$)?

Гауссовская форма обратного шага $q(x_{t-1}|x_t)$ строго доказуема только в пределе малого шага шума ($\beta_t \ll 1$). При большом $\beta$ обратное распределение становится мультимодальным.

Как временной шаг $t$ передается в свёрточные слои U-Net?

Шаг $t$ переводится в синусоидальный позиционный эмбеддинг, пропускается через MLP и прибавляется (или модулирует AdaGN) к картам признаков в каждом блоке ResNet.

Как математически устроено сэмплирование DDIM и почему оно является немарковским процессом?

DDIM задаёт семейство немарковских процессов с тем же маргинальным $q(x_t|x_0)$. При $\sigma_t = 0$ стохастический член исчезает, процесс становится детерминированным и обратимым (Inversion).

Что такое Predictor-Corrector (PC) сэмплеры в диффузионных моделях и какую роль в них играет динамика Ланжевена?

Predictor делает шаг по времени $t \to t-\Delta t$ (численный интегратор), а Corrector выполняет MCMC-шаги динамики Ланжевена при фиксированном $t$, сдвигая сэмпл вдоль градиента плотности (Score) и устраняя накопленные ошибки.

7. 📝 Микро-задачи с решениями

Задача 1. Расчёт коэффициента затухания $\bar{\alpha}_t$

При $\beta_1 = 0.1, \beta_2 = 0.2, \beta_3 = 0.3$ найдите $\bar{\alpha}_3$ и дисперсию шума на шаге 3.

Решение

$\alpha_1 = 0.9, \alpha_2 = 0.8, \alpha_3 = 0.7 \implies \bar{\alpha}_3 = 0.9 \cdot 0.8 \cdot 0.7 = 0.504$.

Дисперсия шума: $1 - \bar{\alpha}_3 = 1 - 0.504 = 0.496$.

Ответ: $\bar{\alpha}_3 = 0.504$, дисперсия $0.496$.

Задача 2. Прямое сэмплирование $x_t$ на числовом примере

Пиксель $x_0 = 2.0$, шум $\epsilon = -1.0$, $\bar{\alpha}_t = 0.64$. Найдите $x_t$.

Решение

$x_t = \sqrt{0.64} \cdot 2.0 + \sqrt{1 - 0.64} \cdot (-1.0) = 0.8 \cdot 2.0 - 0.6 \cdot 1.0 = 1.0$.

Ответ: $x_t = 1.0$.

Задача 3. Восстановление $x_0$ по предсказанному шуму $\hat{\epsilon}$

На шаге $t$: $x_t = 3.0, \bar{\alpha}_t = 0.25$, предсказанный шум $\epsilon_\theta = 1.0$. Оцените $\hat{x}_0$.

Решение

$\hat{x}_0 = \frac{x_t - \sqrt{1 - \bar{\alpha}_t}\epsilon_\theta}{\sqrt{\bar{\alpha}_t}} = \frac{3.0 - \sqrt{0.75} \cdot 1.0}{\sqrt{0.25}} = \frac{3.0 - 0.866}{0.5} = 4.268$.

Ответ: $\hat{x}_0 = 4.268$.

Задача 4. Расчёт вектора Classifier-Free Guidance (CFG)

Безусловный шум $\epsilon_{\text{uncond}} = 0.2$, условный $\epsilon_{\text{cond}} = 0.5$. Найдите $\tilde{\epsilon}$ при $s = 1.0, 3.0, 7.5$.

Решение

$\tilde{\epsilon} = \epsilon_{\text{uncond}} + s(\epsilon_{\text{cond}} - \epsilon_{\text{uncond}}) = 0.2 + s \cdot 0.3$:

При $s=1.0$: $0.5$; при $s=3.0$: $0.2 + 0.9 = 1.1$; при $s=7.5$: $0.2 + 2.25 = 2.45$.

Ответ: $0.5$, $1.1$, $2.45$.

Задача 5. Коэффициент сжатия памяти в Latent Diffusion

Картинка $512\times512\times3$ сжимается VAE в латент $64\times64\times4$. Найдите коэффициент сжатия.

Решение

Исходный объём: $512 \cdot 512 \cdot 3 = 786\,432$. Латент: $64 \cdot 64 \cdot 4 = 16\,384$.

Сжатие: $786\,432 / 16\,384 = 48$ раз.

Ответ: В 48 раз (пространственно в 64 раза).

Задача 6. Временная сложность обучения vs инференса

В чём асимметрия времени обучения и генерации в DDPM?

Решение

Обучение требует $O(1)$ проходов U-Net на батч (случайный шаг $t$ за 1 формулу). Генерация требует $O(T)$ последовательных проходов ($T=1000$ шагов).

Ответ: Обучение $O(1)$, генерация $O(T)$.

8. ⚡ Скелет ответа по билету

Скелет ответа по билету 12 (Диффузионные модели)
  1. Суть и идея: Прямой процесс зашумляет $x_0 \to x_T \sim \mathcal{N}(0, I)$, обратный процесс (U-Net) пошагово очищает шум, генерируя новые объекты.
  2. Прямой процесс: Марковская цепь $q(x_t|x_{t-1}) = \mathcal{N}(\sqrt{1-\beta_t}x_{t-1}, \beta_t I)$ без обучаемых параметров.
  3. Трюк с $\bar{\alpha}_t$: Замкнутая формула $x_t = \sqrt{\bar{\alpha}_t}x_0 + \sqrt{1-\bar{\alpha}_t}\epsilon$, где $\bar{\alpha}_t = \prod (1-\beta_s)$. Вычисляется за 1 шаг.
  4. Обратный процесс: Апостериорный шаг при известном $x_0$ является Гауссианом $q(x_{t-1}|x_t, x_0) = \mathcal{N}(\tilde{\mu}_t, \tilde{\beta}_t I)$. Сеть аппроксимирует его.
  5. Параметризация шума и $L_{\text{simple}}$: Сеть предсказывает шум $\epsilon_\theta(x_t, t)$. Лосс: $\mathcal{L}_{\text{simple}} = \mathbb{E}[\|\epsilon - \epsilon_\theta(x_t, t)\|^2]$.
  6. Score Matching: $\epsilon_\theta \propto -\nabla_{x_t}\log p_t(x_t)$. Диффузия эквивалентна стохастическим ДУ (SDE).
  7. DDIM: Детерминированный ODE-сэмплер ($\sigma=0$), ускоряющий генерацию до 20–50 шагов и обеспечивающий обратимость (Inversion).
  8. Classifier-Free Guidance: Экстраполяция $\epsilon_{\text{uncond}} + s(\epsilon_{\text{cond}} - \epsilon_{\text{uncond}})$ усиливает соответствие промпту ($s > 1$).
  9. Архитектура U-Net: ResNet-блоки, Sinusoidal Time Embedding шага $t$ и Cross-Attention с CLIP-эмбеддингами текста.
  10. Latent Diffusion: Сжатие VAE в латент $64\times 64$ устраняет избыточность пикселей и ускоряет инференс в десятки раз.
  11. Сравнение: Превосходное покрытие мод и стабильное MSE обучение, но медленный итеративный инференс.
