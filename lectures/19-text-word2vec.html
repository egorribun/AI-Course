1. Интуиция и мотивация

Традиционное кодирование One-Hot Encoding представляет слова векторами размера $|V|$, где координаты взаимно ортогональны: $v_{\text{кот}} \cdot v_{\text{пёс}} = 0$. При таком подходе модель не способна оценить семантическую близость понятий, а рост словаря вызывает проклятие размерности.

Дистрибутивная гипотеза Джона Ферса (1957): «You shall know a word by the company it keeps» («Слово познаётся по его окружению»). Слова, употребляемые в схожих контекстах, несут близкий семантический смысл. Архитектура Word2Vec (Mikolov et al., 2013) отображает слова в непрерывное плотное векторное пространство $\mathbb{R}^d$ ($d \approx 100\text{--}300$), где косинусное расстояние между векторами напрямую выражает смысловую близость.

💡 Преимущества плотных дистрибутивных эмбеддингов
  1. Компактность: сжатие словаря из миллионов слов в векторы фиксированной размерности $d \in [100, 300]$.
  2. Векторная арифметика: линейные операции над векторами отражают смысловые аналогии ($\vec{v}_{\text{Король}} - \vec{v}_{\text{Мужчина}} + \vec{v}_{\text{Женщина}} \approx \vec{v}_{\text{Королева}}$).
  3. Градиентная оптимизация: непрерывное представление позволяет обучать семантические пространства методом SGD.

3. Математический аппарат

1. Целевая функция Skip-Gram

$$ \mathcal{L} = \sum_{t=1}^T \sum_{-c \le j \le c, j \ne 0} \log P(w_{t+j} \mid w_t), \quad P(w_O \mid w_I) = \frac{\exp({v'_{w_O}}^\top v_{w_I})}{\sum_{w=1}^{|V|} \exp({v'_w}^\top v_{w_I})} $$

где $v_w$ — вектор входного слова ($W$), $v'_w$ — вектор контекстного слова ($W'$).

2. Skip-Gram Negative Sampling (SGNS)

Замена полного Softmax на $K$ бинарных логистических классификаций:

$$ \mathcal{L}_{\text{SGNS}} = \log \sigma\left( {v'_{w_O}}^\top v_{w_I} \right) + \sum_{k=1}^K \mathbb{E}_{w_k \sim P_n(w)} \left[ \log \sigma\left( -{v'_{w_k}}^\top v_{w_I} \right) \right] $$

3. Шумовое распределение $P_n(w)$

$$ P_n(w) = \frac{f(w)^{3/4}}{\sum_{w' \in V} f(w')^{3/4}} $$

Степень $3/4$ приподнимает шансы редких слов стать негативными примерами относительно частых стоп-слов.

4. FastText

Слово представляется суммой эмбеддингов подсловных $n$-грамм $\mathcal{G}_w$: $v_w = z_w + \sum_{g \in \mathcal{G}_w} z_g$.

4. Пошаговый числовой пример

Шаг градиентного обновления SGNS ($K=1, \eta = 0.1, d=2$):

Вход: $v_I = [1.0, 0.0]^\top, v'_O = [1.0, 1.0]^\top, v'_{\text{neg}} = [0.0, 2.0]^\top$.

Пошаговый расчёт:

  1. $z_{\text{pos}} = {v'_O}^\top v_I = 1.0(1.0) + 1.0(0.0) = \mathbf{1.0}$.
    $z_{\text{neg}} = {v'_{\text{neg}}}^\top v_I = 0.0(1.0) + 2.0(0.0) = \mathbf{0.0}$.
  2. $\sigma(1.0) \approx \mathbf{0.7311}, \quad \sigma(0.0) = \mathbf{0.5000}$.
  3. $\mathcal{L} = \log(0.7311) + \log(0.5) = -0.3132 - 0.6931 = \mathbf{-1.0063}$.
  4. Градиент по $v_I$: $$ \nabla_{v_I} \mathcal{L} = (1 - 0.7311) \begin{bmatrix} 1.0 \\ 1.0 \end{bmatrix} - 0.5 \begin{bmatrix} 0.0 \\ 2.0 \end{bmatrix} = \begin{bmatrix} 0.2689 \\ -0.7311 \end{bmatrix} $$
  5. Обновление $v_I^{\text{new}} = v_I + \eta \nabla_{v_I} \mathcal{L} = \begin{bmatrix} 1.0 \\ 0.0 \end{bmatrix} + 0.1 \begin{bmatrix} 0.2689 \\ -0.7311 \end{bmatrix} = \mathbf{\begin{bmatrix} 1.0269 \\ -0.0731 \end{bmatrix}}$.

Реализация Skip-Gram Negative Sampling на PyTorch

import torch
import torch.nn as nn
import torch.nn.functional as F

class Word2VecSGNS(nn.Module):
    def __init__(self, vocab_size: int, embed_dim: int):
        super().__init__()
        self.in_embed = nn.Embedding(vocab_size, embed_dim)
        self.out_embed = nn.Embedding(vocab_size, embed_dim)

    def forward(self, center_words: torch.Tensor, pos_context: torch.Tensor, neg_context: torch.Tensor) -> torch.Tensor:
        v_center = self.in_embed(center_words)         # [B, d]
        v_pos = self.out_embed(pos_context)           # [B, d]
        v_neg = self.out_embed(neg_context)           # [B, K, d]
        
        pos_scores = torch.sum(v_center * v_pos, dim=-1)
        pos_loss = F.logsigmoid(pos_scores)
        
        neg_scores = torch.bmm(v_neg, v_center.unsqueeze(-1)).squeeze(-1)
        neg_loss = torch.sum(F.logsigmoid(-neg_scores), dim=-1)
        
        return -torch.mean(pos_loss + neg_loss)

5. Преимущества, недостатки и применимость

Подход Сложность Преимущества Недостатки Применимость
One-Hot $O(1)$ Простота. Ортогональность, размер $|V| \times |V|$. Устарело; категориальные признаки.
Word2Vec $O(T K d)$ Компактность, векторная арифметика. Статичность (нет полисемии). Рекомендации, матчинг товаров.
FastText $O(T K |\mathcal{G}| d)$ Устойчив к опечаткам и OOV. Большой объём таблицы $n$-грамм в RAM. Классификация зашумлённых текстов.
Контекстные (BERT) $O(T^2 d)$ Динамический смысл слова в контексте. Тяжёлый инференс на GPU. Современный NLP: LLM, поиск, NLU.

6. 🎯 Препод спросит

В чём разница между CBOW и Skip-Gram и какой алгоритм лучше для редких слов?

CBOW предсказывает центр по среднему контексту. Skip-Gram предсказывает контекст по центру. Skip-Gram лучше для редких слов: в CBOW сигнал редкого слова размывается при усреднении, а в Skip-Gram редкое слово в центре даёт персональные обновления градиента.

Зачем в Negative Sampling частоты возводят в степень 3/4 ($f(w)^{0.75}$)?

Степень $0.75$ — компромисс: она снижает долю сверхчастотных стоп-слов («и», «в») и повышает вероятность выбора редких слов в качестве негативных примеров.

Что такое BPE и почему LLM используют субсловную токенизацию?

Byte-Pair Encoding итеративно объединяет частые пары символов/байтов. Это решает проблему Out-Of-Vocabulary (любое слово делится до морфем/байтов) при компактном словаре (32K–128K).

Почему в Word2Vec обучаются две независимые матрицы ($W$ и $W'$)?

$W$ — векторы центральных слов, $W'$ — контекстных. Разделение устраняет автокорреляцию и стабилизирует сходимость SGD. В финале используют $W$ или $\frac{W + W'}{2}$.

Чем FastText принципиально отличается от Word2Vec?

Word2Vec даёт слову единый неделимый вектор. FastText представляет вектор слова суммой эмбеддингов его символьных $n$-грамм (3–6 символов), что позволяет обрабатывать опечатки и неологизмы.

В чём разница между статическими (Word2Vec) и контекстными (BERT) эмбеддингами?

В Word2Vec у слова всегда один фиксированный вектор (нет учёта полисемии: «песчаный замок» vs «дверной замок»). В BERT вектор токена динамически формируется слоем Self-Attention с учётом контекста.

Как пошагово работает Byte-Pair Encoding (BPE)?

1. Инициализация словарём символов.
2. Подсчёт частот всех смежных пар токенов в корпусе.
3. Объединение самой частой пары в новый токен и запись правила слияния.
4. Повторение до достижения целевого размера $|V|$.

Как выводят целевую функцию SGNS из бинарной логистической регрессии?

Для истинной пары максимизируется $P(y=1) = \sigma({v'_O}^\top v_I)$, для $K$ шумовых — $P(y=0) = \sigma(-{v'_k}^\top v_I)$. Логарифм правдоподобия: $\mathcal{L} = \log \sigma({v'_O}^\top v_I) + \sum_{k=1}^K \log \sigma(-{v'_k}^\top v_I)$.

В чём разница между токенизаторами BPE, WordPiece и SentencePiece (Unigram LM)?

BPE максимизирует абсолютную частоту пары. WordPiece максимизирует $\frac{\text{count}(ab)}{\text{count}(a)\text{count}(b)}$ (прирост правдоподобия). Unigram LM начинает с избыточного словаря и удаляет токены с наименьшим вкладом в языковую модель.

Почему в Word2Vec работает векторная арифметика ($\vec{v}_{\text{Король}} - \vec{v}_{\text{Мужчина}} + \vec{v}_{\text{Женщина}} \approx \vec{v}_{\text{Королева}}$)?

SGNS неявно факторизует матрицу поточечной взаимной информации $M_{ij} = \text{PMI}(w_i, c_j) - \log K$. Логарифмические отношения вероятностей контекстов линейно транслируются в постоянные векторные сдвиги в $\mathbb{R}^d$.

7. 📝 Микро-задачи с решениями

Задача 1. Расчёт косинусного сходства (Cosine Similarity)

$\vec{v}(\text{кот}) = [1, 2], \vec{v}(\text{пёс}) = [2, 4], \vec{v}(\text{дом}) = [-2, 1]$. Найдите $\cos$ для пар «кот-пёс» и «кот-дом».

Решение

1. «кот-пёс»: $\frac{1(2) + 2(4)}{\sqrt{5} \cdot \sqrt{20}} = \frac{10}{10} = \mathbf{1.0}$ (коллинеарны).
2. «кот-дом»: $\frac{1(-2) + 2(1)}{\sqrt{5}\sqrt{5}} = \frac{0}{5} = \mathbf{0.0}$ (ортогональны).

Задача 2. Ручной шаг алгоритма BPE

Корпус: {"н и з к и й </w>": 5, "н и з о к </w>": 2, "в ы с о к и й </w>": 3}. Какая пара объединится первой?

Решение

Частоты пар: (н, и): 7, (и, з): 7, (к, и): 8, (и, й): 8, (й, </w>): 8. При равенстве максимума (8) выбирается первая пара (к, и) $\to$ токен ки.

Задача 3. Подсчёт обучающих пар в Skip-Gram

Фраза из 6 слов, окно $c=2$. Сколько обучающих пар $(w_I, w_O)$ сформируется с учётом краёв?

Решение

Позиции: слово 1 (2 соседа) + сл. 2 (3) + сл. 3 (4) + сл. 4 (4) + сл. 5 (3) + сл. 6 (2) = $\mathbf{18 \text{ пар}}$.

Задача 4. Подсчёт параметров Word2Vec

$|V| = 100\,000, d = 300$. Сколько суммарно параметров в матрицах $W$ и $W'$?

Решение

$W: 100\,000 \times 300 = 30 \text{ млн}$, $W': 30 \text{ млн}$. Итого: $\mathbf{60 \text{ млн параметров}}$ ($\approx 240$ МБ в float32).

Задача 5. Расчёт вероятности Negative Sampling со степенью 0.75

Слово A встретилось $10\,000$ раз, слово B — $16$ раз. Во сколько раз изменится отношение частот после степени $0.75$?

Решение

До: $\frac{10000}{16} = 625$. После: $\frac{10000^{0.75}}{16^{0.75}} = \frac{1000}{8} = 125$. Шанс выбора редкого слова B вырос в $\frac{625}{125} = \mathbf{5 \text{ раз}}$.

Задача 6. Векторная семантическая аналогия

$\vec{v}(\text{Франция}) = [2, 1], \vec{v}(\text{Париж}) = [2, 3], \vec{v}(\text{Германия}) = [5, 1]$. Найдите $X = \text{Париж} - \text{Франция} + \text{Германия}$.

Решение

$\vec{v}(X) = [2, 3] - [2, 1] + [5, 1] = [0, 2] + [5, 1] = \mathbf{[5, 3]}$ (соответствует слову «Берлин»).

8. ⚡ Скелет ответа по билету

Скелет ответа по билету 18 (Тексты, токенизация, Word2Vec)
  1. Предобработка: очистка, удаление стоп-слов, стемминг (отсечение окончаний) vs лемматизация (приведение к словарной форме).
  2. Токенизация: слова (проблема OOV), символы, субслова (BPE, WordPiece — баланс словаря и длины без OOV).
  3. Алгоритм BPE: итеративное слияние частых пар символов/байтов в словарь $|V|$.
  4. Эмбеддинги: One-Hot ортогонален; плотные эмбеддинги ($\mathbb{R}^d$) кодируют семантическую близость через $\cos$.
  5. Дистрибутивная гипотеза: «Слово познаётся по его окружению» (Firth, 1957).
  6. Word2Vec: CBOW (центр по контексту, быстрее); Skip-Gram (контекст по центру, лучше для редких слов).
  7. Negative Sampling (SGNS): замена Softmax на $K$ бинарных классификаций (сглаженное распределение $f(w)^{0.75}$).
  8. Векторная арифметика: $\text{Король} - \text{Мужчина} + \text{Женщина} \approx \text{Королева}$ (линейность PMI-матрицы).
  9. FastText: представление слова суммой $n$-грамм для устойчивости к опечаткам и OOV.
