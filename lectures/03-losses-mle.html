1. Интуиция и мотивация

Функция потерь ($\text{Loss } \mathcal{L}(\theta)$) — это скалярная мера рассогласования между предсказанием модели $\hat{y} = f_\theta(x)$ и истинным значением целевой переменной $y$.

Фундаментальное различие между Loss и метрикой качества:

  • Loss-функция: обязана быть аналитически гладкой и дифференцируемой почти всюду по параметрам $\theta$, чтобы формировать информативный градиент $\nabla_\theta \mathcal{L}$ для численного оптимизатора.
  • Бизнес-метрика (Accuracy, F1, ROC-AUC, BLEU): оценивает прикладное качество работы системы. Чаще всего ступенчата, кусочно-постоянна или недифференцируема, поэтому не может быть напрямую оптимизирована градиентными методами.
💡 Вероятностный генезис функций потерь

Функции потерь в машинном обучении не придумываются эвристически. Каждая каноническая функция потерь строго эквивалентна отрицательному логарифму правдоподобия (Negative Log-Likelihood, NLL) при конкретной гипотезе о вероятностном распределении шума в данных:

  • Нормальный (гауссовский) шум $\epsilon \sim \mathcal{N}(0, \sigma^2) \implies$ Mean Squared Error (MSE) / $L_2$-loss.
  • Шум распределения Лапласа $\epsilon \sim \text{Laplace}(0, b) \implies$ Mean Absolute Error (MAE) / $L_1$-loss.
  • Распределение Бернулли для бинарных меток $y \in \{0, 1\} \implies$ Binary Cross-Entropy (BCE).
  • Категориальное распределение Мультинулли для $K$ классов $\implies$ Categorical Cross-Entropy (CCE).
  • Априорное распределение весов Гаусса $w \sim \mathcal{N}(0, \sigma_w^2) \implies$ $L_2$-регуляризация (Weight Decay).
  • Априорное распределение весов Лапласа $w \sim \text{Laplace}(0, b_w) \implies$ $L_1$-регуляризация (Lasso).

3. Математический аппарат

3.1 Принцип максимального правдоподобия (Maximum Likelihood Estimation, MLE)

Пусть выборка $\mathcal{D} = \{(x_i, y_i)\}_{i=1}^N$ состоит из независимых одинаково распределенных (i.i.d.) наблюдений, порожденных параметрическим распределением $p(y | x; \theta)$. Функция правдоподобия:

$$ L(\theta) = \prod_{i=1}^N p(y_i | x_i; \theta) $$

Логарифмируя и меняя знак, переходим к задаче минимизации отрицательного логарифма правдоподобия (NLL):

$$ \theta_{\text{MLE}} = \arg\max_\theta L(\theta) = \arg\min_\theta \text{NLL}(\theta) = \arg\min_\theta \left[ -\sum_{i=1}^N \log p(y_i | x_i; \theta) \right] $$

3.2 Строгий вывод MSE из нормального распределения ошибок

Предположим аддитивную модель регрессии $y = f(x; w) + \epsilon$, где шум некоррелирован и нормально распределен: $\epsilon \sim \mathcal{N}(0, \sigma^2)$. Плотность вероятности отклика $y_i$ при заданном $x_i$:

$$ p(y_i | x_i; w, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left( -\frac{(y_i - f(x_i; w))^2}{2\sigma^2} \right) $$

Логарифмическая функция правдоподобия всей выборки:

$$ \log L(w) = \sum_{i=1}^N \left[ -\frac{1}{2}\log(2\pi\sigma^2) - \frac{(y_i - f(x_i; w))^2}{2\sigma^2} \right] = -\frac{N}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2} \sum_{i=1}^N (y_i - f(x_i; w))^2 $$

Максимизируя $\log L(w)$ по весам $w$ при постоянной дисперсии шума $\sigma^2$:

$$ \arg\max_w \log L(w) = \arg\min_w \sum_{i=1}^N (y_i - f(x_i; w))^2 = \arg\min_w \text{MSE}(w) $$

Вывод: Минимизация среднеквадратичной ошибки MSE строго эквивалентна оценке максимального правдоподобия при гауссовском распределении шума.

3.3 Строгий вывод MAE из распределения Лапласа

Если шум подчиняется распределению Лапласа $\epsilon \sim \text{Laplace}(0, b)$ с плотностью $p(\epsilon) = \frac{1}{2b}\exp(-\frac{|\epsilon|}{b})$:

$$ \log L(w) = \sum_{i=1}^N \left[ -\log(2b) - \frac{|y_i - f(x_i; w)|}{b} \right] = -N\log(2b) - \frac{1}{b}\sum_{i=1}^N |y_i - f(x_i; w)| $$
$$ \arg\max_w \log L(w) = \arg\min_w \sum_{i=1}^N |y_i - f(x_i; w)| = \arg\min_w \text{MAE}(w) $$

3.4 Оптимумы MSE и MAE: Среднее против Медианы

  • Для MSE: Целевая функция $\mathbb{E}[(y - c)^2]$. Дифференцируя по константе $c$: $\frac{d}{dc}\mathbb{E}[(y - c)^2] = -2\mathbb{E}[y - c] = 0 \implies c^* = \mathbb{E}[y | x]$ (условное математическое ожидание).
  • Для MAE: Целевая функция $\mathbb{E}[|y - c|]$. Дифференцируя: $\frac{d}{dc}\mathbb{E}[|y - c|] = P(y < c) - P(y > c) = 0 \implies P(y < c^*) = P(y > c^*) = 0.5 \implies c^* = \text{Med}(y | x)$ (условная медиана).

3.5 Кросс-энтропия и связь с дивергенцией Кульбака-Лейблера

Для бинарной классификации ($y \in \{0, 1\}$) отклик модели трактуется как параметр распределения Бернулли $\hat{p} = P(y=1|x) = \sigma(z)$:

$$ p(y | x) = \hat{p}^y (1 - \hat{p})^{1-y} \implies \mathcal{L}_{\text{BCE}} = -\log p(y | x) = -y \log \hat{p} - (1 - y) \log (1 - \hat{p}) $$

Для $K$ взаимоисключающих классов ($y$ — one-hot вектор):

$$ \mathcal{L}_{\text{CCE}} = -\sum_{k=1}^K y_k \log \hat{p}_k, \quad \text{где } \hat{p}_k = \frac{e^{z_k}}{\sum_{j=1}^K e^{z_j}} $$

Связь с дивергенцией Кульбака-Лейблера $D_{\text{KL}}(P \parallel Q)$:

$$ D_{\text{KL}}(y \parallel \hat{p}) = \sum_{k=1}^K y_k \log\left( \frac{y_k}{\hat{p}_k} \right) = \sum_{k=1}^K y_k \log y_k - \sum_{k=1}^K y_k \log \hat{p}_k = -H(y) + \mathcal{L}_{\text{CCE}} $$

Поскольку энтропия истинного распределения $H(y) = \text{const}$ (для фиксированной выборки), минимизация Cross-Entropy строго эквивалентна минимизации KL-дивергенции между истинным и модельным распределениями.

3.6 Байесовский вывод: связь L2/L1 регуляризации с MAP

Оценка максимального апостериорного правдоподобия (Maximum A Posteriori, MAP) по теореме Байеса:

$$ p(w | \mathcal{D}) = \frac{p(\mathcal{D} | w) p(w)}{p(\mathcal{D})} \implies \arg\max_w \log p(w | \mathcal{D}) = \arg\max_w \left[ \log L(w) + \log p(w) \right] $$
  • Гауссов априор $w \sim \mathcal{N}(0, \sigma_w^2 I)$:
    $$ \log p(w) = -\frac{\|w\|_2^2}{2\sigma_w^2} - \frac{P}{2}\log(2\pi\sigma_w^2) \implies \arg\min_w \left[ \text{MSE}(w) + \frac{\sigma^2}{\sigma_w^2} \|w\|_2^2 \right] \iff \text{L2-регуляризация (Ridge / Weight Decay)} $$
  • Априор Лапласа $w \sim \text{Laplace}(0, b_w)$:
    $$ \log p(w) = -\frac{\|w\|_1}{b_w} - P\log(2b_w) \implies \arg\min_w \left[ \text{MSE}(w) + \frac{2\sigma^2}{b_w} \|w\|_1 \right] \iff \text{L1-регуляризация (Lasso)} $$

3.7 Focal Loss

Для бинарной классификации определим $p_t = \hat{p}$ если $y=1$, и $p_t = 1 - \hat{p}$ если $y=0$:

$$ \text{FL}(p_t) = -\alpha_t (1 - p_t)^\gamma \log(p_t) $$

где $\gamma \ge 0$ — фокусирующий параметр ($\gamma=2$ канонически), $\alpha_t \in [0, 1]$ — весовой балансировочный коэффициент.

4. Пошаговый числовой пример

Пример 1. Сравнение MSE и MAE на выборке с выбросом

Даны истинные значения $y = [2.0, 3.0, 4.0, 100.0]$. Сравним две модели:
Модель A (робастная, ошиблась только на аномалии): $\hat{y}_A = [2.0, 3.0, 4.0, 4.0]$.
Модель B (смещенная в сторону выброса): $\hat{y}_B = [10.0, 10.0, 10.0, 100.0]$.

Ошибки модели A: $e_A = [0.0, 0.0, 0.0, -96.0]$.

$$ \text{MSE}_A = \frac{0^2 + 0^2 + 0^2 + (-96)^2}{4} = \frac{9216}{4} = 2304.0 $$
$$ \text{MAE}_A = \frac{0 + 0 + 0 + 96}{4} = \frac{96}{4} = 24.0 $$

Ошибки модели B: $e_B = [8.0, 7.0, 6.0, 0.0]$.

$$ \text{MSE}_B = \frac{8^2 + 7^2 + 6^2 + 0^2}{4} = \frac{64 + 49 + 36 + 0}{4} = \frac{149}{4} = 37.25 $$
$$ \text{MAE}_B = \frac{8 + 7 + 6 + 0}{4} = \frac{21}{4} = 5.25 $$

Анализ: MSE модели A колоссален ($2304$) из-за возведения ошибки $96$ в квадрат, что вынуждает оптимизатор разрушать точность на нормальных данных ради подгонки под единичный выброс. MAE растет линейно, сохраняя устойчивость.

Пример 2. Расчет Focal Loss против Cross-Entropy

Сравним два примера при $\gamma = 2.0, \alpha = 1.0$:

  1. Простой пример (модель уверена на $90\%$): $p_t = 0.9$.
    $$ \text{CE} = -\log(0.9) \approx 0.1054 $$
    $$ \text{FL} = -(1 - 0.9)^2 \log(0.9) = 0.01 \cdot 0.1054 = 0.001054 \quad (\text{подавление ошибки в 100 раз!}) $$
  2. Сложный пример (модель сомневается, $p_t = 0.2$):
    $$ \text{CE} = -\log(0.2) \approx 1.6094 $$
    $$ \text{FL} = -(1 - 0.2)^2 \log(0.2) = 0.64 \cdot 1.6094 \approx 1.0300 \quad (\text{сохраняет 64\% веса}) $$

6. 🎯 Препод спросит

Как метод максимального правдоподобия (MLE) связан с минимизацией MSE?

Если предположить, что шум измерений аддитивен, некоррелирован и распределен нормально $y = f(x; w) + \epsilon$, где $\epsilon \sim \mathcal{N}(0, \sigma^2)$, то логарифмическая функция правдоподобия выборки равна $\log L(w) = -\frac{N}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^N (y_i - f(x_i; w))^2$. Константа и масштабный множитель не влияют на положение экстремума, поэтому задача максимизации $\log L(w)$ математически строго тождественна минимизации суммы квадратов остатков $\sum (y_i - f(x_i; w))^2 = N \cdot \text{MSE}$.

Почему априорное распределение Гаусса над весами эквивалентно L2-регуляризации, а Лапласа — L1?

В Байесовской парадигме максимизация апостериорной плотности (MAP) максимизирует $\log p(w|\mathcal{D}) = \log L(w) + \log p(w)$. Гауссовский априор $p(w) \propto \exp(-\frac{\|w\|_2^2}{2\sigma_w^2})$ дает логарифм $\log p(w) = -\frac{1}{2\sigma_w^2}\|w\|_2^2 + C$, что в оптимизационной задаче соответствует штрафу за $L_2$-норму весов (Weight Decay). Априор Лапласа $p(w) \propto \exp(-\frac{\|w\|_1}{b_w})$ порождает штраф $\log p(w) = -\frac{1}{b_w}\|w\|_1 + C$, что в точности соответствует $L_1$-регуляризации Lasso.

Почему нельзя использовать MSE для обучения классификатора с сигмоидой на выходе?

Если использовать $\mathcal{L} = \frac{1}{2}(\sigma(z) - y)^2$, градиент по входному логиту равен $\frac{\partial \mathcal{L}}{\partial z} = (\sigma(z) - y)\sigma'(z) = (\sigma(z) - y)\sigma(z)(1 - \sigma(z))$. Если модель грубо ошиблась (например, истинный класс $y=1$, а предсказание $z=-10 \implies \sigma(z) \approx 0$), то множитель $\sigma(z) \approx 0$ зануляет градиент: $\frac{\partial \mathcal{L}}{\partial z} \approx (0 - 1) \cdot 0 \cdot 1 = 0$. Возникает парадокс: при максимальной ошибке модель не получает градиента и не обучается. В связке с Cross-Entropy множитель $\sigma'(z)$ сокращается, и градиент равен $\sigma(z) - y = -1$, обеспечивая мощный обучающий импульс.

Что такое LogSumExp трюк и как он предотвращает численный underflow в Cross-Entropy?

Вычисление $\log(\text{Softmax}(z)_i) = \log\left(\frac{e^{z_i}}{\sum e^{z_j}}\right) = z_i - \log\left(\sum_{j=1}^K e^{z_j}\right)$. При больших $|z_j|$ прямое вычисление $e^{z_j}$ приводит к переполнению float (overflow при $z>88$ для float32) или занулению (underflow). Трюк LogSumExp вычитает максимум $c = \max_k z_k$: $\log\left(\sum e^{z_j}\right) = c + \log\left(\sum e^{z_j - c}\right)$. Это гарантирует, что максимальный показатель экспоненты равен $0$, исключая переполнение и сохраняя стабильность.

Почему минимум MSE — это условное среднее $\mathbb{E}[y|x]$, а MAE — условная медиана $\text{Med}(y|x)$?

Для произвольного распределения отклика $p(y|x)$ константа $c$, минимизирующая ожидаемую потерю $\mathbb{E}[(y-c)^2]$, находится дифференцированием: $\frac{d}{dc}\int (y-c)^2 p(y|x)dy = -2\int (y-c)p(y|x)dy = -2(\mathbb{E}[y|x] - c) = 0 \implies c = \mathbb{E}[y|x]$. Для MAE минимизируется $\mathbb{E}[|y-c|]$: $\frac{d}{dc}\int |y-c|p(y|x)dy = \int_{-\infty}^c p(y|x)dy - \int_c^{+\infty} p(y|x)dy = P(y \le c) - P(y \ge c) = 0 \implies P(y \le c) = 0.5 \implies c = \text{Med}(y|x)$.

Как дивергенция Кульбака-Лейблера связана с перекрестной энтропией (Cross-Entropy)?

Дивергенция Кульбака-Лейблера $D_{\text{KL}}(P \parallel Q) = \sum P(x)\log\frac{P(x)}{Q(x)} = \sum P(x)\log P(x) - \sum P(x)\log Q(x) = -H(P) + H(P, Q)$. Здесь $H(P)$ — собственная энтропия истинного распределения меток, а $H(P, Q)$ — перекрестная энтропия. Поскольку обучающая выборка фиксирована, $H(P) = \text{const}$. Следовательно, $\arg\min_Q D_{\text{KL}}(P \parallel Q) = \arg\min_Q H(P, Q)$. Минимизируя Cross-Entropy, мы минимизируем расстояние Кульбака-Лейблера от истинного распределения данных до модельного.

Зачем нужен параметр $\gamma$ в Focal Loss и как он решает проблему дисбаланса классов?

В задачах плотной детекции (RetinaNet) на 1 объект переднего плана приходятся $10^5$ фоновых легко распознаваемых окон ($p_t \ge 0.95$). Суммарный градиент от миллионов простых примеров подавляет градиент от редких целевых объектов. Параметр $\gamma$ вводит модулятор $(1 - p_t)^\gamma$. При $\gamma = 2$ для простого примера с $p_t = 0.95$ весовой множитель равен $(1 - 0.95)^2 = 0.0025$ (ошибка подавляется в 400 раз). Для сложного примера ($p_t = 0.2$) множитель равен $(1 - 0.2)^2 = 0.64$. Фокус градиентного спуска смещается на трудные объекты.

В чем преимущество Huber Loss над MSE и MAE в задачах детекции (регрессия bounding box)?

Huber Loss сочетает преимущества обеих функций: в окрестности нуля ($|e| \le \delta$) он ведет себя как $\frac{1}{2}e^2$, обеспечивая строгую дифференцируемость, плавное замедление градиента и отсутствие осцилляций в оптимуме (в отличие от MAE, чей градиент $\pm 1$ «скачет» вокруг нуля). На хвостах ($|e| > \delta$) Huber Loss переходит в линейную функцию $\delta(|e| - \frac{1}{2}\delta)$, гарантируя, что грубые аномалии разметки рамок не взорвут градиенты (в отличие от MSE).

Что такое Label Smoothing и как он предотвращает переобучение модели (Overconfidence)?

В классическом one-hot векторе истинный класс равен 1, а остальные 0. Для достижения $\hat{p}_k = 1$ в Softmax входные логиты $z_k$ должны стремиться к $+\infty$, что вынуждает веса расти до бесконечности и делает сеть overconfident. Label Smoothing заменяет жесткий таргет на смесь: $y_k^{\text{smooth}} = (1 - \epsilon)y_k + \frac{\epsilon}{K}$. Модель обучается предсказывать вероятность $1 - \epsilon + \frac{\epsilon}{K} < 1$, что удерживает логиты в конечных границах и действует как мощный регуляризатор.

В чем концептуальная разница между MLE и MAP оценками?

MLE (Maximum Likelihood Estimation) ищет параметры, при которых наблюдаемые данные наиболее вероятны: $\theta_{\text{MLE}} = \arg\max \log p(\mathcal{D}|\theta)$. Она опирается исключительно на выборку и склонна к переобучению при малом объеме данных. MAP (Maximum A Posteriori) учитывает априорное знание о вероятности самих параметров: $\theta_{\text{MAP}} = \arg\max [\log p(\mathcal{D}|\theta) + \log p(\theta)]$. Добавление априора $p(\theta)$ математически строго эквивалентно введению регуляризатора (штрафа за сложность весов).

Почему Cross-Entropy в связке с Softmax выпукла относительно логитов?

Функция потерь относительно вектора логитов $z$ имеет вид: $\mathcal{L}(z) = -\sum_k y_k z_k + \log\left(\sum_j e^{z_j}\right)$. Первое слагаемое $-\sum y_k z_k$ линейно (и, следовательно, выпукло). Второе слагаемое $\log(\sum e^{z_j})$ (функция LogSumExp) имеет матрицу вторых производных (Гессиан) $H_{ij} = p_i \delta_{ij} - p_i p_j = \text{diag}(p) - p p^\top$. Для любого вектора $v$: $v^\top H v = \sum p_i v_i^2 - (\sum p_i v_i)^2 = \mathbb{D}_p[v] \ge 0$ по неравенству Коши-Буняковского. Гессиан неотрицательно определен, функция строго выпукла, локальный минимум единственен.

7. 📝 Микро-задачи с решениями

Задача 1. Расчет Negative Log-Likelihood для нормального распределения

Имеются 3 одномерных замера $y = [2.0, 3.0, 4.0]$. Модель предсказывает среднее $\mu = 3.0$ при известной дисперсии шума $\sigma^2 = 1.0$. Вычислите отрицательный логарифм правдоподобия (NLL) выборки.

Решение

Формула NLL для выборки из $N=3$ объектов при $\sigma^2 = 1.0$:

$\text{NLL} = \dfrac{N}{2}\ln(2\pi\sigma^2) + \dfrac{1}{2\sigma^2}\sum_{i=1}^N (y_i - \mu)^2$

1. Сумма квадратов остатков: $(2-3)^2 + (3-3)^2 + (4-3)^2 = 1 + 0 + 1 = 2.0$.

2. Член нормализации: $\dfrac{3}{2}\ln(2\pi \cdot 1) = 1.5 \cdot \ln(6.2832) \approx 1.5 \cdot 1.8379 = 2.7568$.

3. Сумма: $\text{NLL} = 2.7568 + \dfrac{2.0}{2 \cdot 1.0} = 2.7568 + 1.0 = 3.7568$.

Задача 2. Ручной расчет Binary Cross-Entropy

Для батча из 3 объектов истинные метки $y = [1, 0, 1]$, предсказанные вероятности модели $\hat{p} = [0.90, 0.20, 0.40]$. Рассчитайте среднее значение Binary Cross-Entropy.

Решение

Потери на каждом объекте $\ell_i = -y_i \ln(\hat{p}_i) - (1 - y_i)\ln(1 - \hat{p}_i)$:

$\ell_1 = -\ln(0.90) \approx 0.1054$

$\ell_2 = -\ln(1 - 0.20) = -\ln(0.80) \approx 0.2231$

$\ell_3 = -\ln(0.40) \approx 0.9163$

Средняя потеря: $\mathcal{L}_{\text{BCE}} = \dfrac{0.1054 + 0.2231 + 0.9163}{3} = \dfrac{1.2448}{3} \approx 0.4149$.

Задача 3. Градиент связки Softmax + Cross-Entropy

В трехклассовой задаче истинный класс объекта $y = [0, 1, 0]^\top$. Логиты модели $z = [1.0, 2.0, 0.0]^\top$. Вычислите вектор вероятностей $\hat{p}$ и точный градиент функции потерь по вектору логитов $\frac{\partial \mathcal{L}}{\partial z}$.

Решение

1. Экспоненты логитов: $e^1 \approx 2.7183, \; e^2 \approx 7.3891, \; e^0 = 1.0$. Сумма: $S = 2.7183 + 7.3891 + 1.0 = 11.1074$.

2. Вероятности Softmax: $\hat{p} = \left[ \dfrac{2.7183}{11.1074}, \dfrac{7.3891}{11.1074}, \dfrac{1.0}{11.1074} \right]^\top \approx [0.2447, 0.6652, 0.0900]^\top$.

3. Градиент: $\frac{\partial \mathcal{L}}{\partial z} = \hat{p} - y = \begin{bmatrix} 0.2447 - 0 \\ 0.6652 - 1 \\ 0.0900 - 0 \end{bmatrix} = \begin{bmatrix} 0.2447 \\ -0.3348 \\ 0.0900 \end{bmatrix}$.

Задача 4. Численный расчет весов Focal Loss

При параметре $\gamma = 2.0$ найдите отношение весовых коэффициентов Focal Loss $\text{FL}(p_1) / \text{FL}(p_2)$ для сложного объекта с уверенностью $p_1 = 0.10$ и простого объекта с уверенностью $p_2 = 0.90$.

Решение

$\text{FL}(0.10) = -(1 - 0.10)^2 \ln(0.10) = 0.90^2 \cdot (-\ln(0.10)) = 0.81 \cdot 2.3026 \approx 1.8651$.

$\text{FL}(0.90) = -(1 - 0.90)^2 \ln(0.90) = 0.10^2 \cdot (-\ln(0.90)) = 0.01 \cdot 0.1054 \approx 0.001054$.

Отношение: $\dfrac{\text{FL}(0.10)}{\text{FL}(0.90)} = \dfrac{1.8651}{0.001054} \approx 1769.5$.

Сложный пример получает в $1770$ раз больший вклад в градиент, чем простой.

Задача 5. Связь коэффициента L2-регуляризации с дисперсией априора

Регрессионная модель имеет дисперсию шума данных $\sigma^2 = 2.0$. Инженер ввел гауссовский априор на веса $w \sim \mathcal{N}(0, \sigma_w^2 I)$ с $\sigma_w^2 = 0.5$. Чему равен теоретический коэффициент регуляризации $\lambda$ в формуле $\mathcal{L} = \text{MSE} + \lambda \|w\|_2^2$?

Решение

Из вывода MAP: логарифм апостериорной плотности $\log p(w|\mathcal{D}) = -\frac{1}{2\sigma^2}\sum (y - f)^2 - \frac{1}{2\sigma_w^2}\|w\|_2^2 + C$.

Умножая на $\frac{2\sigma^2}{N}$, получаем задачу: $\text{MSE}(w) + \dfrac{\sigma^2}{N \sigma_w^2}\|w\|_2^2$.

Для одного объекта: $\lambda = \dfrac{\sigma^2}{\sigma_w^2} = \dfrac{2.0}{0.5} = 4.0$.

Задача 6. Расчет потерь Huber Loss

Вычислите значение Huber Loss при пороговом параметре $\delta = 1.0$ для двух величин ошибок прогноза: $e_1 = 0.40$ и $e_2 = 3.00$.

Решение

Формула Huber Loss при $\delta = 1.0$:

$L_\delta(e) = \begin{cases} \frac{1}{2}e^2, & |e| \le 1.0 \\ 1.0 \cdot (|e| - 0.5), & |e| > 1.0 \end{cases}$

1. Для $e_1 = 0.40 \le 1.0$: $L_\delta(0.40) = \frac{1}{2}(0.40)^2 = \frac{1}{2}(0.16) = 0.08$.

2. Для $e_2 = 3.00 > 1.0$: $L_\delta(3.00) = 1.0 \cdot (3.00 - 0.5) = 2.50$.

Сравнение: MSE для $e_2$ дал бы $\frac{1}{2}(3^2) = 4.50$, Huber ограничил рост потерь линейным значением $2.50$.

8. ⚡ Скелет ответа по билету

Краткий конспект для 5-минутного ответа по Билету 3
  1. Loss vs Метрика: Loss — гладкая дифференцируемая целевая функция для оптимизатора ($\nabla_\theta \mathcal{L}$). Метрика — интерпретируемая мера качества (Accuracy, F1, MAE), часто недифференцируема.
  2. Принцип MLE: Оценка максимального правдоподобия $\arg\max \prod p(y_i|x_i; \theta) \iff \arg\min \sum -\log p(y_i|x_i;\theta) = \text{NLL}$.
  3. Вывод MSE: Аддитивный гауссов шум $\epsilon \sim \mathcal{N}(0, \sigma^2) \implies \text{NLL} \propto \frac{1}{2\sigma^2}\sum (y_i - f(x_i))^2 \implies \arg\min \text{MSE}$. Минимум MSE = условное среднее $\mathbb{E}[y|x]$. Неустойчив к выбросам.
  4. Вывод MAE: Шум Лапласа $\epsilon \sim \text{Laplace}(0, b) \implies \text{NLL} \propto \frac{1}{b}\sum |y_i - f(x_i)| \implies \arg\min \text{MAE}$. Минимум MAE = условная медиана $\text{Med}(y|x)$. Робастен к выбросам.
  5. Huber / Smooth L1: Квадратичный при $|e|\le\delta$, линейный при $|e|>\delta$. Сочетает сходимость MSE и робастность MAE. Стандарт в детекции (bounding box regression).
  6. Вывод Cross-Entropy: Распределение Бернулли ($y \in \{0, 1\}$) $\implies$ $\mathcal{L}_{\text{BCE}} = -y \log \hat{p} - (1-y)\log(1-\hat{p})$. Распределение Мультинулли $\implies \mathcal{L}_{\text{CCE}} = -\sum y_k \log \hat{p}_k$. Эквивалентно минимизации KL-дивергенции $D_{\text{KL}}(y \parallel \hat{p})$.
  7. Связка Softmax + CCE: Градиент по логитам $\frac{\partial \mathcal{L}}{\partial z_i} = \hat{p}_i - y_i$. Функция выпукла относительно логитов $z$.
  8. Байесовский вывод (MAP): $\log p(w|\mathcal{D}) = \log L(w) + \log p(w)$. Гауссов априор $w \sim \mathcal{N}(0, \sigma_w^2) \implies L_2$-регуляризация (Ridge/Weight Decay). Априор Лапласа $w \sim \text{Laplace}(0, b_w) \implies L_1$-регуляризация (Lasso, разреженность).
  9. Focal Loss: $\text{FL}(p_t) = -\alpha_t (1 - p_t)^\gamma \log(p_t)$. Подавляет вклад простых примеров ($p_t \to 1$), решая жесткий дисбаланс foreground/background.
  10. Численная стабильность: LogSumExp трюк $\log(\sum e^{z_j}) = c + \log(\sum e^{z_j - c})$ исключает переполнение (overflow/underflow) экспоненты. Label Smoothing предотвращает Overconfidence.
