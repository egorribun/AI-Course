1. Интуиция и мотивация

Функция потерь ($\mathcal{L}(\theta)$) — скалярная мера ошибки предсказания $\hat{y} = f_\theta(x)$ относительно $y$. Она обязана быть гладкой и дифференцируемой для градиентной оптимизации, в отличие от кусочно-постоянных метрик (Accuracy, F1).

💡 Вероятностный генезис функций потерь

Каждая каноническая функция потерь эквивалентна отрицательному логарифму правдоподобия (NLL) при конкретной гипотезе о распределении шума:

  • Нормальный шум $\epsilon \sim \mathcal{N}(0, \sigma^2) \implies$ Mean Squared Error (MSE) / $L_2$-loss.
  • Шум Лапласа $\epsilon \sim \text{Laplace}(0, b) \implies$ Mean Absolute Error (MAE) / $L_1$-loss.
  • Распределение Бернулли ($y \in \{0, 1\}$) $\implies$ Binary Cross-Entropy (BCE).
  • Категориальное распределение Мультинулли $\implies$ Categorical Cross-Entropy (CCE).
  • Гауссов априор весов $w \sim \mathcal{N}(0, \sigma_w^2) \implies$ $L_2$-регуляризация (Weight Decay).
  • Априор Лапласа $w \sim \text{Laplace}(0, b_w) \implies$ $L_1$-регуляризация (Lasso).

3. Математический аппарат

3.1 Принцип максимального правдоподобия (MLE)

Для независимой выборки $\mathcal{D} = \{(x_i, y_i)\}_{i=1}^N$ функция правдоподобия:

$$ L(\theta) = \prod_{i=1}^N p(y_i | x_i; \theta) \implies \theta_{\text{MLE}} = \arg\min_\theta \text{NLL}(\theta) = \arg\min_\theta \left[ -\sum_{i=1}^N \log p(y_i | x_i; \theta) \right] $$

3.2 Строгий вывод MSE из нормального распределения ошибок

Для $y = f(x; w) + \epsilon$, где $\epsilon \sim \mathcal{N}(0, \sigma^2)$:

$$ p(y_i | x_i; w, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left( -\frac{(y_i - f(x_i; w))^2}{2\sigma^2} \right) $$
$$ \log L(w) = -\frac{N}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2} \sum_{i=1}^N (y_i - f(x_i; w))^2 \implies \arg\max_w \log L(w) = \arg\min_w \text{MSE}(w) $$

3.3 Строгий вывод MAE из распределения Лапласа

Для шума Лапласа $\epsilon \sim \text{Laplace}(0, b)$ с плотностью $p(\epsilon) = \frac{1}{2b}\exp(-\frac{|\epsilon|}{b})$:

$$ \log L(w) = -N\log(2b) - \frac{1}{b}\sum_{i=1}^N |y_i - f(x_i; w)| \implies \arg\max_w \log L(w) = \arg\min_w \text{MAE}(w) $$

3.4 Оптимумы MSE и MAE: Среднее против Медианы

  • MSE: $\arg\min_c \mathbb{E}[(y - c)^2] \implies \frac{d}{dc}\mathbb{E}[(y - c)^2] = -2\mathbb{E}[y - c] = 0 \implies c^* = \mathbb{E}[y | x]$ (условное среднее).
  • MAE: $\arg\min_c \mathbb{E}[|y - c|] \implies P(y < c^*) = P(y > c^*) = 0.5 \implies c^* = \text{Med}(y | x)$ (условная медиана).

3.5 Кросс-энтропия и связь с дивергенцией Кульбака-Лейблера

Для бинарной классификации ($y \in \{0, 1\}, \hat{p} = \sigma(z)$):

$$ \mathcal{L}_{\text{BCE}} = -y \log \hat{p} - (1 - y) \log (1 - \hat{p}) $$

Для $K$ классов ($\hat{p}_k = \text{Softmax}(z)_k$):

$$ \mathcal{L}_{\text{CCE}} = -\sum_{k=1}^K y_k \log \hat{p}_k = D_{\text{KL}}(y \parallel \hat{p}) + H(y) $$

Поскольку $H(y) = \text{const}$, минимизация Cross-Entropy строго эквивалентна минимизации KL-дивергенции $D_{\text{KL}}(y \parallel \hat{p})$.

3.6 Байесовский вывод: связь L2/L1 регуляризации с MAP

Оценка Maximum A Posteriori (MAP): $\arg\max_w [\log L(w) + \log p(w)]$.

  • Гауссов априор $w \sim \mathcal{N}(0, \sigma_w^2 I)$: $\log p(w) = -\frac{\|w\|_2^2}{2\sigma_w^2} + C \implies \text{MSE} + \lambda \|w\|_2^2$ ($L_2$, Weight Decay).
  • Априор Лапласа $w \sim \text{Laplace}(0, b_w)$: $\log p(w) = -\frac{\|w\|_1}{b_w} + C \implies \text{MSE} + \lambda \|w\|_1$ ($L_1$, Lasso).

3.7 Focal Loss

Для $p_t = \hat{p}$ при $y=1$ и $p_t = 1-\hat{p}$ при $y=0$:

$$ \text{FL}(p_t) = -\alpha_t (1 - p_t)^\gamma \log(p_t) $$

4. Пошаговый числовой пример

1. Сравнение MSE и MAE на выбросе: $y = [2.0, 3.0, 4.0, 100.0]$.

Модель A (робастная, ошибка на выбросе): $\hat{y}_A = [2.0, 3.0, 4.0, 4.0]$, ошибки $e = [0, 0, 0, -96]$.

$$ \text{MSE}_A = \frac{0^2 + 0^2 + 0^2 + 96^2}{4} = 2304.0, \qquad \text{MAE}_A = \frac{96}{4} = 24.0 $$

Модель B (смещена к выбросу): $\hat{y}_B = [10.0, 10.0, 10.0, 100.0]$, ошибки $e = [8, 7, 6, 0]$.

$$ \text{MSE}_B = \frac{64 + 49 + 36 + 0}{4} = 37.25, \qquad \text{MAE}_B = \frac{8 + 7 + 6 + 0}{4} = 5.25 $$

MSE вынуждает модель ломать прогноз нормальных точек ради 1 выброса ($2304$ vs $37.25$). MAE линейна и робастна.

2. Расчёт Focal Loss ($\gamma = 2.0, \alpha = 1.0$):

  • Простой пример ($p_t = 0.9$): $\text{FL} = -(1-0.9)^2 \log(0.9) = 0.01 \cdot 0.1054 = 0.001054$ (подавление в 100 раз).
  • Сложный пример ($p_t = 0.2$): $\text{FL} = -(1-0.2)^2 \log(0.2) = 0.64 \cdot 1.6094 \approx 1.0300$ (сохраняет $64\%$ веса).

6. 🎯 Препод спросит

Как метод максимального правдоподобия (MLE) связан с минимизацией MSE?

При аддитивном некоррелированном гауссовском шуме $\epsilon \sim \mathcal{N}(0, \sigma^2)$ логарифм правдоподобия равен $\log L(w) = -\frac{N}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum (y_i - f(x_i))^2$. Константы не влияют на аргумент максимума, поэтому максимизация $\log L(w)$ математически строго тождественна минимизации суммы квадратов остатков $\sum (y_i - f(x_i))^2 = N \cdot \text{MSE}$.

Почему априорное распределение Гаусса над весами эквивалентно L2-регуляризации, а Лапласа — L1?

В схеме MAP максимизируется $\log L(w) + \log p(w)$. Гауссовский априор $p(w) \propto e^{-\frac{\|w\|_2^2}{2\sigma_w^2}}$ даёт логарифм $-\frac{\|w\|_2^2}{2\sigma_w^2} + C$, что в оптимизации задаёт штраф за $L_2$-норму (Weight Decay). Априор Лапласа $p(w) \propto e^{-\frac{\|w\|_1}{b_w}}$ порождает штраф $-\frac{\|w\|_1}{b_w} + C$, в точности соответствующий $L_1$-регуляризации Lasso.

Почему нельзя использовать MSE для обучения классификатора с сигмоидой на выходе?

Для $\mathcal{L} = \frac{1}{2}(\sigma(z)-y)^2$ градиент по логиту равен $(\sigma(z)-y)\sigma'(z)$. При грубой ошибке (например, $y=1, z=-10 \implies \sigma(z) \approx 0$) множитель $\sigma'(z) \approx 0$ зануляет градиент: сеть не обучается при максимальной ошибке. В связке с Cross-Entropy производная $\sigma'$ сокращается, давая градиент $\sigma(z) - y = -1$.

Что такое LogSumExp трюк и как он предотвращает численный underflow в Cross-Entropy?

Прямой расчёт $\log\sum e^{z_j}$ приводит к переполнению float при $z > 88$. Трюк LogSumExp вычитает максимум $c = \max_k z_k$: $\log(\sum e^{z_j}) = c + \log(\sum e^{z_j - c})$. Максимальный показатель экспоненты равен 0, что гарантирует стабильность вычислений без переполнения.

Почему минимум MSE — это условное среднее $\mathbb{E}[y|x]$, а MAE — условная медиана $\text{Med}(y|x)$?

Дифференцируя $\mathbb{E}[(y-c)^2]$ по $c$, получаем $-2\mathbb{E}[y-c] = 0 \implies c^* = \mathbb{E}[y|x]$. Для MAE дифференцирование $\mathbb{E}[|y-c|]$ даёт $P(y < c) - P(y > c) = 0 \implies P(y \le c^*) = 0.5 \implies c^* = \text{Med}(y|x)$.

Как дивергенция Кульбака-Лейблера связана с перекрёстной энтропией (Cross-Entropy)?

$D_{\text{KL}}(P \parallel Q) = \sum P \log\frac{P}{Q} = -H(P) + H(P, Q)$. Так как распределение истинных меток фиксировано ($H(P) = \text{const}$), минимизация Cross-Entropy $H(P, Q)$ тождественна минимизации KL-дивергенции от истинного распределения до модельного.

Зачем нужен параметр $\gamma$ в Focal Loss и как он решает проблему дисбаланса классов?

В детекторах миллионы простых фоновых примеров ($p_t \ge 0.95$) забивают градиент редких объектов. Множитель $(1 - p_t)^\gamma$ при $\gamma = 2$ подавляет ошибку простого примера в $(1 - 0.95)^2 = 400$ раз, сохраняя веса трудных объектов ($p_t = 0.2 \implies 0.64$).

В чём преимущество Huber Loss над MSE и MAE в задачах детекции (регрессия bounding box)?

При малых ошибках ($|e| \le \delta$) Huber Loss квадратичен ($\frac{1}{2}e^2$), обеспечивая гладкую сходимость в нуле без осцилляций MAE. При больших ошибках ($|e| > \delta$) он линеен, защищая оптимизатор от взрыва градиентов на грубых аномалиях разметки (в отличие от MSE).

Что такое Label Smoothing и как он предотвращает переобучение модели (Overconfidence)?

Для достижения вероятности 1 в Softmax логиты должны стремиться к $+\infty$, раздувая веса. Label Smoothing заменяет one-hot на $y_k^{\text{smooth}} = (1 - \epsilon)y_k + \frac{\epsilon}{K}$. Модель предсказывает ограниченную вероятность $< 1$, удерживая нормы весов и регуляризуя сеть.

В чём концептуальная разница между MLE и MAP оценками?

MLE максимизирует правдоподобие данных $\arg\max \log p(\mathcal{D}|\theta)$ и опирается только на выборку. MAP максимизирует апостериорную вероятность $\arg\max [\log p(\mathcal{D}|\theta) + \log p(\theta)]$, где априор $p(\theta)$ выступает регуляризатором сложности весов.

Почему Cross-Entropy в связке с Softmax выпукла относительно логитов?

$\mathcal{L}(z) = -\sum y_k z_k + \log(\sum e^{z_j})$. Первое слагаемое линейно, а второе имеет матрицу Гессе $H = \text{diag}(p) - p p^\top$. Для любого $v$: $v^\top H v = \mathbb{D}_p[v] \ge 0$. Гессиан неотрицательно определен, что гарантирует строгую выпуклость и единственный минимум.

7. 📝 Микро-задачи с решениями

Задача 1. Расчёт Negative Log-Likelihood для нормального распределения

Замеры $y = [2.0, 3.0, 4.0]$, предсказание $\mu = 3.0$, $\sigma^2 = 1.0$. Вычислите NLL выборки.

Решение

1. Сумма квадратов: $(2-3)^2 + (3-3)^2 + (4-3)^2 = 2.0$.

2. Нормировка: $\dfrac{3}{2}\ln(2\pi) \approx 1.5 \cdot 1.8379 = 2.7568$.

3. $\text{NLL} = 2.7568 + \dfrac{2.0}{2 \cdot 1.0} = 3.7568$.

Задача 2. Ручной расчёт Binary Cross-Entropy

Метки $y = [1, 0, 1]$, вероятности $\hat{p} = [0.90, 0.20, 0.40]$. Рассчитайте средний BCE.

Решение

$\ell_1 = -\ln(0.90) \approx 0.1054$, $\quad \ell_2 = -\ln(0.80) \approx 0.2231$, $\quad \ell_3 = -\ln(0.40) \approx 0.9163$.

$\mathcal{L}_{\text{BCE}} = \dfrac{0.1054 + 0.2231 + 0.9163}{3} \approx 0.4149$.

Задача 3. Градиент связки Softmax + Cross-Entropy

Истинный класс $y = [0, 1, 0]^\top$, логиты $z = [1.0, 2.0, 0.0]^\top$. Вычислите $\hat{p}$ и $\frac{\partial \mathcal{L}}{\partial z}$.

Решение

1. $e^1 \approx 2.7183, e^2 \approx 7.3891, e^0 = 1.0 \implies \sum = 11.1074$.

2. $\hat{p} = [0.2447, 0.6652, 0.0900]^\top$.

3. $\frac{\partial \mathcal{L}}{\partial z} = \hat{p} - y = [0.2447, -0.3348, 0.0900]^\top$.

Задача 4. Численный расчёт весов Focal Loss

При $\gamma = 2.0$ найдите отношение весов $\text{FL}(0.10) / \text{FL}(0.90)$.

Решение

$\text{FL}(0.10) = 0.9^2 (-\ln 0.1) = 0.81 \cdot 2.3026 \approx 1.8651$.

$\text{FL}(0.90) = 0.1^2 (-\ln 0.9) = 0.01 \cdot 0.1054 \approx 0.001054$.

Отношение: $\dfrac{1.8651}{0.001054} \approx 1769.5$ (градиент сложного объекта усилен в 1770 раз).

Задача 5. Связь коэффициента L2-регуляризации с дисперсией априора

Шум данных $\sigma^2 = 2.0$, априор $w \sim \mathcal{N}(0, \sigma_w^2 I)$ с $\sigma_w^2 = 0.5$. Найдите $\lambda = \frac{\sigma^2}{\sigma_w^2}$.

Решение

Из вывода MAP: $\lambda = \dfrac{\sigma^2}{\sigma_w^2} = \dfrac{2.0}{0.5} = 4.0$.

Задача 6. Расчёт потерь Huber Loss

Найдите Huber Loss при $\delta = 1.0$ для ошибок $e_1 = 0.40$ и $e_2 = 3.00$.

Решение

1. Для $e_1 = 0.40 \le 1.0$: $L = \frac{1}{2}(0.40)^2 = 0.08$.

2. Для $e_2 = 3.00 > 1.0$: $L = 1.0 \cdot (3.00 - 0.5) = 2.50$ (против $4.50$ в MSE).

8. ⚡ Скелет ответа по билету

Краткий конспект для ответа по Билету 3
  1. Loss vs Метрика: Loss — гладкая дифференцируемая цель для $\nabla_\theta \mathcal{L}$. Метрика — прикладное качество (Accuracy, F1).
  2. Принцип MLE: $\arg\max \prod p(y_i|x_i;\theta) \iff \arg\min \sum -\log p(y_i|x_i;\theta) = \text{NLL}$.
  3. Вывод MSE: Гауссов шум $\epsilon \sim \mathcal{N}(0, \sigma^2) \implies \text{NLL} \propto \text{MSE}$. Оптимум = условное среднее $\mathbb{E}[y|x]$. Чувствителен к выбросам.
  4. Вывод MAE: Шум Лапласа $\epsilon \sim \text{Laplace}(0, b) \implies \text{NLL} \propto \text{MAE}$. Оптимум = условная медиана $\text{Med}(y|x)$. Робастен.
  5. Huber Loss: $\frac{1}{2}e^2$ при $|e|\le\delta$ и $\delta(|e|-\frac{1}{2}\delta)$ дальше. Сочетает гладкость MSE и робастность MAE.
  6. Вывод Cross-Entropy: Бернулли $\implies \mathcal{L}_{\text{BCE}}$; Мультинулли $\implies \mathcal{L}_{\text{CCE}} = D_{\text{KL}}(y \parallel \hat{p}) + \text{const}$.
  7. Softmax + CCE: Градиент по логитам $\frac{\partial \mathcal{L}}{\partial z} = \hat{p} - y$. Выпукла по $z$.
  8. Байесовский вывод (MAP): $\log p(w|\mathcal{D}) = \log L + \log p(w)$. Гаусс $w \sim \mathcal{N}(0, \sigma_w^2) \implies L_2$ (Weight Decay); Лаплас $w \sim \text{Laplace} \implies L_1$ (Lasso).
  9. Focal Loss: $\text{FL}(p_t) = -(1-p_t)^\gamma \log(p_t)$. Подавляет вклад простых примеров при жёстком дисбалансе.
  10. Стабильность: LogSumExp $c + \log(\sum e^{z_j - c})$ исключает переполнение; Label Smoothing подавляет Overconfidence.
