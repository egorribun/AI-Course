1. Loss vs метрика

Два разных понятия, часто путаются.

💡 Ключевое различие

Loss-функция (целевая функция): число, которое модель минимизирует во время обучения. Должна быть дифференцируема по параметрам, чтобы можно было считать градиент и делать обновление.

Метрика: число, которое мы смотрим в конце, чтобы оценить качество. Может быть любая — хоть недифференцируема, хоть хитрая.

Пример: классификация. На выходе нейросеть выдаёт вероятности по классам. Во время обучения мы оптимизируем cross-entropy loss (дифференцируема). После обучения смотрим на accuracy или F1 (недифференцируемы, но понятны человеку).

Почему разные? Loss нужна для оптимизации (градиент), метрика нужна для понимания бизнес-результата. Иногда они совпадают, но часто нет.

Процесс обучения Данные (x, y) │ ▼ Модель f_θ(x) ← оптимизируем вот здесь │ ▼ Предсказание ŷ │ ┌────┴────┐ │ │ ▼ ▼ Loss Метрика (минимиз) (смотрим) │ │ ├────────┘ │ ▼ ∂L/∂θ ─→ θ ← θ - η·∇L Loss: cross-entropy, MSE Метрика: accuracy, F1, AUC (ДИФФЕРЕНЦИРУЕМА) (ПОНЯТНА БИЗНЕСУ) Loss — для оптимизации (нужен градиент). Метрика — для оценки (нужна интерпретируемость).

2. MSE: формула, график, производная

2.1 Определение

$$ \text{MSE} = \frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2 $$

Смысл: средняя квадратичная ошибка. Каждую ошибку возводим в квадрат, усредняем.

2.2 График

MSE как функция от ошибки e = y - ŷ Loss │ │ (квадратичная парабола) │ ╱╲ 4├─── ╱ ╲ │ ╱ ╲ 3├ ╱ ╲ │ ╱ ╲ 2├ ╱ ╲ │ ╱ ╲ 1├ ╱ ╲ │ ╱ ╲ 0├─────┴─────────────────┴─── e │ -2 -1 0 1 2 │ Большие ошибки наказываются РЕЗКО. Маленькие ошибки наказываются МЯГКО. Функция MSE(e) = e². Выпуклая, строго возрастает с |e|. Чувствительна к выбросам.

2.3 Производная по ошибке

$$ \frac{\partial \text{MSE}}{\partial e} = \frac{\partial}{\partial e} e^2 = 2e $$ где $e = y - \hat{y}$ ошибка, или точнее $e_i = \frac{1}{N}\sum (y_i - \hat{y}_i)^2$

Смысл производной: градиент линейно зависит от ошибки. Если ошибка большая (100), градиент тоже большой (200). Если маленькая (0.1), градиент маленький (0.2).

Следствие: большие ошибки дают большие градиенты → быстрое обновление в начале. Маленькие ошибки дают маленькие градиенты → медленное приближение к минимуму. Это хорошая сбалансированность.

2.4 Единицы и RMSE

Если $y$ в метрах, MSE в м². Для интерпретации часто берут квадратный корень:

$$ \text{RMSE} = \sqrt{\text{MSE}} $$

Теперь RMSE в тех же единицах что $y$, удобнее читать.

2.5 Где применяется

Во всех задачах регрессии по умолчанию, если нет сильного выброса в данных или специальных требований.

3. MAE: робастность к выбросам

3.1 Определение

$$ \text{MAE} = \frac{1}{N} \sum_{i=1}^{N} |y_i - \hat{y}_i| $$

Смысл: средняя абсолютная ошибка. Абсолютное значение, не квадрат.

3.2 График

MAE как функция от ошибки e = y - ŷ Loss │ │ (V-образная, линейная) 4├───╱╲ │ ╱ ╲ 3├ ╱ ╲ │╱ ╲ 2├ ╲ │ ╲ 1├ ╲ │ ╲ 0├────┴──────┴── e │ -2 0 2 │ Градиент = ±1 везде. Большие ошибки наказываются ЛИНЕЙНО. Нет резкого скачка в наказании. Функция MAE(e) = |e|. V-образная, одинаковый наклон везде (кроме 0, где недифференцируема).

3.3 Производная

$$ \frac{\partial \text{MAE}}{\partial e} = \begin{cases} 1, & e > 0 \\ -1, & e < 0 \\ \text{undefined}, & e = 0 \end{cases} $$

Смысл: градиент константа ±1, не зависит от величины ошибки. Большая ошибка (100) даёт градиент 1, маленькая (0.01) даёт тоже 1. На практике берут субградиент 0 при $e=0$.

Следствие: большие и маленькие ошибки имеют одинаковый вес при обновлении. Это хорошо для робастности (выбросы не доминируют), но может привести к колебаниям при очень маленьких ошибках (градиент не затухает).

3.4 Сравнение: выборос 100 среди {1,2,3,4,5}

y = [1, 2, 3, 4, 5, 100] Predictions: ŷ = [1.5, 2.5, 3.5, 4.5, 5.5, 99] Errors: e = [-0.5, -0.5, -0.5, -0.5, -0.5, 1] MSE: (0.25 + 0.25 + 0.25 + 0.25 + 0.25 + 1) / 6 = 1.25 / 6 ≈ 0.208 Выброс (1²) доминирует! MAE: (0.5 + 0.5 + 0.5 + 0.5 + 0.5 + 1) / 6 = 3.5 / 6 ≈ 0.583 Все ошибки равны по вкладу. MSE чувствительна к выбросам (квадрат), MAE робастна (абсолютное значение).

4. Huber loss и SmoothL1

Гибрид MSE и MAE: квадратичный для маленьких ошибок, линейный для больших.

$$ L_\delta(e) = \begin{cases} \frac{1}{2}e^2, & |e| \le \delta \\ \delta(|e| - \frac{\delta}{2}), & |e| > \delta \end{cases} $$ $\delta$ — порог, типично 1.0
Huber loss Loss │ ╱╱ 4├───╭──── ╱╱ │ │ ╭╮ ╱╱ 3├───┤ ││ ╱╱ │ │ ││ ╱╱ 2├───┤ ││ ╱╱ │ │ ╱╱ ╱╱ 1├───┤ ╱╱ ← граница δ │ ╱╱ ╱╱ 0├──╱──┴────────┴──╱╱─ e │-2 -δ 0 δ 2 │ MSE-часть MAE-часть (гладкая) (линейная) Huber loss: квадратичная внутри [-δ, δ], линейная снаружи. Компромисс.

Плюсы: гладкий и дифференцируем везде, устойчив к выбросам, но не так резко как MAE.

Где применяется: объектная детекция, где outliers частые, но нужна гладкость для оптимизации.

5. MSE минимизирует среднее, MAE — медиану

Это красивый и часто спрашиваемый результат.

🎯 Готовый ответ на экзамене

Теорема: Если мы минимизируем MSE, минимум достигается при $\hat{y} = E[y|x]$ (условное среднее). Если минимизируем MAE, при $\hat{y} = \text{median}(y|x)$ (условная медиана).

5.1 Доказательство для MSE

Пусть даны значения $\{y_1, \ldots, y_N\}$ и мы хотим найти $a$, минимизирующие $\sum (y_i - a)^2$.

$$ \frac{\partial}{\partial a} \sum (y_i - a)^2 = -2 \sum (y_i - a) = 0 $$ $$ a = \frac{1}{N} \sum y_i = E[y] \quad \checkmark $$

5.2 Доказательство для MAE

Пусть даны значения $\{y_1, \ldots, y_N\}$ (отсортированы) и мы хотим найти $a$, минимизирующие $\sum |y_i - a|$.

Производная $\sum |y_i - a|$ по $a$ это количество элементов, где $y_i > a$, минус количество, где $y_i < a$:

$$ \frac{\partial}{\partial a} \sum |y_i - a| = -\#\{i: y_i < a\} + \#\{i: y_i > a\} $$

Минимум при $\frac{\partial}{\partial a} = 0$ означает одинаковое число элементов слева и справа от $a$. Это определение медианы. $\checkmark$

5.3 Числовой пример

Данные: $y = [1, 2, 3, 4, 100]$.

  • Среднее: $(1+2+3+4+100)/5 = 22$. MSE минимизируется при $\hat{y} = 22$.
  • Медиана: 3 (средний элемент упорядоченного массива). MAE минимизируется при $\hat{y} = 3$.
  • Проверка: $\text{MSE при 22} = (21^2 + 20^2 + 19^2 + 18^2 + 78^2)/5 \approx 1330$. $\text{MSE при 3} = (2^2 + 1^2 + 0^2 + 1^2 + 97^2)/5 \approx 1880$. Ну да, 22 лучше.
  • Проверка: $\text{MAE при 22} = (21 + 20 + 19 + 18 + 78)/5 = 31.2$. $\text{MAE при 3} = (2 + 1 + 0 + 1 + 97)/5 = 20.2$. Ну да, 3 лучше!

6. Cross-entropy и дивергенция Кульбака-Лейблера

6.1 Энтропия

Мера неопределённости / неожиданности распределения $p$:

$$ H(p) = -\sum_{i=1}^{K} p_i \log p_i $$ $\log$ обычно натуральный или по основанию 2 (информационная мера в битах)

Смысл: если $p$ = детерминированное распределение (один класс с вероятностью 1, остальные 0), то $H = 0$ (нет неопределённости). Если $p$ = равномерное, то $H$ максимальна (максимальная неопределённость).

Пример: $p = [1, 0]$ (детерминировано класс 0): $H = -(1 \log 1 + 0 \log 0) = 0$.

$p = [0.5, 0.5]$ (максимальная неопределённость): $H = -(0.5 \log 0.5 + 0.5 \log 0.5) = \log 2 \approx 0.693$ (при натуральном логарифме).

6.2 Кросс-энтропия

$$ H(p, q) = -\sum_{i=1}^{K} p_i \log q_i $$ $p$ — истинное распределение (метки), $q$ — предсказанное (выход модели)

Смысл: средняя неожиданность при использовании кодирования от распределения $q$, когда истинное распределение $p$. Если $q$ хорошо приближает $p$, кросс-энтропия близка к энтропии $H(p)$. Если плохо, кросс-энтропия большая.

6.3 KL-дивергенция (kullback-Leibler)

$$ \text{KL}(p \| q) = \sum_{i=1}^{K} p_i \log \frac{p_i}{q_i} = H(p, q) - H(p) $$

Смысл: расстояние между двумя распределениями. KL ≥ 0 всегда, KL = 0 только если $p = q$.

Ключевой факт: $H(p)$ не зависит от параметров модели (это true labels). Поэтому:

$$ \arg\min_\theta H(p, q_\theta) = \arg\min_\theta \text{KL}(p \| q_\theta) $$

Минимизация кросс-энтропии ≡ минимизация KL-дивергенции ≡ максимизация похожести $q$ на $p$.

7. Binary cross-entropy

7.1 Формула

$$ \text{BCE} = -\frac{1}{N} \sum_{i=1}^{N} [y_i \log \hat{y}_i + (1 - y_i) \log(1 - \hat{y}_i)] $$ $y_i \in \{0, 1\}$, $\hat{y}_i \in (0, 1)$ (вероятность, выход sigmoid)

7.2 График

Binary CE как функция от предсказания ŷ, для истинного y=1 Loss │ ╱╱╱ 4 ├╱ │ 3 ├ │ 2 ├ │ 1 ├ ╭──── │ ╭─╯ 0 ├────┴─────────── ŷ │ 0 0.5 1 │ y=1: BCE = -log(ŷ) Если ŷ=0.99, то BCE ≈ 0.01 Если ŷ=0.5, то BCE ≈ 0.69 Если ŷ→0, то BCE→∞ (ШТРАФ!) Уверенная ошибка (предсказал 0.01 вместо 1) → бесконечный штраф. Это хорошо.

7.3 Интерпретация

Для истинного $y = 1$: $\text{BCE} = -\log \hat{y}$.

  • Если модель уверена и правильна ($\hat{y} \approx 1$): $-\log 1 = 0$ (без штрафа).
  • Если модель неуверена ($\hat{y} = 0.5$): $-\log 0.5 \approx 0.69$ (штраф).
  • Если модель уверена и ошибается ($\hat{y} \approx 0$): $-\log 0 = \infty$ (бесконечный штраф).

Свойство: модель наказывается особенно за уверенные ошибки. Это хорошее свойство — не хочешь изводить уверенно неправильные ответы.

8. Categorical cross-entropy

8.1 Формула

$$ \text{CE} = -\frac{1}{N} \sum_{i=1}^{N} \sum_{k=1}^{K} y_{i,k} \log \hat{y}_{i,k} $$ $y_{i,k}$ — one-hot кодирование (1 если класс k, иначе 0), $\hat{y}_{i,k}$ — предсказанная вероятность класса k

8.2 Упрощение

Так как $y$ one-hot (только одна 1, остальные 0), сумма по $k$ коллапсирует:

$$ \text{CE} = -\frac{1}{N} \sum_{i=1}^{N} \log \hat{y}_{i, y_i^*} $$ $y_i^*$ — истинный класс примера $i$. Берём только логарифм вероятности правильного класса!

Смысл: считаем логарифм только по правильному классу. Остальные классы не влияют. Штраф только за то, что назначили маленькую вероятность правильному классу.

8.3 Пример

Задача: 3 класса (кошка, собака, птица). Истина: класс кошка. Предсказания: $[\hat{y}_{\text{кошка}}, \hat{y}_{\text{собака}}, \hat{y}_{\text{птица}}] = [0.7, 0.2, 0.1]$ (после softmax).

One-hot истина: $y = [1, 0, 0]$.

$\text{CE} = -(1 \cdot \log 0.7 + 0 \cdot \log 0.2 + 0 \cdot \log 0.1) = -\log 0.7 \approx 0.357$.

Если модель уверена неправильно, например $[\hat{y}] = [0.1, 0.6, 0.3]$ (думает собака), то $\text{CE} = -\log 0.1 \approx 2.303$ (большой штраф).

9. Почему нельзя MSE для классификации

Это частый вопрос, и ответ нужно знать с двумя причинами.

9.1 Причина 1: градиент насыщается

Рассмотрим бинарную классификацию с выходом через sigmoid.

$$ \hat{y} = \sigma(z), \quad L_{\text{MSE}} = (y - \hat{y})^2 $$ $$ \frac{\partial L}{\partial z} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z} = 2(y - \hat{y}) \cdot \sigma'(z) = 2(y - \hat{y}) \cdot \sigma(z)(1 - \sigma(z)) $$

Сравним с cross-entropy:

$$ L_{\text{CE}} = -[y \log \hat{y} + (1-y) \log(1-\hat{y})] $$ $$ \frac{\partial L}{\partial z} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z} = (\hat{y} - y) \cdot \sigma'(z) $$

Численный пример: $y = 0, \hat{y} = 0.01$ (модель почти уверена в ошибке).

MSE: $\frac{\partial L}{\partial z} = 2 \cdot (0.01 - 0) \cdot 0.01 \cdot 0.99 \approx 0.0002$ (крошечный градиент!).

CE: $\frac{\partial L}{\partial z} = (0.01 - 0) \cdot 0.01 \cdot 0.99 \approx 0.0001$ (тоже маленький, но...).

Подожди, давай пересчитаем CE более аккуратно. Если $y=0$:

$$ L_{\text{CE}} = -\log(1 - \hat{y}) $$ $$ \frac{\partial L}{\partial \hat{y}} = \frac{1}{1 - \hat{y}} $$

При $\hat{y} = 0.01$: $\frac{\partial L}{\partial \hat{y}} = \frac{1}{0.99} \approx 1.01$.

Градиент по $z$: $1.01 \cdot \sigma'(0.01) \approx 1.01 \cdot 0.0099 \approx 0.01$ (всё ещё маленький, но лучше!).

На самом деле, фишка в том, что в CE множители $\sigma'(z)$ сокращаются с производной от $\log$, получается чистый $(y - \hat{y})$. Вот настоящее доказательство:

$$ L_{\text{CE}} = -[y \log \sigma(z) + (1-y) \log(1-\sigma(z))] $$ $$ \frac{\partial L}{\partial z} = -\left[y \frac{\sigma'(z)}{\sigma(z)} - (1-y) \frac{\sigma'(z)}{1-\sigma(z)}\right] $$ $$ = -\sigma'(z) \left[\frac{y}{\sigma(z)} - \frac{1-y}{1-\sigma(z)}\right] $$ $$ = -\sigma'(z) \left[\frac{y(1-\sigma(z)) - (1-y)\sigma(z)}{\sigma(z)(1-\sigma(z))}\right] $$ $$ = -\sigma'(z) \left[\frac{y - \sigma(z)}{\sigma(z)(1-\sigma(z))}\right] $$ $$ = \sigma(z) - y \quad \text{(так как } \sigma'(z) = \sigma(z)(1-\sigma(z))) $$

Ключевой результат: производная CE по $z$ просто $\sigma(z) - y$, независимо от $\sigma(z)$! Никакого насыщения, всегда хороший градиент.

9.2 Причина 2: неправильная вероятностная модель

MSE предполагает гауссов шум (см. лекцию ниже). Для классификации истинное распределение — категориальное (Бернулли для binary), не гауссово.

10. Метод максимального правдоподобия

10.1 Определение

💡 MLE (Maximum Likelihood Estimation)

Дана выборка $\{(x_i, y_i)\}_{i=1}^N$, нужно найти параметры $\theta$ модели, которые максимизируют правдоподобие:

$$\theta^* = \arg\max_\theta L(\theta) = \arg\max_\theta \prod_{i=1}^N p(y_i | x_i, \theta)$$

Логарифмируем (произведение → сумма, монотонность сохраняется):

$$\theta^* = \arg\max_\theta \sum_{i=1}^N \log p(y_i | x_i, \theta)$$

Или минимизируем отрицательное логарифм-правдоподобие (NLL):

$$\theta^* = \arg\min_\theta \left(-\sum_{i=1}^N \log p(y_i | x_i, \theta)\right) = \arg\min_\theta \text{NLL}$$

10.2 Почему логарифм?

  • Произведение → сумма: произведение N вероятностей становится суммой логарифмов (удобнее).
  • Численная устойчивость: вероятности часто крошечные (0.001 × 0.002 × … = очень мало). Логарифмы избегают underflow.
  • Монотонность: log монотонно возрастает, поэтому max произведения = max суммы логарифмов.

11. ММП для регрессии: гауссов шум → MSE

Это главная тема. Вывод происходит в 3-4 строки.

📐 Главный вывод: откуда берётся MSE

Предположение: $y_i = f(x_i, \theta) + \varepsilon_i$, где $\varepsilon_i \sim N(0, \sigma^2)$ независимый гауссов шум.

Следствие: $y_i | x_i, \theta \sim N(f(x_i, \theta), \sigma^2)$, то есть $p(y_i | x_i, \theta) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y_i - f(x_i, \theta))^2}{2\sigma^2}\right)$.

Логарифм правдоподобия:

$$\log L(\theta) = \sum_{i=1}^N \log p(y_i | x_i, \theta) = \sum_{i=1}^N \left[-\frac{1}{2}\log(2\pi\sigma^2) - \frac{(y_i - f(x_i, \theta))^2}{2\sigma^2}\right]$$

Максимизация по $\theta$: первое слагаемое от $\theta$ не зависит, поэтому:

$$\arg\max_\theta \log L(\theta) = \arg\min_\theta \sum_{i=1}^N (y_i - f(x_i, \theta))^2 = \arg\min_\theta \text{MSE}$$

Вывод: MSE не взята с потолка — это естественное следствие ММП при предположении нормального (гауссова) шума.

Важная тонкость: параметр $\sigma^2$ (дисперсия шума) не оптимизируется, он фиксирован. На практике часто не нужен, так как оптимум по $\theta$ не зависит от $\sigma$.

12. ММП для классификации: категориальное распределение → CE

12.1 Бинарная классификация

Модель: $\hat{y}_i = \sigma(\theta^\top x_i)$ (вероятность класса 1).

Распределение: $y_i | x_i \sim \text{Bernoulli}(\hat{y}_i)$, то есть $p(y_i | x_i, \theta) = \hat{y}_i^{y_i} (1-\hat{y}_i)^{1-y_i}$.

Логарифм правдоподобия:

$$ \log L(\theta) = \sum_{i=1}^N [y_i \log \hat{y}_i + (1-y_i) \log(1-\hat{y}_i)] = -\sum_{i=1}^N \text{BCE}_i $$

Максимизация: $\arg\max_\theta \log L = \arg\min_\theta \text{BCE}$.

12.2 Многоклассовая классификация

Модель: $\hat{y}_{i,k} = \text{softmax}(\theta_k^\top x_i)$ для класса $k = 1 \ldots K$.

Распределение: $y_i | x_i \sim \text{Categorical}(\hat{y}_i)$, то есть $p(y_i | x_i, \theta) = \prod_{k=1}^K \hat{y}_{i,k}^{\mathbb{1}[y_i = k]}$.

Логарифм правдоподобия:

$$ \log L(\theta) = \sum_{i=1}^N \sum_{k=1}^K \mathbb{1}[y_i = k] \log \hat{y}_{i,k} = -\sum_{i=1}^N \text{CE}_i $$

Максимизация: $\arg\max_\theta \log L = \arg\min_\theta \text{CE}$.

13. Регуляризация как байесовский априор (MAP)

L2-регуляризация не с потолка — это эквивалентно байесовскому подходу!

💡 Связь регуляризации и Байеса

Максимум апостериори (MAP): $\theta^* = \arg\max_\theta p(\theta | D) = \arg\max_\theta p(D | \theta) p(\theta)$.

Логарифмируем: $\log p(\theta | D) \propto \log p(D | \theta) + \log p(\theta)$.

Минимизируем: $-\log p(D | \theta) - \log p(\theta) = \text{NLL} + (-\log p(\theta))$.

Если априор $p(\theta) = N(0, \tau^2)$ (гауссов): то $-\log p(\theta) \propto \frac{\|θ\|^2}{\tau^2}$ = L2-регуляризация!

Вывод: $L2 = -\log p(\theta)$ с гауссовым априором. Выбор $\lambda$ в регуляризации = выбор aprior дисперсии $\tau^2$.

Аналогично, L1-регуляризация соответствует лапласову априору.

14. Focal loss и взвешенная CE при дисбалансе

Когда классы сильно дисбалансированы (например, 99% класс 0, 1% класс 1), обычная CE подходит плохо.

14.1 Проблема дисбаланса

Модель может выучиться говорить всегда класс 0. Loss упадёт, потому что на 99% примеров она права. Но на 1% примеров (классе 1) будет полный кошмар.

14.2 Focal Loss

$$ L_{\text{focal}} = -\alpha (1 - \hat{y})^\gamma y \log \hat{y} - (1 - \alpha) \hat{y}^\gamma (1-y) \log(1-\hat{y}) $$ $\alpha$ — балансировочный коэффициент, $\gamma$ (gamma) — focusing parameter, обычно 2

Идея: при $\gamma > 0$ примеры, которые модель уже классифицирует хорошо (высокая $\hat{y}$), получают маленький вес. Примеры, на которых модель ошибается, получают большой вес. Фокусируемся на hard examples.

Пример: если $\hat{y} = 0.99$ и $y = 0$, то $(1-\hat{y})^\gamma = 0.01^\gamma$ очень мал, loss маленький (игнорируем easy negatives). Если $\hat{y} = 0.01$ и $y = 1$, то $(1-\hat{y})^\gamma = 0.99^\gamma \approx 1$, loss нормальная (штрафуем hard positives).

14.3 Взвешенная CE

Простой способ: домножить loss на вес, обратный частоте класса:

$$ L = -w_0 y \log \hat{y} - w_1 (1-y) \log(1-\hat{y}), \quad w_k = \frac{N}{N_k} $$ $N$ — общее число примеров, $N_k$ — число примеров класса $k$

Редкие классы получают больший вес в loss, модель не может их игнорировать.

🎯 Препод спросит

Чем loss отличается от метрики?

Loss — дифференцируемая функция, которую модель минимизирует во время обучения (нужен градиент). Метрика — число, которое мы смотрим в конце, может быть недифференцируемой, главное что понятна человеку. Пример: оптимизируем cross-entropy, смотрим accuracy. Иногда совпадают, но обычно нет.

Почему MSE чувствительна к выбросам, а MAE нет?

MSE = квадрат ошибки, поэтому большая ошибка наказывается резко (квадратично). Выброс с ошибкой 100 вносит вклад 10000 в loss. MAE = абсолютное значение, линейно. Выброс с ошибкой 100 вносит вклад 100. Также, производная MSE зависит от величины ошибки (2e), производная MAE константа (±1). Для робастности выбираем MAE.

MSE минимизирует среднее или медиану?

MSE минимизирует среднее. Доказательство: $\min_a \sum (y_i - a)^2 \Rightarrow \frac{\partial}{\partial a} = 0 \Rightarrow a = \frac{1}{N}\sum y_i$. MAE минимизирует медиану: $\frac{\partial}{\partial a} \sum |y_i - a| = 0$ означает одинаковое число точек слева и справа от $a$, что есть определение медианы.

Что такое cross-entropy и KL-дивергенция?

Cross-entropy $H(p,q) = -\sum p_i \log q_i$ — средняя неожиданность при кодировании истинного распределения $p$ кодом для распределения $q$. KL-дивергенция $\text{KL}(p\|q) = \sum p_i \log(p_i/q_i)$ — расстояние между $p$ и $q$. Связь: $H(p,q) = H(p) + \text{KL}(p\|q)$. Так как $H(p)$ константна, минимизация CE = минимизация KL = максимизация похожести q на p.

Почему нельзя использовать MSE для классификации вместо CE?

Причина 1 (градиент): при использовании sigmoid, градиент MSE = $2(\hat{y} - y) \sigma'(z)$ содержит множитель $\sigma'(z)$, который насыщается (близко к 0) при большой ошибке. Градиент CE = $(\hat{y} - y)$ — чистый, без насыщения. Причина 2 (модель): MSE предполагает гауссов шум, классификация — категориальное распределение. Вероятностно неправильно.

Как работает метод максимального правдоподобия?

Ищем параметры $\theta$, которые максимизируют произведение вероятностей $\prod_i p(y_i|x_i,\theta)$. Логарифмируем: $\max \sum_i \log p(y_i|x_i,\theta)$. Или минимизируем NLL = $-\sum_i \log p(y_i|x_i,\theta)$. Логарифм: произведение становится суммой, избегаем underflow, монотонность сохраняется.

Докажи, что ММП с гауссовым шумом → MSE.

Предположим $y_i = f(x_i,\theta) + \varepsilon_i$, $\varepsilon_i \sim N(0,\sigma^2)$. Тогда $p(y_i|x_i,\theta) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp(-(y_i-f(x_i,\theta))^2/(2\sigma^2))$. Логарифм: $\log p = -\frac{1}{2}\log(2\pi\sigma^2) - (y_i-f(x_i,\theta))^2/(2\sigma^2)$. Первое слагаемое от θ не зависит. Максимизируем второе → минимизируем $\sum (y_i-f(x_i,\theta))^2$ = MSE. Вывод готов.

Откуда берётся binary cross-entropy и почему она лучше MSE?

Для бинарной классификации истинное распределение Бернулли: $p(y|x,\theta) = \hat{y}^y (1-\hat{y})^{1-y}$, где $\hat{y} = \sigma(\theta^\top x)$. По ММП логарифм правдоподобия: $\log p = y\log\hat{y} + (1-y)\log(1-\hat{y})$. Максимизируем = минимизируем $-[y\log\hat{y} + (1-y)\log(1-\hat{y})]$ = BCE. Лучше MSE потому что: (1) нет насыщения градиента, (2) правильная вероятностная модель.

L2-регуляризация — это что из вероятности?

L2-регуляризация = MAP (максимум апостериори) с гауссовым априором на параметры. Логарифм апостериора: $\log p(\theta|D) \propto \log p(D|\theta) + \log p(\theta) = \text{NLL} + \log N(θ; 0, \tau^2) = \text{NLL} - \|θ\|^2/(2\tau^2)$. Минимизируем: NLL + λ·||θ||² где λ~1/τ². Выбор λ = выбор дисперсии априора.

Что такое Focal loss и зачем нужна при дисбалансе?

Focal loss: $L_f = -(1-\hat{y})^\gamma y \log\hat{y} - \hat{y}^\gamma (1-y)\log(1-\hat{y})$ с $\gamma>0$. Идея: примеры, на которых модель уже хорошо работает (высокая $\hat{y}$), получают маленький вес $(1-\hat{y})^\gamma \approx 0$. Примеры, на которых ошибается, получают вес близко к 1. Фокусируемся на hard examples, игнорируем easy. Это помогает при дисбалансе, не даёт модели сосредоточиться только на большом классе.

Какая вероятностная модель стоит за MAE?

MAE стоит за лапласовым распределением шума: $p(y|x,\theta) = \frac{1}{2b} \exp(-|y-f(x,\theta)|/b)$ где $b$ — масштаб. По ММП логарифм: $\log p \propto -|y-f(x,\theta)|/b$. Максимизируем = минимизируем MAE. Лапласово распределение имеет тяжелые хвосты, что и обеспечивает робастность к выбросам.

📝 Микро-задачи

Задача 1. MSE vs MAE на выбросе

Данные: $y = [10, 11, 12, 13, 14, 100]$. Предсказания: $\hat{y} = [10.5, 11.5, 12.5, 13.5, 14.5, 99.5]$. Считай MSE и MAE.

Решение

Ошибки: $e = [-0.5, -0.5, -0.5, -0.5, -0.5, 0.5]$.

$\text{MSE} = \frac{0.25 + 0.25 + 0.25 + 0.25 + 0.25 + 0.25}{6} = \frac{1.5}{6} = 0.25$.

$\text{MAE} = \frac{0.5 + 0.5 + 0.5 + 0.5 + 0.5 + 0.5}{6} = \frac{3}{6} = 0.5$.

Вывод: выброса нет! Модель хорошо предсказывает везде. MSE и MAE одинаковые.

Задача 2. Binary cross-entropy

Истина $y = 1$, предсказания $\hat{y} = [0.9, 0.5, 0.1]$. Считай BCE для каждого.

Решение

$\text{BCE} = -[y\log\hat{y} + (1-y)\log(1-\hat{y})] = -\log\hat{y}$ (так как $y=1$).

$\hat{y} = 0.9$: $\text{BCE} = -\log 0.9 \approx 0.105$.

$\hat{y} = 0.5$: $\text{BCE} = -\log 0.5 \approx 0.693$.

$\hat{y} = 0.1$: $\text{BCE} = -\log 0.1 \approx 2.303$.

Вывод: уверенный правильный ответ (0.9) — маленький штраф. Неуверенный — большой штраф. Уверенный неправильный (0.1) — огромный штраф.

Задача 3. Categorical CE

3 класса. Истина: класс 1 (one-hot = [0,1,0]). Предсказания: $\hat{y} = [0.1, 0.8, 0.1]$. Считай CE.

Решение

$\text{CE} = -\sum_k y_k \log\hat{y}_k = -(0 \cdot \log 0.1 + 1 \cdot \log 0.8 + 0 \cdot \log 0.1) = -\log 0.8 \approx 0.223$.

Только правильный класс (класс 1) вносит в loss! Остальные не важны.

Задача 4. ММП: гауссов шум

Предположим $y_i = \theta x_i + \varepsilon_i$, $\varepsilon_i \sim N(0, 1)$. Выборка: $(x_1, y_1) = (1, 2), (x_2, y_2) = (2, 4)$. Запиши loss функцию NLL.

Решение

$p(y_i | x_i, \theta) = \frac{1}{\sqrt{2\pi}} \exp(-(y_i - \theta x_i)^2 / 2)$.

$\text{NLL} = -\sum_i \log p(y_i | x_i, \theta) = -\sum_i [-\frac{1}{2}\log(2\pi) - \frac{(y_i - \theta x_i)^2}{2}]$

$= \sum_i [\frac{1}{2}\log(2\pi) + \frac{(y_i - \theta x_i)^2}{2}]$

$= \text{const} + \frac{1}{2}[(2 - \theta)^2 + (4 - 2\theta)^2]$ (константу можно опустить)

$= \frac{1}{2}[4 - 4\theta + \theta^2 + 16 - 16\theta + 4\theta^2] = \frac{1}{2}[5\theta^2 - 20\theta + 20]$.

Это MSE loss по определению!

Задача 5. Регуляризация и апостериор

Напиши логарифм апостериора $\log p(\theta|D)$ с гауссовым априором и покажи, что это = NLL + λ||θ||².

Решение

$\log p(\theta|D) = \log p(D|\theta) + \log p(\theta) - \log p(D)$.

Игнорируем $-\log p(D)$ (не зависит от θ). Пусть $p(\theta) = N(0, \tau^2)$, тогда:

$\log p(\theta) = -\frac{\theta^2}{2\tau^2} + \text{const}$.

$\log p(\theta|D) \propto \log p(D|\theta) - \frac{\theta^2}{2\tau^2} = -\text{NLL} - \frac{\|θ\|^2}{2\tau^2}$.

Минимизируем MAP = максимизируем $\log p(\theta|D)$ = минимизируем NLL + λ||θ||² где $\lambda = \frac{1}{2\tau^2}$.

Задача 6. Gradient CE vs MSE

Sigmoid выход, $y = 1, \hat{y} = 0.01$ (уверенная ошибка). Сравни $\frac{\partial L_{\text{CE}}}{\partial z}$ и $\frac{\partial L_{\text{MSE}}}{\partial z}$.

Решение

$\sigma(z) = 0.01$, $\sigma'(z) = 0.01 \cdot 0.99 = 0.0099$.

$\frac{\partial L_{\text{CE}}}{\partial z} = \sigma(z) - y = 0.01 - 1 = -0.99$ (хороший градиент!).

$\frac{\partial L_{\text{MSE}}}{\partial z} = 2(\sigma(z) - y) \sigma'(z) = 2 \cdot (-0.99) \cdot 0.0099 \approx -0.0196$ (крошечный!).

Вывод: CE даёт градиент 0.99, MSE даёт 0.0196 — почти в 50 раз меньше. CE намного лучше.

⚡ Ответ за 3 минуты

Скелет устного ответа на билет 3 (Loss и MLE)
  1. Loss vs метрика. Loss — дифференцируема, минимизируем во время обучения. Метрика — понятна человеку, смотрим в конце. Пример: оптимизируем CE, смотрим accuracy.
  2. MSE. Формула $\frac{1}{N}\sum (y_i - \hat{y}_i)^2$. Квадратична, чувствительна к выбросам. Производная = 2e, линейна по ошибке.
  3. MAE. Формула $\frac{1}{N}\sum |y_i - \hat{y}_i|$. Линейна, робустна к выбросам. Производная = ±1 везде, константа.
  4. Huber loss. Квадратичный внутри [-δ,δ], линейный снаружи. Компромисс между MSE и MAE.
  5. MSE ↔ среднее, MAE ↔ медиана. $\min_a \sum (y_i-a)^2 \Rightarrow a = E[y]$. $\min_a \sum |y_i-a| \Rightarrow a = \text{median}(y)$. Доказывается приравниванием производной к нулю.
  6. Энтропия и кросс-энтропия. $H(p) = -\sum p_i \log p_i$ (неопределённость). $H(p,q) = -\sum p_i \log q_i$ (неожиданность кода q для p). KL$(p\|q) = H(p,q) - H(p)$ (расстояние).
  7. BCE. $-(y\log\hat{y} + (1-y)\log(1-\hat{y}))$. Для y=1 это $-\log\hat{y}$, большой штраф за уверенные ошибки.
  8. CE. $-\sum_k y_k \log\hat{y}_k$. Для one-hot это $-\log\hat{y}_{y^*}$, берём только правильный класс.
  9. Почему не MSE для классификации. (1) Градиент с sigmoid: $(\hat{y}-y) \sigma'$ насыщается. CE: $(\hat{y}-y)$ чистый. (2) Вероятностно: MSE → гауссов шум, классификация → категориальное.
  10. Метод максимального правдоподобия. $\theta^* = \arg\max_\theta \prod_i p(y_i|x_i,\theta) = \arg\min_\theta -\sum_i \log p(y_i|x_i,\theta)$ = NLL.
  11. ММП для регрессии: гауссов шум → MSE. Если $y = f(x,\theta) + \varepsilon, \varepsilon \sim N(0,\sigma^2)$, то $\log L \propto -\sum (y_i - f(x_i,\theta))^2 = $MSE.
  12. ММП для классификации: категориальное → CE. Если $y \sim \text{Categorical}(\hat{y}_\theta)$, то $\log L \propto \sum_i \log\hat{y}_{i,y_i^*} = $CE.
