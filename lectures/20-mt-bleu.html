1. Интуиция и мотивация

Задача нейросетевого машинного перевода (NMT) формулируется как поиск наиболее вероятного целевого предложения $Y = (y_1, \dots, y_T)$ при заданном исходном тексте $X = (x_1, \dots, x_S)$. В отличие от пословных словарей, современные системы генерируют перевод авторегрессионно.

Конвейер NMT включает три компонента:

  1. Языковая модель: оценивает естественность текста; внутренняя метрика — перплексия (Perplexity).
  2. Стратегия декодирования: алгоритм выбора токенов (Beam Search, Top-$p$).
  3. Автоматические метрики: формальное сравнение с эталонами (BLEU, ROUGE, BERTScore).

2. Архитектура и схема

1. GREEDY SEARCH (ЖАДНЫЙ ВЫБОР, B = 1): Шаг 1: [Я] (p=0.7) ──▶ Шаг 2: [люблю] (p=0.9) ──▶ Шаг 3: [ИИ] (p=0.8) (Единственный путь) 2. BEAM SEARCH (ЛУЧЕВОЙ ПОИСК, ШИРИНА ЛУЧА B = 2): Шаг 1: ┬─ [Я] (p=0.7) ──┬─ [люблю] (0.7*0.9=0.63) ──▶ [ИИ] (0.63*0.8 = 0.504) -> ВЫБРАН! └─ [Мне] (p=0.25)─┼─ [нравится] (0.25*0.9=0.225) └─ [кажется] (0.25*0.6=0.150) (Отброшен) Beam Search отслеживает $B$ лучших гипотез на каждом шаге, избегая локальных тупиков жадного выбора.

3. Математический аппарат

1. Целевая функция NMT

$$ Y^* = \arg\max_Y P(Y \mid X) = \arg\max_Y \prod_{t=1}^T P(y_t \mid y_1, \dots, y_{t-1}, X) $$

2. Перплексия (Perplexity, PPL)

$$ \text{PPL} = \exp(\text{NLL}) = \exp\left( -\frac{1}{T} \sum_{t=1}^T \log P(w_t \mid w_{\lt t}) \right) $$
💡 Интуиция перплексии

Перплексия отражает эффективное число равновероятных слов, среди которых колеблется модель. Если $\text{PPL}=10$, модель сомневается между 10 равновероятными словами. Идеал: $\text{PPL} = 1.0$.

3. Стратегии декодирования

  • Температура ($T_{\text{temp}} > 0$): $P(w_i) = \frac{\exp(z_i / T_{\text{temp}})}{\sum_j \exp(z_j / T_{\text{temp}})}$.
  • Top-$k$ Sampling: ограничение выбора $k$ лучшими токенами.
  • Top-$p$ (Nucleus): наименьшее множество токенов $V^{(p)}$, где $\sum_{w \in V^{(p)}} P(w) \ge p$.

4. Метрика BLEU

$$ \text{BLEU} = \text{BP} \cdot \exp\left( \sum_{n=1}^N w_n \log p_n \right), \quad p_n = \frac{\sum \text{Count}_{\text{clip}}(\text{n-gram})}{\sum \text{Count}_{\text{cand}}(\text{n-gram})} $$

где $N=4, w_n = 0.25$. Штраф за краткость (Brevity Penalty):

$$ \text{BP} = \begin{cases} 1, & c > r \\ \exp\left(1 - \frac{r}{c}\right), & c \le r \end{cases} $$

4. Пошаговый числовой пример

Расчёт BLEU-2:

  • Эталон ($r=6$): «the cat is on the mat»
  • Кандидат ($c=4$): «the the the mat»

Пошаговый расчёт:

  1. $p_1$: «the» встретилось 3 раза (в эталоне 2 $\implies \text{clip}=2$), «mat» 1 раз ($\text{clip}=1$).
    $$ p_1 = \frac{2 + 1}{4} = \mathbf{0.75} $$
  2. $p_2$: Биграммы кандидата: «the the» (2 шт., в эталоне 0), «the mat» (1 шт., в эталоне 1). Всего 3 биграммы.
    $$ p_2 = \frac{0 + 1}{3} \approx \mathbf{0.3333} $$
  3. Штраф за краткость ($c=4 \le r=6$): $$ \text{BP} = \exp\left(1 - \frac{6}{4}\right) = \exp(-0.5) \approx \mathbf{0.6065} $$
  4. Итог: $$ \text{BLEU-2} = 0.6065 \cdot \sqrt{0.75 \cdot 0.3333} = 0.6065 \cdot 0.50 = \mathbf{0.3033} \quad (30.33\%) $$

Реализация расчёта метрики BLEU на Python

import math
from collections import Counter

def calculate_bleu(reference: str, candidate: str, max_n: int = 4) -> float:
    ref_tokens = reference.strip().split()
    cand_tokens = candidate.strip().split()
    c = len(cand_tokens)
    r = len(ref_tokens)
    if c == 0:
        return 0.0
    
    bp = 1.0 if c > r else math.exp(1.0 - r / c)
    log_precisions = []
    
    for n in range(1, max_n + 1):
        cand_ngrams = [tuple(cand_tokens[i:i+n]) for i in range(len(cand_tokens) - n + 1)]
        ref_ngrams = [tuple(ref_tokens[i:i+n]) for i in range(len(ref_tokens) - n + 1)]
        if not cand_ngrams:
            return 0.0
        
        cand_counts = Counter(cand_ngrams)
        ref_counts = Counter(ref_ngrams)
        clipped_matches = sum(min(count, ref_counts[ng]) for ng, count in cand_counts.items())
        p_n = clipped_matches / len(cand_ngrams)
        if p_n == 0:
            return 0.0
        log_precisions.append(math.log(p_n))
        
    return bp * math.exp(sum(log_precisions) / max_n)

5. Преимущества, недостатки и применимость

Метрика Тип сравнения Преимущества Недостатки Применимость
BLEU-4 Precision $n$-грамм + BP Быстрый расчёт, стандарт бенчмарков. Не учитывает синонимы; 0 при отсутствии 4-грамм. NMT, валидация перевода.
ROUGE-L Recall (LCS) Оценивает полноту покрытия фактов. Слабо учитывает грамматику. Суммаризация текстов.
METEOR $F_{\text{mean}}$ + WordNet Учитывает стемминг и синонимы. Медленный расчёт. Исследования NMT.
chrF++ Символьные $n$-граммы Отлично подходит для русского и немецкого языков. Сложнее интерпретировать. Соревнования WMT.
BERTScore Эмбеддинги BERT Высокая корреляция с оценкой человека. Требует тяжёлой модели на GPU. Оценка современных LLM.

6. 🎯 Препод спросит

Что такое Перплексия (Perplexity) и как она связана с кросс-энтропией?

Перплексия — это $\text{PPL} = \exp(\text{NLLLoss})$. Она отражает эффективное число равновероятных слов при выборе токена. Чем ниже PPL, тем точнее модель.

Зачем в формулу BLEU введён штраф за краткость (Brevity Penalty)?

Без BP модель могла бы перевести фразу одним частым словом («the») с точностью $p_1=100\%$. $\text{BP} = \exp(1 - r/c)$ штрафует переводы, длина которых $c < r$.

В чём фундаментальный недостаток метрики BLEU?

BLEU требует строгого совпадения слов. Синонимы («автомобиль» вместо «машина») или изменение порядка слов штрафуются нулём. Нейросетевые метрики (BERTScore) лишены этого недостатка.

Чем Top-$p$ (Nucleus) сэмплирование лучше Top-$k$?

В Top-$k$ размер пула фиксирован ($k=50$). При очевидном выборе (вероятность 99%) Top-$k$ берёт 49 маловероятных токенов (риск галлюцинаций). Top-$p$ адаптивно сужает пул до 1 токена.

Как температура генерации $T$ влияет на распределение вероятностей?

Логиты делятся на $T$. При $T \to 0$ Softmax вырождается в жадный выбор (пиковое распределение). При $T > 1$ вероятности сглаживаются, увеличивая креативность и случайность.

В чём принципиальная разница между метриками BLEU и ROUGE?

BLEU ориентирован на Precision (точность перевода: отсутствие выдуманных слов). ROUGE ориентирован на Recall (полнота покрытия ключевых тезисов в суммаризации).

Как рассчитывается модифицированная точность $n$-грамм в BLEU?

Используется клиппинг: $\text{Count}_{\text{clip}} = \min(\text{Count}_{\text{cand}}, \text{Count}_{\text{ref}})$. Для «the the the» при эталоне «the cat» засчитается лишь 1 совпадение, предотвращая обман повторами.

Какова формула Brevity Penalty и почему при $c > r$ штраф не применяется?

$\text{BP} = 1$ при $c > r$ и $\exp(1 - r/c)$ при $c \le r$. Избыточная длина при $c > r$ уже штрафуется знаменателем модифицированной точности $p_n$.

В чём преимущества метрик chrF и BERTScore перед BLEU?

chrF оценивает символьные $n$-граммы (устойчив к морфологии русского языка). BERTScore считает сходство контекстных эмбеддингов, учитывая синонимы и парафразы.

Почему в Beam Search необходима нормализация по длине (Length Penalty)?

Логарифмы вероятностей отрицательны. Длинные фразы накапливают больше штрафов. Без $\text{LP}(Y) = \frac{(5+|Y|)^\alpha}{(5+1)^\alpha}$ поиск преждевременно выдаёт короткие фразы с `<EOS>`.

7. 📝 Микро-задачи с решениями

Задача 1. Расчёт Перплексии по потерям NLL

Кросс-энтропия $\text{NLL} = 2.3026$. Найдите значение Перплексии.

Решение

$\text{PPL} = \exp(2.3026) = e^{2.3026} \approx \mathbf{10.0}$ (модель сомневается между 10 равновероятными словами).

Задача 2. Расчёт Brevity Penalty

Эталон $r = 20$, перевод $c = 15$. Рассчитайте Brevity Penalty.

Решение

Так как $c < r$: $\text{BP} = \exp(1 - 20/15) = \exp(-0.3333) \approx \mathbf{0.7165}$.

Задача 3. Ручной расчёт ядра Top-p (Nucleus) пула

Вероятности: $w_1: 0.50, w_2: 0.25, w_3: 0.15, w_4: 0.07, w_5: 0.03$. Порог $p = 0.85$. Какие токены войдут в ядро?

Решение

Сумма: $w_1 (0.50) + w_2 (0.25) + w_3 (0.15) = 0.90 \ge 0.85$. В ядро войдут $\{w_1, w_2, w_3\}$.

Задача 4. Влияние температуры на распределение вероятностей

Логиты $z_1 = 4.0, z_2 = 2.0$. Найдите $P(w_1)$ при: (а) $T=1.0$; (б) $T=2.0$.

Решение

(а) $T=1.0$: $\frac{e^4}{e^4+e^2} = \frac{54.598}{61.987} \approx \mathbf{0.8808} \quad (88.1\%)$.
(б) $T=2.0$: логиты $2.0, 1.0 \implies \frac{e^2}{e^2+e^1} = \frac{7.389}{10.107} \approx \mathbf{0.7311} \quad (73.1\%)$.

Задача 5. Геометрическое зануление в BLEU-4

Точности: $p_1 = 0.8, p_2 = 0.6, p_3 = 0.4, p_4 = 0.0$. Чему равен скор BLEU-4?

Решение

$\text{BLEU-4} = \text{BP} \cdot (0.8 \cdot 0.6 \cdot 0.4 \cdot 0.0)^{1/4} = \mathbf{0.0}$ (при $p_4=0$ геометрическое среднее обнуляет весь скор).

Задача 6. Сравнение Beam Search с шириной B=1 и B=4

Длина $T = 50$ токенов. Сколько вызовов декодера потребуется при $B=1$ и $B=4$?

Решение

1. $B=1$ (Greedy): $1 \times 50 = \mathbf{50 \text{ вызовов}}$.
2. $B=4$ (Beam Search): $4 \times 50 = \mathbf{200 \text{ вызовов}}$.

8. ⚡ Скелет ответа по билету

Скелет ответа по билету 19 (Машинный перевод, языковые модели, BLEU)
  1. Постановка NMT: авторегрессионная максимизация условной вероятности $\max \prod P(y_t \mid y_{\lt t}, X)$ через Transformer / Seq2Seq.
  2. Языковая модель и Перплексия: оценка естественности текста. Лосс — NLL. Перплексия $\text{PPL} = \exp(\text{NLL})$ — эффективный объём выбора.
  3. Декодирование: Greedy Search ($B=1$, быстрый) vs Beam Search ($B > 1$, параллельное удержание $B$ путей с нормализацией длины).
  4. Сэмплирование: Температура $T$ ($z_i/T$), Top-$k$ (фиксация числа кандидатов), Top-$p$ Nucleus (динамический порог накопленной вероятности).
  5. Метрика BLEU: геометрическое среднее модифицированной точности $n$-грамм ($p_1\dots p_4$) с клиппингом + Brevity Penalty ($\exp(1-r/c)$).
  6. Недостатки BLEU: оценивает только точные совпадения, зануляясь на синонимах.
  7. Альтернативы: ROUGE (Recall для суммаризации), METEOR (синонимы), chrF (символьные $n$-граммы), BERTScore/COMET (семантика эмбеддингов).
