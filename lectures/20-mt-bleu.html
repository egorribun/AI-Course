1. Интуиция и мотивация

Задача нейросетевого машинного перевода (Neural Machine Translation, NMT) заключается в поиске наиболее вероятной целевой фразы $Y = (y_1, \dots, y_T)$ при заданном предложении оригинала $X = (x_1, \dots, x_S)$. В отличие от классического пословного словаря, современные системы моделируют перевод как условную авторегрессионную генерацию последовательности.

Для генерации качественного связного текста и объективной оценки результатов необходимы три взаимосвязанных компонента:

  1. Языковая модель (Language Model): Оценивает грамматическую и семантическую естественность сгенерированного текста на целевом языке. Внутренней метрикой качества выступает перплексия (Perplexity).
  2. Стратегия декодирования (Decoding Strategy): Алгоритм выбора токенов на каждом шаге генерации (детерминированный Beam Search против стохастического Top-$p$ сэмплирования).
  3. Автоматические метрики качества: Формальные критерии сравнения сгенерированного перевода с человеческими эталонами (BLEU, ROUGE, METEOR, chrF, BERTScore).

2. Архитектура и схема

Сравнение стратегий поиска и декодирования при генерации текста:

1. GREEDY SEARCH (ЖАДНЫЙ ВЫБОР, B = 1): Шаг 1: [Я] (p=0.7) ──▶ Шаг 2: [люблю] (p=0.9) ──▶ Шаг 3: [ИИ] (p=0.8) (Единственный путь) 2. BEAM SEARCH (ЛУЧЕВОЙ ПОИСК, ШИРИНА ЛУЧА B = 2): Шаг 1: ┬─ [Я] (p=0.7) ──┬─ [люблю] (0.7*0.9=0.63) ──▶ [ИИ] (0.63*0.8 = 0.504) -> ВЫБРАН! └─ [Мне] (p=0.25)─┼─ [нравится] (0.25*0.9=0.225) └─ [кажется] (0.25*0.6=0.150) (Отброшен) Beam Search сохраняет $B$ лучших гипотез на каждом шаге, предотвращая попадание в локальные тупики жадного выбора.

3. Математический аппарат

1. Постановка NMT и целевая функция

$$ Y^* = \arg\max_Y P(Y \mid X) = \arg\max_Y \prod_{t=1}^T P(y_t \mid y_1, \dots, y_{t-1}, X) $$

2. Перплексия (Perplexity, PPL)

Экспонента от усредненной кросс-энтропии (Negative Log-Likelihood, NLL) по всему тестовому корпусу длины $T$:

$$ \text{PPL} = \exp(\text{NLL}) = \exp\left( -\frac{1}{T} \sum_{t=1}^T \log P(w_t \mid w_{\lt t}) \right) = \left( \prod_{t=1}^T \frac{1}{P(w_t \mid w_{\lt t})} \right)^{1/T} $$
💡 Интуиция перплексии

Перплексия отражает эффективный размер выбора модели. Если $\text{PPL} = 10$, модель на каждом шаге сомневается так, будто выбирает одно верное слово из 10 равновероятных вариантов. Идеальная модель имеет $\text{PPL} = 1.0$. Чем меньше перплексия, тем выше точность языковой модели.

3. Стохастическое сэмплирование

  • Температура ($T_{\text{temp}} > 0$): Масштабирование логитов $z_i$:
    $$ P(w_i) = \frac{\exp(z_i / T_{\text{temp}})}{\sum_j \exp(z_j / T_{\text{temp}})} $$
  • Top-$k$ Sampling: Ограничение пула выбора $k$ наиболее вероятными токенами.
  • Top-$p$ (Nucleus Sampling): Динамический выбор наименьшего множества токенов $V^{(p)}$, суммарная вероятность которых превышает порог $p$:
    $$ \sum_{w \in V^{(p)}} P(w \mid w_{\lt t}) \ge p $$

4. Метрика BLEU (Bilingual Evaluation Understudy)

$$ \text{BLEU} = \text{BP} \cdot \exp\left( \sum_{n=1}^N w_n \log p_n \right) $$

где $N=4$, веса $w_n = 1/4 = 0.25$, а $p_n$ — модифицированная точность $n$-грамм с клиппингом (Clipping):

$$ p_n = \frac{\sum_{\text{n-gram}} \text{Count}_{\text{clip}}(\text{n-gram})}{\sum_{\text{n-gram}} \text{Count}_{\text{cand}}(\text{n-gram})} $$

5. Штраф за краткость (Brevity Penalty, BP)

$$ \text{BP} = \begin{cases} 1, & \text{если } c > r \\ \exp\left(1 - \frac{r}{c}\right), & \text{если } c \le r \end{cases} $$

где $c$ — длина перевода кандидата (Candidate), $r$ — длина эталона (Reference).

4. Пошаговый числовой пример

Рассчитаем вручную метрику BLEU-2 для сгенерированного перевода.

Исходные предложения:

  • Эталон (Reference, $r=6$): «the cat is on the mat»
  • Кандидат (Candidate, $c=4$): «the the the mat»

Пошаговый расчет:

  1. Модифицированная точность униграмм ($p_1$):
    • Слово «the» встретилось в кандидате 3 раза, а в эталоне — максимум 2 раза: $\text{Count}_{\text{clip}}(\text{«the»}) = \min(3, 2) = 2$.
    • Слово «mat» встретилось 1 раз, в эталоне — 1 раз: $\text{Count}_{\text{clip}}(\text{«mat»}) = \min(1, 1) = 1$.
    • Всего униграмм в кандидате: $4$.
    $$ p_1 = \frac{2 + 1}{4} = \frac{3}{4} = \mathbf{0.75} $$
  2. Модифицированная точность биграмм ($p_2$):
    • Биграммы кандидата: «the the», «the the», «the mat». Всего биграмм: $4 - 2 + 1 = 3$.
    • Биграмма «the the» в эталоне отсутствует: $\text{Count}_{\text{clip}} = 0$.
    • Биграмма «the mat» присутствует в эталоне 1 раз: $\text{Count}_{\text{clip}} = 1$.
    $$ p_2 = \frac{0 + 0 + 1}{3} = \frac{1}{3} \approx \mathbf{0.3333} $$
  3. Штраф за краткость (Brevity Penalty):

    Так как $c = 4 \le r = 6$:

    $$ \text{BP} = \exp\left(1 - \frac{6}{4}\right) = \exp(1 - 1.5) = \exp(-0.5) \approx \mathbf{0.6065} $$
  4. Итоговый BLEU-2:
    $$ \text{BLEU-2} = \text{BP} \cdot \exp\left(0.5 \ln p_1 + 0.5 \ln p_2\right) = 0.6065 \cdot \sqrt{0.75 \cdot 0.3333} = 0.6065 \cdot \sqrt{0.25} = 0.6065 \cdot 0.50 = \mathbf{0.3033} \quad (30.33\%) $$

Практическая реализация расчета метрики BLEU на Python

import math
from collections import Counter

def calculate_bleu(reference: str, candidate: str, max_n: int = 4) -> float:
    ref_tokens = reference.strip().split()
    cand_tokens = candidate.strip().split()
    c = len(cand_tokens)
    r = len(ref_tokens)
    if c == 0:
        return 0.0
    
    # 1. Brevity Penalty (штраф за краткость)
    bp = 1.0 if c > r else math.exp(1.0 - r / c)
    
    # 2. Модифицированная точность n-грамм с клиппингом
    log_precisions = []
    for n in range(1, max_n + 1):
        cand_ngrams = [tuple(cand_tokens[i:i+n]) for i in range(len(cand_tokens) - n + 1)]
        ref_ngrams = [tuple(ref_tokens[i:i+n]) for i in range(len(ref_tokens) - n + 1)]
        if not cand_ngrams:
            return 0.0
        
        cand_counts = Counter(cand_ngrams)
        ref_counts = Counter(ref_ngrams)
        clipped_matches = sum(min(count, ref_counts[ng]) for ng, count in cand_counts.items())
        p_n = clipped_matches / len(cand_ngrams)
        if p_n == 0:
            return 0.0
        log_precisions.append(math.log(p_n))
        
    return bp * math.exp(sum(log_precisions) / max_n)

5. Преимущества, недостатки и применимость

Метрика оценки Тип сравнения Преимущества Недостатки Области применения
BLEU (BLEU-4) Precision точных $n$-грамм + BP Быстрый расчет, общепринятый стандарт бенчмарков. Не учитывает синонимы, опечатки и морфологию; 0 при отсутствии 4-грамм. Машинный перевод (NMT), валидация моделей.
ROUGE (ROUGE-L) Recall (LCS — общая подпоследовательность) Оценивает полноту покрытия ключевых фактов эталона. Слабо учитывает грамматическую связность и структуру. Автоматическая суммаризация, Question Answering.
METEOR Гармоническое $F_{\text{mean}}$ + WordNet Учитывает леммы, стеммы, синонимы и штрафует фрагментацию. Медленный расчет, привязан к ресурсам WordNet. Исследования качества NMT.
chrF / chrF++ Символьные $n$-граммы Превосходно оценивает морфологически богатые языки (русский, немецкий). Менее интерпретируем на уровне целых слов. Современные соревнования WMT.
BERTScore / COMET Семантическое сходство эмбеддингов Максимальная корреляция с оценками экспертов-людей. Требует прогона тяжелой нейросети GPU (RoBERTa). Оценка качества современных LLM (GPT-4, Claude).

🎯 Препод спросит

Что такое Перплексия (Perplexity) и как она математически связана с кросс-энтропией?

Перплексия — это экспонента от усредненных кросс-энтропийных потерь (Negative Log-Likelihood) модели на тестовой выборке: $\text{PPL} = \exp(\text{CrossEntropyLoss})$. Интуитивно она равна эффективному числу равновероятных слов, среди которых колеблется модель на каждом шаге предсказания. Чем ниже значение PPL, тем более уверена и точна языковая модель.

Зачем в формулу BLEU введен штраф за краткость (Brevity Penalty)?

Без Brevity Penalty модель могла бы перевести длинное предложение одним единственным словом «the», получив точность униграмм $p_1 = 100\%$ и искусственно завысив BLEU. Brevity Penalty экспоненциально штрафует модель, если длина сгенерированного перевода $c$ меньше длины эталона $r$ ($\text{BP} = \exp(1 - r/c)$), стимулируя генерацию полных фраз.

В чем фундаментальный недостаток метрики BLEU при оценке современных систем перевода?

BLEU опирается на строгое пословное совпадение $n$-грамм. Если модель использовала точный контекстный синоним (например, «автомобиль» вместо «машина») или перефразировала предложение в другом порядке слов, BLEU оценит такой перевод как ошибочный (0 баллов). Современные нейросетевые метрики (BERTScore, COMET) лишены этого недостатка, так как оценивают косинусную близость в пространстве смысловых эмбеддингов.

Чем Top-$p$ (Nucleus) сэмплирование лучше классического Top-$k$ сэмплирования?

В Top-$k$ размер пула кандидатов строго фиксирован (например, $k=50$). Когда следующее слово однозначно предопределено (вероятность 99%), Top-$k$ все равно добавляет 49 маловероятных токенов, создавая риск генерации галлюцинаций. Top-$p$ адаптивно сжимает пул до 1 токена при высокой уверенности и расширяет его при неоднозначном контексте.

Как температура генерации $T$ влияет на распределение вероятностей Softmax?

Логиты делятся на температуру $z_i / T$. При $T \to 0$ разница между логитами усиливается, Softmax превращается в резкий пик (детерминированный жадный выбор). При $T > 1.0$ логиты сближаются, распределение становится плоским и приближается к равномерному, увеличивая разнообразие и случайность сэмплирования.

В чем принципиальная разница между метриками BLEU и ROUGE?

BLEU ориентирован на Precision (Точность): какую долю сгенерированных слов подтверждает эталон (критично для перевода, чтобы исключить выдуманные факты). ROUGE ориентирован на Recall (Полноту): какую долю эталонного содержания смогла охватить модель (критично для суммаризации, чтобы не упустить ключевые тезисы текста).

Как математически рассчитывается модифицированная точность $n$-грамм в BLEU и почему простой подсчет совпадений неприменим?

Простая точность делит совпадения на длину гипотезы. Для строки «the the the the the» и эталона «the cat is on the mat» обычная точность униграмм составила бы $5/5 = 100\%$. Модифицированная точность вводит клиппинг (усечение): $\text{Count}_{\text{clip}}(\text{n-gram}) = \min(\text{Count}_{\text{cand}}, \, \text{Count}_{\text{ref}})$. В этом примере $\text{Count}_{\text{clip}}(\text{«the»}) = \min(5, 2) = 2$, и точность падает до $2/5 = 40\%$, ликвидируя уязвимость к повторам.

Какова строгая формула Brevity Penalty и почему при $c > r$ штраф не применяется?

Формула: $\text{BP} = 1$ при $c > r$, и $\text{BP} = \exp(1 - r/c)$ при $c \le r$. При $c > r$ (кандидат длиннее эталона) штраф $\text{BP} = 1.0$, поскольку избыточная длина автоматически штрафуется знаменателем модифицированной точности $p_n$ из-за появления лишних $n$-грамм, отсутствующих в эталоне.

В чем преимущества метрик chrF, BERTScore и COMET по сравнению с BLEU?

• chrF: Сравнивает символьные $n$-граммы, эффективно оценивая морфологические вариации и основы слов флективных языков (русский, немецкий).
• BERTScore: Вычисляет жадное косинусное сходство контекстуализированных эмбеддингов BERT, распознавая синонимы и парафразы.
• COMET: Обученная кросс-языковая нейросеть (на XLM-RoBERTa), напрямую предсказывающая человеческую оценку качества перевода на основе оригинала, гипотезы и эталона.

Почему в Beam Search необходима нормализация по длине (Length Penalty)?

Логарифм вероятности последовательности равен сумме неположительных логарифмов: $\sum \log P(y_t) \le 0$. С каждым новым токеном сумма строго убывает. Без нормализации Beam Search систематически отдает предпочтение коротким гипотезам, генерирующим токен `<EOS>` раньше времени. Штраф по длине $\text{LP}(Y) = \frac{(5 + |Y|)^\alpha}{(5 + 1)^\alpha}$ ($\alpha \approx 0.6\text{--}0.8$) компенсирует это смещение.

📝 Микро-задачи

Задача 1. Расчет Перплексии по потерям NLL

Языковая модель показала средний лосс кросс-энтропии $\text{NLL} = 2.3026$. Найдите значение Перплексии модели.

Решение
$$ \text{PPL} = \exp(2.3026) = e^{2.3026} \approx \mathbf{10.0} $$

Модель выбирает следующее слово с уверенностью, эквивалентной выбору среди 10 равновероятных токенов.

Задача 2. Расчет Brevity Penalty

Длина эталона $r = 20$ слов, длина сгенерированного перевода $c = 15$ слов. Рассчитайте коэффициент Brevity Penalty.

Решение

Так как $c < r$:

$$ \text{BP} = \exp\left(1 - \frac{20}{15}\right) = \exp(1 - 1.3333) = \exp(-0.3333) \approx \mathbf{0.7165} $$

Итоговый скор BLEU будет уменьшен на $28.35\%$ из-за неполноты длины.

Задача 3. Ручной расчет ядра Top-p (Nucleus) пула

Вероятности кандидатов: $w_1: 0.50$, $w_2: 0.25$, $w_3: 0.15$, $w_4: 0.07$, $w_5: 0.03$. Порог $p = 0.85$. Какие слова войдут в ядро сэмплирования?

Решение

Считаем накопленную вероятность по убыванию:

  • $w_1$: $0.50 \le 0.85$ (берем, сумма 0.50)
  • $w_2$: $0.50 + 0.25 = 0.75 \le 0.85$ (берем, сумма 0.75)
  • $w_3$: $0.75 + 0.15 = 0.90 \ge 0.85$ (берем и останавливаемся, порог $0.85$ достигнут!)

В ядро войдут токены: $\{w_1, w_2, w_3\}$. Токены $w_4, w_5$ отсекаются.

Задача 4. Влияние температуры на распределение вероятностей

Логиты двух токенов: $z_1 = 4.0, z_2 = 2.0$. Найдите вероятность $P(w_1)$ при: (а) $T=1.0$; (б) $T=2.0$.

Решение

(а) При $T=1.0$:

$$ P(w_1) = \frac{e^4}{e^4 + e^2} = \frac{54.598}{54.598 + 7.389} = \frac{54.598}{61.987} \approx \mathbf{0.8808} \quad (88.1\%) $$

(б) При $T=2.0$:

Логиты делятся на 2: $z_1' = 2.0, z_2' = 1.0$.

$$ P(w_1) = \frac{e^2}{e^2 + e^1} = \frac{7.389}{7.389 + 2.718} = \frac{7.389}{10.107} \approx \mathbf{0.7311} \quad (73.1\%) $$

Повышение температуры снизило доминирование фаворита с $88.1\%$ до $73.1\%$.

Задача 5. Геометрическое зануление в BLEU-4

Перевод модели показал точности $n$-грамм: $p_1 = 0.8, p_2 = 0.6, p_3 = 0.4, p_4 = 0.0$. Чему равен классический скор BLEU-4?

Решение

В формуле BLEU используется геометрическое среднее: $\exp\left(\frac{1}{4} \sum \ln p_n\right) = (p_1 p_2 p_3 p_4)^{1/4}$.

$$ \text{BLEU-4} = \text{BP} \cdot (0.8 \cdot 0.6 \cdot 0.4 \cdot 0.0)^{1/4} = \mathbf{0.0} $$

Вывод: Если отсутствует хотя бы одна 4-грамма, классический BLEU зануляется целиком (для коротких фраз в библиотеках применяют сглаживание Smoothing).

Задача 6. Сравнение Beam Search с шириной B=1 и B=4

Длина генерации составляет $T = 50$ токенов. Сколько вызовов декодера потребуется при жадном поиске ($B=1$) и лучевом поиске ($B=4$)?

Решение

1. При $B=1$ (Greedy): 1 гипотеза $\times 50$ шагов = $\mathbf{50 \text{ вызовов}}$.

2. При $B=4$ (Beam Search): 4 гипотезы параллельно $\times 50$ шагов = $\mathbf{200 \text{ вызовов}}$.

  1. Постановка NMT: Авторегрессионная максимизация условной вероятности $\max \prod P(y_t \mid y_{\lt t}, X)$ через Transformer / Seq2Seq.
  2. Языковая модель и Перплексия: Модель оценивает $P(w_1, \dots, w_T)$. Лосс — кросс-энтропия (NLL). Перплексия $\text{PPL} = \exp(\text{NLL})$ — эффективное число равновероятных слов при выборе (меньше — лучше).
  3. Стратегии декодирования: Greedy Search ($B=1$, быстрый, но локальный) vs Beam Search ($B > 1$, параллельное отслеживание $B$ лучших путей с нормализацией по длине).
  4. Стохастическое сэмплирование: Температура $T$ ($z_i/T$, баланс строгости и креативности), Top-$k$ (фиксация $k$ лучших), Top-$p$ Nucleus (динамический пул с кумулятивной вероятностью $\ge p$).
  5. Метрика BLEU (2002): Геометрическое среднее модифицированной точности $n$-грамм ($p_1, \dots, p_4$) с клиппингом + Brevity Penalty (штраф за краткость $\exp(1 - r/c)$).
  6. Недостатки BLEU: Оценка только точных совпадений слов; 0 при синонимах и парафразах.
  7. Альтернативные метрики: ROUGE (Recall для суммаризации), METEOR (синонимы WordNet), chrF (символьные $n$-граммы для морфологии), BERTScore/COMET (семантическое сходство эмбеддингов).
