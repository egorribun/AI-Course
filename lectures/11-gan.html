1. Интуиция и мотивация

В генеративно-состязательных сетях (GAN, Goodfellow et al., 2014) плотность вероятности $p(x)$ не вычисляется явно. Обучение строится как антагонистическая игра двух сетей:

  • Генератор ($G$): отображает шум $z \sim \mathcal{N}(0, I)$ в синтетический объект $G(z)$, стремясь обмануть дискриминатор.
  • Дискриминатор ($D$): оценивает вероятность $D(x) \in [0, 1]$ того, что образец $x$ взят из реального распределения $p_{\text{data}}$.
💡 Равновесие по Нэшу (Nash Equilibrium)

В точке глобального оптимума генератор точно воспроизводит данные: $p_g = p_{\text{data}}$, а дискриминатор не может различить подделку: $D^*(x) = \frac{1}{2}$.

2. Архитектура и схема

ДВУХФАЗНЫЙ ШАГ ОБУЧЕНИЯ Фаза 1 (Дискриминатор, веса G заморожены): - Real: loss_real = -log(D(x)) - Fake: loss_fake = -log(1 - D(G(z).detach())) - Шаг градиентного подъема по θ_D Фаза 2 (Генератор, веса D заморожены): - Non-Saturating Loss: loss_G = -log(D(G(z))) - Шаг градиентного спуска по θ_G Схема обучения GAN: поочерёдная оптимизация Дискриминатора и Генератора на реальных и сгенерированных сэмплах.

3. Математический аппарат

3.1 Минимаксная целевая функция

$$\min_G \max_D V(D, G) = \mathbb{E}_{x \sim p_{\text{data}}} [\log D(x)] + \mathbb{E}_{z \sim p_z} [\log (1 - D(G(z)))]$$

3.2 Аналитический вывод оптимального дискриминатора $D^*(x)$

📐 Вывод $D^*(x)$ при фиксированном $G$
$$V(D, G) = \int_{\mathcal{X}} \Big[ p_{\text{data}}(x) \log D(x) + p_g(x) \log(1 - D(x)) \Big] dx$$

Максимизация подынтегрального выражения $f(y) = a \log y + b \log(1-y)$ при $y = D(x)$:

$$f'(y) = \frac{a}{y} - \frac{b}{1-y} = 0 \implies y^* = \frac{a}{a+b} \implies D^*(x) = \frac{p_{\text{data}}(x)}{p_{\text{data}}(x) + p_g(x)}$$

3.3 Связь с дивергенцией Йенсена–Шеннона

Подставляя $D^*(x)$ в $V(D^*, G)$:

$$V(D^*, G) = -\log 4 + 2 \cdot D_{\text{JS}}(p_{\text{data}} \,\parallel\, p_g)$$

Минимум по $G$ достигается при $p_g = p_{\text{data}}$, где $D_{\text{JS}} = 0$ и $V(D^*, G^*) = -\log 4 \approx -1.3863$.

3.4 Non-Saturating Loss генератора

На старте $D(G(z)) \approx 0$, градиент оригинального $\log(1 - D)$ исчезает из-за насыщения. Решение — Non-Saturating Loss:

$$\mathcal{L}_G^{\text{NS}} = -\mathbb{E}_{z \sim p_z} [\log D(G(z))]$$

При $D \to 0$ градиент $-\frac{1}{D} \to -\infty$, обеспечивая мощный обучающий сигнал.

3.5 Wasserstein GAN (WGAN) и Gradient Penalty (WGAN-GP)

Из-за непересекающихся многообразий $D_{\text{JS}} \equiv \text{const}$. Расстояние Вассерштейна непрерывно всюду:

$$W(p_{\text{data}}, p_g) = \sup_{\|f\|_L \le 1} \mathbb{E}_{x \sim p_{\text{data}}}[f(x)] - \mathbb{E}_{x \sim p_g}[f(x)]$$

1-Липшицевость критика в WGAN-GP обеспечивается дифференцируемым штрафом за градиент:

$$\mathcal{L}_{\text{Critic}} = \mathbb{E}_{\tilde{x}}[f_w(\tilde{x})] - \mathbb{E}_{x}[f_w(x)] + \lambda \, \mathbb{E}_{\hat{x}}\left[ \Big(\|\nabla_{\hat{x}} f_w(\hat{x})\|_2 - 1\Big)^2 \right]$$

где $\hat{x} = \epsilon x + (1-\epsilon)\tilde{x}$ — случайная интерполяция, $\lambda = 10$.

3.6 Метрики качества: IS и FID

$$\text{IS}(G) = \exp\Big( \mathbb{E}_{x \sim p_g} [D_{\text{KL}}(p(y|x) \parallel p(y))] \Big), \qquad \text{FID} = \|\mu_r - \mu_g\|_2^2 + \text{Tr}\Big(\Sigma_r + \Sigma_g - 2(\Sigma_r \Sigma_g)^{1/2}\Big)$$

3.7 Реализации на PyTorch

import torch
import torch.nn as nn

class DCGANGenerator(nn.Module):
    def __init__(self, z_dim=100, img_channels=3, feature_g=64):
        super().__init__()
        self.net = nn.Sequential(
            nn.ConvTranspose2d(z_dim, feature_g * 8, 4, 1, 0, bias=False),
            nn.BatchNorm2d(feature_g * 8), nn.ReLU(True),
            nn.ConvTranspose2d(feature_g * 8, feature_g * 4, 4, 2, 1, bias=False),
            nn.BatchNorm2d(feature_g * 4), nn.ReLU(True),
            nn.ConvTranspose2d(feature_g * 4, feature_g * 2, 4, 2, 1, bias=False),
            nn.BatchNorm2d(feature_g * 2), nn.ReLU(True),
            nn.ConvTranspose2d(feature_g * 2, img_channels, 4, 2, 1, bias=False),
            nn.Tanh()
        )

    def forward(self, z):
        return self.net(z)
class DCGANDiscriminator(nn.Module):
    def __init__(self, img_channels=3, feature_d=64):
        super().__init__()
        self.net = nn.Sequential(
            nn.Conv2d(img_channels, feature_d, 4, 2, 1, bias=False),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Conv2d(feature_d, feature_d * 2, 4, 2, 1, bias=False),
            nn.BatchNorm2d(feature_d * 2), nn.LeakyReLU(0.2, inplace=True),
            nn.Conv2d(feature_d * 2, feature_d * 4, 4, 2, 1, bias=False),
            nn.BatchNorm2d(feature_d * 4), nn.LeakyReLU(0.2, inplace=True),
            nn.Conv2d(feature_d * 4, 1, 4, 1, 0, bias=False),
            nn.Sigmoid()
        )

    def forward(self, x):
        return self.net(x).view(-1, 1)
def compute_gradient_penalty(critic, real_samples, fake_samples, device):
    alpha = torch.rand(real_samples.size(0), 1, 1, 1, device=device)
    interpolates = (alpha * real_samples + ((1 - alpha) * fake_samples)).requires_grad_(True)
    d_interpolates = critic(interpolates)
    gradients = torch.autograd.grad(
        outputs=d_interpolates, inputs=interpolates,
        grad_outputs=torch.ones_like(d_interpolates),
        create_graph=True, retain_graph=True, only_inputs=True
    )[0].view(real_samples.size(0), -1)
    return ((gradients.norm(2, dim=1) - 1) ** 2).mean()

4. Пошаговый числовой пример

🔢 Дано:
  • Батч $B=2$: $D(x_1)=0.8, D(x_2)=0.9$ (Real), $D(G(z_1))=0.3, D(G(z_2))=0.4$ (Fake).

Шаг 1. Лосс дискриминатора $L_D$ (BCE)

$$L_{D,\text{real}} = -\frac{1}{2}(\ln 0.8 + \ln 0.9) = -\frac{1}{2}(-0.22314 - 0.10536) = 0.16425$$
$$L_{D,\text{fake}} = -\frac{1}{2}(\ln 0.7 + \ln 0.6) = -\frac{1}{2}(-0.35667 - 0.51083) = 0.43375 \implies L_D = 0.16425 + 0.43375 = 0.5980$$

Шаг 2. Non-Saturating Loss генератора $L_G^{\text{NS}}$

$$L_G^{\text{NS}} = -\frac{1}{2}(\ln 0.3 + \ln 0.4) = -\frac{1}{2}(-1.20397 - 0.91629) = 1.0601$$

Шаг 3. Производная генератора по выходу дискриминатора

Для $u = D(G(z_1)) = 0.3$: $\frac{\partial L_G^{\text{NS}}}{\partial u} = -\frac{1}{0.3} \approx -3.3333$ (против $-1.4286$ у saturating loss, в 2.33 раза мощнее).

6. 🎯 Препод спросит

Почему в GAN нельзя просто обучить генератор минимизировать MSE между $G(z)$ и реальными картинками?

Шум $z$ не привязан к конкретному изображению $x$. Минимизация пиксельного MSE приведёт к усреднению всех картинок датасета в серое пятно. Дискриминатор оценивает распределение целиком, заставляя синтезировать чёткие текстуры.

Чему равен оптимальный дискриминатор $D^*(x)$ и значение функции стоимости при идеальном генераторе?

$D^*(x) = \frac{p_{\text{data}}(x)}{p_{\text{data}}(x) + p_g(x)}$. При $p_g = p_{\text{data}}$ имеем $D^*(x) = 1/2$ для всех $x$, а значение функционала $V(D^*, G^*) = -\log 4 = -2\ln 2 \approx -1.3863$.

В чем математическая причина проблемы Mode Collapse?

Дивергенция $D_{\text{JS}}$ слабо штрафует пропуск мод. Генератор стягивает все сэмплы $z$ в одну моду, дающую низкий лосс (например, цифру «1»). При адаптации $D$ генератор просто прыгает на другую моду («7»), осциллируя по кругу.

Зачем в WGAN нужно требование 1-Липшицевости и как оно реализовано в WGAN-GP?

1-Липшицевость $(\|\nabla f(x)\| \le 1)$ следует из двойственности Канторовича–Рубинштейна. В WGAN-GP она задаётся штрафом $\mathbb{E}_{\hat{x}} [(\|\nabla_{\hat{x}} D(\hat{x})\|_2 - 1)^2]$ на случайных интерполяциях $\hat{x} = \epsilon x + (1-\epsilon)\tilde{x}$.

Почему в шаге обучения дискриминатора нужно вызывать `fake_imgs.detach()`?

`.detach()` отсоединяет тензор от графа генератора, предотвращая ненужный прогон градиентов через генератор и сохраняя ресурсы GPU.

Чем StyleGAN принципиально отличается от традиционных генераторов?

StyleGAN переводит $z \to w \in \mathcal{W}$ через Mapping Network. Синтез стартует с константного тензора $4\times 4$, а вектор $w$ управляет слоями через модуляции AdaIN, распутывая глобальные и локальные стили.

Зачем в CycleGAN нужен Cycle Consistency Loss?

Adversarial Loss гарантирует лишь правдоподобие $G(x) \in Y$, но не привязку к $x$. Cycle Consistency $\|F(G(x)) - x\|_1$ требует восстановимости исходного изображения, сохраняя геометрию и контент объекта.

В чем главные недостатки Inception Score (IS) и почему все перешли на FID?

IS оценивает только $p(y|x)$ и $p(y)$, игнорируя реальный датасет (слеп к Mode Collapse при запоминании 1000 картинок). FID сравнивает распределения признаков (средние и ковариации) реальных и синтетических данных.

В чем математическая разница между Minimax Loss и Non-Saturating Loss генератора и почему первый приводит к затуханию градиентов на старте?

В Minimax $\mathcal{L}_G = \mathbb{E}[\log(1 - D(G(z)))]$. При $D \approx 0$ производная насыщается ($\approx 0$). В Non-Saturating $\mathcal{L}_G^{\text{NS}} = -\mathbb{E}[\log D(G(z))]$ градиент $-\frac{1}{D} \to -\infty$, давая сильный обучающий сигнал.

Почему в WGAN ограничение весов (Weight Clipping) приводит к деградации сети и как штраф на градиент (Gradient Penalty, WGAN-GP) решает эту проблему?

Клиппинг весов $w \in [-c, c]$ вызывает затухание/взрыв градиентов и сбивает веса к $\pm c$, убивая ёмкость критика. WGAN-GP накладывает мягкий штраф за отклонение нормы градиента от 1, стабилизируя обучение.

7. 📝 Микро-задачи с решениями

Задача 1. Расчёт функции стоимости при идеальном дискриминаторе

Пусть $D(x) = 0.99$, $D(G(z)) = 0.01$. Вычислите приближённое значение $V(D, G)$.

Решение

$V(D, G) = \ln(0.99) + \ln(1 - 0.01) \approx -0.01005 - 0.01005 = -0.0201 \approx 0$.

Ответ: $V(D, G) \approx -0.02$ (дискриминатор близок к теоретическому максимуму 0).

Задача 2. Размерность выхода транспонированной свёртки (ConvTranspose2d)

Вход $(B, 100, 1, 1)$, слой `ConvTranspose2d(100, 256, kernel_size=4, stride=1, padding=0)`. Найдите размер выхода.

Решение

$H_{out} = (H_{in} - 1)\cdot\text{stride} - 2\cdot\text{padding} + \text{kernel\_size} = (1 - 1)\cdot1 - 0 + 4 = 4$.

Ответ: Размерность тензора $(B, 256, 4, 4)$.

Задача 3. Сравнение градиентов Saturating vs Non-Saturating Loss

При $u = D(G(z)) = 0.05$ найдите лоссы и производные по $u$ для: (а) $\ln(1-u)$; (б) $-\ln(u)$.

Решение

(а) $\ln(0.95) \approx -0.0513$, градиент $-\frac{1}{0.95} \approx -1.05$.

(б) $-\ln(0.05) \approx 2.996$, градиент $-\frac{1}{0.05} = -20$.

Ответ: Non-Saturating градиент в 19 раз мощнее ($-20$ против $-1.05$).

Задача 4. Вычисление 1D расстояния Вассерштейна

Распределения: $P = \delta(x)$, $Q = \delta(x - \theta)$ при $\theta \ne 0$. Найдите $D_{\text{JS}}(P \parallel Q)$ и $W(P, Q)$.

Решение

1) Носители не пересекаются $\implies D_{\text{JS}}(P \parallel Q) = \ln 2 \approx 0.693$ (градиент 0).

2) $W(P, Q) = 1 \cdot |\theta - 0| = |\theta|$, градиент $\text{sign}(\theta) \ne 0$.

Ответ: $D_{\text{JS}} = \ln 2$, $W = |\theta|$.

Задача 5. Расчёт FID для 1D распределений

Признаки: $\mu_r = 2.0, \sigma_r^2 = 4.0$ и $\mu_g = 5.0, \sigma_g^2 = 9.0$. Вычислите FID.

Решение

$\text{FID} = (\mu_r - \mu_g)^2 + (\sigma_r - \sigma_g)^2 = (2 - 5)^2 + (2 - 3)^2 = 9 + 1 = 10.0$.

Ответ: $\text{FID} = 10.0$.

Задача 6. Количество параметров в WGAN-GP Gradient Penalty

Почему в критике WGAN-GP не используют BatchNorm и чем его заменяют?

Решение

BatchNorm связывает сэмплы батча, нарушая индивидуальный расчёт $\|\nabla_{\hat{x}_i} D(\hat{x}_i)\|_2$.

Ответ: Заменяется на Layer Normalization, Instance Normalization или Spectral Normalization.

8. ⚡ Скелет ответа по билету

Скелет ответа по билету 11 (GAN)
  1. Суть и идея: Игровая постановка: $G(z)$ создаёт фейки, $D(x)$ отличает от реальных данных. Явной плотности $p(x)$ нет.
  2. Минимаксная игра: $\min_G \max_D V(D, G) = \mathbb{E}[\log D(x)] + \mathbb{E}[\log(1 - D(G(z)))]$. $D$ максимизирует классификацию, $G$ минимизирует.
  3. Оптимальный дискриминатор: $D^*(x) = \frac{p_{\text{data}}}{p_{\text{data}} + p_g}$. Равновесие по Нэшу при $p_g = p_{\text{data}}, D^* = 1/2, V = -\log 4$.
  4. Non-Saturating Loss: $-\log D(G(z))$ предотвращает затухание градиента на старте ($-\frac{1}{D} \to -\infty$).
  5. Проблемы обучения: Mode Collapse (генерация одной моды), осцилляции, затухание градиентов из-за непересекающихся многообразий ($D_{\text{JS}} = \text{const}$).
  6. WGAN: 1-Вассерштейн $W(p_{\text{data}}, p_g) = \sup_{\|f\|_L \le 1} \mathbb{E}[f(x)] - \mathbb{E}[f(G(z))]$. Обеспечивает непрерывный градиент.
  7. WGAN-GP: Штраф за градиент $\|\nabla_{\hat{x}} D(\hat{x})\|_2 \approx 1$ на интерполяциях $\hat{x}$ вместо клиппинга весов. LayerNorm/InstanceNorm вместо BatchNorm.
  8. DCGAN: Свёртки со страйдом, BatchNorm, LeakyReLU в $D$, ReLU + Tanh в $G$.
  9. StyleGAN: Mapping $z \to w \in \mathcal{W}$, константный вход, AdaIN модуляция стилей, распутанное пространство признаков.
  10. CycleGAN: Непарный перенос стилей через Cycle Consistency $\|F(G(x)) - x\|_1 + \|G(F(y)) - y\|_1$.
  11. Метрики: IS: Inception Score оценивает чёткость $p(y|x)$ и разнообразие $p(y)$, но не сравнивает с реальным датасетом.
  12. Метрики: FID: Fréchet Inception Distance — расстояние между Гауссианами признаков слоя pool3 Inception-v3: $\|\mu_r - \mu_g\|^2 + \text{Tr}(\Sigma_r + \Sigma_g - 2\sqrt{\Sigma_r\Sigma_g})$.
