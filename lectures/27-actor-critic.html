1. Интуиция и мотивация

В обучении с подкреплением исторически сложились две полярные школы мысли, каждая со своими сильными и слабыми сторонами:

  1. Value-Based методы (Q-Learning, DQN): Обучают критика ценности $Q(s, a)$ методом временных разностей (TD). Плюсы: высокая эффективность выборки, низкая дисперсия благодаря бутстрэпингу. Минусы: не могут работать в непрерывных пространствах действий $\mathbb{R}^k$, не способны выучить стохастическую стратегию.
  2. Policy-Based методы (REINFORCE, CEM): Напрямую оптимизируют параметры стратегии $\pi_\theta(a|s)$ градиентным подъемом. Плюсы: работают с непрерывными и стохастическими действиями, плавная оптимизация. Минусы: гигантская дисперсия градиента из-за ожидания конца эпизода ($G_t$), низкая скорость обучения.
💡 Идея архитектуры Actor-Critic: идеальный симбиоз

Мы объединяем оба подхода в единую взаимодействующую систему:

  • Actor (Актор $\pi_\theta$): «Исполнитель». Принимает состояние $S_t$ и выбирает действие $A_t \sim \pi_\theta(\cdot \mid S_t)$. Умеет работать в непрерывных пространствах.
  • Critic (Критик $V_\phi$): «Судья / Тренер». Оценивает текущее состояние $V_\phi(S_t)$ и вычисляет ошибку временных разностей (Advantage) на каждом шаге. Критик заменяет шумный доход целого эпизода $G_t$ на компактный 1-шаговый TD-таргет, радикально снижая дисперсию градиента актора.

3. Математический аппарат

1. Функция преимущества (Advantage Function $A(s, a)$)

Функция преимущества показывает, насколько конкретное действие $a$ лучше или хуже среднестатистического действия в состоянии $s$:

$$ A^\pi(s, a) \doteq Q^\pi(s, a) - V^\pi(s) $$

Фундаментальное свойство: математическое ожидание преимущества по стратегии тождественно равно нулю:

$$ \mathbb{E}_{a \sim \pi(\cdot \mid s)} \left[ A^\pi(s, a) \right] = \sum_{a \in \mathcal{A}} \pi(a \mid s) \Big( Q^\pi(s, a) - V^\pi(s) \Big) = V^\pi(s) - V^\pi(s) = 0 $$
  • Если $A(s, a) > 0$ — действие $a$ превосходит ожидания, его вероятность увеличивается.
  • Если $A(s, a) < 0$ — действие $a$ хуже среднего, его вероятность подавляется.

2. Одношаговый TD-критик как аппроксимация Advantage

Так как $Q^\pi(S_t, A_t) = \mathbb{E}[R_{t+1} + \gamma V^\pi(S_{t+1}) \mid S_t, A_t]$, 1-шаговая TD-ошибка является несмещенной оценкой функции преимущества:

$$ \delta_t \doteq R_{t+1} + \gamma V_\phi(S_{t+1}) - V_\phi(S_t) \approx A(S_t, A_t) $$

3. Правила обновления весов в Advantage Actor-Critic (A2C)

Обучение происходит параллельно для двух нейросетей:

  1. Критик ($V_\phi$, веса $\phi$): Минимизирует среднеквадратичную ошибку прогнозирования ценности (MSE Bellman residual):
    $$ \mathcal{L}_{\text{critic}}(\phi) = \frac{1}{2} \left( R_{t+1} + \gamma V_{\phi^-}(S_{t+1}) - V_\phi(S_t) \right)^2 $$ $$ \phi \leftarrow \phi + \alpha_\phi \, \delta_t \nabla_\phi V_\phi(S_t) $$
  2. Актор ($\pi_\theta$, веса $\theta$): Максимизирует математическое ожидание с регуляризацией энтропией $\mathcal{H}$:
    $$ \mathcal{L}_{\text{actor}}(\theta) = -\log \pi_\theta(A_t \mid S_t) \, \delta_t - \beta \mathcal{H}\left(\pi_\theta(\cdot \mid S_t)\right) $$ $$ \theta \leftarrow \theta + \alpha_\theta \left( \nabla_\theta \log \pi_\theta(A_t \mid S_t) \, \delta_t + \beta \nabla_\theta \mathcal{H}(\pi_\theta) \right) $$

4. Generalized Advantage Estimation (GAE($\gamma, \lambda$), Schulman et al., 2015)

Для тонкой настройки компромисса между смещением (Bias) и дисперсией (Variance) вводится параметр экспоненциального сглаживания $\lambda \in [0, 1]$:

$$ \hat{A}_t^{\text{GAE}(\gamma, \lambda)} \doteq \sum_{l=0}^{\infty} (\gamma \lambda)^l \delta_{t+l}^V = \delta_t^V + \gamma \lambda \hat{A}_{t+1}^{\text{GAE}(\gamma, \lambda)} $$

где $\delta_{t+l}^V = R_{t+l+1} + \gamma V(S_{t+l+1}) - V(S_{t+l})$.

  • При $\lambda = 0 \implies \hat{A}_t = \delta_t$ (1-step TD: минимальная дисперсия, максимальное смещение от критика).
  • При $\lambda = 1 \implies \hat{A}_t = \sum_{l=0}^\infty \gamma^l R_{t+l+1} - V(S_t) = G_t - V(S_t)$ (Monte Carlo: нулевое смещение, максимальная дисперсия).
  • На практике значение $\lambda \in [0.92, 0.98]$ обеспечивает наилучшую сходимость в PPO и A2C.

5. Soft Actor-Critic (SAC, Haarnoja et al., 2018)

SAC — современный SOTA-алгоритм для непрерывного управления, основанный на концепции Maximum Entropy RL:

$$ J(\pi) = \mathbb{E}_{\tau \sim \pi} \left[ \sum_{t=0}^\infty \gamma^t \left( R(S_t, A_t) + \alpha \mathcal{H}\left(\pi(\cdot \mid S_t)\right) \right) \right] $$

где $\alpha > 0$ — температура энтропии, управляющая компромиссом между исследованием и максимизацией награды. SAC использует Twin Q-networks ($Q_{\phi_1}, Q_{\phi_2}$) для предотвращения переоценки и автоматическую настройку температуры $\alpha$ через градиентный спуск.

6. Практическая реализация Actor-Critic и GAE на PyTorch

import torch
import torch.nn as nn
import torch.nn.functional as F

class ActorCriticNet(nn.Module):
    """Общий бэкбон с отдельными головами Актора и Критика."""
    def __init__(self, state_dim, action_dim, hidden_dim=64):
        super().__init__()
        self.actor = nn.Sequential(
            nn.Linear(state_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, action_dim)
        )
        self.critic = nn.Sequential(
            nn.Linear(state_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 1)
        )

    def forward(self, state):
        logits = self.actor(state)
        probs = F.softmax(logits, dim=-1)
        value = self.critic(state)
        return probs, value

def compute_gae_advantages(rewards, values, next_values, dones, gamma=0.99, lam=0.95):
    """Вычисление обобщенных преимуществ GAE-lambda."""
    deltas = rewards + gamma * next_values * (1.0 - dones) - values
    advantages = torch.zeros_like(rewards)
    running_adv = 0.0
    for t in reversed(range(len(rewards))):
        running_adv = deltas[t] + gamma * lam * (1.0 - dones[t]) * running_adv
        advantages[t] = running_adv
    return advantages

4. Пошаговый числовой пример

🔢 Пример 1. Расчет обновления Actor-Critic за один шаг

Агент совершил переход: $(S_t, A_t, R_{t+1}=+2.0, S_{t+1})$. Коэффициент дисконтирования $\gamma = 0.9$.

  • Оценки критика: $V_\phi(S_t) = 1.0, \quad V_\phi(S_{t+1}) = 2.0$.
  • Градиент критика: $\nabla_\phi V_\phi(S_t) = [0.5, -0.2]$.
  • Градиент актора: $\nabla_\theta \log \pi_\theta(A_t \mid S_t) = [1.2, 0.4]$.
  • Скорости обучения: $\alpha_\phi = 0.1, \quad \alpha_\theta = 0.05$.

1. Вычисление TD-таргета и Advantage $\delta_t$:

$$ \text{Target} = R_{t+1} + \gamma V_\phi(S_{t+1}) = 2.0 + 0.9 \cdot 2.0 = 2.0 + 1.8 = 3.8 $$ $$ \delta_t = \text{Target} - V_\phi(S_t) = 3.8 - 1.0 = +2.8 $$

2. Обновление весов Критика:

$$ \Delta \phi = \alpha_\phi \cdot \delta_t \cdot \nabla_\phi V_\phi(S_t) = 0.1 \cdot 2.8 \cdot [0.5, -0.2] = 0.28 \cdot [0.5, -0.2] = [0.14, -0.056] $$

3. Обновление весов Актора:

$$ \Delta \theta = \alpha_\theta \cdot \delta_t \cdot \nabla_\theta \log \pi_\theta(A_t \mid S_t) = 0.05 \cdot 2.8 \cdot [1.2, 0.4] = 0.14 \cdot [1.2, 0.4] = [0.168, 0.056] $$
🔢 Пример 2. Расчет GAE на траектории из 3 шагов

Пусть вычислены одношаговые TD-ошибки: $\delta_0 = 1.0, \quad \delta_1 = -0.5, \quad \delta_2 = 2.0$.

Параметры: $\gamma = 0.9, \quad \lambda = 0.8 \implies \gamma \lambda = 0.9 \cdot 0.8 = 0.72$. Эпизод завершился на шаге $t=3$ ($\hat{A}_3 = 0$).

Вычисляем GAE рекуррентно с конца:

  • Шаг 2: $\hat{A}_2 = \delta_2 = 2.0$
  • Шаг 1: $\hat{A}_1 = \delta_1 + (\gamma \lambda) \hat{A}_2 = -0.5 + 0.72 \cdot 2.0 = -0.5 + 1.44 = +0.94$
  • Шаг 0: $\hat{A}_0 = \delta_0 + (\gamma \lambda) \hat{A}_1 = 1.0 + 0.72 \cdot 0.94 = 1.0 + 0.6768 = +1.6768$

Обучающий шаг Actor-Critic на PyTorch

import torch
import torch.optim as optim

def train_actor_critic_step(model, optimizer, state, action, reward, next_state, done, gamma=0.99):
    probs, value = model(state)
    _, next_value = model(next_state)
    target = reward + gamma * (1.0 - float(done)) * next_value.item()
    advantage = target - value.item()
    
    critic_loss = (target - value) ** 2
    actor_loss = -torch.log(probs[action] + 1e-8) * advantage
    total_loss = actor_loss + 0.5 * critic_loss
    
    optimizer.zero_grad()
    total_loss.backward()
    optimizer.step()
    return total_loss.item()

6. 🎯 Препод спросит

1. Какую роль выполняет Critic в архитектуре Actor-Critic? Может ли Критик сам выбирать действия?

Критик выполняет исключительно роль оценщика (baseline/evaluator): он аппроксимирует функцию ценности $V(s)$ и вычисляет скалярную ошибку преимущества $\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)$. Критик не выбирает действия. Выбор действий — исключительная прерогатива Актора $\pi_\theta(a|s)$. Это разделение позволяет Актору работать в любых непрерывных пространствах действий без поиска максимума.

2. В чем разница между синхронным A2C и асинхронным A3C?

В A3C (Asynchronous Advantage Actor-Critic) несколько параллельных потоков на CPU независимо взаимодействуют со своими копиями среды и асинхронно обновляют глобальные веса без блокировок (Hogwild!). В A2C (Advantage Actor-Critic) параллельные среды синхронизированы: мастер собирает батч переходов со всех воркеров одновременно и делает один синхронный батчевый шаг на GPU. A2C работает быстрее на современных GPU и не уступает A3C по качеству.

3. Что регулирует параметр $\lambda$ в Generalized Advantage Estimation (GAE)?

Параметр $\lambda \in [0, 1]$ регулирует компромисс между смещением (bias) и дисперсией (variance). При $\lambda = 0$ берется чистый 1-шаговый TD-критик с минимальной дисперсией, но высоким смещением, если критик неточен. При $\lambda = 1$ берется чистый эмпирический доход Монте-Карло с нулевым смещением, но огромной дисперсией. Промежуточные значения ($\lambda \approx 0.95$) дают оптимальный компромисс.

4. Зачем в Soft Actor-Critic (SAC) введена максимизация энтропии (Maximum Entropy RL)?

Максимизация энтропии $\mathcal{H}(\pi(\cdot|s))$ стимулирует стратегию быть максимально случайной при сохранении высокой награды. Это дает 3 преимущества: 1) Агент исследует все перспективные моды решений, не застревая в локальных субоптимумах; 2) Стратегия становится робастной к возмущениям среды; 3) Упрощается дообучение на новые смежные задачи (Transfer Learning).

5. Зачем в SAC используются две Q-сети (Twin Q-Networks)?

Как и в Double DQN, нейросетевой критик страдает от завышения оценок ценности. SAC обучает две независимые Q-сети $Q_{\phi_1}$ и $Q_{\phi_2}$, а при вычислении целевого значения берет минимум: $\min(Q_{\phi_1}(s', a'), Q_{\phi_2}(s', a'))$. Это гарантирует консервативную пессимистичную оценку и полностью подавляет расходимость.

6. Можно ли использовать одну общую нейросеть (Backbone) для Актора и Критика?

Да, в большинстве практических реализаций (включая PPO в Atari и LLM RLHF) используется единая нейросеть-бэкбон с двумя выходными головами: голова политики (выдает логиты/параметры распределения действий) и голова ценности (выдает скаляр $V(s)$). Суммарный лосс равен $\mathcal{L} = \mathcal{L}_{\text{policy}} + c_1 \mathcal{L}_{\text{value}} - c_2 \mathcal{H}(\pi)$.

7. В чем отличие Off-Policy Actor-Critic (DDPG, SAC) от On-Policy Actor-Critic (A2C, PPO)?

On-Policy методы (A2C, PPO) обновляют актора только по свежим траекториям, сгенерированным текущей стратегией, после чего данные отбрасываются. Off-Policy методы (DDPG, SAC) сохраняют все переходы в Replay Buffer и обучают Q-критика по старым данным произвольных стратегий, что на 1-2 порядка повышает Sample Efficiency.

8. Как вычисляется градиент непрерывного действия в алгоритме DDPG (Deep Deterministic Policy Gradient)?

DDPG использует детерминированного актора $\mu_\theta(s)$. Градиент берется по цепочке через Q-сеть критика (Deterministic Policy Gradient Theorem): $\nabla_\theta J(\theta) = \mathbb{E}_{s \sim \mathcal{D}} \left[ \nabla_a Q_\phi(s, a) \big|_{a=\mu_\theta(s)} \cdot \nabla_\theta \mu_\theta(s) \right]$.

9. Что такое Reparameterization Trick в SAC для стохастического актора?

Чтобы градиент критика $\nabla_a Q(s, a)$ мог протечь назад в веса актора $\theta$, сэмплирование действия дифференцируется через вспомогательный шум: $a_\theta(s, \epsilon) = \tanh\left(\mu_\theta(s) + \sigma_\theta(s) \odot \epsilon\right)$, где $\epsilon \sim \mathcal{N}(0, I)$. Это позволяет брать производные $\nabla_\theta Q(s, a_\theta(s, \epsilon))$ методом Autograd (аналогично VAE!).

10. Почему именно Actor-Critic стал доминирующей парадигмой современного Deep RL?

Потому что он решает «трилемму RL»: поддерживает произвольные непрерывные и дискретные пространства действий, обладает низкой дисперсией градиентов благодаря бутстрэпингу критика и позволяет стабильно масштабироваться на гигантские нейросети и миллионы параллельных сред.

7. 📝 Микро-задачи с решениями

Задача 1. Расчет скалярного Advantage

В состоянии $s$ для действия $a$ критик предсказал $Q(s, a) = 8.4$, а ценность состояния $V(s) = 6.0$. Чему равен Advantage $A(s, a)$ и как изменится вероятность этого действия?

Решение

По определению функции преимущества:

$$ A(s, a) = Q(s, a) - V(s) = 8.4 - 6.0 = +2.4 $$

Так как $A(s, a) > 0$, действие $a$ лучше среднего исхода из состояния $s$. Градиентный шаг $\nabla_\theta \log \pi(a|s) \cdot (+2.4)$ увеличит вероятность выбора действия $a$.

Ответ: $A(s, a) = +2.4$, вероятность увеличится.

Задача 2. Расчет TD-ошибки Критика с терминальным флагом

Переход $(S_t, A_t, R_{t+1}=+10.0, S_{t+1}, done=1)$. Оценки критика $V(S_t) = 4.0, V(S_{t+1}) = 15.0$, дисконт $\gamma = 0.99$. Чему равна TD-ошибка $\delta_t$?

Решение

Так как $done=1$, ценность следующего состояния обнуляется множителем $(1 - done)$:

$$ \text{Target} = R_{t+1} + \gamma (1 - done) V(S_{t+1}) = 10.0 + 0.99 \cdot 0 \cdot 15.0 = 10.0 $$ $$ \delta_t = \text{Target} - V(S_t) = 10.0 - 4.0 = +6.0 $$

Ответ: $\delta_t = +6.0$.

Задача 3. Расчет GAE($\lambda=0$) vs GAE($\lambda=1$)

В эпизоде длины 2 получены TD-ошибки $\delta_0 = 2.0, \delta_1 = 4.0$. Дисконт $\gamma = 0.5$. Чему равно значение преимущества $\hat{A}_0$ при $\lambda = 0$ и при $\lambda = 1$?

Решение

Формула: $\hat{A}_0 = \delta_0 + (\gamma \lambda) \delta_1$.

  • При $\lambda = 0$: $\hat{A}_0 = \delta_0 + 0 = 2.0$.
  • При $\lambda = 1$: $\hat{A}_0 = \delta_0 + \gamma \delta_1 = 2.0 + 0.5 \cdot 4.0 = 2.0 + 2.0 = 4.0$.

Ответ: $\lambda=0 \implies \hat{A}_0 = 2.0; \quad \lambda=1 \implies \hat{A}_0 = 4.0$.

Задача 4. Maximum Entropy целевая функция в SAC

В дискретном состоянии стратегия предсказывает вероятности $\pi = [0.5, 0.5]$. Награда перехода $R = 5.0$. Температура энтропии $\alpha = 2.0$. Чему равна модифицированная награда $R_{\text{soft}} = R + \alpha \mathcal{H}(\pi)$ (энтропия с натуральным логарифмом, $\ln 2 \approx 0.6931$)?

Решение

Вычисляем энтропию Шеннона распределения:

$$ \mathcal{H}(\pi) = -\sum_{i=1}^2 \pi_i \ln \pi_i = -(0.5 \ln 0.5 + 0.5 \ln 0.5) = -\ln(0.5) = \ln(2) \approx 0.6931 $$

Модифицированная награда:

$$ R_{\text{soft}} = 5.0 + 2.0 \cdot 0.6931 = 5.0 + 1.3862 = 6.3862 $$

Ответ: $R_{\text{soft}} \approx 6.3862$.

Задача 5. Twin Q-Networks консервативный таргет в SAC

Две Q-сети предсказывают для состояния $s'$ и действия $a'$ значения $Q_1(s', a') = 14.5$ и $Q_2(s', a') = 11.2$. Награда $R = 3.0$, дисконт $\gamma = 0.9$. Чему равен таргет критика $y = R + \gamma \min(Q_1, Q_2)$?

Решение

Берем консервативный минимум оценок:

$$ \min(Q_1, Q_2) = \min(14.5, 11.2) = 11.2 $$ $$ y = 3.0 + 0.9 \cdot 11.2 = 3.0 + 10.08 = 13.08 $$

Ответ: $y = 13.08$.

Задача 6. Совокупная функция потерь Actor-Critic с регуляризацией энтропией

В общем бэкбоне лосс политики $\mathcal{L}_{\text{policy}} = -1.5$, лосс критика $\mathcal{L}_{\text{value}} = 0.8$, энтропия $\mathcal{H} = 0.4$. Коэффициенты $c_1 = 0.5, c_2 = 0.01$. Чему равен итоговый скалярный лосс $\mathcal{L} = \mathcal{L}_{\text{policy}} + c_1 \mathcal{L}_{\text{value}} - c_2 \mathcal{H}$?

Решение
$$ \mathcal{L} = -1.5 + 0.5 \cdot 0.8 - 0.01 \cdot 0.4 = -1.5 + 0.4 - 0.004 = -1.104 $$

Ответ: $\mathcal{L} = -1.104$.

8. ⚡ Скелет ответа по билету

Скелет устного ответа по билету 25 (Value-based vs Policy-based, Actor-Critic)
  1. Сравнение парадигм: Value-based (DQN) оценивает $Q(s, a)$ и берет $\arg\max$ (эффективно по выборке, но только дискретные действия); Policy-based (REINFORCE) напрямую параметризует $\pi_\theta(a|s)$ (непрерывные действия, но высокая дисперсия).
  2. Архитектура Actor-Critic: Синтез двух идей. Актор $\pi_\theta(a|s)$ выбирает действия; Критик $V_\phi(s)$ оценивает их качество и выдает TD-ошибку $\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t) \approx A(S_t, A_t)$, снижая дисперсию актора.
  3. Функция преимущества (Advantage): $A(s, a) = Q(s, a) - V(s)$. Показывает, насколько действие $a$ лучше среднего исхода ($\mathbb{E}_\pi[A(s, a)] = 0$).
  4. Обновление A2C: Критик: $\min_\phi (R + \gamma V(S') - V_\phi(S))^2$; Актор: $\theta \leftarrow \theta + \alpha \nabla_\theta \log \pi_\theta(A|S) \delta_t + \beta \nabla_\theta \mathcal{H}(\pi)$.
  5. Generalized Advantage Estimation (GAE): Экспоненциальное сглаживание $\hat{A}_t^{\text{GAE}} = \sum (\gamma \lambda)^l \delta_{t+l}$. Параметр $\lambda$ балансирует смещение (Bias при $\lambda=0$) и дисперсию (Variance при $\lambda=1$).
  6. Soft Actor-Critic (SAC): SOTA для непрерывного управления. Maximum Entropy RL: $\max \mathbb{E}[R + \alpha \mathcal{H}(\pi)]$. Twin Q-сети $\min(Q_1, Q_2)$ и репараметризованный стохастический актор.
  7. Практическая значимость: Actor-Critic лежит в основе всех передовых систем ИИ: от управления гуманоидными роботами до выравнивания больших языковых моделей (PPO в ChatGPT / RLHF).
