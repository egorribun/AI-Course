2. Идея и устройство архитектуры Actor-Critic

┌────────────────────────────────────────┐ │ АГЕНТ │ │ │ │ ┌────────────────────────────────┐ │ │ │ ACTOR (АКТЁР, π_θ) │───┼──▶ Действие a_t │ │ (Выбирает действие) │ │ │ └───────────────▲────────────────┘ │ │ │ │ │ TD-Ошибка / Advantage δ_t │ │ │ │ │ ┌───────────────┴────────────────┐ │ │ │ CRITIC (КРИТИК, V_ϕ) │ │ │ │ (Оценивает ценность V(s)) │ │ │ └───────────────▲────────────────┘ │ └───────────────────┼────────────────────┘ │ Состояние s_t, Награда r_{t+1} ┌───────────────────┴────────────────────┐ │ СРЕДА │ └────────────────────────────────────────┘ Архитектура Actor-Critic: Актёр управляет средой, а Критик направляет градиент Актёра через TD-оценку качества.
💡 Разделение ролей
  • Актёр (Actor, $\pi_\theta(a \mid s)$): Занимается управлением (Policy Improvement). Выдает действие по состоянию $s$.
  • Критик (Critic, $V_\phi(s)$): Занимается оценкой (Policy Evaluation). Вычисляет TD-ошибку $\delta_t = r_{t+1} + \gamma V_\phi(s_{t+1}) - V_\phi(s_t)$, которая показывает, оказалось ли действие лучше или хуже ожиданий.

3. Generalized Advantage Estimation (GAE)

Функция преимущества (Advantage): $A(s, a) = Q(s, a) - V(s)$.

Джон Шульман (2016) предложил GAE (Generalized Advantage Estimation) — объединение $k$-шаговых TD-ошибок с экспоненциальным затуханием по параметру $\lambda \in [0, 1]$:

$$ \hat{A}_t^{\text{GAE}(\gamma, \lambda)} = \sum_{l=0}^\infty (\gamma \lambda)^l \delta_{t+l}^V = \delta_t^V + \gamma \lambda \hat{A}_{t+1}^{\text{GAE}} $$ где $\delta_t^V = r_{t+1} + \gamma V(s_{t+1}) - V(s_t)$. Регулирует баланс смещения и дисперсии!
  • При $\lambda = 0$: $\hat{A}_t = \delta_t$ (TD(0) — минимальная дисперсия, но есть смещение неточного Критика).
  • При $\lambda = 1$: $\hat{A}_t = \sum \gamma^l r_{t+l+1} - V(s_t) = G_t - V(s_t)$ (Монте-Карло — строго несмещенная оценка, но максимальная дисперсия).
  • На практике берут $\lambda \approx 0.95$, получая идеальный баланс.

4. A2C и A3C (Advantage Actor-Critic)

  • A3C (Asynchronous Advantage Actor-Critic, Mnih et al., 2016): Несколько параллельных потоков на CPU независимо взаимодействуют со своими копиями среды и асинхронно обновляют глобальную модель.
  • A2C (Advantage Actor-Critic — Синхронный): Синхронный сбор данных из батча векторных сред (`gym.vector.AsyncVectorEnv`). Гораздо эффективнее утилизирует тензорные ядра GPU.

Функции потерь A2C:

$$ L_{\text{total}}(\theta, \phi) = L_{\text{actor}}(\theta) + c_1 L_{\text{critic}}(\phi) - c_2 \mathcal{H}\left(\pi_\theta(\cdot \mid s_t)\right) $$ $$ L_{\text{actor}}(\theta) = -\log \pi_\theta(a_t \mid s_t) \cdot \hat{A}_t, \quad L_{\text{critic}}(\phi) = \frac{1}{2} \left( V_\phi(s_t) - (r_{t+1} + \gamma V_\phi(s_{t+1})) \right)^2 $$ $\mathcal{H}(\pi)$ — энтропия стратегии. Максимизация энтропии заставляет Актёра исследовать новые действия и не коллапсировать в детерминизм.

5. DDPG (Deep Deterministic Policy Gradient)

DDPG (Lillicrap et al., DeepMind, 2015) — алгоритм для задач непрерывного управления (роботы, автопилот, манипуляторы):

  • Детерминированный Актёр $\mu_\theta(s) \in \mathbb{R}^n$: Выдает непрерывный вектор действия (углы, силы).
  • Off-policy Критик $Q_\phi(s, a)$: Оценивает пару «состояние-непрерывное действие».
  • Градиент Актёра по теореме Silver et al. (DPG Theorem): $$ \nabla_\theta J(\theta) = \mathbb{E}_{s \sim \mathcal{D}} \left[ \nabla_a Q_\phi(s, a)\big|_{a = \mu_\theta(s)} \cdot \nabla_\theta \mu_\theta(s) \right] $$ Градиент протекает от Критика через действие $a$ прямо в веса Актёра по обычному правилу цепного дифференцирования!

6. Soft Actor-Critic (SAC)

SAC (Tuomas Haarnoja et al., UC Berkeley, 2018) — самый мощный и стабильный современный алгоритм для непрерывного управления (SOTA в робототехнике).

🌟 Парадигма Maximum Entropy RL в SAC

Вместо стандартной максимизации наград SAC максимизирует награду плюс энтропию стратегии:

$$ J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta} \left[ \sum_{t=0}^\infty \gamma^t \left( r(s_t, a_t) + \alpha \mathcal{H}\left(\pi_\theta(\cdot \mid s_t)\right) \right) \right] $$

где $\mathcal{H}(\pi) = \mathbb{E}[-\log \pi(a \mid s)]$ — энтропия, а $\alpha$ — температурный коэффициент энтропии (часто настраивается автоматически).

Три ключевых преимущества SAC:

  1. Исследование множества оптимумов: Если есть 2 равноценных пути к цели, модель не выбирает один случайно, а выучивает оба пути.
  2. Надежность (Robustness): Стратегия с максимальной энтропией максимально устойчива к внезапным шумам и физическим возмущениям среды.
  3. Clipped Double-Q Trick: Использует две независимые Q-сети $Q_{\phi_1}, Q_{\phi_2}$ и берет минимум $\min(Q_1, Q_2)$, полностью побеждая Overestimation Bias.

8. Практическая реализация A2C на PyTorch

import torch
import torch.nn as nn
import torch.optim as optim
from torch.distributions import Categorical

class ActorCritic(nn.Module):
    def __init__(self, state_dim, action_dim):
        super().__init__()
        # Общий костяк признаков
        self.shared = nn.Sequential(
            nn.Linear(state_dim, 128),
            nn.ReLU()
        )
        # Голова Актёра (распределение действий)
        self.actor = nn.Linear(128, action_dim)
        # Голова Критика (оценка ценности состояния V)
        self.critic = nn.Linear(128, 1)

    def forward(self, x):
        features = self.shared(x)
        logits = self.actor(features)
        value = self.critic(features)
        return Categorical(logits=logits), value

def train_a2c_step(model, optimizer, states, actions, rewards, next_states, dones, gamma=0.99):
    dist, values = model(states)
    _, next_values = model(next_states)
    
    # 1. TD-мишень и Advantage
    target_values = rewards + gamma * next_values.squeeze(-1) * (1 - dones)
    advantage = target_values.detach() - values.squeeze(-1)
    
    # 2. Лоссы Актёра, Критика и Энтропии
    log_probs = dist.log_prob(actions)
    actor_loss = -(log_probs * advantage.detach()).mean()
    critic_loss = nn.functional.mse_loss(values.squeeze(-1), target_values.detach())
    entropy_loss = -dist.entropy().mean()
    
    total_loss = actor_loss + 0.5 * critic_loss + 0.01 * entropy_loss
    
    optimizer.zero_grad()
    total_loss.backward()
    optimizer.step()

🎯 Препод спросит

В чем концептуальная разница ролей Актёра и Критика и как устроена их совместная архитектура?

Архитектура Actor-Critic разделяет обучение агента на две взаимодействующие компоненты:

  • Актёр (Actor): параметризует политику $\pi_\theta(a \mid s)$ (вероятностное распределение или детерминированное действие) и отвечает за генерацию действий в среде.
  • Критик (Critic): параметризует функцию ценности $V_\phi(s)$ или $Q_\phi(s, a)$ и оценивает качество выбранного действия через одношаговую TD-ошибку $\delta_t = R_{t+1} + \gamma V_\phi(S_{t+1}) - V_\phi(S_t)$.

Критик вычисляет скаляр преимущества (Advantage), который масштабирует градиент логарифма правдоподобия Актёра. Критик обучается методом наименьших квадратов минимизировать TD-ошибку, а Актёр поднимается по градиенту функции выигрыша.

Запишите формулы одношагового градиентного обновления 1-step TD Actor-Critic для Актёра и Критика и объясните принцип двух масштабов времени (Two-timescale rule).

Пусть в момент времени $t$ совершен переход $(S_t, A_t, R_{t+1}, S_{t+1})$.

  1. TD-ошибка Критика: $$ \delta_t^V = R_{t+1} + \gamma V_\phi(S_{t+1}) - V_\phi(S_t) $$
  2. Шаг обновления параметров Критика ($\phi$): $$ \phi \leftarrow \phi + \alpha_c \, \delta_t^V \nabla_\phi V_\phi(S_t) $$
  3. Шаг обновления параметров Актёра ($\theta$): $$ \theta \leftarrow \theta + \alpha_a \, \delta_t^V \nabla_\theta \log \pi_\theta(A_t \mid S_t) $$

Правило двух масштабов времени ($\alpha_c > \alpha_a$): Для гарантированной сходимости темп обучения Критика $\alpha_c$ должен быть выше темпа обучения Актёра $\alpha_a$. Критик должен быстро адаптироваться и обеспечивать квазистационарную точную оценку $V^{\pi_\theta}$ для текущей политики, пока медленный шаг Актёра плавно улучшает параметры стратегии.

Выведите формулу Generalized Advantage Estimation (GAE) и проанализируйте предельные случаи $\lambda = 0$ и $\lambda = 1$.

Определим $k$-шаговую оценку функции преимущества:

$$ \hat{A}_t^{(k)} = \sum_{j=0}^{k-1} \gamma^j R_{t+j+1} + \gamma^k V(S_{t+k}) - V(S_t) = \sum_{j=0}^{k-1} \gamma^j \delta_{t+j}^V $$

Оценка GAE($\gamma, \lambda$) определяется как экспоненциально взвешенное среднее оценок разной длины:

$$ \hat{A}_t^{\text{GAE}(\gamma, \lambda)} = (1 - \lambda) \sum_{k=1}^{\infty} \lambda^{k-1} \hat{A}_t^{(k)} = \sum_{l=0}^{\infty} (\gamma \lambda)^l \delta_{t+l}^V $$

где $\delta_{t+l}^V = R_{t+l+1} + \gamma V(S_{t+l+1}) - V(S_{t+l})$.

  • При $\lambda = 0$ (TD(0)): $\hat{A}_t^{\text{GAE}(\gamma, 0)} = \delta_t^V$. Минимальная дисперсия, но сильное смещение от неточности нейросети Критика.
  • При $\lambda = 1$ (Монте-Карло): $\hat{A}_t^{\text{GAE}(\gamma, 1)} = \sum_{l=0}^\infty \gamma^l \delta_{t+l}^V = G_t - V(S_t)$. Строго несмещенная оценка, но максимальная дисперсия.
Как математически формулируется задача Maximum Entropy Reinforcement Learning в алгоритме SAC (Soft Actor-Critic)?

В парадигме Maximum Entropy RL агент максимизирует сумму наград и энтропию своего поведения в каждом посещенном состоянии:

$$ J(\pi) = \sum_{t=0}^{\infty} \mathbb{E}_{(s_t, a_t) \sim \rho_\pi} \left[ R(s_t, a_t) + \alpha \mathcal{H}\left(\pi(\cdot \mid s_t)\right) \right] $$

где $\mathcal{H}(\pi(\cdot \mid s_t)) = \mathbb{E}_{a \sim \pi}[-\log \pi(a \mid s_t)]$, а $\alpha > 0$ — температура энтропии.

Мягкое уравнение Беллмана (Soft Bellman Equation):

$$ Q^*(s, a) = R(s, a) + \gamma \, \mathbb{E}_{s' \sim \mathcal{P}} \left[ V^*(s') \right] $$ $$ V^*(s) = \mathbb{E}_{a \sim \pi^*} \left[ Q^*(s, a) - \alpha \log \pi^*(a \mid s) \right] = \alpha \log \int \exp\left( \frac{Q^*(s, a)}{\alpha} \right) da $$

Оптимальная политика представляет собой распределение Больцмана: $\pi^*(a \mid s) \propto \exp\left(\frac{Q^*(s, a)}{\alpha}\right)$.

В чем суть репараметризационного трюка для непрерывных действий в SAC и как корректируется логарифм вероятности при отображении через $\tanh$?

Для сквозного дифференцирования функции ценности $Q_\phi(s, a)$ по весам Актёра $\theta$ случайность выносится в независимый шум:

$$ u = \mu_\theta(s) + \sigma_\theta(s) \odot \epsilon, \qquad \epsilon \sim \mathcal{N}(0, I) $$

Для ограничения диапазона непрерывного действия интервалом $[-1, 1]$ применяется сжатие $a = \tanh(u)$.

Формула замены переменных для плотности вероятности:

$$ \log \pi(a \mid s) = \log \mu(u \mid s) - \sum_{i=1}^D \log\left| \frac{\partial \tanh(u_i)}{\partial u_i} \right| = \log \mu(u \mid s) - \sum_{i=1}^D \log\left( 1 - \tanh^2(u_i) + 10^{-6} \right) $$

где $\mu(u \mid s)$ — плотность гауссовского вектора. Это дает точный аналитический расчет энтропии сжатого действия.

Зачем в SAC применяется техника Clipped Double Q-trick и как вычисляется целевое значение $y_t$?

В SAC поддерживаются два независимых Критика $Q_{\phi_1}$ и $Q_{\phi_2}$ с целевыми сетями $\bar{\phi}_1, \bar{\phi}_2$. Целевое значение Беллмана вычисляется по минимуму из двух оценок (Clipped Double Q-trick):

$$ y_t = R(s_t, a_t) + \gamma \left( \min_{j=1,2} Q_{\bar{\phi}_j}(s_{t+1}, \tilde{a}_{t+1}) - \alpha \log \pi_\theta(\tilde{a}_{t+1} \mid s_{t+1}) \right) $$

где $\tilde{a}_{t+1} \sim \pi_\theta(\cdot \mid s_{t+1})$.

Выбор минимума $\min(Q_1, Q_2)$ формирует пессимистическую оценку полезности перехода, исключая накопление Overestimation Bias в $Q$-сетях и стабилизируя обучение непрерывного Актёра.

Зачем в лосс Актёра добавляют энтропийный член $-\beta \mathcal{H}(\pi)$?

Энтропия $\mathcal{H}(\pi)$ максимальна для равномерного случайного распределения и равна 0 для детерминированного выбора. Максимизация энтропии предотвращает преждевременный коллапс стратегии в субоптимальный детерминизм (преждевременную сходимость) и стимулирует агента постоянно исследовать (Exploration) альтернативные действия.

Как DDPG решает проблему непрерывного пространства действий?

DDPG использует детерминированную нейросеть Актёра $\mu_\theta(s)$, которая выдает непрерывный вектор действий напрямую. Для обновления весов Актёра градиент дифференцируется по цепочке прямо через нейросеть Q-Критика: $\nabla_\theta J = \nabla_a Q(s, a) \cdot \nabla_\theta \mu(s)$.

В чем различие между алгоритмами A2C и A3C (Asynchronous Advantage Actor-Critic)?

A3C (Mnih et al., 2016): несколько параллельных процессов независимо взаимодействуют со средой на CPU и асинхронно обновляют глобальные веса модели без блокировок. Не требует буфера опыта, но страдает от проблемы устаревших градиентов (Stale Gradients).

A2C (Advantage Actor-Critic — синхронный): воркеры выполняют шаги синхронно. Батчи переходов объединяются в единый тензор и обрабатываются централизованно на GPU. A2C эффективнее использует параллелизм современных видеокарт и обеспечивает лучшую стабильность сходимости.

Как в алгоритме SAC работает автоматическая подстройка температуры энтропии $\alpha$?

Температура $\alpha$ оптимизируется автоматически через метод множителей Лагранжа с ограничением на целевую минимальную энтропию $\mathcal{H}_{\text{target}} = -\dim(\mathcal{A})$:

$$ J(\alpha) = \mathbb{E}_{a_t \sim \pi_t} \left[ -\alpha \left( \log \pi_\theta(a_t \mid s_t) + \mathcal{H}_{\text{target}} \right) \right] $$

Если текущая энтропия падает ниже пороговой, лосс увеличивает $\alpha$, стимулируя исследование. Если энтропия выше целевой, $\alpha$ снижается в пользу эксплуатации выученных навыков.

📝 Микро-задачи

Задача 1. Ручной расчет Advantage в Actor-Critic

Состояние $s_t$: Критик выдал $V(s_t) = 10.0$. Агент сделал шаг, получил награду $r = 3.0$ и перешел в $s_{t+1}$ ($V(s_{t+1}) = 12.0$). Коэффициент $\gamma = 0.9$. Найдите TD-ошибку $\delta_t$ и значение Advantage.

Решение

1. TD-мишень: $y = r + \gamma V(s_{t+1}) = 3.0 + 0.9 \cdot 12.0 = 3.0 + 10.8 = 13.8$.

2. TD-ошибка / Advantage: $\delta_t = y - V(s_t) = 13.8 - 10.0 = +3.8$.

Действие оказалось на $3.8$ балла лучше среднего ожидания Критика.

Задача 2. Расчет энтропии для двух исходов

Стратегия выдает вероятности двух действий: $\pi(a_1) = 0.5, \pi(a_2) = 0.5$. Другая стратегия: $\pi(a_1) = 0.9, \pi(a_2) = 0.1$. Чему равна энтропия Шеннона $\mathcal{H} = -\sum p_i \ln p_i$ для обеих стратегий?

Решение

1. Для $[0.5, 0.5]$:

$$ \mathcal{H}_1 = -(0.5 \ln 0.5 + 0.5 \ln 0.5) = -\ln 0.5 = \ln 2 \approx 0.693 \quad (\text{Максимальная энтропия}) $$

2. Для $[0.9, 0.1]$:

$$ \mathcal{H}_2 = -(0.9 \ln 0.9 + 0.1 \ln 0.1) \approx -(0.9 \cdot (-0.105) + 0.1 \cdot (-2.302)) = 0.0945 + 0.2302 = 0.325 $$

Задача 3. Расчет GAE на 2 шагах

Последовательность TD-ошибок: $\delta_0 = 2.0, \delta_1 = 4.0$. Параметры: $\gamma = 0.9, \lambda = 0.8$. Найдите $\hat{A}_0^{\text{GAE}}$.

Решение

Формула: $\hat{A}_0 = \delta_0 + (\gamma \lambda) \delta_1$.

$$ \gamma \lambda = 0.9 \cdot 0.8 = 0.72 $$

$$ \hat{A}_0 = 2.0 + 0.72 \cdot 4.0 = 2.0 + 2.88 = 4.88 $$

Задача 4. Градиент детерминированного Актёра в DDPG

Скалярное действие $a = \mu_\theta(s) = 3.0$. Критик оценивает $Q(s, a) = -(a - 5)^2 + 10$. Производная сети Актёра по весам $\nabla_\theta \mu = 2.0$. Найдите градиент оптимизации весов $\nabla_\theta J$.

Решение

1. Производная Критика по действию в точке $a=3.0$:

$$ \frac{\partial Q}{\partial a} = -2(a - 5) = -2(3 - 5) = +4.0 $$

2. По формуле DPG:

$$ \nabla_\theta J = \frac{\partial Q}{\partial a} \cdot \nabla_\theta \mu = 4.0 \cdot 2.0 = 8.0 $$

Градиент подталкивает Актёра увеличивать выдаваемое значение $a$ в сторону оптимума $a=5$.

Задача 5. Clipped Double-Q трюк в SAC

В состоянии $s'$ при сэмплированном действии $a'$ первый Критик выдал $Q_1(s', a') = 25.0$, второй Критик — $Q_2(s', a') = 18.0$. Награда $r = 2.0$, $\gamma = 0.9$, энтропийная добавка $\alpha \mathcal{H} = 0.0$. Какое значение Q будет использовано для TD-мишени?

Решение

В SAC берется строгий минимум двух Q-сетей:

$$ Q_{\text{target}} = \min(25.0, 18.0) = 18.0 $$

TD-мишень: $y = 2.0 + 0.9 \cdot 18.0 = 2.0 + 16.2 = 18.2$.

Задача 6. Сравнение Sample Efficiency

Почему алгоритм SAC требует в 10–50 раз меньше реальных шагов в среде робота, чем алгоритм PPO?

Решение

SAC является Off-policy алгоритмом: он сохраняет весь прошлый опыт в Replay Buffer и многократно переобучает сети на старых данных. PPO является On-policy алгоритмом: он обязан собирать свежие траектории текущей стратегией и выбрасывать данные после нескольких эпох обновления, требуя постоянного сбора нового опыта.

Скелет устного ответа по билету 25 (Actor-Critic, A2C, DDPG, SAC)
  1. Value vs Policy based. Value-based (DQN) учит $Q(s, a)$ и ограничен дискретными действиями. Policy-based (REINFORCE) учит $\pi_\theta(a|s)$, умеет непрерывные действия, но страдает от высокой дисперсии.
  2. Идея Actor-Critic. Объединение двух сетей: Actor ($\pi_\theta$) выбирает действие; Critic ($V_\phi$) оценивает его через TD-ошибку $\delta_t = r + \gamma V(s') - V(s)$.
  3. Advantage и GAE. Функция преимущества $A(s, a) = Q(s, a) - V(s)$. GAE экспоненциально балансирует смещение и дисперсию параметром $\lambda \in [0, 1]$.
  4. A2C / A3C. Синхронный (GPU) и асинхронный (CPU) Advantage Actor-Critic. Лосс = Actor Loss + Critic Loss + Entropy bonus.
  5. DDPG (2015). Off-policy алгоритм для непрерывного управления. Детерминированный Актёр $\mu(s)$, градиент протекает через Q-Критика: $\nabla Q \cdot \nabla \mu$.
  6. Soft Actor-Critic (SAC, 2018). SOTA в робототехнике. Максимизирует награду плюс энтропию $\mathcal{H}(\pi)$. Исследует несколько оптимумов, устойчив к шумам, использует 2 Q-критика от overestimation bias.
