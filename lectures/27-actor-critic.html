Лекция 27. Value-based vs Policy-based подходы и архитектура Actor-Critic (A2C, GAE, SAC)

1. Интуиция и мотивация

В RL исторически выделились две полярные парадигмы:

  1. Value-Based (Q-Learning, DQN): Обучают критика $Q(s, a)$ методом TD. Эффективны по выборке, низкая дисперсия, но не работают в непрерывных пространствах действий $\mathbb{R}^k$.
  2. Policy-Based (REINFORCE): Напрямую оптимизируют параметры стратегии $\pi_\theta(a|s)$. Работают с непрерывными и стохастическими действиями, но страдают от высокой дисперсии градиента ($G_t$).
💡 Идея архитектуры Actor-Critic
  • Actor (Актор $\pi_\theta$): Выбирает действие $A_t \sim \pi_\theta(\cdot \mid S_t)$ (включая непрерывные пространства $\mathbb{R}^k$).
  • Critic (Критик $V_\phi$): Оценивает состояние $V_\phi(S_t)$ и вычисляет ошибку преимущества (Advantage), заменяя шумный доход эпизода $G_t$ компактным TD-таргетом, радикально снижая дисперсию градиента.

2. Архитектура и схема

3. Математический аппарат

1. Функция преимущества (Advantage Function $A(s, a)$)

Преимущество показывает, насколько действие $a$ лучше среднего исхода из состояния $s$:

$$ A^\pi(s, a) \doteq Q^\pi(s, a) - V^\pi(s) $$

Свойство: $\mathbb{E}_{a \sim \pi} [A^\pi(s, a)] = \sum_a \pi(a \mid s)(Q^\pi(s, a) - V^\pi(s)) = 0$.

  • $A(s, a) > 0$ — действие лучше ожидаемого (поощряется).
  • $A(s, a) < 0$ — действие хуже ожидаемого (подавляется).

2. TD-критик как оценка Advantage

Поскольку $Q^\pi(S_t, A_t) = \mathbb{E}[R_{t+1} + \gamma V^\pi(S_{t+1}) \mid S_t, A_t]$, 1-шаговая TD-ошибка аппроксимирует Advantage:

$$ \delta_t \doteq R_{t+1} + \gamma V_\phi(S_{t+1}) - V_\phi(S_t) \approx A(S_t, A_t) $$

3. Правила обновления весов в Advantage Actor-Critic (A2C)

  1. Критик ($V_\phi$): Минимизация MSE Bellman residual:
    $$ \mathcal{L}_{\text{critic}}(\phi) = \frac{1}{2} \left( R_{t+1} + \gamma V_{\phi^-}(S_{t+1}) - V_\phi(S_t) \right)^2 \implies \phi \leftarrow \phi + \alpha_\phi \, \delta_t \nabla_\phi V_\phi(S_t) $$
  2. Актор ($\pi_\theta$): Градиентный подъём с энтропийной регуляризацией $\mathcal{H}$:
    $$ \mathcal{L}_{\text{actor}}(\theta) = -\log \pi_\theta(A_t \mid S_t) \, \delta_t - \beta \mathcal{H}\left(\pi_\theta(\cdot \mid S_t)\right) $$ $$ \theta \leftarrow \theta + \alpha_\theta \left( \nabla_\theta \log \pi_\theta(A_t \mid S_t) \, \delta_t + \beta \nabla_\theta \mathcal{H}(\pi_\theta) \right) $$

4. Generalized Advantage Estimation (GAE($\gamma, \lambda$))

Экспоненциальное сглаживание TD-ошибок с параметром $\lambda \in [0, 1]$:

$$ \hat{A}_t^{\text{GAE}(\gamma, \lambda)} \doteq \sum_{l=0}^{\infty} (\gamma \lambda)^l \delta_{t+l}^V = \delta_t^V + \gamma \lambda \hat{A}_{t+1}^{\text{GAE}(\gamma, \lambda)} $$

где $\delta_{t+l}^V = R_{t+l+1} + \gamma V(S_{t+l+1}) - V(S_{t+l})$. $\lambda = 0 \implies \delta_t$ (TD(0)); $\lambda = 1 \implies G_t - V(S_t)$ (MC). Оптимум $\lambda \in [0.92, 0.98]$.

5. Soft Actor-Critic (SAC, Haarnoja et al., 2018)

SOTA-алгоритм непрерывного управления на основе Maximum Entropy RL:

$$ J(\pi) = \mathbb{E}_{\tau \sim \pi} \left[ \sum_{t=0}^\infty \gamma^t \left( R(S_t, A_t) + \alpha \mathcal{H}\left(\pi(\cdot \mid S_t)\right) \right) \right] $$

где $\alpha > 0$ — температура энтропии. SAC использует Twin Q-networks ($Q_{\phi_1}, Q_{\phi_2}$) с таргетом $\min(Q_1, Q_2)$ для защиты от переоценки.

6. Реализация Actor-Critic и GAE на PyTorch

import torch
import torch.nn as nn
import torch.nn.functional as F

class ActorCriticNet(nn.Module):
    def __init__(self, state_dim, action_dim, hidden_dim=64):
        super().__init__()
        self.actor = nn.Sequential(
            nn.Linear(state_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, action_dim)
        )
        self.critic = nn.Sequential(
            nn.Linear(state_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 1)
        )

    def forward(self, state):
        probs = F.softmax(self.actor(state), dim=-1)
        value = self.critic(state)
        return probs, value

def compute_gae_advantages(rewards, values, next_values, dones, gamma=0.99, lam=0.95):
    deltas = rewards + gamma * next_values * (1.0 - dones) - values
    advantages = torch.zeros_like(rewards)
    running_adv = 0.0
    for t in reversed(range(len(rewards))):
        running_adv = deltas[t] + gamma * lam * (1.0 - dones[t]) * running_adv
        advantages[t] = running_adv
    return advantages

4. Пошаговый числовой пример

🔢 Пример 1. Расчёт обновления Actor-Critic за 1 шаг

Переход $(S_t, A_t, R_{t+1}=+2.0, S_{t+1})$ при $\gamma = 0.9, \alpha_\phi = 0.1, \alpha_\theta = 0.05$:

  • Критик: $V_\phi(S_t) = 1.0, V_\phi(S_{t+1}) = 2.0, \nabla_\phi V = [0.5, -0.2]$.
  • Актор: $\nabla_\theta \log \pi = [1.2, 0.4]$.
  1. Таргет: $2.0 + 0.9 \cdot 2.0 = 3.8 \implies \delta_t = 3.8 - 1.0 = +2.8$.
  2. Шаг Критика: $\Delta \phi = 0.1 \cdot 2.8 \cdot [0.5, -0.2] = [0.14, -0.056]$.
  3. Шаг Актора: $\Delta \theta = 0.05 \cdot 2.8 \cdot [1.2, 0.4] = [0.168, 0.056]$.
🔢 Пример 2. Расчёт GAE ($\gamma = 0.9, \lambda = 0.8 \implies \gamma\lambda = 0.72$)

TD-ошибки: $\delta_0 = 1.0, \delta_1 = -0.5, \delta_2 = 2.0$ ($\hat{A}_3 = 0$):

  • $\hat{A}_2 = \delta_2 = 2.0$
  • $\hat{A}_1 = -0.5 + 0.72 \cdot 2.0 = 0.94$
  • $\hat{A}_0 = 1.0 + 0.72 \cdot 0.94 = 1.6768$

Шаг Actor-Critic на PyTorch

import torch

def train_actor_critic_step(model, optimizer, state, action, reward, next_state, done, gamma=0.99):
    probs, value = model(state)
    _, next_value = model(next_state)
    target = reward + gamma * (1.0 - float(done)) * next_value.item()
    advantage = target - value.item()
    
    critic_loss = (target - value) ** 2
    actor_loss = -torch.log(probs[action] + 1e-8) * advantage
    total_loss = actor_loss + 0.5 * critic_loss
    
    optimizer.zero_grad()
    total_loss.backward()
    optimizer.step()
    return total_loss.item()

6. 🎯 Препод спросит

1. Какую роль выполняет Critic в архитектуре Actor-Critic? Может ли Критик сам выбирать действия?

Критик выполняет роль оценщика: аппроксимирует $V(s)$ и вычисляет $\delta_t \approx A(S_t, A_t)$. Критик не выбирает действия; это делает Актор $\pi_\theta(a|s)$. Разделение позволяет Актору работать в непрерывных пространствах без поиска $\max$.

2. В чем разница между синхронным A2C и асинхронным A3C?

A3C асинхронно обновляет веса от нескольких параллельных потоков на CPU без блокировок. A2C синхронно собирает батч переходов со всех воркеров и делает один батчевый шаг на GPU, работая быстрее на современном оборудовании.

3. Что регулирует параметр $\lambda$ в Generalized Advantage Estimation (GAE)?

Компромисс Bias-Variance: $\lambda=0$ даёт 1-шаговый TD-критик (минимальная дисперсия, смещение от критика); $\lambda=1$ даёт Монте-Карло $G_t - V(S_t)$ (нулевое смещение, высокая дисперсия). $\lambda \approx 0.95$ оптимален.

4. Зачем в Soft Actor-Critic (SAC) введена максимизация энтропии (Maximum Entropy RL)?

Максимизация $\mathcal{H}(\pi)$ побуждает политику исследовать различные альтернативные решения, повышает робастность к шуму среды и облегчает дообучение (Transfer Learning).

5. Зачем в SAC используются две Q-сети (Twin Q-Networks)?

Для устранения Overestimation Bias: SAC берёт пессимистичный минимум $\min(Q_1(s', a'), Q_2(s', a'))$ при расчёте целевого значения критика.

6. Можно ли использовать одну общую нейросеть (Backbone) для Актора и Критика?

Да: единый бэкбон с двумя головами (политика $\pi_\theta$ и ценность $V_\phi$) оптимизируется совместным лоссом $\mathcal{L} = \mathcal{L}_{\text{policy}} + c_1 \mathcal{L}_{\text{value}} - c_2 \mathcal{H}(\pi)$.

7. В чем отличие Off-Policy Actor-Critic (DDPG, SAC) от On-Policy Actor-Critic (A2C, PPO)?

On-Policy (A2C, PPO) обучаются только на свежих данных текущей политики. Off-Policy (DDPG, SAC) используют Replay Buffer для переиспользования старых переходов, повышая Sample Efficiency.

8. Как вычисляется градиент непрерывного действия в алгоритме DDPG (Deep Deterministic Policy Gradient)?

По теореме детерминированного градиента: $\nabla_\theta J(\theta) = \mathbb{E}[\nabla_a Q_\phi(s, a)|_{a=\mu_\theta(s)} \cdot \nabla_\theta \mu_\theta(s)]$, дифференцируя $Q$ по действиям.

9. Что такое Reparameterization Trick в SAC для стохастического актора?

Действие дифференцируется через вспомогательный шум: $a = \tanh(\mu_\theta(s) + \sigma_\theta(s) \odot \epsilon)$, $\epsilon \sim \mathcal{N}(0, I)$, позволяя градиенту $\nabla_a Q$ протекать в веса $\theta$ через Autograd.

10. Почему именно Actor-Critic стал доминирующей парадигмой современного Deep RL?

Он совмещает поддержку непрерывных действий, низкую дисперсию градиентов за счёт бутстрэпинга критика и масштабируемость на глубокие нейросети (PPO/SAC в робототехнике и RLHF).

7. 📝 Микро-задачи с решениями

Задача 1. Расчёт скалярного Advantage

$Q(s, a) = 8.4, V(s) = 6.0$. Чему равен Advantage $A(s, a)$ и как изменится вероятность действия?

Решение
$$ A(s, a) = Q(s, a) - V(s) = 8.4 - 6.0 = +2.4 $$

Так как $A > 0$, действие лучше среднего, его вероятность увеличится.

Ответ: $A(s, a) = +2.4$, вероятность увеличится.

Задача 2. Расчёт TD-ошибки Критика с терминальным флагом

$R_{t+1} = 10.0, done = 1, V(S_t) = 4.0, V(S_{t+1}) = 15.0, \gamma = 0.99$. Чему равна TD-ошибка $\delta_t$?

Решение

Таргет: $y = 10.0 + 0.99 \cdot (1 - 1) \cdot 15.0 = 10.0$. Ошибка: $\delta_t = 10.0 - 4.0 = +6.0$.

Ответ: $\delta_t = +6.0$.

Задача 3. Расчёт GAE($\lambda=0$) vs GAE($\lambda=1$)

$\delta_0 = 2.0, \delta_1 = 4.0, \gamma = 0.5$. Найдите $\hat{A}_0$ при $\lambda = 0$ и $\lambda = 1$.

Решение

$\lambda = 0 \implies \hat{A}_0 = \delta_0 = 2.0$. $\lambda = 1 \implies \hat{A}_0 = 2.0 + 0.5 \cdot 4.0 = 4.0$.

Ответ: $\lambda=0 \implies 2.0; \quad \lambda=1 \implies 4.0$.

Задача 4. Maximum Entropy целевая функция в SAC

$\pi = [0.5, 0.5], R = 5.0, \alpha = 2.0$. Найдите $R_{\text{soft}} = R + \alpha \mathcal{H}(\pi)$ ($\ln 2 \approx 0.6931$).

Решение

$\mathcal{H}(\pi) = -\sum 0.5 \ln 0.5 = \ln 2 \approx 0.6931$. $R_{\text{soft}} = 5.0 + 2.0 \cdot 0.6931 = 6.3862$.

Ответ: $R_{\text{soft}} \approx 6.3862$.

Задача 5. Twin Q-Networks консервативный таргет в SAC

$Q_1(s', a') = 14.5, Q_2(s', a') = 11.2, R = 3.0, \gamma = 0.9$. Чему равен таргет $y = R + \gamma \min(Q_1, Q_2)$?

Решение
$$ y = 3.0 + 0.9 \cdot \min(14.5, 11.2) = 3.0 + 0.9 \cdot 11.2 = 3.0 + 10.08 = 13.08 $$

Ответ: $y = 13.08$.

Задача 6. Совокупная функция потерь Actor-Critic с регуляризацией энтропией

$\mathcal{L}_{\text{policy}} = -1.5, \mathcal{L}_{\text{value}} = 0.8, \mathcal{H} = 0.4, c_1 = 0.5, c_2 = 0.01$. Найдите $\mathcal{L} = \mathcal{L}_{\text{policy}} + c_1 \mathcal{L}_{\text{value}} - c_2 \mathcal{H}$.

Решение
$$ \mathcal{L} = -1.5 + 0.5 \cdot 0.8 - 0.01 \cdot 0.4 = -1.5 + 0.4 - 0.004 = -1.104 $$

Ответ: $\mathcal{L} = -1.104$.

8. ⚡ Скелет ответа по билету

Скелет ответа по билету 25 (Value-based vs Policy-based, Actor-Critic)
  1. Сравнение парадигм: Value-based (DQN) оценивает $Q(s, a)$ и берёт $\max$ (только дискретные действия); Policy-based (REINFORCE) параметризует $\pi_\theta(a|s)$ (непрерывные действия, высокая дисперсия).
  2. Архитектура Actor-Critic: Актор $\pi_\theta(a|s)$ выбирает действия; Критик $V_\phi(s)$ оценивает их через TD-ошибку $\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t) \approx A(S_t, A_t)$, снижая дисперсию.
  3. Advantage Function: $A(s, a) = Q(s, a) - V(s)$. Показывает превосходство действия над средним исходом ($\mathbb{E}_\pi[A] = 0$).
  4. Обновление A2C: Критик: $\min_\phi (R + \gamma V(S') - V_\phi(S))^2$; Актор: $\theta \leftarrow \theta + \alpha \nabla_\theta \log \pi_\theta(A|S) \delta_t + \beta \nabla_\theta \mathcal{H}(\pi)$.
  5. GAE($\gamma, \lambda$): Экспоненциальное сглаживание $\hat{A}_t^{\text{GAE}} = \sum (\gamma \lambda)^l \delta_{t+l}$. $\lambda$ балансирует смещение ($\lambda=0$) и дисперсию ($\lambda=1$).
  6. Soft Actor-Critic (SAC): Maximum Entropy RL: $\max \mathbb{E}[R + \alpha \mathcal{H}(\pi)]$. Twin Q-сети $\min(Q_1, Q_2)$ и репараметризация стохастического актора.
  7. Применение: SOTA-стандарт для робототехники, беспилотных систем и выравнивания языковых моделей (RLHF/PPO).
