1. Интуиция и мотивация

Полносвязные (FCNN) и свёрточные сети предполагают входы фиксированной размерности и свойство $i.i.d.$ Однако реальные данные (текст, аудио, временные ряды) обладают временной структурой и переменной длиной.

Барьеры применения FCNN к последовательностям:

  1. Переменная длина ($T$): размер входа в FCNN жёстко зафиксирован матрицей $W \in \mathbb{R}^{d_{\text{in}} \times d_{\text{hidden}}}$.
  2. Отсутствие разделения весов во времени (Weight Sharing): FCNN вынуждена обучать независимые веса для каждого временного шага.
  3. Отсутствие контекстной памяти: отклик на шаге $t$ не зависит от шагов $1, \dots, t-1$.
💡 Ключевая идея рекуррентности

Рекуррентная сеть (RNN) обрабатывает $(x_1, \dots, x_T)$ пошагово во времени, обновляя скрытое состояние (Hidden State, $h_t$). Один и тот же набор матриц весов переиспользуется на всех шагах, делая число параметров независимым от $T$.

2. Архитектура и схема

Ячейка принимает $x_t$ и $h_{t-1}$, вычисляя $h_t$ и $y_t$. Развёртка во времени (unrolling) превращает цикл в эквивалентную глубокую сеть с разделяемыми весами:

КОМПАКТНЫЙ ЦИКЛ: РАЗВЕРТКА ПО ВРЕМЕНИ (UNROLLING): y_t y_1 y_2 y_3 y_T ▲ ▲ ▲ ▲ ▲ │ │ │ │ │ ┌──┴──┐ ┌────┴────┐ ┌────┴────┐ ┌────┴────┐ ┌────┴────┐ x_t ─┤ RNN ├─┐ h_t h_0─┤ RNN_1 ├─h_1┤ RNN_2 ├─h_2┤ RNN_3 ├─...─h_{T-1}┤ RNN_T ├─▶ h_T └──┬──┘ │ └────▲────┘ └────▲────┘ └────▲────┘ └────▲────┘ └────┘ │ │ │ │ x_1 x_2 x_3 x_T Развёртка RNN во времени: матрицы $(W_{xh}, W_{hh}, W_{hy})$ переиспользуются на всех $T$ шагах.

Анатомия ячейки LSTM

Для устранения затухания градиента LSTM (Hochreiter & Schmidhuber, 1997) разделяет память на Cell State ($C_t$) — долговременную магистраль («конвейер константной ошибки»), и Hidden State ($h_t$) — кратковременное состояние, управляемое тремя гейтами:

УСТРОЙСТВО ЯЧЕЙКИ LSTM: C_{t-1} ──────────────────[ ⊗ ]─────────────────[ ⊕ ]─────────────────────────▶ C_t ▲ ▲ │ │ Forget │ Input │ ~C_t (Кандидат) Gate f_t │ Gate i_t │ │ │ │ │ h_{t-1} ─┬──────────────[ σ ]─────────[ σ ]────[ ⊗ ]───[ tanh ]───[ ⊗ ]───────▶ h_t │ ▲ ▲ ▲ ▲ │ │ │ │ Output │ x_t ─────┴─────────────────┴─────────────┴───────┴─────── Gate o_t─[ σ ] Гейты LSTM: Forget Gate $f_t$ (стирание памяти), Input Gate $i_t$ (запись кандидата), Output Gate $o_t$ (выдача в скрытое состояние).

biLSTM и GRU

biLSTM объединяет прямой $\overrightarrow{h}_t$ и обратный $\overleftarrow{h}_t$ слои: $h_t = [\overrightarrow{h}_t; \overleftarrow{h}_t]$. Применяется при анализе готового контекста (NER, POS, классификация).

GRU (Cho et al., 2014) объединяет $C_t$ и $h_t$, используя 2 гейта: Update Gate ($z_t$) и Reset Gate ($r_t$). Это экономит 25% параметров при сопоставимом качестве.

3. Математический аппарат

1. Базовая модель Vanilla RNN (Elman RNN)

Прямой проход на шаге $t \in \{1, \dots, T\}$:

$$ h_t = \tanh\left( W_{hh} h_{t-1} + W_{xh} x_t + b_h \right), \quad y_t = W_{hy} h_t + b_y $$
  • $x_t \in \mathbb{R}^{d_{\text{in}}}$, $h_t \in \mathbb{R}^{d_{\text{hidden}}}$, $y_t \in \mathbb{R}^{d_{\text{out}}}$.
  • $W_{xh} \in \mathbb{R}^{d_{\text{hidden}} \times d_{\text{in}}}$, $W_{hh} \in \mathbb{R}^{d_{\text{hidden}} \times d_{\text{hidden}}}$, $W_{hy} \in \mathbb{R}^{d_{\text{out}} \times d_{\text{hidden}}}$.
  • $b_h \in \mathbb{R}^{d_{\text{hidden}}}$, $b_y \in \mathbb{R}^{d_{\text{out}}}$.

2. BPTT и вывод затухания/взрыва градиентов

Ошибка последовательности: $\mathcal{L} = \sum_{t=1}^T \mathcal{L}_t(y_t, \hat{y}_t)$. Градиент ошибки по $W_{hh}$:

$$ \frac{\partial \mathcal{L}_T}{\partial W_{hh}} = \sum_{k=1}^T \frac{\partial \mathcal{L}_T}{\partial h_T} \cdot \frac{\partial h_T}{\partial h_k} \cdot \frac{\partial h_k}{\partial W_{hh}} $$

Якобиан перехода $\frac{\partial h_T}{\partial h_k}$ через произведение по промежуточным шагам:

$$ \frac{\partial h_T}{\partial h_k} = \prod_{j=k+1}^T \frac{\partial h_j}{\partial h_{j-1}} = \prod_{j=k+1}^T \text{diag}\left(1 - \tanh^2(z_j)\right) W_{hh}^T $$
⚠️ Анализ нормы градиента

Так как $|\tanh'(z)| \le 1$, оценка нормы сверху:

$$ \left\| \frac{\partial h_T}{\partial h_k} \right\| \le \prod_{j=k+1}^T \|W_{hh}\|_2 \le \left( \lambda_{\max}(W_{hh}) \right)^{T-k} $$
  • При $\lambda_{\max}(W_{hh}) < 1$: экспоненциальное затухание градиента (Vanishing Gradient) — сеть теряет долгосрочные связи.
  • При $\lambda_{\max}(W_{hh}) > 1$: экспоненциальный взрыв градиента (Exploding Gradient) — параметры уходят в NaN. Лечится клиппингом: $g \leftarrow g \cdot \min\left(1, \frac{C}{\|g\|_2}\right)$.

3. Канонические уравнения LSTM

На каждом шаге $t$ вычисляются 4 вентильные проекции и обновление состояния:

$$ \begin{aligned} f_t &= \sigma\left( W_{xf} x_t + W_{hf} h_{t-1} + b_f \right) && \text{Forget Gate (стирание старой памяти } C_{t-1}\text{)} \\ i_t &= \sigma\left( W_{xi} x_t + W_{hi} h_{t-1} + b_i \right) && \text{Input Gate (запись нового кандидата } \tilde{C}_t\text{)} \\ \tilde{C}_t &= \tanh\left( W_{xc} x_t + W_{hc} h_{t-1} + b_c \right) && \text{Candidate State (вектор признаков)} \\ C_t &= f_t \odot C_{t-1} + i_t \odot \tilde{C}_t && \text{Cell State (линейное накопление памяти)} \\ o_t &= \sigma\left( W_{xo} x_t + W_{ho} h_{t-1} + b_o \right) && \text{Output Gate (фильтр скрытого состояния)} \\ h_t &= o_t \odot \tanh(C_t) && \text{Hidden State (выход ячейки)} \end{aligned} $$

где $\sigma(z) = \frac{1}{1 + e^{-z}}$, $\odot$ — умножение Адамара.

💡 Constant Error Carousel

Частная производная ячейки: $\frac{\partial C_t}{\partial C_{t-1}} = f_t$. Градиент ошибки: $\frac{\partial \mathcal{L}}{\partial C_k} = \frac{\partial \mathcal{L}}{\partial C_T} \prod_{j=k+1}^T f_j$. При $f_j \approx 1$ градиент передаётся без затухания и матричных перемножений.

4. Уравнения biLSTM и GRU

biLSTM: $\overrightarrow{h}_t = \text{LSTM}_{\text{fwd}}(x_t, \overrightarrow{h}_{t-1})$, $\overleftarrow{h}_t = \text{LSTM}_{\text{bwd}}(x_t, \overleftarrow{h}_{t+1})$, $h_t = \left[ \overrightarrow{h}_t; \, \overleftarrow{h}_t \right] \in \mathbb{R}^{2 d_{\text{hidden}}}$.

GRU:

$$ \begin{aligned} z_t &= \sigma\left( W_{xz} x_t + W_{hz} h_{t-1} + b_z \right) && \text{Update Gate} \\ r_t &= \sigma\left( W_{xr} x_t + W_{hr} h_{t-1} + b_r \right) && \text{Reset Gate} \\ \tilde{h}_t &= \tanh\left( W_{xh} x_t + W_{hh} (r_t \odot h_{t-1}) + b_h \right) && \text{Кандидат состояния} \\ h_t &= (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t && \text{Выпуклая интерполяция} \end{aligned} $$

4. Пошаговый числовой пример

Один шаг 1D-ячейки LSTM ($d_{\text{in}}=1, d_{\text{hidden}}=1$):

Вход: $x_t = 1.0, h_{t-1} = 0.5, C_{t-1} = 2.0$.

Параметры:

  • Forget: $W_{xf} = 0.5, W_{hf} = 0.2, b_f = 0.5$
  • Input: $W_{xi} = 0.8, W_{hi} = -0.4, b_i = 0.0$
  • Candidate: $W_{xc} = -0.5, W_{hc} = 1.0, b_c = 0.0$
  • Output: $W_{xo} = 0.1, W_{ho} = 0.6, b_o = 0.2$

Расчёт:

  1. $z_f = 0.5(1.0) + 0.2(0.5) + 0.5 = 1.1 \implies f_t = \sigma(1.1) \approx \mathbf{0.7503}$.
  2. $z_i = 0.8(1.0) - 0.4(0.5) + 0.0 = 0.6 \implies i_t = \sigma(0.6) \approx \mathbf{0.6457}$.
  3. $z_c = -0.5(1.0) + 1.0(0.5) + 0.0 = 0.0 \implies \tilde{C}_t = \tanh(0.0) = \mathbf{0.0}$.
  4. $C_t = f_t C_{t-1} + i_t \tilde{C}_t = 0.7503(2.0) + 0.6457(0.0) = \mathbf{1.5006}$.
  5. $z_o = 0.1(1.0) + 0.6(0.5) + 0.2 = 0.6 \implies o_t = \sigma(0.6) \approx \mathbf{0.6457}$.
  6. $h_t = o_t \tanh(C_t) = 0.6457 \cdot \tanh(1.5006) \approx 0.6457 \cdot 0.9052 = \mathbf{0.5845}$.

Реализация ячейки LSTM на PyTorch

import torch
import torch.nn as nn

class CustomLSTMCell(nn.Module):
    def __init__(self, input_dim: int, hidden_dim: int):
        super().__init__()
        self.input_dim = input_dim
        self.hidden_dim = hidden_dim
        self.ih = nn.Linear(input_dim, 4 * hidden_dim)
        self.hh = nn.Linear(hidden_dim, 4 * hidden_dim)

    def forward(self, x: torch.Tensor, state: tuple[torch.Tensor, torch.Tensor]) -> tuple[torch.Tensor, torch.Tensor]:
        h_prev, c_prev = state
        gates = self.ih(x) + self.hh(h_prev)
        f, i, c_tilde, o = gates.chunk(4, dim=-1)
        
        f_gate = torch.sigmoid(f)
        i_gate = torch.sigmoid(i)
        c_cand = torch.tanh(c_tilde)
        o_gate = torch.sigmoid(o)
        
        c_next = f_gate * c_prev + i_gate * c_cand
        h_next = o_gate * torch.tanh(c_next)
        return h_next, c_next

6. 🎯 Препод спросит

В чём математическая причина отсутствия затухания градиента в LSTM?

Обновление $C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$ аддитивно: $\frac{\partial C_t}{\partial C_{t-1}} = f_t$. При $f_t \approx 1$ градиент $\frac{\partial \mathcal{L}}{\partial C_0} = \frac{\partial \mathcal{L}}{\partial C_T} \prod_{t=1}^T f_t \approx \frac{\partial \mathcal{L}}{\partial C_T} \cdot 1^T$ распространяется назад без затухания и матричных перемножений (Constant Error Carousel).

Сколько обучаемых параметров в одном слое LSTM по сравнению с обычной RNN?

В обычной RNN: 1 пара $(W_{xh}, W_{hh})$ и вектор $b_h$. В LSTM — 4 независимых гейта ($f_t, i_t, \tilde{C}_t, o_t$). Параметров в 4 раза больше: $4 \times (d_{\text{in}} d_{\text{hidden}} + d_{\text{hidden}}^2 + d_{\text{hidden}})$.

Зачем в гейтах LSTM используется сигмоида $\sigma$, а при создании кандидата $\tilde{C}_t$ — $\tanh$?

Сигмоида ($\sigma \in [0, 1]$): мягкий бинарный вентиль ($0$ — закрыт, $1$ — открыт).
Тангенс ($\tanh \in [-1, 1]$): создаёт центрированные относительно нуля значения, позволяя и увеличивать, и уменьшать память $C_t$ без накопления смещения.

Что такое Teacher Forcing и к какой проблеме на инференсе (Exposure Bias) он приводит?

Teacher Forcing — подача эталонного $y_{t-1}^{\text{true}}$ вместо предсказанного $\hat{y}_{t-1}$ на вход декодера при обучении. Exposure Bias: на инференсе подсказок нет, и первая же ошибка уводит модель в не встречавшееся состояние (накопление ошибок). Лечение: Scheduled Sampling.

В чём главное отличие GRU от LSTM?

1. В GRU 2 гейта (Update $z_t$, Reset $r_t$) вместо 3 в LSTM.
2. Нет отдельного $C_t$: состояние $h_t$ объединяет долговременную и рабочую память.
3. На 25% меньше параметров при сопоставимом качестве.

Можно ли распараллелить вычисления в RNN по времени при обучении?

Нет. Для вычисления $h_t$ строго необходимо готовое $h_{t-1}$. Временная сложность — $O(T)$ последовательных шагов на GPU. Это ограничение стимулировало создание Transformer.

Зачем смещение Forget Gate инициализируют единицей ($b_f = 1.0$)?

При $b_f = 0$ имеем $\sigma(0) = 0.5$, и память затухает за 10 шагов ($0.5^{10} \approx 0.001$). Инициализация $b_f = 1.0$ даёт $\sigma(1) \approx 0.73$, заставляя сеть по умолчанию помнить всю историю в начале обучения.

Почему biLSTM нельзя использовать для авторегрессионной генерации текста?

В biLSTM обратный слой $\overleftarrow{h}_t$ идёт от $T$ к $1$. При генерации будущих токенов ещё не существует, поэтому вычислить $\overleftarrow{h}_t$ невозможно. biLSTM применима только к готовым текстам.

Как устроен PackedSequence в PyTorch и почему он ускоряет обучение?

Padding батча нулями тратит FLOPs и искажает скрытые состояния через bias. pack_padded_sequence сжимает батч в 1D-массив реальных токенов с массивом batch_sizes, исключая холостые операции на нулях.

Как работает Gradient Clipping по норме (torch.nn.utils.clip_grad_norm_)?

Вычисляется $\|g\|_2 = \sqrt{\sum_i \|g_i\|_2^2}$. Если $\|g\|_2 > C$, градиенты масштабируются: $g \leftarrow g \cdot \frac{C}{\|g\|_2}$. Это ограничивает шаг обновления, сохраняя точное направление антиградиента и предотвращая взрыв параметров.

7. 📝 Микро-задачи с решениями

Задача 1. Подсчёт параметров слоя LSTM

Слой `nn.LSTM(input_size=100, hidden_size=256, bias=True)`. Сколько обучаемых параметров содержит этот слой в PyTorch?

Решение

Для каждого из 4 гейтов ($f, i, \tilde{C}, o$):

  • $W_{xh}$: $100 \times 256 = 25\,600$.
  • $W_{hh}$: $256 \times 256 = 65\,536$.
  • Смещения: $256 + 256 = 512$ (раздельные $b_{ih}$ и $b_{hh}$).
  • На один гейт: $25\,600 + 65\,536 + 512 = 91\,648$.

Итого для 4 гейтов: $\text{Параметры} = 4 \times 91\,648 = \mathbf{366\,592}$.

Задача 2. Сравнение числа параметров GRU и LSTM

Сравните количество обучаемых параметров для слоёв `nn.GRU(100, 256)` и `nn.LSTM(100, 256)`.

Решение

В GRU 3 группы гейтов ($z, r, \tilde{h}$) вместо 4 в LSTM:

$$ \text{Параметры GRU} = 3 \times (100 \times 256 + 256 \times 256 + 512) = 3 \times 91\,648 = \mathbf{274\,944} $$

Экономия параметров: $\frac{366\,592 - 274\,944}{366\,592} = \frac{91\,648}{366\,592} = 0.25 \implies \mathbf{25\%}$.

Задача 3. Ручной расчёт обновления ячейки памяти $C_t$

Пусть $C_{t-1} = [2.0, -1.0]$. Гейты выдали: $f_t = [0.9, 0.1]$, $i_t = [0.5, 0.8]$, $\tilde{C}_t = [1.0, 2.0]$. Вычислите $C_t$.

Решение

Формула $C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$:

  • 1-я компонента: $0.9(2.0) + 0.5(1.0) = 1.8 + 0.5 = \mathbf{2.3}$.
  • 2-я компонента: $0.1(-1.0) + 0.8(2.0) = -0.1 + 1.6 = \mathbf{1.5}$.

Ответ: $C_t = [2.3, \, 1.5]$.

Задача 4. Размерности тензоров в biLSTM

Батч $B=32$, длина $T=50$, $d_{\text{in}}=300$. Слой `nn.LSTM(300, 128, bidirectional=True, batch_first=True)`. Каковы формы выходных тензоров `output` и `h_n`?

Решение

1. `output`: скрытые состояния всех $T$ шагов (прямое + обратное): $\text{shape} = (B, T, 2 d_{\text{hidden}}) = \mathbf{(32, 50, 256)}$.
2. `h_n`: состояния финального шага по направлениям: $\text{shape} = (\text{num\_directions}, B, d_{\text{hidden}}) = \mathbf{(2, 32, 128)}$.

Задача 5. Расчёт градиентного клиппинга

Норма градиентов $\|g\|_2 = 10.0$. Порог клиппинга $C = 2.0$. Какой множитель будет применён к градиентам и чему равна новая норма?

Решение

Так как $\|g\|_2 = 10.0 > C = 2.0$, множитель равен $\alpha = \frac{C}{\|g\|_2} = \frac{2.0}{10.0} = \mathbf{0.2}$.
Новый градиент: $g_{\text{new}} = 0.2 \cdot g$. Новая норма: $\|g_{\text{new}}\|_2 = 0.2 \times 10.0 = \mathbf{2.0}$.

Задача 6. Бутылочное горлышко Seq2Seq

Входная фраза содержит 100 слов. Скрытое состояние энкодера $d_{\text{hidden}} = 256$. В чём дефект сжатия фразы в один вектор $h_{100}$?

Решение

Information Bottleneck: упаковка 100 слов в 256 чисел приводит к потере контекста (особенно начальных токенов) из-за компрессии. Это ограничение привело к разработке механизма внимания (Attention).

8. ⚡ Скелет ответа по билету

Скелет ответа по билету 13 (Рекуррентные сети, LSTM, biLSTM)
  1. Мотивация: переменная длина $T$, разделение весов во времени (weight sharing), пошаговая память $h_t$.
  2. Vanilla RNN: $h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b_h)$. Развёртка во времени эквивалентна глубокой сети длины $T$.
  3. BPTT и затухание градиента: множитель $\prod \text{diag}(1-\tanh^2) W_{hh}^T$. При $\lambda_{\max} < 1$ градиент затухает, при $\lambda > 1$ взрывается (лечится клиппингом).
  4. Архитектура LSTM: Cell State $C_t$ (долговременный канал) и Hidden State $h_t$ (кратковременный выход).
  5. 3 гейта LSTM: Forget $f_t = \sigma(\cdot)$, Input $i_t = \sigma(\cdot)$, Output $o_t = \sigma(\cdot)$.
  6. Математика памяти: $C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$, $h_t = o_t \odot \tanh(C_t)$. Аддитивность даёт $\frac{\partial C_t}{\partial C_{t-1}} = f_t \approx 1$ (Constant Error Carousel).
  7. biLSTM: конкатенация прямого $\overrightarrow{h}_t$ и обратного $\overleftarrow{h}_t$. Даёт полный контекст; запрещена для авторегрессии.
  8. GRU: 2 гейта ($z_t$ update, $r_t$ reset), объединение $C_t$ и $h_t$, на 25% меньше весов.
  9. Режимы работы: Many-to-One (классификация/регрессия), Many-to-Many синхронный (NER, POS), Seq2Seq (перевод).
  10. Teacher Forcing: подача истинного $y_{t-1}$ при обучении. Ускоряет сходимость, но порождает Exposure Bias на инференсе.
