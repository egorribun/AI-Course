1. Интуиция и мотивация

Машинное обучение (ML) — индуктивный поиск параметров решающей функции $f_\theta(x)$ по обучающей выборке примеров $\{(x_i, y_i)\}$ вместо ручного программирования правил.

💡 Триада машинного и глубокого обучения
  • 1. Архитектура ($f_\theta$): класс функций (линейная модель, MLP, свёрточная сеть, трансформер).
  • 2. Функция потерь ($\mathcal{L}(\theta)$): скалярная мера ошибки предсказания $\hat{y} = f_\theta(x)$ относительно $y$ (MSE, Cross-Entropy).
  • 3. Оптимизатор: численный алгоритм $\theta^* = \arg\min_\theta \mathcal{L}(\theta)$ (SGD, Momentum, AdamW).

3. Математический аппарат

3.1 Градиентный спуск (Gradient Descent)

Для дифференцируемой функции потерь $\mathcal{L}(\theta) = \frac{1}{N}\sum_{i=1}^N \ell(f_\theta(x_i), y_i)$ вектор антиградиента $-\nabla_\theta \mathcal{L}(\theta)$ задаёт направление наискорейшего спуска:

$$ \nabla_\theta \mathcal{L}(\theta) = \left[ \frac{\partial \mathcal{L}}{\partial \theta_1}, \dots, \frac{\partial \mathcal{L}}{\partial \theta_P} \right]^\top, \qquad \theta_{t+1} = \theta_t - \eta \, \nabla_\theta \mathcal{L}(\theta_t) $$

3.2 Метрики качества классификации

Истина \ Прогноз$\hat{y} = 1$ (Positive)$\hat{y} = 0$ (Negative)
$y = 1$$\text{TP}$ (True Positive)$\text{FN}$ (Ложноотрицательный, II род)
$y = 0$$\text{FP}$ (Ложноположительный, I род)$\text{TN}$ (True Negative)
$$ \text{Accuracy} = \frac{\text{TP} + \text{TN}}{\text{TP} + \text{TN} + \text{FP} + \text{FN}}, \quad \text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}}, \quad \text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}} $$
$$ F_1 = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}} = \frac{2\text{TP}}{2\text{TP} + \text{FP} + \text{FN}} $$

3.3 Метрики качества регрессии

$$ \text{MSE} = \frac{1}{N}\sum_{i=1}^N (y_i - \hat{y}_i)^2, \quad \text{MAE} = \frac{1}{N}\sum_{i=1}^N |y_i - \hat{y}_i|, \quad R^2 = 1 - \frac{\sum_{i=1}^N (y_i - \hat{y}_i)^2}{\sum_{i=1}^N (y_i - \bar{y})^2} $$

3.4 Разложение ошибки: Bias-Variance Tradeoff

Для $y = f(x) + \epsilon$ с шумом $\mathbb{E}[\epsilon]=0, \mathbb{D}[\epsilon]=\sigma^2$ ожидаемая квадратичная ошибка модели $\hat{f}(x)$ строго равна:

$$ \mathbb{E}_\mathcal{D}\left[ (y - \hat{f}(x))^2 \right] = \underbrace{\left(\mathbb{E}_\mathcal{D}[\hat{f}(x)] - f(x)\right)^2}_{\text{Bias}^2 \text{ (смещение)}} + \underbrace{\mathbb{E}_\mathcal{D}\left[(\hat{f}(x) - \mathbb{E}_\mathcal{D}[\hat{f}(x)])^2\right]}_{\text{Variance (дисперсия)}} + \underbrace{\sigma^2}_{\text{шум}} $$
  • $\text{Bias}^2$: ошибка недообучения (Underfitting) из-за малой ёмкости модели.
  • $\text{Variance}$: ошибка переобучения (Overfitting) из-за чувствительности к выборке.
  • $\sigma^2$: неустранимый шум (теоретический нижний предел ошибки).

4. Пошаговый числовой пример

Шаг градиентного спуска для $\hat{y} = w x + b$ ($w_0 = 0.5, b_0 = 0.0, \eta = 0.1$) при MSE-потерях на 2 объектах:

$i$$x_i$$y_i$$\hat{y}_i = 0.5 x_i + 0$Ошибка $e_i = \hat{y}_i - y_i$
11.02.00.5$-1.5$
22.04.01.0$-3.0$

1. Градиенты $\mathcal{L}(w, b) = \frac{1}{2}\sum_{i=1}^2 (\hat{y}_i - y_i)^2$:

$$ \frac{\partial \mathcal{L}}{\partial w} = \frac{1}{2}(2(-1.5)(1.0) + 2(-3.0)(2.0)) = -7.5, \quad \frac{\partial \mathcal{L}}{\partial b} = \frac{1}{2}(2(-1.5) + 2(-3.0)) = -4.5 $$

2. Обновление:

$$ w_1 = 0.5 - 0.1 \cdot (-7.5) = 1.25, \qquad b_1 = 0.0 - 0.1 \cdot (-4.5) = 0.45 $$

6. 🎯 Препод спросит

В чём математический смысл разложения ошибки на Bias, Variance и неустранимый шум?

$\mathbb{E}[(y - \hat{f})^2] = \text{Bias}^2 + \text{Variance} + \sigma^2$. $\text{Bias}$ измеряет ошибку аппроксимации (недообучение). $\text{Variance}$ отражает разброс предсказаний при смене обучающей выборки (переобучение). $\sigma^2$ — стохастический шум данных. Усложнение модели снижает $\text{Bias}$, но растит $\text{Variance}$.

Почему Accuracy бесполезна при сильном дисбалансе классов (например, 99% к 1%)?

При дисбалансе 99:1 тривиальный константный классификатор ($\hat{y} \equiv 0$) получает $\text{Accuracy} = 99\%$, но имеет $\text{Recall} = 0\%$ по целевому классу. Информативны $\text{Precision}$, $\text{Recall}$, $F_1$-score и $\text{PR-AUC}$.

В чём разница между Validation и Test выборками? Почему нельзя выбирать гиперпараметры по Test?

Validation служит для подбора гиперпараметров и ранней остановки (подвержена косвенной подгонке). Test используется строго один раз для финальной несмещённой оценки обобщающей способности. Тюнинг по Test разрушает независимость контроля.

Что такое утечка данных (Data Leakage) и как она возникает при нормализации признаков?

Data Leakage — попадание информации из валидации/теста в обучение. Пример: расчёт $\mu$ и $\sigma$ на всей выборке до сплита. Корректный протокол: $\mu_{\text{train}}, \sigma_{\text{train}}$ считаются строго на Train и применяются к Val/Test.

Как связаны понятия «эпоха», «батч» и «итерация» при $N=10\,000$ и batch_size $=64$?

Эпоха — 1 проход по $N$ объектам. Батч ($B$) — подвыборка за 1 forward/backward. Итерация — 1 шаг обновления весов $\theta$. Число итераций за эпоху: $K = \lceil N / B \rceil = \lceil 10\,000 / 64 \rceil = 157$.

Почему слишком большой learning rate приводит к расходимости, а слишком малый — к застреванию?

При $\eta > \frac{2}{\lambda_{\max}(H)}$ шаг выходит за область локальной квадратичной аппроксимации, вызывая расходящиеся осцилляции. При малом $\eta$ шаг ничтожен, сходимость резко замедляется и модель застревает на плато.

Чем L1-регуляризация принципиально отличается от L2 по структуре весов (разреженность vs сжатие)?

Градиент $L_2$ равен $\lambda w$ (веса плавно убывают, но не зануляются). Субградиент $L_1$ равен $\lambda \cdot \text{sign}(w) = \text{const}$ (вес уменьшается с постоянной скоростью, приводя к точному занулению параметров — разреженности).

Почему ROC-AUC может быть обманчиво оптимистичным при дисбалансе и когда предпочтительнее PR-AUC?

$\text{FPR} = \frac{\text{FP}}{\text{FP} + \text{TN}}$. При $\text{TN} \gg \text{FP}$ рост $\text{FP}$ почти не меняет $\text{FPR}$, завышая ROC-AUC. В $\text{PR-AUC}$ метрика $\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}}$ прямо реагирует на $\text{FP}$, объективно оценивая миноритарный класс.

В чём разница между параметрами и гиперпараметрами модели? Приведите по 3 примера каждого.

Параметры вычисляет оптимизатор по данным (веса $W$, смещения $b$, ядра свёрток $K$). Гиперпараметры задаёт инженер до обучения (темп обучения $\eta$, размер батча $B$, вес регуляризации $\lambda$).

Что такое Early Stopping и почему это эффективная форма регуляризации?

Early Stopping — остановка обучения при прекращении снижения $\mathcal{L}_{\text{val}}$ в течение $P$ эпох. Метод ограничивает длину траектории спуска в пространстве параметров, предотвращая оверфиттинг на шум Train.

7. 📝 Микро-задачи с решениями

Задача 1. Train/val/test split

Датасет содержит 5000 образцов. Разделите выборку на Train, Validation и Test в пропорции 60% / 20% / 20%.

Решение

Train: $5000 \times 0.60 = 3000$ объектов.

Validation: $5000 \times 0.20 = 1000$ объектов.

Test: $5000 \times 0.20 = 1000$ объектов.

Контроль: $3000 + 1000 + 1000 = 5000$ ✓.

Задача 2. Расчёт числа итераций и эпох

Выборка $N = 8000$, батч $B = 32$, эпох $E = 50$. Найдите число итераций за эпоху и суммарно шагов.

Решение

1. Итераций за эпоху: $K = \dfrac{N}{B} = \dfrac{8000}{32} = 250$.

2. Суммарно шагов: $N_{\text{total}} = 250 \times 50 = 12\,500$.

Задача 3. Расчёт метрик по Confusion Matrix

Дано: $\text{TP} = 40, \text{FP} = 5, \text{FN} = 10, \text{TN} = 45$. Вычислите Accuracy, Precision, Recall и F1-score.

Решение

$\text{Accuracy} = \dfrac{40 + 45}{100} = 0.85 = 85\%$

$\text{Precision} = \dfrac{40}{40 + 5} = \dfrac{40}{45} \approx 88.89\%$

$\text{Recall} = \dfrac{40}{40 + 10} = \dfrac{40}{50} = 80.0\%$

$F_1 = \dfrac{2 \cdot 0.8889 \cdot 0.80}{0.8889 + 0.80} \approx 84.21\%$

Задача 4. Анализ тривиального классификатора при дисбалансе

Выборка: 900 объектов класса 0 и 100 класса 1. Модель константно выдаёт 0. Найдите Accuracy и Recall класса 1.

Решение

$\text{TP} = 0, \text{FP} = 0, \text{FN} = 100, \text{TN} = 900$.

$\text{Accuracy} = \dfrac{0 + 900}{1000} = 90\%$ (иллюзия качества).

$\text{Recall}_{\text{class 1}} = \dfrac{0}{0 + 100} = 0\%$ (пропущены все целевые события).

Задача 5. Сравнение робастности MSE и MAE к выбросу

Истинные $y = [1, 2, 3, 4, 100]$, предсказания $\hat{y} = [2, 2, 3, 4, 50]$, ошибки $e = [-1, 0, 0, 0, 50]$. Рассчитайте MSE и MAE.

Решение

$\text{MSE} = \dfrac{(-1)^2 + 0 + 0 + 0 + 50^2}{5} = \dfrac{2501}{5} = 500.2$

$\text{MAE} = \dfrac{|-1| + 0 + 0 + 0 + |50|}{5} = \dfrac{51}{5} = 10.2$

Вывод: MSE чувствителен к выбросу ($50^2 = 2500$); MAE робастна.

Задача 6. Анализ шага градиентного спуска при разном learning rate

$L(\theta) = (\theta - 5)^2$, $\theta_0 = 0$, $\nabla L(0) = -10$. Найдите $\theta_1$ при $\eta = 0.1$ и $\eta = 1.0$.

Решение

1. При $\eta = 0.1$: $\theta_1 = 0 - 0.1 \cdot (-10) = 1.0$ ($L(1) = 16 < 25$, сходимость).

2. При $\eta = 1.0$: $\theta_1 = 0 - 1.0 \cdot (-10) = 10.0$ ($L(10) = 25 = L(0)$, осцилляция).

8. ⚡ Скелет ответа по билету

Краткий конспект для ответа у доски
  1. Суть ML: подбор параметров $f_\theta$ по данным. Триада: Архитектура + Loss + Оптимизатор.
  2. Парадигмы: Supervised (регрессия $\mathbb{R}$, классификация), Unsupervised (кластеризация, снижение размерности), RL (максимизация $R$).
  3. Выборки: Train (подгонка $\theta$), Validation (гиперпараметры, Early Stopping), Test (финальный контроль 1 раз). Защита от Data Leakage.
  4. Bias-Variance Tradeoff: Ошибка $= \text{Bias}^2 + \text{Variance} + \sigma^2$. Underfitting — высокий Bias; Overfitting — высокая Variance.
  5. Градиентный спуск: $\theta \leftarrow \theta - \eta \nabla L(\theta)$. Batch GD, SGD, Mini-batch.
  6. Дискретизация: 1 эпоха = проход по $N$ объектам; $K = \lceil N/B \rceil$ итераций (шагов $\theta$).
  7. Метрики классификации: Accuracy (баланс), Precision, Recall, $F_1 = 2\frac{P \cdot R}{P + R}$, PR-AUC (дисбаланс).
  8. Метрики регрессии: MSE (квадратичный штраф), MAE (робастная), $R^2$ (доля объяснённой дисперсии).
  9. Регуляризация: L2 (Weight Decay, сжатие), L1 (Lasso, разреженность), Dropout, Early Stopping.
  10. Параметры vs Гиперпараметры: параметры ($W, b$) оптимизируются; гиперпараметры ($\eta, B, \lambda$) задаются вручную.
