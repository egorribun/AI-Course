1. Интуиция и мотивация

Обучение с подкреплением (Reinforcement Learning, RL) — парадигма ML, где агент учится принимать решения во взаимодействии со средой путём проб и ошибок, максимизируя суммарный выигрыш.

💡 Сравнение парадигм машинного обучения
  1. Отложенная награда (Delayed Reward): Действие в момент $t$ приносит результат спустя десятки шагов.
  2. Распределение ответственности (Credit Assignment): Определение вклада конкретных действий в итоговый успех/неудачу.
  3. Exploration vs Exploitation: Баланс между эксплуатацией известного действия и исследованием новых.

2. Архитектура и схема

Взаимодействие агента со средой разворачивается во времени как дискретный стохастический процесс:

3. Математический аппарат

1. Марковское свойство (Markov Property)

Состояние $S_t$ марковское, если распределение будущего зависит только от $S_t$ и $A_t$, а не от предыстории:

$$ \mathbb{P}(S_{t+1} = s', R_{t+1} = r \mid S_t = s_t, A_t = a_t, \dots, S_0 = s_0, A_0 = a_0) = \mathbb{P}(S_{t+1} = s', R_{t+1} = r \mid S_t = s_t, A_t = a_t) $$

$S_t$ служит достаточной статистикой процесса («будущее независимо от прошлого при известном настоящем»).

2. Марковский процесс принятия решений (MDP)

MDP задаётся кортежем $\mathcal{M} = \langle \mathcal{S}, \, \mathcal{A}, \, \mathcal{P}, \, \mathcal{R}, \, \gamma \rangle$:

  • $\mathcal{S}$ — пространство состояний (дискретное или непрерывное $\mathcal{S} \subseteq \mathbb{R}^d$).
  • $\mathcal{A}$ — пространство действий (дискретное $\{a_1, \dots, a_m\}$ или непрерывное $\mathcal{A} \subseteq \mathbb{R}^k$).
  • $\mathcal{P}(s' \mid s, a) = \mathbb{P}(S_{t+1} = s' \mid S_t = s, A_t = a)$ — функция переходов, где $\sum_{s'} \mathcal{P}(s' \mid s, a) = 1$.
  • $\mathcal{R}(s, a) = \mathbb{E}[R_{t+1} \mid S_t = s, A_t = a]$ — функция ожидаемой немедленной награды.
  • $\gamma \in [0, 1)$ — коэффициент дисконтирования.

3. Дисконтированный доход ($G_t$)

Цель агента — максимизировать суммарный доход $G_t$:

$$ G_t \doteq \sum_{k=0}^{\infty} \gamma^k R_{t+k+1} = R_{t+1} + \gamma G_{t+1} $$
📐 Свойства коэффициента дисконтирования $\gamma$
  1. Сходимость: При $|R| \le R_{\max}$ ряд сходится: $G_t \le \frac{R_{\max}}{1 - \gamma}$.
  2. Горизонт: Эффективный горизонт планирования $H_{\text{eff}} \approx \frac{1}{1 - \gamma}$ ($\gamma=0.9 \implies H \approx 10$).
  3. Приоритет: Ранние награды ценнее поздних из-за фактора риска и стохастичности среды.

4. Стратегия агента (Policy $\pi$)

  • Детерминированная: $a = \mu(s)$.
  • Стохастическая: $\pi(a \mid s) = \mathbb{P}(A_t = a \mid S_t = s)$, где $\sum_{a} \pi(a \mid s) = 1$.

5. Функции ценности (Value Functions)

Функции ценности состояния $V^\pi(s)$ и действия $Q^\pi(s, a)$:

$$ V^\pi(s) \doteq \mathbb{E}_\pi \left[ G_t \;\middle|\; S_t = s \right] = \mathbb{E}_\pi \left[ \sum_{k=0}^\infty \gamma^k R_{t+k+1} \;\middle|\; S_t = s \right] $$
$$ Q^\pi(s, a) \doteq \mathbb{E}_\pi \left[ G_t \;\middle|\; S_t = s, A_t = a \right] = \mathbb{E}_\pi \left[ \sum_{k=0}^\infty \gamma^k R_{t+k+1} \;\middle|\; S_t = s, A_t = a \right] $$

Связь между функциями:

$$ V^\pi(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s) Q^\pi(s, a) = \mathbb{E}_{a \sim \pi(\cdot|s)} [Q^\pi(s, a)] $$

6. Стратегии исследования (Exploration vs Exploitation)

  1. $\epsilon$-Greedy:
    $$ \pi(a \mid s) = \begin{cases} 1 - \epsilon + \frac{\epsilon}{|\mathcal{A}|}, & a = \arg\max_{a'} Q(s, a') \\ \frac{\epsilon}{|\mathcal{A}|}, & a \ne \arg\max_{a'} Q(s, a') \end{cases} $$
  2. Softmax (Boltzmann):
    $$ \pi(a \mid s) = \frac{\exp(Q(s, a) / \tau)}{\sum_{b \in \mathcal{A}} \exp(Q(s, b) / \tau)} $$
  3. UCB: $A_t = \arg\max_{a} \left[ Q(a) + c \sqrt{\frac{\ln t}{N_t(a)}} \right]$.

7. Реализация среды и расчёта доходов на Python

import numpy as np

class SimpleGridWorld:
    def __init__(self, length=4):
        self.length = length
        self.state = 0
        self.goal = length - 1

    def reset(self):
        self.state = 0
        return self.state

    def step(self, action):
        if action == 1 and self.state < self.goal:
            self.state += 1
        elif action == 0 and self.state > 0:
            self.state -= 1
        reward = 10.0 if self.state == self.goal else -1.0
        done = (self.state == self.goal)
        return self.state, reward, done

def compute_discounted_return(rewards, gamma=0.9):
    g = 0.0
    returns = []
    for r in reversed(rewards):
        g = r + gamma * g
        returns.insert(0, g)
    return returns

def epsilon_greedy_select(q_values, epsilon=0.1):
    if np.random.rand() < epsilon:
        return int(np.random.randint(len(q_values)))
    return int(np.argmax(q_values))

def evaluate_policy_expected_value(q_table, state, policy_probs):
    return float(np.sum(policy_probs * q_table[state]))

4. Пошаговый числовой пример

🔢 Пример 1. Расчёт дисконтированного дохода траектории

Траектория из 4 шагов с $\gamma = 0.9$ и терминальным состоянием на $t=4$:

$$ R_1 = +2, \quad R_2 = 0, \quad R_3 = -1, \quad R_4 = +10 $$

Рекуррентный расчёт $G_t = R_{t+1} + \gamma G_{t+1}$ с конца:

  • $G_3 = R_4 = 10.0$
  • $G_2 = R_3 + 0.9 \cdot 10.0 = -1 + 9.0 = 8.0$
  • $G_1 = R_2 + 0.9 \cdot 8.0 = 0 + 7.2 = 7.2$
  • $G_0 = R_1 + 0.9 \cdot 7.2 = 2 + 6.48 = 8.48$

Прямой расчёт: $G_0 = 2\cdot0.9^0 + 0\cdot0.9^1 - 1\cdot0.9^2 + 10\cdot0.9^3 = 2 - 0.81 + 7.29 = 8.48$.

Симуляция эпизода на Python

import numpy as np

def simulate_episode(env, policy, max_steps=100):
    state = env.reset()
    trajectory = []
    for _ in range(max_steps):
        action = policy(state)
        next_state, reward, done = env.step(action)
        trajectory.append((state, action, reward))
        state = next_state
        if done:
            break
    return trajectory
🔢 Пример 2. Расчёт $V^\pi(s)$ через $Q^\pi(s, a)$ при стохастической стратегии

В состоянии $s$ доступны 3 действия: $\mathcal{A} = \{a_1, a_2, a_3\}$.

  • Оценки: $Q^\pi(s, a_1) = 4.0, \quad Q^\pi(s, a_2) = 2.0, \quad Q^\pi(s, a_3) = 9.0$.
  • Политика: $\pi(a_1|s) = 0.2, \quad \pi(a_2|s) = 0.1, \quad \pi(a_3|s) = 0.7$.
$$ V^\pi(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s) Q^\pi(s, a) = 0.2 \cdot 4.0 + 0.1 \cdot 2.0 + 0.7 \cdot 9.0 = 0.8 + 0.2 + 6.3 = 7.3 $$

Жадная ценность: $V^*(s) = \max_a Q(s, a) = 9.0$.

6. 🎯 Препод спросит

1. В чем строгое математическое определение Марковского свойства и почему оно фундаментально для RL?

$\mathbb{P}(S_{t+1}, R_{t+1} \mid S_t, A_t, \dots, S_0, A_0) = \mathbb{P}(S_{t+1}, R_{t+1} \mid S_t, A_t)$. Состояние $S_t$ полностью определяет будущее, позволяя выводить рекуррентные уравнения Беллмана без предыстории.

2. Зачем нужен коэффициент дисконтирования $\gamma < 1$? Что произойдет при $\gamma = 0$ и $\gamma = 1$?

$\gamma$ гарантирует сходимость ряда $\sum \gamma^k R \le \frac{R_{\max}}{1 - \gamma}$, отражает неопределённость и задаёт горизонт $H \approx \frac{1}{1-\gamma}$. При $\gamma = 0$ агент близорук (максимизирует $R_{t+1}$). При $\gamma = 1$ доход расходится в бесконечных задачах, но допустим в эпизодических.

3. Чем принципиально отличаются $V^\pi(s)$ и $Q^\pi(s, a)$?

$V^\pi(s) = \mathbb{E}_\pi [G_t \mid S_t = s]$ — ожидаемый доход из $s$ при следовании $\pi$ со старта. $Q^\pi(s, a) = \mathbb{E}_\pi [G_t \mid S_t = s, A_t = a]$ — доход при фиксированном первом действии $a$ и последующем следовании $\pi$. Связь: $V^\pi(s) = \sum_a \pi(a \mid s) Q^\pi(s, a)$.

4. Что такое Credit Assignment Problem и почему она сложна в RL?

Задача определения действий из длинной траектории, определивших итоговую отложенную награду. Сложность обусловлена временной задержкой между действием и результатом, а также стохастичностью переходов.

5. Что произойдет, если ко всем наградам в среде прибавить положительную константу $c > 0$?

В бесконечных задачах $V(s)$ вырастет на $\frac{c}{1 - \gamma}$, сохраняя оптимальную политику $\arg\max_a Q(s, a)$. В эпизодических задачах со штрафом за шаг ($R=-1$) сдвиг $+c$ может сделать награды положительными, вызвав зацикливание агента.

6. В чем разница между Partially Observable MDP (POMDP) и классическим MDP?

В MDP агент видит полное марковское состояние $S_t$. В POMDP наблюдение $O_t = g(S_t)$ неполно (шумные датчики, 1 кадр). Для восстановления марковости используют память (RNN/LSTM или Frame Stacking).

7. В чем отличие Model-Based RL от Model-Free RL?

Model-Based RL знает или обучает модель переходов $\mathcal{P}$ и наград $\mathcal{R}$, используя её для планирования (VI, PI, MCTS). Model-Free RL не моделирует динамику, напрямую оценивая $Q(s, a)$ или оптимизируя стратегию $\pi_\theta(a \mid s)$.

8. Как температура $\tau$ в Softmax exploration влияет на стратегию агента?

В $\pi(a \mid s) \propto \exp(Q(s, a)/\tau)$: при $\tau \to \infty$ политика стремится к равномерной $\pi = 1/|\mathcal{A}|$ (максимальный exploration); при $\tau \to 0$ переходит в детерминированную жадную $\arg\max_a Q(s, a)$ (чистый exploitation).

9. Почему нельзя обучать RL-агента обычной кросс-энтропией как в Supervised Learning?

В RL отсутствуют эталонные метки правильных действий $y^*$. Скалярная награда $R$ лишь оценивает текущее действие. Кроме того, распределение данных нестационарно и зависит от текущей стратегии.

10. Что такое дилемма Exploration vs Exploitation и почему чистая эксплуатация гибельна?

Exploitation — выбор известного наилучшего $Q(s, a)$. Exploration — выбор неоптимальных действий для поиска лучших путей. Чистая эксплуатация с первых шагов застревает в локальном минимуме, не исследуя среду.

7. 📝 Микро-задачи с решениями

Задача 1. Расчёт дисконтированного дохода конечной траектории

Награды: $R_1 = +1, R_2 = +2, R_3 = +4, R_4 = +10$ при $\gamma = 0.5$. Вычислите $G_0$.

Решение

По формуле $G_0 = \sum_{k=0}^3 \gamma^k R_{k+1}$:

$$ G_0 = 1 \cdot 1 + 2 \cdot 0.5 + 4 \cdot 0.25 + 10 \cdot 0.125 = 1 + 1 + 1 + 1.25 = 4.25 $$

Ответ: $G_0 = 4.25$.

Задача 2. Теоретический предел бесконечного дохода

Постоянная награда $R_t = +5$ при $\gamma = 0.95$. Чему равен суммарный доход $G_t$?

Решение

Сумма прогрессии:

$$ G_t = \sum_{k=0}^\infty \gamma^k R = \frac{R}{1 - \gamma} = \frac{5}{1 - 0.95} = \frac{5}{0.05} = 100.0 $$

Ответ: $G_t = 100.0$.

Задача 3. Расчёт вероятностей при $\epsilon$-Greedy стратегии

В MDP 4 действия $\mathcal{A}=\{a_1, a_2, a_3, a_4\}$ с $Q = [5.0, 8.0, 2.0, 6.0]$ при $\epsilon = 0.2$. Найдите $\pi(a \mid s)$.

Решение

Жадное действие $a^* = a_2$ ($Q = 8.0 = \max$), $|\mathcal{A}| = 4$:

  • Нежадные ($a_1, a_3, a_4$): $\pi(a \mid s) = \frac{\epsilon}{|\mathcal{A}|} = \frac{0.2}{4} = 0.05$.
  • Жадное ($a_2$): $\pi(a_2 \mid s) = 1 - \epsilon + \frac{\epsilon}{|\mathcal{A}|} = 1 - 0.2 + 0.05 = 0.85$.

Ответ: $\pi(a_2|s) = 0.85$, для $a_1, a_3, a_4$: $\pi = 0.05$.

Задача 4. Связь между $V(s)$ и $Q(s, a)$

В состоянии $s$ вероятности $\pi = [0.3, 0.5, 0.2]$ и $Q = [10, 4, -5]$. Чему равно $V^\pi(s)$?

Решение

Вычисляем математическое ожидание:

$$ V^\pi(s) = \sum_{i=1}^3 \pi(a_i \mid s) Q^\pi(s, a_i) = 0.3 \cdot 10 + 0.5 \cdot 4 + 0.2 \cdot (-5) = 3.0 + 2.0 - 1.0 = 4.0 $$

Ответ: $V^\pi(s) = 4.0$.

Задача 5. Расчёт Softmax (Boltzmann) стратегии

В состоянии $s$ два действия: $Q(s, a_1) = 2.0$, $Q(s, a_2) = 1.0$ при $\tau = 1.0$. Найдите $\pi(a_1 \mid s)$ и $\pi(a_2 \mid s)$ ($e \approx 2.7183, e^2 \approx 7.3891$).

Решение

Экспоненты: $\exp(2.0) \approx 7.3891, \exp(1.0) \approx 2.7183$, сумма $\sum = 10.1074$.

$$ \pi(a_1 \mid s) = \frac{7.3891}{10.1074} \approx 0.7311, \quad \pi(a_2 \mid s) = \frac{2.7183}{10.1074} \approx 0.2689 $$

Ответ: $\pi(a_1|s) \approx 0.7311, \pi(a_2|s) \approx 0.2689$.

Задача 6. Влияние сдвига наград на функцию ценности

Награды сдвинуты: $R'_{t+1} = R_{t+1} + c$. Как изменится $V^\pi(s)$ при бесконечном горизонте с фактором $\gamma$?

Решение

Раскладываем доход $G'_t$:

$$ G'_t = \sum_{k=0}^\infty \gamma^k (R_{t+k+1} + c) = G_t + c \sum_{k=0}^\infty \gamma^k = G_t + \frac{c}{1 - \gamma} $$

Ожидание: $V'_{\pi}(s) = V^\pi(s) + \frac{c}{1 - \gamma}$.

Ответ: Ценность каждого состояния увеличится на константу $\frac{c}{1 - \gamma}$.

8. ⚡ Скелет ответа по билету

Скелет ответа по билету 21 (RL: строение агента, стратегия, полезность, модель, MDP)
  1. Парадигма RL: Обучение методом проб и ошибок без учителя. Вызовы: отложенная награда (delayed reward), распределение ответственности (credit assignment), нестационарность данных.
  2. Цикл взаимодействия: Шаг $t$: агент в $S_t$ выбирает $A_t \sim \pi(\cdot|S_t)$, среда возвращает $R_{t+1}$ и $S_{t+1} \sim \mathcal{P}(\cdot|S_t, A_t)$. Траектория $\tau = (S_0, A_0, R_1, S_1, \dots)$.
  3. Марковское свойство: $\mathbb{P}(S_{t+1}, R_{t+1} \mid S_t, A_t, \dots, S_0, A_0) = \mathbb{P}(S_{t+1}, R_{t+1} \mid S_t, A_t)$. Будущее зависит только от текущего состояния.
  4. Формализация MDP: Кортеж $\langle \mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \gamma \rangle$: состояния $\mathcal{S}$, действия $\mathcal{A}$, переходы $\mathcal{P}$, награды $\mathcal{R}$, дисконт $\gamma \in [0, 1)$.
  5. Дисконтированный доход: $G_t = \sum_{k=0}^\infty \gamma^k R_{t+k+1} = R_{t+1} + \gamma G_{t+1}$. Ограничивает сумму $G_t \le \frac{R_{\max}}{1 - \gamma}$, задаёт горизонт $H \approx \frac{1}{1 - \gamma}$.
  6. Стратегия и функции ценности: Политика $\pi(a|s) = \mathbb{P}(A_t=a|S_t=s)$. State-Value $V^\pi(s) = \mathbb{E}_\pi [G_t \mid S_t = s]$. Action-Value $Q^\pi(s, a) = \mathbb{E}_\pi [G_t \mid S_t=s, A_t=a]$. Связь: $V^\pi(s) = \sum_a \pi(a|s) Q^\pi(s, a)$.
  7. Exploration vs Exploitation: Баланс между эксплуатацией найденных решений и поиском новых ($\epsilon$-greedy, Softmax с $\tau$, UCB).
