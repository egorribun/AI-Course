1. Принцип динамического программирования Ричарда Беллмана (1957)

💡 Принцип оптимальности Беллмана (Bellman's Principle of Optimality)

«Оптимальная стратегия обладает тем свойством, что каковы бы ни были первоначальное состояние и первоначальное решение, последующие решения должны составлять оптимальную стратегию относительно состояния, полученного в результате первого решения.»

Смысл принципа в том, что сложную многошаговую оптимизационную задачу на бесконечном горизонте можно свести к рекуррентной взаимосвязи между текущим состоянием и состояниями-преемниками через шаг времени на единицу вперед.

2. Уравнение Беллмана для $V^\pi(s)$ и его вывод

📐 Строгий вывод уравнения Беллмана для $V^\pi(s)$

По определению функции ценности состояния:

$$ V^\pi(s) = \mathbb{E}_\pi \left[ G_t \;\middle|\; S_t = s \right] $$

Раскроем доход $G_t$ в рекуррентную форму $G_t = R_{t+1} + \gamma G_{t+1}$:

$$ V^\pi(s) = \mathbb{E}_\pi \left[ R_{t+1} + \gamma G_{t+1} \;\middle|\; S_t = s \right] $$

Применим закон полного математического ожидания, развернув его по действиям $a \sim \pi(a \mid s)$ и следующим состояниям $s' \sim \mathcal{P}(s' \mid s, a)$:

$$ V^\pi(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s) \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left( \mathcal{R}(s, a, s') + \gamma \, \mathbb{E}_\pi [G_{t+1} \mid S_{t+1} = s'] \right) $$

Заметим, что $\mathbb{E}_\pi [G_{t+1} \mid S_{t+1} = s'] = V^\pi(s')$. Получаем итоговое уравнение:

$$ V^\pi(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s) \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma V^\pi(s') \right] $$ Уравнение Беллмана для $V^\pi$: ценность состояния $s$ равна средневзвешенной сумме немедленной награды и дисконтированной ценности следующего состояния $s'$.

3. Уравнение Беллмана для $Q^\pi(s, a)$

Аналогично раскрываем ценность действия $Q^\pi(s, a) = \mathbb{E}_\pi [R_{t+1} + \gamma G_{t+1} \mid S_t = s, A_t = a]$:

$$ Q^\pi(s, a) = \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma \sum_{a' \in \mathcal{A}} \pi(a' \mid s') Q^\pi(s', a') \right] $$ Уравнение Беллмана для $Q^\pi$: ценность пары $(s, a)$ равна матожиданию награды плюс дисконтированное среднее $Q(s', a')$ по действиям стратегии в следующем состоянии.

4. Backup-диаграммы (Диаграммы обратного обновления)

BACKUP-ДИАГРАММА ДЛЯ V^π(s): BACKUP-ДИАГРАММА ДЛЯ Q^π(s, a): ○ s (Состояние) ● (s, a) (Действие) ╱ │ ╲ π(a|s) ╱ │ ╲ P(s'|s, a) ● ● ● (Действия a) ○ ○ ○ (Состояния s') ╱ ╲ ╱ ╲ ╱ ╲ P(s'|s, a) ╱ ╲ ╱ ╲ ╱ ╲ π(a'|s') ○ ○ ○ ○ (Состояния s') ● ● ● ● (Действия a') │ │ │ │ │ │ │ │ V(s') V(s') V(s') Q(s',a') Q(s',a') Backup-диаграммы Саттона и Барто: визуализируют дерево усреднения по стохастичности стратегии и среды.

5. Уравнения оптимальности Беллмана для $V^*(s)$ и $Q^*(s, a)$

Стратегия $\pi^*$ называется оптимальной, если ее функция ценности превосходит или равна любой другой стратегии для всех состояний: $V^*(s) = \max_\pi V^\pi(s)$ для всех $s \in \mathcal{S}$.

В оптимальной стратегии вместо взвешенного усреднения по действиям $\sum \pi(a|s)$ берется максимум по всем возможным действиям $\max_{a}$:

Уравнение оптимальности для $V^*(s)$:

$$ V^*(s) = \max_{a \in \mathcal{A}} \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma V^*(s') \right] $$ $$ V^*(s) = \max_{a \in \mathcal{A}} Q^*(s, a) $$

Уравнение оптимальности для $Q^*(s, a)$:

$$ Q^*(s, a) = \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma \max_{a' \in \mathcal{A}} Q^*(s', a') \right] $$ Уравнения оптимальности нелинейны из-за операции $\max$. Их нельзя решить простой матричной инверсией — требуется метод итераций (Value Iteration).

6. Матричная форма и сжимающее отображение

1. Матричная форма уравнения Беллмана для фиксированной стратегии $\pi$:

Для конечного пространства состоя $|\mathcal{S}| = N$ уравнение $V^\pi(s)$ превращается в систему линейных уравнений:

$$ V^\pi = \mathcal{R}^\pi + \gamma \mathcal{P}^\pi V^\pi $$ $$ (I - \gamma \mathcal{P}^\pi) V^\pi = \mathcal{R}^\pi \implies V^\pi = (I - \gamma \mathcal{P}^\pi)^{-1} \mathcal{R}^\pi $$

Сложность прямого обращения матрицы: $O(|\mathcal{S}|^3)$. Применимо только для крошечных сред.

2. Оператор Беллмана и сжимающее отображение (Теорема Банаха):

🔒 Теорема о сжатии оператора Беллмана

Определим оператор Беллмана $(\mathcal{T}^* V)(s) = \max_a \sum_{s'} \mathcal{P}(s'|s,a) [\mathcal{R} + \gamma V(s')]$.

В Чебышевской норме $\|U - V\|_\infty = \max_s |U(s) - V(s)|$ оператор Беллмана является $\gamma$-сжимающим отображением:

$$ \|\mathcal{T}^* U - \mathcal{T}^* V\|_\infty \le \gamma \|U - V\|_\infty $$

Так как $\gamma < 1$, по теореме Банаха о неподвижной точке последовательность $V_{k+1} = \mathcal{T}^* V_k$ гарантированно сходится к единственной глобальной оптимальной функции $V^*$ из любого начального приближения $V_0$ со скоростью геометрической прогрессии!

7. Пошаговый расчет уравнений Беллмана на графе

Рассмотрим систему из двух состояний $A$ и $B$ ($\gamma = 0.5$):

  • Из состояния $A$: действие ведет в $B$ с вероятностью $1.0$, награда $r = 4$.
  • Из состояния $B$: действие ведет обратно в $A$ с вероятностью $1.0$, награда $r = 2$.

Запишем систему уравнений Беллмана:

$$ \begin{cases} V(A) = 4 + 0.5 \cdot V(B) \\ V(B) = 2 + 0.5 \cdot V(A) \end{cases} $$

Подставим $V(B)$ в первое уравнение:

$$ V(A) = 4 + 0.5 \cdot (2 + 0.5 V(A)) = 4 + 1 + 0.25 V(A) = 5 + 0.25 V(A) $$ $$ 0.75 V(A) = 5 \implies V(A) = \frac{5}{0.75} = \frac{20}{3} \approx 6.67 $$ $$ V(B) = 2 + 0.5 \cdot \frac{20}{3} = 2 + \frac{10}{3} = \frac{16}{3} \approx 5.33 $$

🎯 Препод спросит

В чем фундаментальное различие между уравнениями ожидания Беллмана и уравнениями оптимальности Беллмана?

Уравнение ожидания Беллмана (Bellman Expectation Equation): оценивает ценность состояний $V^\pi(s)$ или пар состояние-действие $Q^\pi(s, a)$ при следовании фиксированной политике $\pi$. Оно линейно по вектору ценностей, так как усредняет будущие доходы по распределению действий $\pi(a \mid s)$.

Уравнение оптимальности Беллмана (Bellman Optimality Equation): описывает ценности $V^*(s)$ и $Q^*(s, a)$ для наилучшей возможной политики $\pi^*$. Оно содержит оператор максимума $\max_{a \in \mathcal{A}}$, который связывает оптимальное действие с наивысшим ожидаемым будущим доходом. Из-за наличия $\max_a$ уравнение является строго нелинейным.

Приведите строгий математический вывод уравнения ожидания Беллмана для функции ценности состояния $V^\pi(s)$ через закон полного математического ожидания.

По определению ценность состояния $s$ при политике $\pi$ равна матожиданию дисконтированного дохода:

$$ V^\pi(s) = \mathbb{E}_\pi [G_t \mid S_t = s] $$

Раскроем доход $G_t = R_{t+1} + \gamma G_{t+1}$:

$$ V^\pi(s) = \mathbb{E}_\pi [R_{t+1} + \gamma G_{t+1} \mid S_t = s] $$

Применяя закон полного математического ожидания (Law of Total Expectation) по действию $A_t = a$, следующему состоянию $S_{t+1} = s'$ и награде $R_{t+1} = r$:

$$ V^\pi(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s) \sum_{s' \in \mathcal{S}} \sum_{r \in \mathcal{R}} p(s', r \mid s, a) \left[ r + \gamma \, \mathbb{E}_\pi [G_{t+1} \mid S_{t+1} = s'] \right] $$

По определению $\mathbb{E}_\pi [G_{t+1} \mid S_{t+1} = s'] = V^\pi(s')$, получаем итоговое уравнение ожидания Беллмана:

$$ V^\pi(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s) \left[ \mathcal{R}(s, a) + \gamma \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) V^\pi(s') \right] $$
Запишите и выведите уравнение ожидания Беллмана для функции ценности действия $Q^\pi(s, a)$.

Функция $Q^\pi(s, a)$ оценивает ожидаемый доход при совершении действия $a$ в состоянии $s$ с последующим следованием политике $\pi$:

$$ Q^\pi(s, a) = \mathbb{E}_\pi [G_t \mid S_t = s, A_t = a] = \mathbb{E}_\pi [R_{t+1} + \gamma G_{t+1} \mid S_t = s, A_t = a] $$

Усредняя по следующему состоянию $s'$ и награде $r$:

$$ Q^\pi(s, a) = \sum_{s' \in \mathcal{S}} \sum_{r \in \mathcal{R}} p(s', r \mid s, a) \left[ r + \gamma \, \mathbb{E}_\pi [G_{t+1} \mid S_{t+1} = s'] \right] $$

Учитывая, что $\mathbb{E}_\pi [G_{t+1} \mid S_{t+1} = s'] = V^\pi(s') = \sum_{a' \in \mathcal{A}} \pi(a' \mid s') Q^\pi(s', a')$, получаем:

$$ Q^\pi(s, a) = \mathcal{R}(s, a) + \gamma \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \sum_{a' \in \mathcal{A}} \pi(a' \mid s') Q^\pi(s', a') $$
Почему уравнения оптимальности Беллмана нельзя решить через аналитическую матричную инверсию $(I - \gamma P)^{-1} R$?

Уравнение оптимальности Беллмана имеет вид:

$$ V^*(s) = \max_{a \in \mathcal{A}} \left[ \mathcal{R}(s, a) + \gamma \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) V^*(s') \right] $$

Оператор $\max_{a}$ является кусочно-гладким и нелинейным: $\max(u + v) \ne \max(u) + \max(v)$. Выбор оптимального действия в каждом состоянии зависит от самих неизвестных значений $V^*(s')$, превращая систему в систему нелинейных уравнений. В отличие от линейного уравнения ожидания, нелинейные уравнения Беллмана решаются численными итерационными алгоритмами (Value Iteration, Policy Iteration).

Докажите, что оператор оптимальности Беллмана $\mathcal{T}^*$ является $\gamma$-сжатием в пространстве с sup-нормой $\|\cdot\|_\infty$.

Определим оператор оптимальности Беллмана: $(\mathcal{T}^* V)(s) = \max_{a} \left[ \mathcal{R}(s, a) + \gamma \sum_{s'} \mathcal{P}(s' \mid s, a) V(s') \right]$.

Используем алгебраическое свойство $|\max_x f(x) - \max_x g(x)| \le \max_x |f(x) - g(x)|$. Тогда для любого состояния $s$:

$$ |(\mathcal{T}^* U)(s) - (\mathcal{T}^* V)(s)| \le \max_{a \in \mathcal{A}} \left| \gamma \sum_{s'} \mathcal{P}(s' \mid s, a) (U(s') - V(s')) \right| \le \gamma \max_{a \in \mathcal{A}} \sum_{s'} \mathcal{P}(s' \mid s, a) |U(s') - V(s')| $$

Так как $|U(s') - V(s')| \le \|U - V\|_\infty$ и $\sum_{s'} \mathcal{P}(s' \mid s, a) = 1$:

$$ |(\mathcal{T}^* U)(s) - (\mathcal{T}^* V)(s)| \le \gamma \|U - V\|_\infty $$

Беря супремум по всем $s \in \mathcal{S}$, получаем:

$$ \|\mathcal{T}^* U - \mathcal{T}^* V\|_\infty \le \gamma \|U - V\|_\infty $$

При $\gamma < 1$ оператор $\mathcal{T}^*$ является сжимающим отображением на полном метрическом пространстве $(\mathbb{R}^{|\mathcal{S}|}, \|\cdot\|_\infty)$. По теореме Банаха существует строго единственная неподвижная точка $V^* = \mathcal{T}^* V^*$, к которой сходятся любые итерации.

Выведите теоретическую оценку погрешности $\|V_k - V^*\|_\infty \le \frac{\gamma^k}{1-\gamma} \|V_1 - V_0\|_\infty$ и ее практическое применение.

По свойству $\gamma$-сжатия разность между соседними итерациями убывает геометрически: $\|V_{j+1} - V_j\|_\infty \le \gamma^j \|V_1 - V_0\|_\infty$.

По неравенству треугольника для ряда $V^* - V_k = \sum_{j=k}^\infty (V_{j+1} - V_j)$:

$$ \|V_k - V^*\|_\infty \le \sum_{j=k}^\infty \|V_{j+1} - V_j\|_\infty \le \sum_{j=k}^\infty \gamma^j \|V_1 - V_0\|_\infty = \frac{\gamma^k}{1 - \gamma} \|V_1 - V_0\|_\infty $$

Практическое значение: эта оценка дает критерий остановки в алгоритме Value Iteration: условие $\|V_{k+1} - V_k\|_\infty < \frac{\epsilon(1-\gamma)}{2\gamma}$ строго гарантирует, что результирующая жадная политика отклоняется от оптимальной не более чем на $\epsilon$: $\|V^{\pi_k} - V^*\|_\infty \le \epsilon$.

Как выглядит матричная форма уравнения ожидания Беллмана $V^\pi = (I - \gamma P^\pi)^{-1} R^\pi$ и почему матрица $(I - \gamma P^\pi)$ всегда обратима при $\gamma < 1$?

Определим вектор наград $R^\pi(s) = \sum_a \pi(a \mid s) \mathcal{R}(s, a)$ и стохастическую матрицу переходов $P^\pi(s, s') = \sum_a \pi(a \mid s) \mathcal{P}(s' \mid s, a)$.

Уравнение в матричном виде:

$$ V^\pi = R^\pi + \gamma P^\pi V^\pi \implies (I - \gamma P^\pi) V^\pi = R^\pi \implies V^\pi = (I - \gamma P^\pi)^{-1} R^\pi $$

Доказательство обратимости: Поскольку $P^\pi$ — стохастическая матрица, ее спектральный радиус $\rho(P^\pi) \le 1$. При $\gamma < 1$ спектральный радиус $\rho(\gamma P^\pi) < 1$. Следовательно, матрица $(I - \gamma P^\pi)$ не имеет нулевых собственных значений, строго невырождена, и обратная матрица разлагается в сходящийся ряд Неймана $(I - \gamma P^\pi)^{-1} = \sum_{k=0}^\infty (\gamma P^\pi)^k$.

Как восстановить оптимальную стратегию $\pi^*(s)$, если мы нашли $V^*(s)$ или $Q^*(s, a)$?

1. Через функцию $Q^*(s, a)$ (без знания модели среды):

$$ \pi^*(s) = \arg\max_{a \in \mathcal{A}} Q^*(s, a) $$

2. Через функцию ценности $V^*(s)$ (требуется 1-step lookahead с моделью $\mathcal{P}$ и $\mathcal{R}$):

$$ \pi^*(s) = \arg\max_{a \in \mathcal{A}} \left[ \mathcal{R}(s, a) + \gamma \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) V^*(s') \right] $$
Что такое резервная диаграмма (Backup Diagram) и что означают ее узлы?

Резервная диаграмма визуализирует поток обновления ценностей во времени на один шаг вперед:

  • Белые круги: состояния $s \in \mathcal{S}$.
  • Черные точки: действия $a \in \mathcal{A}$.
  • В диаграмме для $V^\pi(s)$ корень $s$ разветвляется по действиям $a$ согласно $\pi(a \mid s)$, а затем ветвится по состояниям $s'$ согласно вероятностям среды $\mathcal{P}(s' \mid s, a)$. Значение в корне вычисляется как взвешенное матожидание листьев.
  • В диаграмме для $V^*(s)$ вместо усреднения по действиям используется дуга оператора максимума $\max_a$.
Почему жадная политика относительно $V^*(s)$ является глобально оптимальной для всего бесконечного горизонта?

Согласно принципу оптимальности Беллмана, оптимальное поведение обладает тем свойством, что каково бы ни было начальное состояние и начальное действие, все последующие решения должны быть оптимальными относительно результирующего состояния.

Поскольку $V^*(s')$ по определению уже содержит в себе максимальный достижимый доход от момента времени $t+1$ до бесконечности, локальный выбор жадного действия $a^* = \arg\max_a [\mathcal{R}(s, a) + \gamma \sum_{s'} \mathcal{P}(s' \mid s, a) V^*(s')]$ максимизирует сумму немедленной награды и оптимального бесконечного продолжения. Локальная жадность относительно истинной функции $V^*$ строго эквивалентна глобальной оптимальности всей бесконечной траектории.

📝 Микро-задачи

Задача 1. Расчет $V^*(s)$ по доступным $Q^*(s, a)$

В состоянии $s$ агент может пойти в 3 стороны: $Q^*(s, \text{влево}) = 5.2$, $Q^*(s, \text{прямо}) = 8.7$, $Q^*(s, \text{вправо}) = 4.1$. Чему равно оптимальное значение ценности состояния $V^*(s)$ и каково оптимальное действие $\pi^*(s)$?

Решение

Формула: $V^*(s) = \max_a Q^*(s, a)$.

$$ V^*(s) = \max(5.2, 8.7, 4.1) = 8.7 $$

$$ \pi^*(s) = \arg\max_a Q^*(s, a) = \text{«прямо»} $$

Задача 2. Ручной расчет шага оператора Беллмана

Из состояния $s$ действие $a_1$ дает немедленную награду $r=3$ и переводит в $s_1$ ($V_0(s_1) = 10$). Действие $a_2$ дает $r=1$ и переводит в $s_2$ ($V_0(s_2) = 20$). Коэффициент $\gamma = 0.8$. Найдите $V_1(s) = (\mathcal{T}^* V_0)(s)$.

Решение

1. Для $a_1$: $Q(s, a_1) = 3 + 0.8 \cdot 10 = 3 + 8 = 11$.

2. Для $a_2$: $Q(s, a_2) = 1 + 0.8 \cdot 20 = 1 + 16 = 17$.

$$ V_1(s) = \max(11, 17) = 17 $$

Задача 3. Матричное решение линейного уравнения Беллмана

В среде одно состояние $s$ с переходом в себя: $\mathcal{P}(s \mid s) = 1.0$, награда $r = 6$, $\gamma = 0.75$. Найдите $V^\pi(s)$ аналитически.

Решение

Уравнение: $V(s) = r + \gamma V(s) \implies (1 - \gamma) V(s) = r$.

$$ V(s) = \frac{r}{1 - \gamma} = \frac{6}{1 - 0.75} = \frac{6}{0.25} = 24.0 $$

Задача 4. Оценка погрешности после $k$ итераций Беллмана

Начальная ошибка $\|V_0 - V^*\|_\infty = 100$. Коэффициент дисконтирования $\gamma = 0.5$. Сколько итераций оператора Беллмана нужно сделать, чтобы гарантировать ошибку $\|V_k - V^*\|_\infty \le 0.1$?

Решение

По свойству сжатия: $\|V_k - V^*\|_\infty \le \gamma^k \|V_0 - V^*\|_\infty \le 0.1$.

$$ 0.5^k \cdot 100 \le 0.1 \implies 0.5^k \le 0.001 \implies 2^k \ge 1000 \implies k \ge 10 $$

Достаточно сделать 10 итераций.

Задача 5. Расчет Беллмана для стохастической среды

Действие $a$ в состоянии $s$ дает награду $r=2$. Среда с вероятностью $0.7$ переходит в $s_1$ ($V(s_1)=10$) и с вероятностью $0.3$ в $s_2$ ($V(s_2)=0$). При $\gamma = 0.9$ найдите $Q(s, a)$.

Решение

$$ Q(s, a) = r + \gamma \left( 0.7 \cdot V(s_1) + 0.3 \cdot V(s_2) \right) $$

$$ Q(s, a) = 2 + 0.9 \cdot (0.7 \cdot 10 + 0.3 \cdot 0) = 2 + 0.9 \cdot 7.0 = 2 + 6.3 = 8.3 $$

Задача 6. Влияние сдвига наград на $V(s)$

Все награды в среде увеличили на константу $c$: $r' = r + c$. Как изменится истинное значение $V^\pi(s)$ для всех состояний при бесконечном горизонте?

Решение

$$ G'_t = \sum_{k=0}^\infty \gamma^k (r_{t+k+1} + c) = G_t + c \sum_{k=0}^\infty \gamma^k = G_t + \frac{c}{1 - \gamma} $$

Значение $V^\pi(s)$ в каждом состоянии увеличится на строго постоянную величину $\frac{c}{1 - \gamma}$.

Скелет устного ответа по билету 22 (ч. 1, Уравнения Беллмана)
  1. Принцип Беллмана. Оптимальное поведение на всем пути состоит из оптимального первого шага и оптимального поведения из нового состояния.
  2. Уравнение ожидания для $V^\pi(s)$. $V^\pi(s) = \sum_a \pi(a|s) \sum_{s'} \mathcal{P}(s'|s,a) [ \mathcal{R} + \gamma V^\pi(s') ]$. Средневзвешенная сумма наград и ценностей преемников.
  3. Уравнение ожидания для $Q^\pi(s, a)$. $Q^\pi(s, a) = \sum_{s'} \mathcal{P}(s'|s,a) [ \mathcal{R} + \gamma \sum_{a'} \pi(a'|s') Q^\pi(s', a') ]$.
  4. Backup-диаграммы. Графическое представление обратного распространения ценности: белые кружки (состояния), черные (действия).
  5. Уравнение оптимальности для $V^*(s)$. $V^*(s) = \max_a \sum_{s'} \mathcal{P}(s'|s,a) [ \mathcal{R} + \gamma V^*(s') ] = \max_a Q^*(s, a)$.
  6. Уравнение оптимальности для $Q^*(s, a)$. $Q^*(s, a) = \sum_{s'} \mathcal{P}(s'|s,a) [ \mathcal{R} + \gamma \max_{a'} Q^*(s', a') ]$.
  7. Сжатие оператора Беллмана. Оператор $\mathcal{T}^*$ сжимает расстояние в Чебышевской норме с коэффициентом $\gamma < 1$. По теореме Банаха итерации гарантированно сходятся к единственной $V^*$.
  8. Матричный вид. $V^\pi = (I - \gamma \mathcal{P}^\pi)^{-1} \mathcal{R}^\pi$ (только для линейного ожидания, не для $\max$).
