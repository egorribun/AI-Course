1. Интуиция и мотивация

Прямой перебор траекторий в RL ведёт к комбинаторному взрыву: число путей длины $T$ растёт как $|\mathcal{A}|^T$. Принцип оптимальности Беллмана (1957) сводит многошаговую оптимизацию к 1-шаговой рекурсии:

💡 Принцип оптимальности Ричарда Беллмана

«Оптимальная стратегия обладает тем свойством, что каковы бы ни были начальное состояние и начальное решение, последующие решения должны составлять оптимальную стратегию относительно состояния, полученного в результате первого шага.»

Идея разбиения ценности на два слагаемых:

  1. Немедленная награда $R_{t+1}$ за текущий переход $(S_t, A_t) \to S_{t+1}$.
  2. Дисконтированная суммарная ценность будущего $\gamma V(S_{t+1})$, аккумулирующая все последующие шаги.

2. Архитектура и схема

Backup-диаграммы визуализируют потоки обновления ценности. Кружок $\bigcirc$ — состояние $s$, точка $\bullet$ — пара «состояние-действие» $(s, a)$:

УРАВНЕНИЕ ОЖИДАНИЯ V^π(s): УРАВНЕНИЕ ОЖИДАНИЯ Q^π(s, a): ○ s (Состояние) ● (s, a) (Действие) ╱ │ ╲ π(a|s) ╱ │ ╲ P(s'|s, a) ● ● ● (Действия a) ○ ○ ○ (Состояния s') ╱│╲ ╱│╲ ╱│╲ P(s'|s, a) ╱│╲ ╱│╲ ╱│╲ π(a'|s') ○○○○○○○○○○○ (Состояния s') ●●●●●●●●●●● (Действия a') УРАВНЕНИЕ ОПТИМАЛЬНОСТИ V*(s): УРАВНЕНИЕ ОПТИМАЛЬНОСТИ Q*(s, a): ○ s (Состояние) ● (s, a) (Действие) ╱ │ ╲ max_a ╱ │ ╲ P(s'|s, a) ● ● ● (Действия a) ○ ○ ○ (Состояния s') ╱│╲ ╱│╲ ╱│╲ P(s'|s, a) | | | max_a' ○○○○○○○○○○○ (Состояния s') ● ● ● (Действия a') Backup-диаграммы: в уравнениях ожидания берётся усреднение по $\pi$ и $\mathcal{P}$; в уравнениях оптимальности усреднение по действиям заменяется оператором $\max$.

3. Математический аппарат

1. Уравнение Беллмана для $V^\pi(s)$

По определению $V^\pi(s) = \mathbb{E}_\pi [G_t \mid S_t = s]$. Используя $G_t = R_{t+1} + \gamma G_{t+1}$:

$$ V^\pi(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s) \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma V^\pi(s') \right] $$

2. Уравнение Беллмана для $Q^\pi(s, a)$

$$ Q^\pi(s, a) = \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma \sum_{a' \in \mathcal{A}} \pi(a' \mid s') Q^\pi(s', a') \right] $$

3. Матричная форма уравнения Беллмана для $V^\pi$

Для $|\mathcal{S}| = N$ состояний уравнение $V^\pi$ задаёт линейную систему:

$$ V^\pi = \mathcal{R}^\pi + \gamma \mathcal{P}^\pi V^\pi \implies (I - \gamma \mathcal{P}^\pi) V^\pi = \mathcal{R}^\pi \implies V^\pi = (I - \gamma \mathcal{P}^\pi)^{-1} \mathcal{R}^\pi $$

где $\mathcal{R}^\pi_s = \sum_a \pi(a|s) \mathcal{R}(s, a)$, $\mathcal{P}^\pi_{s, s'} = \sum_a \pi(a|s) \mathcal{P}(s'|s, a)$. Так как $\rho(\gamma \mathcal{P}^\pi) = \gamma < 1$, матрица $(I - \gamma \mathcal{P}^\pi)$ невырождена. Вычислительная сложность обращения — $O(|\mathcal{S}|^3)$.

4. Уравнения оптимальности Беллмана (Bellman Optimality)

Для $V^*(s) = \max_\pi V^\pi(s)$ и $Q^*(s, a) = \max_\pi Q^\pi(s, a)$:

$$ V^*(s) = \max_{a \in \mathcal{A}} \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma V^*(s') \right] = \max_{a \in \mathcal{A}} Q^*(s, a) $$
$$ Q^*(s, a) = \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma \max_{a' \in \mathcal{A}} Q^*(s', a') \right] $$

Из-за оператора $\max$ система нелинейна и решается итерационными методами.

5. Оператор Беллмана и доказательство сжатия (Банах)

📐 Теорема о сжимающем отображении оператора Беллмана

Определим оператор оптимальности $(\mathcal{T}^* V)(s) \doteq \max_{a} \left[ \mathcal{R}(s, a) + \gamma \sum_{s'} \mathcal{P}(s' \mid s, a) V(s') \right]$.

Доказательство $\gamma$-сжатия в Чебышевской норме $\|V\|_\infty = \max_s |V(s)|$:

Для $U, V \in \mathbb{R}^{|\mathcal{S}|}$ и любого $s$ используем $|\max_a f(a) - \max_a g(a)| \le \max_a |f(a) - g(a)|$:

$$ |(\mathcal{T}^* U)(s) - (\mathcal{T}^* V)(s)| \le \max_{a} \left| \gamma \sum_{s'} \mathcal{P}(s' \mid s, a) (U(s') - V(s')) \right| \le \gamma \max_a \sum_{s'} \mathcal{P}(s'|s, a) \|U - V\|_\infty = \gamma \|U - V\|_\infty $$

Беря максимум по всем $s \in \mathcal{S}$:

$$ \|\mathcal{T}^* U - \mathcal{T}^* V\|_\infty \le \gamma \|U - V\|_\infty $$

По теореме Банаха о неподвижной точке при $\gamma < 1$:

  1. Существует единственная неподвижная точка $V^* = \mathcal{T}^* V^*$.
  2. Итерации $V_{k+1} = \mathcal{T}^* V_k$ сходятся к $V^*$ со скоростью $\|V_k - V^*\|_\infty \le \gamma^k \|V_0 - V^*\|_\infty$.

6. Реализация матричного решения и оператора Беллмана на Python

import numpy as np

def solve_bellman_matrix(P_pi, R_pi, gamma=0.9):
    n_states = P_pi.shape[0]
    I = np.eye(n_states)
    return np.linalg.solve(I - gamma * P_pi, R_pi)

def apply_bellman_optimality_operator(V, P, R, gamma=0.9):
    n_states, n_actions, _ = P.shape
    Q = np.zeros((n_states, n_actions))
    for s in range(n_states):
        for a in range(n_actions):
            Q[s, a] = R[s, a] + gamma * np.sum(P[s, a] * V)
    return np.max(Q, axis=1)

4. Пошаговый числовой пример

🔢 Пример. Решение 2-состоятельного MDP с $\gamma = 0.9$

Состояния $\mathcal{S}=\{s_1, s_2\}$, действия $\mathcal{A}=\{a_1, a_2\}$:

  • В $s_1$: $a_1 \to s_1$ ($R=1$); $a_2 \to s_2$ ($R=0$).
  • В $s_2$: $a_1 \to s_2$ ($R=2$); $a_2 \to s_1$ ($R=0$).

Система уравнений оптимальности Беллмана:

$$ V^*(s_1) = \max(1.0 + 0.9 V^*(s_1), \; 0.9 V^*(s_2)), \quad V^*(s_2) = \max(2.0 + 0.9 V^*(s_2), \; 0.9 V^*(s_1)) $$

Аналитический расчёт:

  1. Для $s_2$: оставаясь в $s_2$, $V(s_2) = 2.0 + 0.9 V(s_2) \implies V^*(s_2) = \frac{2.0}{0.1} = 20.0$.
  2. Для $s_1$: выбор $a_1$ даёт $\frac{1.0}{0.1} = 10.0$; выбор $a_2$ даёт $0.9 \cdot 20.0 = 18.0$. Оптимум $a^*=a_2 \implies V^*(s_1) = 18.0$.

Вектор ценностей: $V^* = \begin{pmatrix} 18.0 \\ 20.0 \end{pmatrix}$.

Сходимость Value Iteration ($V_0 = [0, 0]^T$):

  • Итерация 1: $V_1 = [\max(1, 0), \max(2, 0)] = [1.0, 2.0]$.
  • Итерация 2: $V_2 = [\max(1.9, 1.8), \max(3.8, 0.9)] = [1.9, 3.8]$.
  • Итерация 3: $V_3 = [\max(2.71, 3.42), 2 + 0.9(3.8)] = [3.42, 5.42]$.

Симуляция на Python

import numpy as np

def run_contraction_simulation():
    gamma = 0.9
    V = np.array([0.0, 0.0])
    for _ in range(200):
        v0 = max(1.0 + gamma * V[0], 0.0 + gamma * V[1])
        v1 = max(2.0 + gamma * V[1], 0.0 + gamma * V[0])
        V = np.array([v0, v1])
    return V

6. 🎯 Препод спросит

1. Почему уравнение оптимальности Беллмана нельзя решить аналитически через обращение матрицы?

Из-за нелинейного оператора $\max_{a \in \mathcal{A}}$. В отличие от $V^\pi$, где $\sum_a \pi(a|s)$ линейна, оператор $\max$ нарушает линейность $Ax = b$, требуя итерационных методов (Value Iteration).

2. В чем разница между $V^*(s)$ и $Q^*(s, a)$ и как получить одно из другого?

$V^*(s) = \max_a Q^*(s, a)$ — оптимальная ценность состояния. $Q^*(s, a) = \sum_{s'} \mathcal{P}(s'|s, a) [\mathcal{R} + \gamma V^*(s')]$. Зная $Q^*$, политика строится без модели: $\pi^*(s) = \arg\max_a Q^*(s, a)$.

3. Почему теорема Банаха о сжатии критически важна для сходимости алгоритмов RL?

Она гарантирует единственность неподвижной точки $V^*$ и сходимость итераций $V_{k+1} = \mathcal{T}^* V_k$ из любой начальной точки $V_0$, обосновывая сходимость Value Iteration и Q-learning.

4. Какова скорость сходимости Value Iteration и от чего она зависит?

Геометрическая со знаменателем $\gamma$: $\|V_k - V^*\|_\infty \le \gamma^k \|V_0 - V^*\|_\infty$. Чем ближе $\gamma$ к 1, тем медленнее сходимость.

5. Почему матрица $(I - \gamma \mathcal{P}^\pi)$ всегда обратима при $\gamma < 1$?

Спектральный радиус стохастической матрицы $\rho(\mathcal{P}^\pi) = 1$, поэтому $\rho(\gamma \mathcal{P}^\pi) = \gamma < 1$. Матрица не имеет нулевых собственных значений и строго невырождена.

6. Что произойдет со сжимающим свойством оператора Беллмана, если $\gamma = 1$?

Коэффициент сжатия становится равным 1 (оператор нерастягивающий). Теорема Банаха не гарантирует единственность решения в непрерывных бесконечных задачах.

7. Чем отличаются Backup-диаграммы для $V^\pi$ и $V^*$?

Для $V^\pi$ дуга обозначает усреднение по действиям $\sum_a \pi(a|s)$. Для $V^*$ дуга обозначает выбор единственной максимальной ветви $\max_a Q^*(s, a)$.

8. Как получить детерминированную оптимальную стратегию $\pi^*(s)$, зная $V^*(s)$?

По формуле $\pi^*(s) = \arg\max_a \sum_{s'} \mathcal{P}(s' \mid s, a) [\mathcal{R}(s, a, s') + \gamma V^*(s')]$. Для этого требуется знание модели переходов $\mathcal{P}$.

9. В чем заключается неравенство Йенсена и как оно связано со сжатием Беллмана?

Выпуклость нормы даёт $\|\sum_{s'} \mathcal{P}(s'|s, a) \Delta(s')\|_\infty \le \sum_{s'} \mathcal{P}(s'|s, a) \|\Delta\|_\infty = \|\Delta\|_\infty$, что позволяет вынести норму за знак математического ожидания.

10. Почему уравнения Беллмана называют уравнениями «динамического программирования»?

Они опираются на оптимальную подструктуру и перекрывающиеся подзадачи: оптимальное решение строится рекуррентным переиспользованием ценностей подсостояний $V(s')$.

7. 📝 Микро-задачи с решениями

Задача 1. Расчёт Беллмановского обновления для $V(s)$

В $s$ стратегия $\pi = [0.6, 0.4]$. $a_1 \to s_1$ ($R=2, V=10$), $a_2 \to s_2$ ($R=5, V=2$). Дисконт $\gamma = 0.8$. Вычислите $V^\pi(s)$.

Решение

$Q(s, a_1) = 2 + 0.8 \cdot 10 = 10.0$, $Q(s, a_2) = 5 + 0.8 \cdot 2 = 6.6$.

$$ V^\pi(s) = 0.6 \cdot 10.0 + 0.4 \cdot 6.6 = 6.0 + 2.64 = 8.64 $$

Ответ: $V^\pi(s) = 8.64$.

Задача 2. Расчёт Беллмановского обновления для $V^*(s)$

Для условий Задачи 1 вычислите оптимальное $V^*(s)$ и действие $a^*$.

Решение

По уравнению оптимальности Беллмана $V^*(s) = \max(Q(s, a_1), Q(s, a_2)) = \max(10.0, 6.6) = 10.0$. Оптимальное действие $a^* = a_1$.

Ответ: $V^*(s) = 10.0, a^* = a_1$.

Задача 3. Стохастический переход в $Q(s, a)$

Действие $a$: переход в $s'_1$ ($R=10, V=20$) с вер. $0.7$, в $s'_2$ ($R=-5, V=5$) с вер. $0.3$. При $\gamma = 0.9$ найдите $Q(s, a)$.

Решение
$$ Q(s, a) = 0.7 \cdot [10 + 0.9 \cdot 20] + 0.3 \cdot [-5 + 0.9 \cdot 5] = 0.7 \cdot 28.0 + 0.3 \cdot (-0.5) = 19.6 - 0.15 = 19.45 $$

Ответ: $Q(s, a) = 19.45$.

Задача 4. Оценка числа итераций по теореме Банаха

$\|V_0 - V^*\|_\infty = 100$, $\gamma = 0.5$. Сколько итераций нужно для достижения погрешности $\|V_k - V^*\|_\infty < 0.1$?

Решение

$(0.5)^k \cdot 100 < 0.1 \implies (0.5)^k < 10^{-3} = \frac{1}{1000}$. Так как $2^{10} = 1024 > 1000 \implies k = 10$.

Ответ: 10 итераций.

Задача 5. Аналитическое матричное решение для 1-состоятельного MDP

В MDP с одним состоянием $s$: $R=4, \mathcal{P}=1.0, \gamma = 0.8$. Найдите $V^\pi(s) = (I - \gamma \mathcal{P})^{-1} \mathcal{R}$.

Решение
$$ V^\pi = (1 - 0.8 \cdot 1)^{-1} \cdot 4 = \frac{4}{0.2} = 20.0 $$

Ответ: $V^\pi(s) = 20.0$.

Задача 6. Сравнение жадных действий по $Q$-функции

В $s$ три действия с $Q = [7.2, 7.8, 6.9]$. Найдите разность $V^*(s) - V^{\text{uniform}}(s)$.

Решение

$V^*(s) = \max(7.2, 7.8, 6.9) = 7.8$. $V^{\text{uniform}}(s) = \frac{7.2 + 7.8 + 6.9}{3} = 7.3$. Разность: $7.8 - 7.3 = 0.5$.

Ответ: $0.5$.

8. ⚡ Скелет ответа по билету

Скелет ответа по билету 22 (ч. 1, Уравнения Беллмана)
  1. Принцип оптимальности: Оптимальное поведение на всем горизонте состоит из оптимального первого шага и оптимального поведения из следующего состояния.
  2. Уравнение ожидания $V^\pi(s)$: $V^\pi(s) = \sum_a \pi(a|s) \sum_{s'} \mathcal{P}(s'|s,a) [ \mathcal{R}(s, a, s') + \gamma V^\pi(s') ]$. Линейно по $V$.
  3. Уравнение ожидания $Q^\pi(s, a)$: $Q^\pi(s, a) = \sum_{s'} \mathcal{P}(s'|s,a) [ \mathcal{R} + \gamma \sum_{a'} \pi(a'|s') Q^\pi(s', a') ]$.
  4. Матричная форма: $V^\pi = (I - \gamma \mathcal{P}^\pi)^{-1} \mathcal{R}^\pi$. Точное решение за $O(|\mathcal{S}|^3)$.
  5. Уравнения оптимальности: $V^*(s) = \max_a Q^*(s, a) = \max_a \sum_{s'} \mathcal{P} [ \mathcal{R} + \gamma V^*(s') ]$. $Q^*(s, a) = \sum_{s'} \mathcal{P} [ \mathcal{R} + \gamma \max_{a'} Q^*(s', a') ]$. Нелинейны ($\max$).
  6. Сжимающее отображение: $\|\mathcal{T}^* U - \mathcal{T}^* V\|_\infty \le \gamma \|U - V\|_\infty$. При $\gamma < 1$ существует единственная $V^*$, итерации сходятся со скоростью $\gamma^k$.
  7. Backup-диаграммы: $\bigcirc$ — состояния, $\bullet$ — действия, дуги — усреднение по $\pi$ или выбор $\max$.
