1. Интуиция и мотивация

В обучении с подкреплением агент сталкивается с задачей максимизации бесконечного ряда наград. Прямой перебор всех возможных траекторий приводит к комбинаторному взрыву: число возможных путей длины $T$ при $|\mathcal{A}|$ действиях растет экспоненциально как $|\mathcal{A}|^T$.

💡 Принцип оптимальности Ричарда Беллмана (1957)

«Оптимальная стратегия обладает тем свойством, что каковы бы ни были первоначальное состояние и первоначальное решение, последующие решения должны составлять оптимальную стратегию относительно состояния, полученного в результате первого решения.»

Фундаментальная идея уравнений Беллмана — разбить сложную многошаговую задачу на два слагаемых:

  1. Немедленная награда $R_{t+1}$, полученная за один текущий переход.
  2. Дисконтированная суммарная ценность всех будущих шагов, аккумулированная в ценности следующего состояния $\gamma V(S_{t+1})$.

Благодаря этому бесконечный горизонт заменяется рекуррентным соотношением через 1 шаг, что позволяет решать MDP полиномиальными алгоритмами динамического программирования.

2. Архитектура и схема: Backup-диаграммы

Backup-диаграммы визуализируют потоки обновления ценности во времени. Белый кружок $\bigcirc$ обозначает состояние $s$, черный кружок $\bullet$ обозначает пару «состояние-действие» $(s, a)$:

3. Математический аппарат

1. Уравнение Беллмана для функции ценности состояния $V^\pi(s)$

По определению $V^\pi(s) = \mathbb{E}_\pi [G_t \mid S_t = s]$. Используя рекуррентную форму дохода $G_t = R_{t+1} + \gamma G_{t+1}$ и закон полного математического ожидания:

$$ V^\pi(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s) \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma V^\pi(s') \right] $$

2. Уравнение Беллмана для функции ценности действия $Q^\pi(s, a)$

$$ Q^\pi(s, a) = \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma \sum_{a' \in \mathcal{A}} \pi(a' \mid s') Q^\pi(s', a') \right] $$

3. Матричная форма уравнения Беллмана для $V^\pi$

Для конечного пространства состоя $|\mathcal{S}| = N$ уравнение $V^\pi$ представляет собой линейную систему $N$ уравнений с $N$ неизвестными:

$$ V^\pi = \mathcal{R}^\pi + \gamma \mathcal{P}^\pi V^\pi $$

где $V^\pi \in \mathbb{R}^N$, $\mathcal{R}^\pi_s = \sum_a \pi(a|s) \mathcal{R}(s, a)$, а $\mathcal{P}^\pi_{s, s'} = \sum_a \pi(a|s) \mathcal{P}(s'|s, a)$. Точное аналитическое решение:

$$ (I - \gamma \mathcal{P}^\pi) V^\pi = \mathcal{R}^\pi \implies V^\pi = (I - \gamma \mathcal{P}^\pi)^{-1} \mathcal{R}^\pi $$

Матрица $(I - \gamma \mathcal{P}^\pi)$ всегда обратима при $\gamma < 1$, так как максимальное собственное значение стохастической матрицы $\mathcal{P}^\pi$ равно $1$, а спектральный радиус $\rho(\gamma \mathcal{P}^\pi) = \gamma < 1$. Сложность обращения матрицы — $O(|\mathcal{S}|^3)$.

4. Уравнения оптимальности Беллмана (Bellman Optimality Equations)

Оптимальные функции ценности определяются как $V^*(s) = \max_\pi V^\pi(s)$ и $Q^*(s, a) = \max_\pi Q^\pi(s, a)$:

$$ V^*(s) = \max_{a \in \mathcal{A}} \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma V^*(s') \right] = \max_{a \in \mathcal{A}} Q^*(s, a) $$
$$ Q^*(s, a) = \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma \max_{a' \in \mathcal{A}} Q^*(s', a') \right] $$

Уравнение оптимальности нелинейно из-за оператора $\max$, поэтому его нельзя решить прямым обращением матрицы!

5. Оператор Беллмана и строгое доказательство сжатия (Banach Fixed Point)

📐 Теорема о сжимающем отображении оператора Беллмана

Определим оператор оптимальности Беллмана $\mathcal{T}^*: \mathbb{R}^{|\mathcal{S}|} \to \mathbb{R}^{|\mathcal{S}|}$:

$$ (\mathcal{T}^* V)(s) \doteq \max_{a \in \mathcal{A}} \left[ \mathcal{R}(s, a) + \gamma \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) V(s') \right] $$

Докажем, что $\mathcal{T}^*$ является $\gamma$-сжимающим отображением в Чебышевской норме $\|V\|_\infty = \max_{s \in \mathcal{S}} |V(s)|$:

Пусть $U, V \in \mathbb{R}^{|\mathcal{S}|}$. Для любого фиксированного состояния $s$:

$$ |(\mathcal{T}^* U)(s) - (\mathcal{T}^* V)(s)| = \left| \max_{a} \left( \mathcal{R}(s, a) + \gamma \sum_{s'} \mathcal{P}(s'|s, a) U(s') \right) - \max_{a'} \left( \mathcal{R}(s, a') + \gamma \sum_{s'} \mathcal{P}(s'|s, a') V(s') \right) \right| $$

Используем алгебраическое неравенство $|\max_a f(a) - \max_a g(a)| \le \max_a |f(a) - g(a)|$:

$$ |(\mathcal{T}^* U)(s) - (\mathcal{T}^* V)(s)| \le \max_{a} \left| \gamma \sum_{s'} \mathcal{P}(s' \mid s, a) (U(s') - V(s')) \right| $$

Выносим $\gamma$ и оцениваем сумму модулем максимума $|U(s') - V(s')| \le \|U - V\|_\infty$:

$$ |(\mathcal{T}^* U)(s) - (\mathcal{T}^* V)(s)| \le \gamma \max_a \sum_{s'} \mathcal{P}(s' \mid s, a) \|U - V\|_\infty = \gamma \|U - V\|_\infty \underbrace{\sum_{s'} \mathcal{P}(s' \mid s, a)}_{= 1} = \gamma \|U - V\|_\infty $$

Беря максимум по всем $s \in \mathcal{S}$ в левой части, получаем:

$$ \|\mathcal{T}^* U - \mathcal{T}^* V\|_\infty \le \gamma \|U - V\|_\infty $$

Так как $\gamma < 1$, оператор $\mathcal{T}^*$ является строго сжимающим. По теореме Банаха о неподвижной точке в полном метрическом пространстве $\mathbb{R}^{|\mathcal{S}|}$:

  1. Существует единственная неподвижная точка $V^*$, удовлетворяющая $\mathcal{T}^* V^* = V^*$.
  2. Последовательные итерации $V_{k+1} = \mathcal{T}^* V_k$ гарантированно сходятся к $V^*$ из любого начального приближения $V_0$ с геометрической скоростью $\|V_k - V^*\|_\infty \le \gamma^k \|V_0 - V^*\|_\infty$.

6. Практическая реализация матричного решения и оператора Беллмана на Python

import numpy as np

def solve_bellman_matrix(P_pi, R_pi, gamma=0.9):
    """Точное аналитическое решение уравнения Беллмана V = (I - gamma*P)^(-1) * R."""
    n_states = P_pi.shape[0]
    I = np.eye(n_states)
    V = np.linalg.solve(I - gamma * P_pi, R_pi)
    return V

def apply_bellman_optimality_operator(V, P, R, gamma=0.9):
    """Применение сжимающего оператора оптимальности T*(V)."""
    n_states, n_actions, _ = P.shape
    Q = np.zeros((n_states, n_actions))
    for s in range(n_states):
        for a in range(n_actions):
            Q[s, a] = R[s, a] + gamma * np.sum(P[s, a] * V)
    V_next = np.max(Q, axis=1)
    return V_next

4. Пошаговый числовой пример решения 2-состоятельного MDP

🔢 Точное решение уравнений оптимальности Беллмана для MDP из двух состояний

Рассмотрим дискретный MDP с состояниями $\mathcal{S} = \{s_1, s_2\}$ и действиями $\mathcal{A} = \{a_1, a_2\}$.

Динамика среды:

  • В $s_1$: действие $a_1$ оставляет в $s_1$ с наградой $R=1$; действие $a_2$ переводит в $s_2$ с наградой $R=0$.
  • В $s_2$: действие $a_1$ оставляет в $s_2$ с наградой $R=2$; действие $a_2$ переводит в $s_1$ с наградой $R=0$.
  • Фактор дисконтирования $\gamma = 0.9$.

Запишем систему уравнений оптимальности Беллмана:

$$ V^*(s_1) = \max \Big( 1.0 + 0.9 V^*(s_1), \; 0.0 + 0.9 V^*(s_2) \Big) $$
$$ V^*(s_2) = \max \Big( 2.0 + 0.9 V^*(s_2), \; 0.0 + 0.9 V^*(s_1) \Big) $$

Аналитический расчет:

  1. Для состояния $s_2$: действие $a_1$ дает награду $+2$ на каждом шаге. Если оставаться в $s_2$, то:
    $$ V(s_2) = 2.0 + 0.9 V(s_2) \implies 0.1 V(s_2) = 2.0 \implies V^*(s_2) = 20.0 $$
  2. Для состояния $s_1$: сравним два действия с учетом $V^*(s_2) = 20.0$:
    • Действие $a_1$ (оставаться в $s_1$): дает $1.0 / (1 - 0.9) = 10.0$.
    • Действие $a_2$ (перейти в $s_2$): дает $0.0 + 0.9 V^*(s_2) = 0.9 \cdot 20.0 = 18.0$.
    Так как $18.0 > 10.0$, оптимальным действием в $s_1$ является $a_2$, и $V^*(s_1) = 18.0$.

Итоговый точный вектор оптимальных ценностей: $V^* = \begin{pmatrix} 18.0 \\ 20.0 \end{pmatrix}$.

Численные итерации Value Iteration (старт с $V_0 = \begin{pmatrix} 0 \\ 0 \end{pmatrix}$):

  • Итерация 1: $V_1(s_1) = \max(1, 0) = 1.0$, $V_1(s_2) = \max(2, 0) = 2.0$.
  • Итерация 2: $V_2(s_1) = \max(1 + 0.9(1), 0.9(2)) = \max(1.9, 1.8) = 1.9$; $V_2(s_2) = \max(2 + 0.9(2), 0.9(1)) = 3.8$.
  • Итерация 3: $V_3(s_1) = \max(1 + 0.9(1.9), 0.9(3.8)) = \max(2.71, 3.42) = 3.42$; $V_3(s_2) = 2 + 0.9(3.8) = 5.42$.
  • Через 50 итераций: $V_{50} = \begin{pmatrix} 17.91 \\ 19.90 \end{pmatrix} \to \begin{pmatrix} 18.0 \\ 20.0 \end{pmatrix}$.

Программная симуляция сходимости Value Iteration на Python

import numpy as np

def run_contraction_simulation():
    gamma = 0.9
    V = np.array([0.0, 0.0])
    for _ in range(200):
        v0 = max(1.0 + gamma * V[0], 0.0 + gamma * V[1])
        v1 = max(2.0 + gamma * V[1], 0.0 + gamma * V[0])
        V = np.array([v0, v1])
    return V

6. 🎯 Препод спросит

1. Почему уравнение оптимальности Беллмана нельзя решить аналитически через обращение матрицы?

Потому что уравнение оптимальности содержит нелинейный оператор $\max_{a \in \mathcal{A}}$. В отличие от уравнения ожидания $V^\pi$, где взвешенная сумма $\sum_a \pi(a|s)$ линейна по вектору $V$, оператор максимума нарушает линейность, делая невозможным представление системы в виде $A x = b$. Поэтому $V^*$ решается итерационными методами (Value Iteration, Policy Iteration).

2. В чем разница между $V^*(s)$ и $Q^*(s, a)$ и как получить одно из другого?

$V^*(s) = \max_a Q^*(s, a)$ — это максимальная ценность состояния, если из него совершить наилучшее действие. $Q^*(s, a) = \sum_{s'} \mathcal{P}(s'|s, a) [\mathcal{R}(s, a, s') + \gamma V^*(s')]$ — это ценность конкретного действия $a$ с последующим оптимальным поведением. Зная $Q^*$, оптимальная стратегия строится мгновенно: $\pi^*(s) = \arg\max_a Q^*(s, a)$ без необходимости заглядывать в модель среды $\mathcal{P}$.

3. Почему теорема Банаха о сжатии критически важна для сходимости алгоритмов RL?

Она гарантирует, что оператор Беллмана $\mathcal{T}^*$ имеет строго одну неподвижную точку $V^*$, и любое итерационное обновление $V_{k+1} = \mathcal{T}^* V_k$ гарантированно сходится к $V^*$ независимо от начальной инициализации $V_0$. Это доказывает математическую корректность алгоритма Value Iteration и Q-learning.

4. Какова скорость сходимости Value Iteration и от чего она зависит?

Скорость сходимости линейная (геометрическая) со знаменателем $\gamma$: $\|V_k - V^*\|_\infty \le \gamma^k \|V_0 - V^*\|_\infty$. Чем ближе $\gamma$ к $1$, тем медленнее сходятся итерации (при $\gamma = 0.99$ требуется значительно больше шагов, чем при $\gamma = 0.5$).

5. Почему матрица $(I - \gamma \mathcal{P}^\pi)$ всегда обратима при $\gamma < 1$?

Матрица $\mathcal{P}^\pi$ является стохастической (сумма по строкам равна $1$), поэтому ее спектральный радиус $\rho(\mathcal{P}^\pi) = 1$. Для любого $\gamma < 1$ спектральный радиус $\rho(\gamma \mathcal{P}^\pi) = \gamma < 1$. Следовательно, матрица $(I - \gamma \mathcal{P}^\pi)$ не имеет нулевых собственных значений (все собственные значения строго положительны по вещественной части) и абсолютно невырождена.

6. Что произойдет со сжимающим свойством оператора Беллмана, если $\gamma = 1$?

При $\gamma = 1$ коэффициент сжатия равен $1$, и оператор $\mathcal{T}^*$ становится лишь нерастягивающим ($\|\mathcal{T}^* U - \mathcal{T}^* V\| \le \|U - V\|$). Теорема Банаха перестает гарантировать единственность и сходимость к неподвижной точке в общем случае (возможны зацикливания или бесконечные значения), кроме строго эпизодических задач, где терминальное состояние гарантированно достигается с вероятностью 1.

7. Чем отличаются Backup-диаграммы для $V^\pi$ и $V^*$?

На диаграмме для $V^\pi$ ветвление по действиям из состояния $s$ объединяется дугой усреднения с вероятностями $\pi(a|s)$. На диаграмме для $V^*$ дуга обозначает оператор максимизации $\max_a$, то есть берется не взвешенная сумма, а единственная наилучшая ветвь с максимальным $Q^*(s, a)$.

8. Как получить детерминированную оптимальную стратегию $\pi^*(s)$, зная $V^*(s)$?

Для восстановления $\pi^*$ по $V^*$ требуется знать модель среды $\mathcal{P}$ и $\mathcal{R}$: $\pi^*(s) = \arg\max_{a \in \mathcal{A}} \sum_{s'} \mathcal{P}(s' \mid s, a) [\mathcal{R}(s, a, s') + \gamma V^*(s')]$. Если известна функция $Q^*(s, a)$, модель среды не нужна: $\pi^*(s) = \arg\max_{a} Q^*(s, a)$.

9. В чем заключается неравенство Йенсена и как оно связано со сжатием Беллмана?

При доказательстве сжатия для оператора с математическим ожиданием выпуклость нормы и неравенство Йенсена $\|\mathbb{E}[X]\| \le \mathbb{E}[\|X\|]$ позволяют перенести норму внутрь суммы по вероятностям: $\|\sum_{s'} \mathcal{P}(s'|s, a) (U(s') - V(s'))\|_\infty \le \sum_{s'} \mathcal{P}(s'|s, a) \|U - V\|_\infty = \|U - V\|_\infty$.

10. Почему уравнения Беллмана называют уравнениями «динамического программирования»?

Потому что они используют принцип оптимальной подструктуры и перекрывающихся подзадач: решение глобальной задачи нахождения оптимального пути достигается сохранением и рекуррентным переиспользованием промежуточных решений (ценностей состояний $V(s')$), вычисленных на предыдущих шагах.

7. 📝 Микро-задачи с решениями

Задача 1. Расчет Беллмановского обновления для $V(s)$

В состоянии $s$ доступны 2 действия. Стратегия $\pi(a_1|s) = 0.6, \pi(a_2|s) = 0.4$. Действие $a_1$ ведет в $s_1$ с наградой $R=2$ (переход детерминирован). Действие $a_2$ ведет в $s_2$ с наградой $R=5$. Текущие оценки: $V(s_1) = 10.0, V(s_2) = 2.0$. Дисконт $\gamma = 0.8$. Вычислите обновленное значение $V^\pi(s)$.

Решение

Рассчитаем $Q$-значения действий:

  • $Q(s, a_1) = R_1 + \gamma V(s_1) = 2.0 + 0.8 \cdot 10.0 = 2.0 + 8.0 = 10.0$
  • $Q(s, a_2) = R_2 + \gamma V(s_2) = 5.0 + 0.8 \cdot 2.0 = 5.0 + 1.6 = 6.6$

Вычисляем $V^\pi(s)$ по уравнению Беллмана:

$$ V^\pi(s) = \pi(a_1 \mid s) Q(s, a_1) + \pi(a_2 \mid s) Q(s, a_2) = 0.6 \cdot 10.0 + 0.4 \cdot 6.6 = 6.0 + 2.64 = 8.64 $$

Ответ: $V^\pi(s) = 8.64$.

Задача 2. Расчет Беллмановского обновления для $V^*(s)$

Для условий Задачи 1 вычислите оптимальное значение $V^*(s)$ и определите оптимальное действие $a^*$.

Решение

По уравнению оптимальности Беллмана $V^*(s) = \max_a Q^*(s, a)$:

$$ V^*(s) = \max(Q(s, a_1), Q(s, a_2)) = \max(10.0, 6.6) = 10.0 $$

Оптимальное действие: $a^* = \arg\max_a Q(s, a) = a_1$.

Ответ: $V^*(s) = 10.0, a^* = a_1$.

Задача 3. Стохастический переход в $Q(s, a)$

При совершении действия $a$ из состояния $s$ среда с вероятностью $0.7$ переходит в состояние $s'_1$ ($R=10$), и с вероятностью $0.3$ — в состояние $s'_2$ ($R=-5$). Известно: $V(s'_1) = 20.0, V(s'_2) = 5.0$, дисконт $\gamma = 0.9$. Чему равно $Q(s, a)$?

Решение

Усредняем по стохастическим переходам среды $\mathcal{P}(s'|s, a)$:

$$ Q(s, a) = 0.7 \cdot [10.0 + 0.9 \cdot 20.0] + 0.3 \cdot [-5.0 + 0.9 \cdot 5.0] = 0.7 \cdot [10 + 18] + 0.3 \cdot [-5 + 4.5] = 0.7 \cdot 28.0 + 0.3 \cdot (-0.5) = 19.6 - 0.15 = 19.45 $$

Ответ: $Q(s, a) = 19.45$.

Задача 4. Оценка числа итераций до сходимости по теореме Банаха

Начальная погрешность $\|V_0 - V^*\|_\infty = 100$. Фактор дисконтирования $\gamma = 0.5$. Сколько итераций Value Iteration потребуется, чтобы гарантировать погрешность $\|V_k - V^*\|_\infty < 0.1$?

Решение

По теореме Банаха $\|V_k - V^*\|_\infty \le \gamma^k \|V_0 - V^*\|_\infty$. Требуется:

$$ (0.5)^k \cdot 100 < 0.1 \implies (0.5)^k < \frac{0.1}{100} = 10^{-3} = \frac{1}{1000} $$

Так как $2^{10} = 1024 > 1000 \implies (0.5)^{10} = \frac{1}{1024} < \frac{1}{1000}$. Следовательно, необходимо $k \ge 10$ итераций.

Ответ: 10 итераций.

Задача 5. Аналитическое матричное решение для 1-состоятельного MDP

В MDP с одним состоянием $s$ агент совершает действие $a$, получая награду $R=4$ и оставаясь в состоянии $s$ с вероятностью $1.0$. Дисконт $\gamma = 0.8$. Найдите $V^\pi(s)$ по формуле $V^\pi = (I - \gamma \mathcal{P})^{-1} \mathcal{R}$.

Решение

Матрица переходов $\mathcal{P} = (1)$, единичная матрица $I = (1)$, вектор наград $\mathcal{R} = (4)$:

$$ V^\pi = (1 - 0.8 \cdot 1)^{-1} \cdot 4 = (0.2)^{-1} \cdot 4 = \frac{1}{0.2} \cdot 4 = 5 \cdot 4 = 20.0 $$

Ответ: $V^\pi(s) = 20.0$.

Задача 6. Сравнение жадных действий по $Q$-функции

В состоянии $s$ доступны 3 действия с оценками $Q(s, a_1) = 7.2, Q(s, a_2) = 7.8, Q(s, a_3) = 6.9$. Чему равна разница между $V^*(s)$ и $V^{\text{uniform}}(s)$ (при равномерно-случайной стратегии)?

Решение

1) Оптимальная ценность: $V^*(s) = \max(7.2, 7.8, 6.9) = 7.8$.

2) Равномерная ценность: $V^{\text{uniform}}(s) = \frac{7.2 + 7.8 + 6.9}{3} = \frac{21.9}{3} = 7.3$.

3) Разница: $V^*(s) - V^{\text{uniform}}(s) = 7.8 - 7.3 = 0.5$.

Ответ: Разница составляет $0.5$.

8. ⚡ Скелет ответа по билету

Скелет устного ответа по билету 22 (ч. 1, Уравнения Беллмана)
  1. Принцип оптимальности Беллмана: Оптимальное поведение на всем горизонте складывается из оптимального первого шага и оптимального поведения из нового достигнутого состояния.
  2. Уравнение ожидания для $V^\pi(s)$ линейно: $V^\pi(s) = \sum_a \pi(a|s) \sum_{s'} \mathcal{P}(s'|s,a) [ \mathcal{R}(s, a, s') + \gamma V^\pi(s') ]$. Ценность состояния — взвешенное среднее наград и дисконтированных ценностей преемников.
  3. Уравнение ожидания для $Q^\pi(s, a)$: $Q^\pi(s, a) = \sum_{s'} \mathcal{P}(s'|s,a) [ \mathcal{R} + \gamma \sum_{a'} \pi(a'|s') Q^\pi(s', a') ]$.
  4. Матричная форма: $V^\pi = (I - \gamma \mathcal{P}^\pi)^{-1} \mathcal{R}^\pi$. Точное решение линейной системы за $O(|\mathcal{S}|^3)$ шагов.
  5. Уравнения оптимальности Беллмана нелинейны: $V^*(s) = \max_a \sum_{s'} \mathcal{P}(s'|s,a) [ \mathcal{R} + \gamma V^*(s') ] = \max_a Q^*(s, a)$. $Q^*(s, a) = \sum_{s'} \mathcal{P} [ \mathcal{R} + \gamma \max_{a'} Q^*(s', a') ]$.
  6. Сжимающее отображение (Банах): Оператор Беллмана $\mathcal{T}^*$ сжимает расстояние в Чебышевской норме: $\|\mathcal{T}^* U - \mathcal{T}^* V\|_\infty \le \gamma \|U - V\|_\infty$. При $\gamma < 1$ гарантирована единственная неподвижная точка $V^*$ и сходимость со скоростью $\gamma^k$.
  7. Backup-диаграммы: Графическое представление потока обновления ценности (белые кружки — состояния, черные — действия, дуги — усреднение $\pi$ или $\max$).
