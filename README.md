# Методы ИИ — интенсив на 3 дня

Курс подготовки к устному экзамену по предмету «Методы искусственного интеллекта».
Собран с нуля: от «что такое градиентный спуск» до Actor-Critic.

**Открывать: [`index.html`](index.html)** — там оглавление, план по дням и переходы между лекциями.

## Как устроена каждая лекция

1. Зачем это нужно — интуиция и аналогия
2. Схема устройства (ASCII-графы, диаграммы потоков данных)
3. Формулы с разбором каждого символа
4. Разбор на числовом примере
5. Плюсы, минусы, когда применять
6. **🎯 Препод спросит** — 10–12 каверзных вопросов с полными ответами
7. **📝 Микро-задачи** — задачи «у доски» с пошаговыми решениями
8. **⚡ Ответ за 3 минуты** — скелет устного ответа по билету

Каждый HTML-файл самодостаточен: стили вшиты внутрь, формулы рендерятся через MathJax.

## Метод работы

Не читай пассивно. По каждому разделу:

1. Прочитал → закрыл → **переписал схему и формулы от руки** своими словами.
2. В блоке «Препод спросит» — **сначала ответил вслух сам**, потом раскрыл ответ.
3. Задачи решай, не подглядывая в решение.

Экзамен устный: если не можешь произнести объяснение вслух — ты его не знаешь.

Последние 40 минут каждого дня — не новый материал, а повторение вслух скелетов
из «Ответ за 3 минуты» по всем темам дня.
